## 작성자가 언급하지 않은 사항 (중요)
- [중간, 불확실 — 문맥 판단] Fig 12.95 / 12.96 귀환 극성이 문장과 맞지 않음. 400 dpi 판독: 12.95의 M2는 NMOS 소스 폴로어(전류원 부하), 12.96의 M2는 PMOS 공통 소스(R_L 부하) — md 넷리스트는 인쇄대로 정확함. 그런데 예제 12.18의 관찰 논리(I_in↑ → I_D1↓ → V_X↑ → …)를 적용하면
  - 12.96 (PMOS CS): V_X↑ → |V_GS2|↓ → I_D2↓ → V_out↓ → R_F 전류↓ → **부귀환** (E12.18의 NMOS CS와 같은 반전). 그러나 P12.31은 "prove … the feedback is positive"라고 함.
  - 12.95 (NMOS 폴로어): V_X↑ → V_out↑ → R_F 전류↑ → **정귀환**. 그러나 P12.30은 "Repeat Example 12-18"이고 E12.18 (a)는 부귀환 증명.
  - 같은 묶음의 다른 쌍(12.92 부귀환 / 12.93 정귀환 / 12.94 부귀환 / 12.97 부귀환 / 12.102 정귀환)은 모두 문장과 맞으므로, 12.95와 12.96의 M2(또는 두 그림)가 서로 뒤바뀐 것으로 보임 (12.99/12.100의 Q1 뒤바뀜과 같은 유형).
  - 권고: 넷리스트는 그대로 두고, P12.30·P12.31(·P12.32) `## 조건`에 FORMAT 오식 형식의 별도 줄을 추가: 예) P12.31 "인쇄된 Fig 12.96의 $M_2$는 PMOS 공통 소스 단이라 관찰로는 부귀환이 됨. 문장의 '정귀환'과 맞지 않음(오식으로 보임), Fig 12.95(NMOS 소스 폴로어)와 뒤바뀐 것으로 보임 (원문에 없음)", P12.30에도 대칭되는 줄. 단정이 부담스러우면 "문장과 맞지 않음" 사실만 적는다.
