# 장말문제 15.40 — 1.1배 코너 각주파수에서 20 dB 감쇠를 내는 차수

## 조건
- 문제 15.39에서 평가할 주파수를 $\omega=1.1\omega_0$로 바꾼다.
- 식 (15.138)은 $|H(j\omega)|=1/\sqrt{1+(\omega/\omega_0)^{2n}}$이다. (본문 식, 원문에 없음)

## 구할 것
- 문제 15.39처럼 $n$을 가로축으로, 롤오프를 데시벨 단위의 세로축으로 그린다.
- 이 주파수에서 $20\ \mathrm{dB}$의 감쇠를 얻는 데 필요한 차수는 얼마인가?

## 상속·참조
- 문제 15.39의 버터워스 크기 응답과 그래프 축은 그대로 사용하고 주파수비를 0.9에서 1.1로 바꾼다.
