# 문제집 힌트 채우기 (`## 힌트`) — 설계

날짜: 2026-09-26. 기준 커밋은 `main` = `34113ec`이다. 앞 작업은 ① 생성기와 ② 원문(`2026-09-25-workbook-original-text-design.md`)이다.

## 의도
문제집 PDF를 푸는 학생에게, 막힐 만한 문제에만 짧은 힌트를 준다. 힌트는 공식이 아니라 핵심 아이디어("회로를 이렇게 보면 쉽게 풀린다")다. 공식은 학생이 이미 안다고 본다.

- 399개 md를 모두 검토한다(교과서 ch09 110, ch10 151, ch11 116, 기출 22).
- 힌트가 필요한 문제에만 `## 힌트`를 넣는다. 목표는 전체의 약 25~40%다.
- 끝났다고 보는 조건
  - 모든 md에 대한 판정(힌트 N개 / 없음 + 이유)이 판정 원장에 있다.
  - 모든 배치가 독립 리뷰를 받았다.
  - `--all` 빌드에서 OVERFLOW가 없다.

분류: bounded. `## 힌트` 형식, `hints()` 파서, 문제지 Hint 띠와 답안지 Hint 쪽은 이미 있다.

## 끝났을 때의 동작
- **문제지**: 힌트가 있는 문제만 오른쪽에 24mm 폭의 Hint 띠가 생기고, 번호와 이름표(핵심 아이디어 한 줄)가 보인다. 힌트가 없는 문제는 지금과 같다(띠 폭 0).
- **답안지**: Hint 쪽에 이름표와 1~3줄 설명이 나온다.
- **`check_md.py`가 막는 것**
  - 한 소절에 `> 띠:` 줄이 둘 이상
  - 들여쓴 `> 띠:` 줄
  - 24자를 넘는 이름표
  - 한 문제에 힌트 셋 이상
- **`source_pages.py next/missing --ledger <원장>`**
  - 판정 원장에 없는 md를 배치로 낸다.
  - 원장과 md의 힌트 개수가 다르면 `MISMATCH`를 낸다.

## 이번 범위 밖
- ④ 풀이는 ③을 모두 끝낸 뒤 따로 한다. 힌트 작성자가 문제를 풀며 한 계산은 md에 넣지 않는다.
- `## 상속·참조`의 `식 (x.y)`를 띠로 옮기는 자동 초안은 버린다. 공식은 이미 안다는 방침과 반대다.
- 핸드오프의 다른 사소한 문제 1~3, 5~7은 다루지 않는다.

## 힌트 작성 규칙
- **넣을 때**: 공식 대입만으로는 바로 풀리지 않는 경우에만 넣는다.
  - 회로를 다른 모양으로 다시 보기: 반회로, 가운데 노드에서 본 저항, 퇴화 저항으로 보기, 알려진 구조로 알아보기
  - 어느 노드에서 무엇을 들여다볼지
  - 무시해도 되는 소자
  - 대칭이나 가상 접지 알아보기
- **넣지 않을 때**: 값을 대입하면 끝나는 문제, 예제를 바로 되풀이하는 문제, 정의를 묻는 문제. 억지로 만들지 않는다.
- **개수**: 문제당 1개가 기본이고 최대 2개다. 2개면 순서가 곧 풀이 순서다.
- **이름표**(`### ` 뒤, 문제지 띠에 그대로 보임)
  - 24자 이내의 명령형 또는 명사구로 쓴다.
  - 예: `꼬리 노드는 AC 접지`, `Q1 위에서 보면 퇴화 CE`, `$C_\mu$를 밀러로 쪼갠다`
- **본문**(답안지 Hint 쪽)
  - 1~3줄로, 그렇게 볼 수 있는 이유를 쓴다.
  - 수치 답, 최종 식, 중간 계산 값은 쓰지 않는다.
- **`> 띠:` 식**
  - 기본으로 쓰지 않는다. 식 자체가 아이디어일 때만 예외로 쓴다.
  - 식이 있으면 띠가 50mm로 넓어진다(`problem.html:140-141`).
- **예제 이어받기**
  - `## 조건`에 이미 있으므로 그것만으로는 힌트가 아니다.
  - 보는 법이 핵심일 때만 넣는다. 예: "예제 9.1과 같고 $I_{C1}$만 절반".
- **적용 범위**: 예제와 기출에도 같은 기준을 쓴다.

## 판정 원장
- 위치: 라벨(`ch09`, `ch10`, `ch11`, `exams`)마다 `docs/superpowers/reports/<라벨>/hints-ledger.md` 하나를 둔다.
- 줄 형식: `- <id> | 힌트 <1|2> | <이유>` 또는 `- <id> | 없음 | <이유>`. `- `로 시작하지 않는 줄은 무시한다.
- 필요한 이유: 힌트는 선택 절이라 md만 보고는 검토가 끝났는지 알 수 없다. 원장이 진행 추적과 리뷰 대상이 된다.
