# 연습문제 13.7 — PMOS 교차 결합 발진기 그리기 (예제 13.7 변형)

## 원문
PMOS 트랜지스터를 가지고 있는 교차 결합 발진기를 그려라.

## 조건
- 예제 13.7의 교차 결합 발진기(Fig 13.20(c), NMOS)를 PMOS 트랜지스터로 구성
- 참고 회로 (본문 Fig 13.20(c)): $V_{DD}$ 레일과 $X$, $Y$ 사이에 각각 병렬 탱크 $C_1$, $L_1$, $R_p$. NMOS $M_1$(드레인 $X$, 게이트 $Y$)과 $M_2$(드레인 $Y$, 게이트 $X$)의 소스가 공통 노드에서 만나고 테일 전류원 $I_{SS}$가 공통 노드에서 접지로 흐름 (원문에 없음)
- 소자 값은 주어지지 않음 (답은 회로도로) (원문에 없음)

## 구할 것
- PMOS 트랜지스터를 쓰는 교차 결합 발진기 회로도

## 상속·참조
- 본문 Fig 13.20(c) (교재 746쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig13-20-c.png): 연결 `C_1, L_1, R_p (왼쪽): VDD – X`, `C_1, L_1, R_p (오른쪽): VDD – Y`, `M1: D = X, G = Y, S = 공통 소스 노드`, `M2: D = Y, G = X, S = 공통 소스 노드`, `I_SS: 공통 소스 노드 → 접지`
- 예제 13.7 (E13.07): 큰 스윙에서 $M_1$, $M_2$의 드레인 전류는 서로 반대로 0과 $I_{SS}$ 사이를 오감
