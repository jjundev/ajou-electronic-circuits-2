# 장말문제 11.27 — 베이스 통과 시간 τ_F로 본 바이폴라 f_T와 I_C의 관계

## 원문
It can be shown that, if the minority carriers injected by the emitter into the base take $\tau_F$ seconds to cross the base region, then $C_b = g_m \tau_F$.

(a) Writing $C_\pi = C_b + C_{je}$, assuming that $C_{je}$ is independent of the bias current, and using Eq. (11.52), derive an expression for the $f_T$ of bipolar transistors in terms of the collector bias current.

(b) Sketch $f_T$ as a function of $I_C$.

## 조건
- 이미터가 베이스로 주입한 소수 캐리어가 베이스 영역을 건너는 데 $\tau_F$초가 걸리면 $C_b = g_m \tau_F$임을 보일 수 있음
- $C_\pi = C_b + C_{je}$로 씀
- $C_{je}$는 바이어스 전류와 무관하다고 가정
- 식 (11.52): $2\pi f_T \approx \dfrac{g_m}{C_\pi}$, $f_T$는 소신호 전류 이득이 1로 떨어지는 주파수 (본문 식, 원문에 없음)

## 구할 것
- (a) 식 (11.52)를 이용해 바이폴라 트랜지스터의 $f_T$를 컬렉터 바이어스 전류로 나타내는 식을 유도
- (b) $f_T$를 $I_C$의 함수로 그림 (개형)

## 상속·참조
- 식 (11.52) (교재 596쪽): $2\pi f_T \approx \dfrac{g_m}{C_\pi}$ 또는 $\dfrac{g_m}{C_{GS}}$ — 소신호 전류 이득이 1로 떨어지는 주파수(트랜싯 주파수)

## 회로 — 없음 (식 유도·그래프 스케치 문제, 그림 없음)

## 풀이
### (a) $C_\pi$를 $I_C$로 쓰기
- $g_m = I_C/V_T$ ($V_T$: 열전압)이므로 $C_\pi = C_b + C_{je} = \dfrac{I_C}{V_T}\tau_F + C_{je}$
### (a) $f_T$ 식
- 식 (11.52) $2\pi f_T \approx g_m/C_\pi$에 넣으면 $2\pi f_T = \dfrac{I_C/V_T}{(I_C/V_T)\tau_F + C_{je}} = \dfrac{1}{\tau_F + V_T C_{je}/I_C}$
### (b) 두 극한
- $I_C \ll V_T C_{je}/\tau_F$ ($C_{je}$가 지배): $2\pi f_T \approx \dfrac{I_C}{V_T C_{je}}$, $I_C$에 비례해 오른다
- $I_C \gg V_T C_{je}/\tau_F$ ($C_b$가 지배): $2\pi f_T \to 1/\tau_F$로 포화한다
- $I_C = V_T C_{je}/\tau_F$에서 $f_T$는 최대값 $1/(2\pi\tau_F)$의 절반이다
### 답
- (a) $f_T = \dfrac{1}{2\pi}\cdot\dfrac{I_C}{I_C\tau_F + V_T C_{je}} = \dfrac{1}{2\pi(\tau_F + V_T C_{je}/I_C)}$
- (b) 원점에서 기울기 $1/(2\pi V_T C_{je})$로 직선처럼 오르다가 $I_C \approx V_T C_{je}/\tau_F$ 부근에서 꺾여, 점점 $1/(2\pi\tau_F)$에 다가가 평평해지는 단조 증가 곡선이다.
