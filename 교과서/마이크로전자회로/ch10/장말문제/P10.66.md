# 장말문제 10.66 — 공통 모드 이득 < 0.01을 위한 조건 R_C I_C < 0.02(V_A + V_T) 증명 (Fig 10.87)

## 원문
The bipolar differential pair depicted in Fig. 10.87 must exhibit a common-mode gain of less than 0.01. Assuming $V_A = \infty$ for $Q_1$ and $Q_2$ but $V_A < \infty$ for $Q_3$, prove that

$$R_C I_C < 0.02(V_A + V_T). \qquad (10.223)$$

## 조건
- 회로: Fig 10.87 — 테일 전류원이 $Q_3$(베이스 $V_b$)인 바이폴라 차동쌍, 두 베이스는 공통 모드 소스 $v_{CM}$에 연결
- 공통 모드 이득이 $0.01$보다 작아야 함
- $Q_1$, $Q_2$: $V_A = \infty$
- $Q_3$: $V_A < \infty$
- $I_C$는 $Q_3$의 컬렉터 전류(꼬리 전류 $I_{EE}$)로 봄. 그래야 식 (10.223)의 0.02가 나오고, $Q_1$, $Q_2$ 한쪽의 전류로 보면 0.01이 됨 (원문은 정의하지 않음, 원문에 없음)

## 구할 것
- 다음을 증명
  $$R_C I_C < 0.02(V_A + V_T) \qquad (10.223)$$

## 풀이
### 테일 임피던스
- $Q_3$은 베이스가 $V_b$(교류 접지), 이미터가 접지이므로 공통 이미터 노드에서 $r_{O3} = V_A/I_C$로 보인다 ($I_C$는 $Q_3$ 컬렉터 전류 $I_{EE}$)
### 공통 모드 이득
- 공통 모드에서는 대칭이라 두 출력을 묶어 $Q_1$, $Q_2$를 병렬 트랜스컨덕턴스 $2g_m$인 한 소자로 본다. $g_m = (I_C/2)/V_T$는 $Q_1$, $Q_2$ 각각의 값이다
- 축퇴 CE 단: $|A_{CM}| = \dfrac{R_C/2}{r_{O3} + \dfrac{1}{2g_m}}$, $\dfrac{1}{2g_m} = \dfrac{V_T}{I_C}$
- $|A_{CM}| = \dfrac{R_C/2}{(V_A + V_T)/I_C} = \dfrac{R_C I_C}{2(V_A + V_T)}$
### 조건
- $\dfrac{R_C I_C}{2(V_A + V_T)} < 0.01$ → $R_C I_C < 0.02(V_A + V_T)$
### 답
- $|A_{CM}| = R_C I_C/[2(V_A + V_T)] < 0.01$에서 $R_C I_C < 0.02(V_A + V_T)$ (식 (10.223))가 나온다
