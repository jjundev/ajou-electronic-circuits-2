# 전자회로2 설계과제 보고서 노션 업로드

`설계과제/과제<n>/report/설계과제<n>_보고서.md` 를 `.claude/과목정보.md` 의 `notion_parent_page_id` 아래에 새 페이지 `전자회로2 설계과제<n> 보고서` 로 올린다 (판본 번호 v<N> 은 `notion.json` 과 baseline 파일명에만 남고 페이지 제목에는 붙지 않는다 — 제목이 PDF 본문 제목과 머리글이 되기 때문). 그림은 올리지 않는다 — 사용자가 노션에서 넣고, 다 넣었는지는 `check-images` 로 확인한다. 코드는 `scripts/ec2_report/sync.py`.

## 절대 규칙

1. **덮어쓰기 금지.** 언제나 새 페이지를 만든다. 기존 노션 페이지를 고치거나 지우지 않는다 (그런 함수가 없다).
2. **토큰 비노출.** 토큰은 환경변수 `NOTION_TOKEN` 에서만 읽는다. 토큰을 출력·파일·커밋·채팅 어디에도 쓰지 않고, 사용자에게 채팅으로 달라고 하지 않는다. 바꿔야 하면 사용자가 터미널에서 `~/.zshenv` 를 고친다.
3. **그림 자동 업로드 금지.** 그림 자리는 상대경로로 두고 사용자가 노션에서 직접 넣는다.
4. 본문에 AI 관련 언급이 있으면 검사기가 막는다. 우회하지 않는다.

## push (업로드)

1. 저장소 루트에서 실행한다.
   ```bash
   python3 -m scripts.ec2_report.sync push --n <n>
   ```
2. 종료 코드로 갈린다.
   - **2** — 본문 검사 error. 출력된 finding 을 그대로 보고하고 멈춘다. 본문을 고치는 것은 `ec2-write-design-report` 의 몫이다. 줄 맨 앞 `▶`, 본문 첫 블록 `#` 헤딩처럼 노션이 망가뜨리는 형태는 `docs/notion-probe.md` 에 근거가 있다.
   - **3** — 노션·설정 오류 (부모 페이지 id 없음, 토큰 없음, Connect 안 함 404 등). 메시지를 보고하고 고칠 방법을 안내한다.
   - **0** — 성공.
3. 성공하면 다음을 알린다: 페이지 제목과 URL, 판본 번호, 노션에서 넣을 그림 목록(info 줄), 왕복 검사 결과. `warn 노션:` 줄(직전 판본에 md 로 되돌리지 않은 노션 수정이 있음)이 있으면 그것을 먼저 짚는다 — 업로드는 이미 됐으므로, 아래 diff 로 수정 내용을 확인해 md 에 반영했는지 사용자와 확인한다. 왕복 검사가 손실을 보고하면(예: "헤딩 개수가 4개에서 3개로 줄었다") 그 항목을 짚어 사용자에게 노션 페이지를 확인해 달라고 한다.
4. "그림을 넣은 뒤 '확인해줘' 라고 말해 달라" 고 요청하고 끝낸다.

### 중간 실패 복구

- 업로드 기록(`report/notion/notion.json`)은 있는데 `baseline_v<N>.md` 만 없으면 되읽기만 다시 한다.
  ```bash
  python3 -m scripts.ec2_report.sync recover --n <n>
  ```
- 업로드 도중 끊겨 기록 없이 페이지만 생겼을 수 있으면 **재업로드하지 않는다.** 부모 페이지(`notion_parent_page_id`)를 알려 주고, 같은 제목의 페이지가 생겼는지 사용자가 보고 판단하게 한다. 다시 올리면 같은 판본 번호의 페이지가 둘 생긴다.

## diff (노션에서 고친 내용 확인)

사용자가 노션에서 본문을 직접 고쳤다고 하면 최신 판본을 되읽어 업로드 당시 baseline 과 비교한다. 그림 줄은 비교에서 뺀다 (그림을 넣으면 URL 만 바뀐다).

```bash
python3 -m scripts.ec2_report.sync diff --n <n>
```

- 종료 코드 **0** — 텍스트 수정 없음. **1** — `-`/`+` 줄이 수정 내용이다. **3** — 노션·설정 오류 (baseline 이 없으면 먼저 `recover`).
- 1 이면 수정을 md 로 되돌리는 일은 `ec2-write-design-report` 절차 6 의 몫이다. 이 스킬은 diff 를 보여 주고 넘긴다. 되읽은 md 는 형식이 달라 자동 병합하지 않는다.

## check-images (그림 빈자리 검사)

1. 가장 최근 판본을 되읽어 `report/notion/pulled_v<N>.md` 에 저장하고 빈 그림을 찾는다.
   ```bash
   python3 -m scripts.ec2_report.sync check-images --n <n>
   ```
2. 종료 코드 **1** (✗ 줄 있음) — 아직 비어 있는 그림 목록을 알리고 멈춘다. **3** — 노션·설정 오류.
3. 종료 코드 **0** — "노션에서 `⋯ → Export → PDF`(A4, 페이지 크기 A4) 로 내려받은 뒤 `ec2-merge-report` 로 표지와 합친다" 고 안내한다.
