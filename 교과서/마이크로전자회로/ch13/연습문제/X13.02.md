# 연습문제 13.2 — 4단 링 발진기에 초기 조건 0을 인가하면 (예제 13.2 변형)

## 원문
만약 링 발진기가 4개의 동일한 단으로 이루어져 있고 초기 조건으로 노드들 중의 하나에 0을 인가한다면 어떻게 될까?

## 조건
- 예제 13.2의 링 발진기를 동일한 단 4개로 구성한 경우
- 참고 회로 (본문 Fig 13.8): 각 단은 부하 $R_D$와 드레인 커패시턴스 $C_D$를 가진 NMOS 공통 소스 단이고, 각 단의 드레인이 다음 단 게이트를 구동하며 마지막 단 드레인이 첫 단 게이트로 귀환 (원문에 없음)
- 초기 조건으로 노드 중 하나에 0을 인가
- 소자 값은 주어지지 않음 (답은 설명으로) (원문에 없음)

## 구할 것
- 이때 회로가 어떻게 되는지 설명

## 상속·참조
- 예제 13.2 (E13.02): 3단 링(Fig 13.8)에서 과도 SPICE 시뮬레이션은 같은 드레인 전압이라는 dc 해를 유지해 발진하지 않는다. 노드 $X$에 0을 초기 조건으로 주면 $V_Y = V_{DD}$, $V_Z \approx 0$이 되면서 $V_X$가 $V_{DD}$로 상승해 평형점을 찾지 못하고 발진이 일어난다
- 본문 Fig 13.8 (교재 736쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig13-08.png): 연결 `R_D: VDD – X, VDD – Y, VDD – Z`, `M1: D = X, G = Z, S = 0`, `M2: D = Y, G = X, S = 0`, `M3: D = Z, G = Y, S = 0`, `C_D: X – 0, Y – 0, Z – 0`, 출력 V_out은 Z. 4단이면 같은 단이 하나 더 들어가고 넷째 단 드레인이 첫 단 게이트로 귀환

## 회로 — 없음 (단 수를 바꾸는 글 문제, 문제 그림 없음)
