# 예제 10.6 — 공급 2 V, 이득 10, 전력 1 mW인 바이폴라 차동쌍 설계

## 원문
공급 전압 $2\ \text{V}$, 이득이 $10$이고 한계 전력 소모가 $1\ \text{mW}$인 바이폴라 차동쌍을 설계하라.

## 조건
- 공급 전압 $2\ \text{V}$
- 전압 이득 $10$
- 전력 소모 한계 $1\ \text{mW}$

## 구할 것
- 위 조건을 만족하는 바이폴라 차동쌍 설계
- 정할 값: 테일 전류 $I_{EE}$와 컬렉터 저항 $R_C$ (원문에 없음, 원문은 "설계하라"만 적음)

## 상속·참조
- 본문 Fig 10.7(a) (교재 504쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-07.png): 바이폴라 차동쌍. 연결: `RC(왼쪽): VCC – X`, `RC(오른쪽): VCC – Y`, `Q1: C = X, B = Vin1, E = 공통 이미터 노드`, `Q2: C = Y, B = Vin2, E = 공통 이미터 노드`, `I_EE: 공통 이미터 노드 → 접지` (공통 이미터 노드는 이 그림에 라벨 없음) (원문에 없음, 예제는 그림을 참조하지 않음)
- 식 (10.45): 소신호 차동 이득 $A_v = -g_m R_C$ ($g_m$은 평형 상태 근처 각 트랜지스터의 트랜스컨덕턴스, 각 트랜지스터 전류 $I_{EE}/2$)
- $g_m = I_C / V_T$, $V_T = 26\ \text{mV}$ (풀이가 쓴 값)
- 전력 소모 = $V_{CC} I_{EE}$ (원문에 없음, 풀이가 암시)

## 회로 — 없음 (설계 문제, 문제 그림 없음)

## 답 (검증용)
- $V_{CC} = 2\ \text{V}$ → $1\ \text{mW}$ 한계는 테일 전류 $I_{EE} = 0.5\ \text{mA}$. 각 트랜지스터 $0.25\ \text{mA}$ → $g_m = 0.25\ \text{mA}/26\ \text{mV} = (104\ \Omega)^{-1}$
- $R_C = |A_v| / g_m = 1040\ \Omega$ (식 10.46–10.47)
