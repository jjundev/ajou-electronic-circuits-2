# STT 요약 에이전트 지시문

메인 에이전트는 날짜마다 아래 브리프로 에이전트 1명을 띄운다(병렬, model: opus / lite: sonnet; GPT에서는 sol / luna).

자료 준비자가 추출을 끝낸 뒤 호출한다. [delegation.md](delegation.md)에 따라 `<RUN>/briefs/stt-<MMDD>.json` 경로만 넘겨도 아래 브리프와 같은 입력 계약으로 허용한다. 입력 파일에서 실제 경로·날짜·슬라이드 유무를 읽고, STT 전체 읽기와 대조·출력 요구는 모두 유지한다.

---
전자회로2(권익진 교수님) <MMDD> 수업 녹음 전사를 정밀 요약한다.

- 입력(읽기 전용): `<RUN>/repo/STT/<MMDD 전회2.md>` — **처음부터 끝까지 전부** 읽는다. 건너뛰지 않는다.
- 대조 자료: `<RUN>/repo/강의노트/<2026F_LecN_*.pdf>` 슬라이드 텍스트(자료 준비자가 추출해 `<RUN>/slides.txt`에 둠, 쪽마다 `=== LNN sK ===`). 이 자리가 "없음(이 날짜 슬라이드 미게시)"이면 이 날짜는 업로드된 슬라이드보다 수업이 더 나간 것이다 — 슬라이드 대조 없이 STT와 교과서만으로 진행한다(아래 4번 대신 5번만 쓴다).
- 출력: `<RUN>/summaries/stt-<MMDD>.md` 한 파일만 쓴다. 다른 곳에는 쓰지 않는다(임시 파일은 아래 규칙). 이 파일은 내부 근거 대조용 비공개 작업 기록이다. 아래의 타임스탬프·줄 번호·Part·시각 정보 유무는 이 RUN 기록에만 보관하고 공개 학습 HTML·요약·동반 MD·툴팁·접근성 문구로 옮기지 않는다.
- 임시·보조 파일(스크립트, 초안, 그림 생성 폴더)은 자기 전용 `<RUN>/work/stt-<MMDD>/` 아래에만 둔다. 저장소(`STT/`, `강의노트/`, `교과서/`, `workbook/`, `복습노트/`)와 scratchpad 루트, `/tmp`에는 아무것도 쓰지 않는다. 한글(NFD) 파일명은 복사하거나 이름을 바꾸지 말고 Python `os.listdir` + `unicodedata.normalize('NFC', …)`로 찾아 그 경로로 연다.

출력 형식:
1. `# <MMDD> 전자회로2 강의 개요 (권익진 교수, <YYYY-MM-DD>)`
2. **총평**: 녹음 길이, 이번 수업이 다룬 강의자료와 슬라이드 범위(예: "L03 s7–12"), **시작하지 않은** 슬라이드, 흐름 한 줄.
3. 흐름 순서대로 `## N. 제목 (MM:SS–MM:SS)` 절. 각 절에:
   - **핵심 내용**: 정의, 식(TeX `$…$`), 칠판 유도 단계, 소신호 등가회로를 말로 설명한 것(어느 노드에 무엇이 연결되는지). 슬라이드에 없는 설명은 `[슬라이드 외]` 표시. 식은 슬라이드나 교과서의 식과 대조해 적고, 칠판 발언과 다르면 슬라이드·교과서 식을 적고 차이를 `## 말실수 정정`에 남긴다.
   - **교과서 연결**: 교수님이 언급한 Razavi 절·예제·그림 번호(예: "Example 9.3", "Fig. 9.12"). 없으면 생략.
   - **비유와 일화**: 개념을 싣는 비유만. 순수 잡담(출석, 자리, 이메일 등)은 쓰지 않는다.
   - **학생과의 대화**: 학생 이름은 "한 학생".
   - 강조 발언: 원문 인용 + `(MM:SS)`. "중요", "시험", "꼭" 같은 표현이 붙은 발언은 모두.
   - "나중에 할게요/유도는 생략" 처럼 **미룬 유도**는 `🕳️ 미룬 유도:`로 표시.
4. `## 슬라이드 대조표`: | 슬라이드 | 다룸/일부/예고만/안 다룸 | 근거 타임스탬프 | (슬라이드가 없는 날짜는 이 절 대신 5의 `## 교과서 절 대조`만 쓴다)
5. `## 교과서 절 대조`: 이번 수업이 다룬 Razavi 절 번호(예: 9.1.1, 9.1.2)와 다룸/일부. 복습문제 선별에 쓴다.
6. `## 용어·식 목록`: 수업에서 실제로 쓴 용어와 식을 TeX 그대로 나열(정리노트 required_terms 후보). 표기는 `g_m`, `r_O`, `R_{out}`, `V_{GS}`, `\parallel`로 맞춘다.
7. `## 동기 발언`: "왜 이 회로를 쓰는가"(풀려는 문제, 단순한 회로가 안 되는 이유, 대가)에 대한 교수님 발언을 원문 인용 + `(MM:SS)`로 모은다. 정리노트 첫 페이지(`why-circuit`)의 근거다. 없으면 "없음".
8. `## 말실수 정정`: STT 오인식(예: "캐스코드"가 "케스 코드"로 적힘) 또는 교수님 말실수와 올바른 형태.

보고: 파일 경로와 총평 3줄만 돌려준다.
