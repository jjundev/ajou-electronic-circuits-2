# 장말문제 13.40 — 위상 시프트 발진기와 3단 링 발진기의 비교

## 원문
Compare the oscillation frequency and startup condition of the phase shift oscillator with those of a three-stage ring oscillator.

## 조건
- 위상 시프트 발진기 (본문 Fig 13.24(a)): 고역 통과 RC 세 단 ($R_1 = R_2 = R_3 = R$, $C_1 = C_2 = C_3 = C$)과 반전 증폭기 하나 (원문에 없음)
- 식 (13.35): 위상 시프트 발진기의 발진 주파수 $\omega_1 = \dfrac{1}{\sqrt{6}RC}$ (본문 식, 원문에 없음)
- 식 (13.37): 위상 시프트 발진기의 스타트업 조건, 증폭기 이득 $A = 29$ 이상 (본문 식, 원문에 없음)
- 3단 링 발진기 (본문 Fig 13.8): 같은 CS 단 셋 (각 단 부하 $R_D$, $C_D$)을 고리로 연결 (원문에 없음)
- 식 (13.3): 3단 링 발진기의 발진 주파수 $\omega_1 = \dfrac{\sqrt{3}}{R_D C_D}$ (본문 식, 원문에 없음)
- 식 (13.5)–(13.6): 3단 링 발진기의 스타트업 조건 $g_m R_D = \sqrt{1 + R_D^2 C_D^2 \omega_1^2} = 2$, 곧 각 단의 저주파 이득이 2 이상 (본문 식, 원문에 없음)

## 구할 것
- 위상 시프트 발진기와 3단 링 발진기의 발진 주파수 비교
- 두 발진기의 스타트업 조건 비교

## 상속·참조
- 본문 Fig 13.8 (교재 736쪽, 크롭 안 함): 3단 링 발진기. CS 단 $M_1$, $M_2$, $M_3$ (각 드레인 $X$, $Y$, $Z$에 $R_D$가 $V_{DD}$로, $C_D$가 접지로), $X$ → $M_2$ 게이트, $Y$ → $M_3$ 게이트, $Z$($V_{out}$) → $M_1$ 게이트
- 3단 링 해석 (13.2절): 각 극점이 $60°$씩 위상 시프트
  - 식 (13.2)–(13.3): $-\tan^{-1}(R_D C_D \omega_1) = -60°$, $\omega_1 = \dfrac{\sqrt{3}}{R_D C_D}$
  - 식 (13.5)–(13.6): $g_m R_D = \sqrt{1 + R_D^2 C_D^2 \omega_1^2} = 2$
- 본문 Fig 13.24(a) (교재 750쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig13-24-a.png): 위상 시프트 발진기. $C_1$ → $X$ → $C_2$ → $Y$ → $C_3$ → 증폭기 입력, 각 노드에서 $R_1$, $R_2$, $R_3$가 접지로, 증폭기 $-A_0$ 출력 $V_{out}$이 $C_1$로 되돌아감
- 위상 시프트 해석 (13.4절): 식 (13.35) $\omega_1 = \dfrac{1}{\sqrt{6}RC}$, 식 (13.37) $A = 29$
