# 전압 이득에서 부하 전류 계산

2026-11-27 사용자는 1125 P1에 소스 팔로워 공식을 명시하고, P2도 출력단의 전압 이득을 구한 뒤 부하 저항으로 나누길 요청했다. 같은 조건에서 이 순서를 이후 해설에도 적용하기로 확정했다.

| 근거 | 기존 해설 | 반영 |
|---|---|---|
| 1125 P1, 2021-1 기말 4번, 원본 PDF 1쪽 | 팔로워의 전압 이득과 전류 환산을 이미 사용했다. | 소스 팔로워 공식과 $R_{\mathrm{source}}=R_L+R_M$을 명시하고, $V_S$를 같은 저항으로 나눈다. |
| 1125 P2, 2023-1 기말 3번, 원본 PDF 3쪽 | PMOS 출력단 전류를 전류 분배로 바로 구했다. | 공통 소스 전압 이득의 병렬 부하를 보이고, 그림의 드레인 전압 $V_D$를 $R_L+R_M$으로 나눈다. |
