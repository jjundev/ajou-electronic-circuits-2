# 장말문제 13.56 — 2 GHz 콜피츠 발진기 설계

## 원문
(a) A $20\ \text{nH}$ inductor has a series resistance of $15\ \Omega$. Compute the equivalent parallel resistance, $R_p$, at $2\ \text{GHz}$.

(b) Design a $2\ \text{GHz}$ Colpitts oscillator using this inductor with a power budget of $2\ \text{mW}$ and $V_{DD} = 1.5\ \text{V}$. For simplicity, neglect the capacitances of the bipolar transistor and assume $C_1 = C_2$. Verify that the startup condition is met.

## 조건
- (a) 인덕터 $20\ \text{nH}$, 직렬 저항 $15\ \Omega$, 주파수 $2\ \text{GHz}$
- (b) 이 인덕터로 $2\ \text{GHz}$ 콜피츠 발진기를 설계
- (b) 전력 예산 $2\ \text{mW}$, $V_{DD} = 1.5\ \text{V}$
- (b) 단순화를 위해 바이폴라 트랜지스터의 커패시턴스는 무시하고 $C_1 = C_2$로 가정
- 공통 가정: $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $\mu_p C_{ox} = 50\ \mu\text{A/V}^2$, $\lambda_n = 0.1\ \text{V}^{-1}$, $\lambda_p = 0.2\ \text{V}^{-1}$, $V_{THN} = 0.3\ \text{V}$, $V_{THP} = -0.35\ \text{V}$ (원문의 Design Problems 머리말)
- 머리말의 "$\lambda_n = 0.5\ \lambda_p = 0.1\ \text{V}^{-1}$"은 쉼표 없이 인쇄됨. "$\mu_n C_{ox} = 2\mu_p C_{ox}$"와 같은 꼴로 $\lambda_n = 0.5\lambda_p = 0.1\ \text{V}^{-1}$로 읽음 (원문에 없음)
- 참고 회로 (본문 Fig 13.22(a), 바이폴라 콜피츠 발진기): $V_{DD}$와 노드 $Y$ 사이에 $L_1$과 $R_p$ 병렬, $Q_1$ 컬렉터 $Y$, 베이스 $V_b$, 이미터 $X$, $X$에서 접지로 전류원 $I_1$, $Y$–$X$ 사이 $C_1$, $X$–접지 사이 $C_2$ (원문에 없음)
- 식 (13.25): 발진 주파수 $\omega_1^2 \approx \dfrac{1}{L_1 \dfrac{C_1 C_2}{C_1 + C_2}}$ (본문 식, 원문에 없음)
- 식 (13.26): 스타트업 조건 $g_m R_p = \dfrac{(C_1 + C_2)^2}{C_1 C_2}$, $C_1 = C_2$이면 $g_m R_p \ge 4$ (본문 식, 원문에 없음)

## 구할 것
- (a) $2\ \text{GHz}$에서의 등가 병렬 저항 $R_p$
- (b) 콜피츠 발진기 설계 (정할 값 예: 바이어스 전류 $I_1$, $C_1 = C_2$) (원문에 없음, 원문은 "Design"만 적음)
- (b) 스타트업 조건을 만족하는지 확인

## 상속·참조
- Design Problems 공통 가정 (원문 머리말을 그대로 옮김, 문제에 따로 적힌 값이 우선): In the following problems, unless otherwise stated, assume $\mu_n C_{ox} = 2\mu_p C_{ox} = 100\ \mu\text{A/V}^2$, $\lambda_n = 0.5\ \lambda_p = 0.1\ \text{V}^{-1}$, $V_{THN} = 0.3\ \text{V}$, and $V_{THP} = -0.35\ \text{V}$.
  - 해석: $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $\mu_p C_{ox} = 50\ \mu\text{A/V}^2$. "$\lambda_n = 0.5\ \lambda_p = 0.1$"은 쉼표 없이 인쇄돼 있어 같은 머리말의 "$\mu_n C_{ox} = 2\mu_p C_{ox} = 100$"과 같은 꼴, 곧 $\lambda_n = 0.5\lambda_p = 0.1\ \text{V}^{-1}$로 읽어 $\lambda_n = 0.1\ \text{V}^{-1}$, $\lambda_p = 0.2\ \text{V}^{-1}$로 봄 ("$\lambda_n = 0.5$, $\lambda_p = 0.1$"로 읽을 수도 있음)
- 공통 가정은 MOS 값뿐이며 바이폴라 트랜지스터 값은 없음. 이 문제는 바이폴라 트랜지스터를 씀
- 본문 Fig 13.22(a) (크롭 안 함, 크롭은 fig13-22-a.png): 콜피츠 발진기
  - `L1: VDD — Y`, `R_p: VDD — Y` (병렬 탱크)
  - `Q1 (npn): C = Y, B = V_b, E = X`
  - `C1: Y — X`, `C2: X — 0`, `I1: X → 0`
- 본문 13.3.3절 해석 (얼리 효과 무시): 식 (13.25) 발진 주파수, 식 (13.26) 스타트업 조건 (조건에 적은 대로). $C_1 = C_2$일 때 우변이 최소이므로 $g_m R_p$는 최소 4
- 본문 Fig 13.23과 식 (13.27): 출력을 이미터에서 감지하는 형태로, 개별 소자 설계에서 흔히 씀. 이 문제는 그림 번호를 정하지 않음
