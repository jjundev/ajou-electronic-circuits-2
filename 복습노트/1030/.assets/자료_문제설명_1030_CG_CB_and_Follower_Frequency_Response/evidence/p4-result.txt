Source gain: (Cgs1*s + gm1)/(Cgs1*s + gm1 + gm2 + gmb1 + go1 + go2)
Input admittance: Cgs1*s*(gm2 + gmb1 + go1 + go2)/(Cgs1*s + gm1 + gm2 + gmb1 + go1 + go2)
Low-frequency Cin: Cgs1*(gm2 + gmb1 + go1 + go2)/(gm1 + gm2 + gmb1 + go1 + go2)
Diode M2 has fixed source and bulk so no body transconductance term. The usual no-body-effect model sets gmb1=0.
