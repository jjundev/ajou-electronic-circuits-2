# 연습문제 12.5 — K = 1일 때 폐루프 주파수 응답 (예제 12.5 변형)

## 원문
$K = 1$일 경우 위의 예제를 다시 풀어라.

## 조건
- 예제 12.5와 같은 시스템: 단일 극점 개루프 증폭기 식 (12.19) $A_1(s) = \dfrac{A_0}{1 + s/\omega_0}$에 귀환율 $K$인 부귀환을 건 시스템 (원문에 없음)
- 식 (12.22): $\dfrac{Y}{X}(s) = \dfrac{\dfrac{A_0}{1 + KA_0}}{1 + \dfrac{s}{(1 + KA_0)\omega_0}}$ (본문 식, 원문에 없음)
- $A_0 = 200$ (예제 12.5의 값, 원문에 없음)
- 바뀐 점: $K = 1$ (예제는 $K = 0, 0.1, 0.5$)

## 구할 것
- $K = 1$일 때 식 (12.22)의 폐루프 주파수 응답 도시

## 상속·참조
- 예제 12.5 (E12.05): $A_0 = 200$. $K = 0$이면 $Y/X = A_1(s)$, $K = 0.1$이면 $1 + KA_0 = 21$, $K = 0.5$이면 $1 + KA_0 = 101$ → 이득은 $1 + KA_0$배 감소하고 대역폭은 같은 인수만큼 증가 (Fig 12.9)
- 식 (12.23), (12.24): 폐루프 이득 $= \dfrac{A_0}{1 + KA_0}$, 폐루프 대역폭 $= (1 + KA_0)\omega_0$
