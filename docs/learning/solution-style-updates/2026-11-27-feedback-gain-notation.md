# 귀환 이득과 레이저 출력저항 표기

2026-11-27 대화에서 나온 사용자의 명시적 표기 요청과 승인한 적용안을 반영했다.

| 결정 | 기존 표기 | 적용 |
|---|---|---|
| 전체 전달비 | 문항에 따라 $A$, $R_0$, $A_{I,\mathrm{open}}$ | 첫 $A_{\mathrm{open}}$ 정의식에 입출력 기준과 $[\mathrm{V/V}]$, $[\mathrm{A/V}]$, $[\mathrm{V/A}]$, $[\mathrm{A/A}]$ 중 맞는 단위를 표시한다. 폐루프 전달비는 $A_{\mathrm{closed}}$로 쓴다. |
| 루프 이득 | $T$와 $T_0$ 또는 $KA_{\mathrm{open}}$ | $KA_{\mathrm{open}}$을 부호와 함께 직접 쓴다. 1120 P9는 $KA_{\mathrm{open}}<0$인 정귀환이다. |
| 직렬 전류 감지의 출력저항 | 레이저 자리의 단락 조건에서 별도 루프 이득 계산 | $(R_{\mathrm{out,open}}+R_L)(1+KA_{\mathrm{open}})-R_L$로 쓴다. $A_{\mathrm{open}}$은 레이저를 연결한 값이며, $R_{\mathrm{out,open}}$은 부하를 뗀 두 단자에서 본 값이다. |
| 노턴 등가 | 단락 이득에 별도 기호를 지정 | 폐루프 전달비 전체에 $R_L=0$을 표시해 단락 전류를 구한다. 노턴 저항은 같은 포트의 출력저항이며 전개식에 $R_L$이 남지 않는다. |

개인 풀이 방식의 `GAIN-01`, `NOTATION-01`과 `ec2-problem-explain`의 저작·내용 검토 지침을 갱신했다. 기존 문항 적용 범위는 1120 P1–P11과 1125 P1–P5의 해설과 요약이다. 1125 P2–P5는 기존 소신호 근사의 적용 범위를 유지했다.

검증에서는 두 회차의 원 회로 SymPy 스크립트 16개를 재실행하고, 레이저 출력저항과 노턴 등가의 새 식을 기존 두 단자 시험원 결과와 대조했다. 개인 풀이 명세와 해설 스킬 테스트 279개가 통과했다.
