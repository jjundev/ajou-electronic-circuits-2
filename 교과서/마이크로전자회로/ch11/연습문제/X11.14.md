# 연습문제 11.14 — 45 nm, 이동도 300 cm²/(V·s)일 때의 f_T (예제 11.14 변형)

## 원문
채널 길이는 $45\ \text{nm}$로 축소되었지만, 이동도가 $300\ \text{cm}^2/(\text{V}\cdot\text{s})$로 떨어진 경우에 $f_T$를 결정하라.

## 조건
- 채널 길이 $L = 45\ \text{nm}$
- 이동도 $\mu_n = 300\ \text{cm}^2/(\text{V}\cdot\text{s})$
- 과구동 전압 $V_{GS} - V_{TH} = 100\ \text{mV}$ (예제 11.14의 값을 그대로 씀) (원문에 없음)
- 식 (11.53): $2\pi f_T = \dfrac{3}{2}\dfrac{\mu_n}{L^2}(V_{GS} - V_{TH})$ (본문 식, 원문에 없음)

## 구할 것
- $f_T$

## 상속·참조
- 예제 11.14 (E11.14): $2\pi f_T = \dfrac{3}{2}\dfrac{\mu_n}{L^2}(V_{GS} - V_{TH})$ (식 11.53). $\mu_n = 400\ \text{cm}^2/(\text{V}\cdot\text{s})$, 과구동 전압 $100\ \text{mV}$, $L = 65\ \text{nm}$이면 $f_T = 226\ \text{GHz}$

## 회로 — 없음 (그림 없는 글 문제)

## 풀이
### 트랜싯 주파수 식
- 예제 11.14와 같이 $2\pi f_T = \dfrac{3}{2}\dfrac{\mu_n}{L^2}(V_{GS} - V_{TH})$
### 값 대입
- $\mu_n = 300\ \text{cm}^2/(\text{V}\cdot\text{s}) = 0.03\ \text{m}^2/(\text{V}\cdot\text{s})$
- $2\pi f_T = \dfrac{3}{2} \cdot \dfrac{0.03\ \text{m}^2/(\text{V}\cdot\text{s})}{(45\ \text{nm})^2}(0.1\ \text{V}) = 2.22 \times 10^{12}\ \text{rad/s}$
- $f_T = 354\ \text{GHz}$
### 예제와 비교
- $L^2$이 $(65/45)^2 = 2.09$배 줄어든 효과가 이동도 감소($0.75$배)보다 커서 $f_T$는 예제의 $226\ \text{GHz}$보다 약 $1.56$배 높다
### 답
- $f_T \approx 354\ \text{GHz}$
