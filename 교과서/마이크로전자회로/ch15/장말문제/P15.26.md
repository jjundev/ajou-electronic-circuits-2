# 장말문제 15.26 — KHN 필터의 Q와 저항 감도가 0이 되는 조건

## 조건
- 식 (15.103), (15.104)로부터 양호도를 다룬다.
- 식 (15.103)의 인쇄식은 $\omega_n/Q=[R_4/(R_4+R_5)]/(R_1C_1)$, 식 (15.104)는 $\omega_n^2=(R_6/R_3)/(R_1R_2C_1C_2)$이다. (본문 식, 원문에 없음)
- 식 (15.101)의 $1/s$ 항과 식 (15.103)은 문맥과 맞지 않음(오식으로 보임). 식 (15.100)에서는 $V_X$ 항에도 $1+R_6/R_3$이 곱해지므로 회로의 $\omega_n/Q$에는 인쇄된 식 (15.103)의 우변에 이 인수가 추가된다. (원문에 없음)

## 구할 것
- $Q$의 식을 유도한다.
- $R_3=R_6$일 때 $R_3$ 및 $R_6$에 대한 $Q$ 감도가 사라지는 이유를 설명한다.

## 상속·참조
- 식 (15.100)은 $V_{out}=[(V_{in}R_5+V_XR_4)/(R_4+R_5)](1+R_6/R_3)-V_YR_6/R_3$이다. 이를 기준으로 정리하면 $Q=[(R_4+R_5)/R_4]\sqrt{(R_6/R_3)R_1C_1/(R_2C_2)}/(1+R_6/R_3)$가 된다. 인쇄된 식 (15.103)만 사용하면 마지막 분모가 생기지 않는다. (원문에 없음)

## 회로 — Fig 15.36(b)
```spice
R4 Vin n1 {R_4}
R5 X n1 {R_5}
R3 Y n2 {R_3}
R6 Vout n2 {R_6}
XA n1 n2 Vout opamp
R1 Vout n3 {R_1}
C1 X n3 {C_1}
XB 0 n3 X opamp
R2 X n4 {R_2}
C2 Y n4 {C_2}
XC 0 n4 Y opamp
```
- 단자: Vin = 입력 (개방 원) / Vout = 출력 (개방 원)
- 표시: 노드 라벨 V_in, V_out, X, Y / 소자 라벨 R_1–R_6, C_1, C_2, XA, XB, XC (증폭기 라벨 없음) / 부호 세 연산증폭기의 왼쪽 위 −, 아래 + / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 합산 증폭기의 비반전 입력 분기(점)에는 입력의 R_4와 아래쪽으로 X에서 돌아오는 R_5가 연결된다. 반전 입력 쪽(점)에는 옆 R_6 및 맨 위 Y에서 돌아오는 R_3이 닿는다. R_6 오른쪽 V_out 원의 분기(점)와 그 아래 합산기 출력 분기(점)를 세로선이 잇는다. 가운데와 오른쪽 적분기는 비반전 입력이 접지이며, 각 반전 입력의 분기(점)에는 가로 R_1·R_2와 위쪽 되먹임 C_1·C_2가 연결된다. X 출력 분기(점)에는 C_1, R_2, R_5 선이 닿고 Y 위쪽 분기(점)는 C_2와 R_3으로 이어진다. 교차: 없음
