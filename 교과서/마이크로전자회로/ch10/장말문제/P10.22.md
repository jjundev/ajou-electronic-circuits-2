# 장말문제 10.22 — 식 10.83으로 구하는 바이폴라 차동쌍의 소신호 전압 이득 (dc 성분 30 mV)

## 조건
- 식 (10.83)으로 바이폴라 차동쌍의 소신호 전압 이득을 계산할 수 있음:
  $$A_v = \frac{\partial (V_{out1} - V_{out2})}{\partial (V_{in1} - V_{in2})} \qquad (10.218)$$
- $V_{in1} - V_{in2}$에 $30\ \text{mV}$의 dc 성분이 들어 있는 경우

## 구할 것
- 이득 $A_v$
- $V_{in1} - V_{in2}$에 $30\ \text{mV}$ dc 성분이 있을 때 이득의 값

## 상속·참조
- 식 (10.83) (교재 516쪽, Fig 10.14의 대신호 해석, $\alpha = 1$, $V_A = \infty$):
  $$V_{out1} - V_{out2} = -R_C I_{EE} \tanh\frac{V_{in1} - V_{in2}}{2V_T}$$
- 식 (10.83)의 회로: 본문 Fig 10.14 (교재 514쪽, 크롭은 문제 10.18 등에 있음). 연결: `R_C: VCC – Vout1`, `R_C: VCC – Vout2`, `Q1: C = Vout1, B = Vin1, E = P`, `Q2: C = Vout2, B = Vin2, E = P`, `I_EE: P → 접지`
