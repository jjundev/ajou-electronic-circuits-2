# 예제 10.15 — 입력 CM 레벨 1.6 V인 MOS 차동쌍의 최대 부하 저항

## 조건
- MOS 차동쌍이 입력 공통 모드 레벨 $V_{CM} = 1.6\ \text{V}$로 구동됨
- $I_{SS} = 0.5\ \text{mA}$
- $V_{TH} = 0.5\ \text{V}$
- $V_{DD} = 1.8\ \text{V}$

## 구할 것
- 허용 가능한 최대 부하 저항 $R_D$

## 상속·참조
- 본문 Fig 10.26 (교재 525쪽, 크롭 안 함): 두 입력을 $V_{CM}$으로 묶은 MOS 차동쌍. 연결: `RD(왼쪽): VDD – X`, `RD(오른쪽): VDD – Y`, `M1: D = X, G = 공통 게이트 노드, S = 공통 소스 노드`, `M2: D = Y, G = 공통 게이트 노드, S = 공통 소스 노드`, `V_CM: + = 공통 게이트 노드, − = 접지`, `I_SS: 공통 소스 노드 → 접지` (공통 게이트·소스 노드는 이 그림에 라벨 없음) (원문에 없음, 예제는 그림을 참조하지 않음)
- 본문 가정: $\lambda = 0$, $I_D = \tfrac{1}{2}\mu_n C_{ox}\tfrac{W}{L}(V_{GS} - V_{TH})^2$, 평형에서 $I_{D1} = I_{D2} = I_{SS}/2$ (식 10.109)
- 식 (10.112): $M_1$, $M_2$가 포화 영역에 있으려면 드레인 전압이 $V_{CM} - V_{TH}$ 아래로 내려가지 않아야 함 → $V_{DD} - R_D \dfrac{I_{SS}}{2} > V_{CM} - V_{TH}$

## 회로 — 없음 (그림 없는 글 문제, 본문 그림 10.26은 상속·참조에 적음)

## 답 (검증용)
- 식 (10.112)에서 $R_D < 2\dfrac{V_{DD} - V_{CM} + V_{TH}}{I_{SS}}$ (식 10.113) $< 2.8\ \text{k}\Omega$ (식 10.114). 이런 제한이 전압 이득을 억제할 수 있음
