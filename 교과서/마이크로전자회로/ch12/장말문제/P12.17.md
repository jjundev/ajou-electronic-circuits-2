# 장말문제 12.17 — 예제 12.7 회로(CG 단과 저항 분배 귀환)의 증폭기 모델

## 원문
Repeat Problem 12.16 for the circuit in Example 12-7.

## 조건
- 회로: 예제 12.7의 회로 (Fig 12.11, 원문 표기 "Example 12-7")
- 문제 12.16에서 이어받는 요구: 회로의 증폭기 모델을 구함 (원문에 없음)
- 문제 12.16에서 이어받는 가정: $\lambda > 0$ (원문에 없음)
- 예제 12.7에서는 $\lambda = 0$, $R_1 + R_2 \gg R_D$로 가정했음. 이 문제가 문제 12.16의 $\lambda > 0$을 따르는지 예제 12.7의 가정을 따르는지는 원문에 적혀 있지 않음 (원문에 없음)
- 증폭기 모델: 본문 Fig 12.18처럼 입력 저항 $R_{in}$, 출력 저항 $R_{out}$, 종속 전원 이득으로 나타낸 모델 (원문에 없음)

## 구할 것
- 예제 12.7 회로(Fig 12.11)의 증폭기 모델

## 상속·참조
- 문제 12.16: "Determine the amplifier model for the circuit depicted in Fig. 12.84. Assume $\lambda > 0$." (그 회로는 $M_1$, $M_2$ NMOS 캐스코드)
- 예제 12.7 (교재 654쪽, PDF 8, 12.2.3 I/O 임피던스의 변화): 그림 12.11은 그림 12.2 귀환 회로의 트랜지스터 레벨 실현. $\lambda = 0$, $R_1 + R_2 \gg R_D$로 가정. (a) 귀환 시스템의 네 가지 성분, (b) 개루프와 폐루프 전압 이득, (c) 개루프와 폐루프 I/O 임피던스를 구함
- 예제 12.7 풀이의 결과 (참고): 순방향 증폭기는 $M_1$과 $R_D$로 된 공통 게이트 단, $A_0 \approx g_m R_D$, 귀환율 $K = R_2/(R_1 + R_2)$, 폐루프 이득 $\dfrac{g_m R_D}{1 + \frac{R_2}{R_1 + R_2} g_m R_D}$, 개루프 $R_{in,open} = 1/g_m$, $R_{out,open} = R_D$
- 본문 Fig 12.18 (교재 661쪽, PDF 11): 네 가지 증폭기의 실제 모델. 크롭 안 함
  - 전압 입력: $v_{in}$ 단자와 접지 사이 $R_{in}$ / 전류 입력: $i_{in}$이 $R_{in}$(접지로)으로 흘러 들어감
  - 전압 출력: 종속 전압원에 $R_{out}$ 직렬 / 전류 출력: 종속 전류원과 $R_{out}$이 출력 노드와 접지 사이에 병렬

## 회로 — Fig 12.11
```spice
RD  VDD   Vout  {R_D}
M1  Vout  n1    Vin   nmos   ; 좌우 반전 (게이트 오른쪽)
R1  Vout  n1    {R_1}
R2  n1    0     {R_2}
```
- 단자: VDD = 전원, 값 미지정 (T 전원 기호) / Vin = 입력 (개방 원) / Vout = 출력 (개방 원)
- 표시: 노드 라벨 VDD (T 기호 오른쪽), V_in (입력 원 왼쪽), V_out (출력 원 오른쪽) / 소자 라벨 R_D (저항 왼쪽), M1 (트랜지스터 왼쪽), R1, R2 (각 저항 오른쪽) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 세로줄 위→아래 VDD T 기호, R_D, 접속점, M1 / M1 nmos 좌우 반전 (게이트 오른쪽, 드레인 위, 소스 왼쪽 아래·화살표 바깥) / M1 소스에서 아래로 내려가 왼쪽으로 꺾여 V_in 원 / R_D 아래 접속점에서 가로선이 오른쪽으로 뻗어 오른쪽 접속점(Vout)에 닿고 계속 오른쪽 V_out 원 / 오른쪽 세로줄 위→아래 Vout 접속점, R1, n1 접속점, R2, 접지 / n1에서 가로선이 왼쪽으로 M1 게이트 / 접속점 (세 갈래 이상, 3곳): R_D 아래 = 위 R_D + 아래 M1 드레인 + 오른쪽 가로선 (점), 오른쪽 Vout = 왼쪽 가로선 + 아래 R1 + 오른쪽 V_out 선 (점), n1 = 위 R1 + 아래 R2 + 왼쪽 M1 게이트선 (점) / 교차: 없음
