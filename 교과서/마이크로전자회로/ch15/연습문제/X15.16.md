# 연습문제 15.16 — 중간 노드 Y에 접지 저항을 추가한 SK 필터

## 조건
- Fig 15.34의 노드 $Y$와 접지 사이에 저항 $R_0$을 추가한다.
- 예제 15.16에서처럼 이상적 연산증폭기와 비반전 이득 $K=1+R_3/R_4$를 사용한다. (원문에 없음)

## 구할 것
- 변경된 회로의 전달 함수를 구한다.

## 상속·참조
- 예제 15.16의 Y는 두 입력 저항과 출력 피드백 커패시터가 만나는 지점이다. 이 노드에서 추가된 저항으로 전류가 흐르는 조건으로 분석을 반복한다.

## 회로 — Fig 15.34
```spice
VIN  Vin  0     {V_in}
R1   Vin  Y     {R_1}
R2   Y    X     {R_2}
C1   Y    Vout  {C_1}
C2   X    0     {C_2}
R3   Vout n1    {R_3}
R4   n1   0     {R_4}
XA   X    n1    Vout  opamp
```
- 단자: Vout = 출력 (개방 원) / Vin = 접지 기준 전압원 전압
- 표시: 노드 라벨 Y, X, V_out / 소자 라벨 V_in, R_1, R_2, R_3, R_4, C_1, C_2, XA (라벨 없음) / 부호 입력 전압원 위 +, 아래 −, 연산증폭기 왼쪽 위 +, 아래 − / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 전압원 위에서 가로 R_1, Y, R_2, X, 비반전 입력이 차례로 이어진다. Y(점)에서 위로 올라간 가지에 피드백 C_1이 있고, X(점)에서는 아래로 C_2를 거쳐 접지된다. 출력의 접속점(점)에 위쪽 C_1 선과 아래쪽 R_3 선이 닿는다. 아래쪽 반전 입력의 분기(점)는 오른쪽의 가로 R_3과 아래쪽 접지 R_4를 잇는다. 교차: 없음
