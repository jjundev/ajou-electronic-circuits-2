# 브리프 03: C-C 귀환 신호 경로와 루프 이득 부호

- **제목:** C-C 귀환 신호 경로와 루프 이득 부호
- **저장 파일명:** `CC_귀환_신호경로와_루프이득_부호` (예상 산출물: `인터렉티브_03_CC_귀환_신호경로와_루프이득_부호.html`)
- **아키타입:** `probe`
- **선정 점수:** 7점
  - $I_{in}, R_F, R_M, r_{O2}$ 변화에 따라 $V_X, I^*, I_{out}, V_P, I_F$ 및 루프 이득이 연동 변화 (+2)
  - 입력 테브난 변환 → CG 단 $V_X$ → PMOS 반전 $I^*$ 및 $r_{O2}$ 전류 분배 → $V_P$ → $I_F$의 5단계 인과 경로 추적 (+2)
  - $K<0$이지만 $A_{I,open}<0$이므로 $KA_{I,open}>0$(음의 귀환)인 부호 메커니즘을 도미노로 확인 (+2)
  - 기존 위젯이 없는 `s2-cc-gain`·`s2-cc-closed`의 신호 전파와 부호 직관을 채우는 새 실험 (+1)

## 기존 `.widget` 관계 및 처리 계획
- 관련 절 `s2-cc-gain`, `s2-cc-closed`에는 위젯이 없다. 이웃 절 `s2-cc-io`의 `widget-ccio`는 임피던스 오차율 비교 전용이므로 본 실험의 신호 전파·부호 예측과 중복되지 않는다.
- **처리:** 해당 없음(`widget-ccio` 유지).

## 모드·조작·대표 설정·인과 단계
- **모드 1 (`open_path` — 개루프 2단 전류 경로):**
  - 회로: 로딩 포함 개루프 C-C 회로 ($I_{in}$ 입력 노드에서 $R_F+R_M$과 $1/g_{m1}$ 분배 → $M_1$ 드레인 $V_X$ → PMOS $M_2$의 $I^* = -g_{m2}V_X$가 $r_{O2}$($I'$)와 $R_L + R_F\parallel R_M$($I_{out}$)으로 분배).
  - 파라미터: `iin` ($-5$–$5\ \mu\text{A}$, 기본 $1$), `rf` ($2$–$50\text{ k}\Omega$, 기본 $10$), `rm` ($0.2$–$5\text{ k}\Omega$, 기본 $1$), `ro2` ($5$–$100\text{ k}\Omega$, 기본 $50$). 고정: $g_{m1}=2\text{ mS}, R_D=10\text{ k}\Omega, g_{m2}=5\text{ mS}, R_L=1\text{ k}\Omega$.
  - 인과 단계 (`causalSteps`, 4단계):
    1. 입력 전류 $I_{in}$이 $1/g_{m1}$과 $R_F+R_M$으로 분배
    2. 공통 게이트 $M_1$ 드레인 전압 $V_X$ 상승
    3. PMOS $M_2$ 드레인 전류 $I^* = -g_{m2}V_X$ 반전 발생
    4. $r_{O2}$와 부하 경로($R_L + R_F\parallel R_M$)의 전류 분배로 $I_{out}$ 결정
- **모드 2 (`closed_path` — 폐루프 음의 귀환 부호 추적):**
  - 회로: 실제 폐루프 C-C 회로 ($R_F$가 $M_1$ 소스 노드 $S$와 감지 노드 $P$를 직접 연결, $R_M$이 $P$에서 접지로 연결).
  - 파라미터: `iin` ($-5$–$5\ \mu\text{A}$, 기본 $1$), `rf` ($2$–$50\text{ k}\Omega$, 기본 $10$), `rm` ($0.2$–$5\text{ k}\Omega$, 기본 $1$), `ro2` ($5$–$100\text{ k}\Omega$, 기본 $50$).
  - 인과 단계 (`causalSteps`, 5단계):
    1. 입력 전류 $I_{in}$ 인가 (↑)
    2. $M_1$ 드레인 $V_X$ 상승 (↑)
    3. PMOS $M_2$ 출력 전류 $I_{out}$ 하강 (↓, 음수)
    4. 감지 노드 $V_P$ 하강 (↓) → $R_F$로 빠지는 귀환 전류 $I_F$ 상승 (↑)
    5. 입력 노드 KCL $I_{S1} = I_{in} - I_F$ 감소 → 처음 변화를 억제하는 음의 귀환 완성!
- **대표 설정(`presets`):**
  - `open_path`: `수업 예시 (A_I,open ≈ -46.07)`, `낮은 r_O2 (5 kΩ, 분배 손실)`, `낮은 R_F (2 kΩ, 입력 분배 손실)`
  - `closed_path`: `수업 예시 (KA ≈ 4.19, 음의 귀환)`, `강한 귀환 (R_M = 3 kΩ)`, `반대 입력 (I_in = -2 μA)`

## 예측 질문 및 오개념
- **예측 질문 (`predict`, `mode: 'closed_path'`):**
  - 질문: "C-C 폐루프 회로에서 귀환 계수 $K = -R_M/(R_F+R_M)$은 음수입니다. 입력 전류 $I_{in}$을 양의 방향으로 키우면 입력 노드에서 빠지는 귀환 전류 $I_F$는 어떻게 변할까요?"
  - 보기: `inc`("양의 방향으로 커져 $I_{S1}=I_{in}-I_F$를 줄인다(음의 귀환)"), `dec`("음의 방향으로 흘러 $I_{S1}$을 더 키운다(양의 귀환)"), `zero`("0으로 유지된다") — 정답: `inc`.
  - `check`: `before: { params: { iin: 0, rf: 10, rm: 1, ro2: 50 } }`, `after: { params: { iin: 2 }, causalStep: 5 }`, `tiles: ['귀환 전류 I_F', '출력 전류 I_out']`.
- **모드별 오개념 (`mistakes`, 각 3개):**
  - `open_path`: (1) PMOS $M_2$의 반전 부호($I^*=-g_{m2}V_X$)를 빠뜨려 $A_{I,open}>0$로 쓰는 오류, (2) $M_2$ 드레인 전류 $I^*$가 $r_{O2}$로 새는 분배를 무시하는 오류, (3) 테브난 변환 시 $R_F+R_M$이 $1/g_{m1}$과 직렬로 합쳐진다는 점을 놓치는 오류.
  - `closed_path`: (1) $K<0$만 보고 양의 귀환이라고 단정하는 오류(루프 이득 $KA_{I,open}>0$으로 판단), (2) $I_F$의 양의 방향을 입력으로 들어오는 쪽으로 혼동하는 오류, (3) 폐루프 입력 임피던스가 커진다고 착각(병렬 전류 반송이므로 $1+KA_{I,open}$으로 나눠 작아짐).

## 수식·모델 가정·근거
- 소신호 선형 모델, $M_1$의 $r_{O1}$ 무시, $M_2$의 $r_{O2}$ 포함. 폐루프 MNA 해석에는 $R_F$를 통한 미소한 순방향(feedforward) 전류가 자연히 포함되며, 2포트 귀환 근사 $A_{I,open}/(1+KA_{I,open})$와 소수점 둘째 자리 이내로 일치함을 진단에 명시한다.
- 근거: 강의노트 L06 s59–60, 정리노트 `s2-cc-gain`·`s2-cc-closed`, Razavi 12장 예제 IV.
