문제를 읽어요

이번 CG(common gate) 회로는 입력이 게이트가 아니라 소스로 들어가요. 게이트는 고정 바이어스 $V_b$에 연결되고, 출력은 드레인이에요.

$v_{in}$은 $R_S$ 앞의 독립 입력이고, $v_X$는 그 저항 뒤의 실제 소스 전압이에요. 소스와 출력에 접지 커패시터가 하나씩 있으므로 각 노드의 저항 경로를 찾아요.

이 개념과 공식을 떠올려요

게이트가 AC 접지이고 소스에서 신호를 받는다는 단서에서, 소스 쪽 입력저항(source input resistance)이라는 알려진 블록을 떠올려요. $\lambda=0$이고 몸체효과를 무시하면 그 값은 $1/g_m$이에요.

$g_m$은 $M_1$의 트랜스컨덕턴스예요. 이 $1/g_m$은 소자 내부의 소신호 저항을 나타내며, 외부에 붙인 소스 축퇴 저항이 아니에요.

$$g_m\left(\frac1{g_m}\right)=1$$

따라서 내부 $1/g_m$에 외부 축퇴 저항의 큰 곱 근사를 적용해 항을 없애지 않아요. $R_S$와 $1/g_m$의 상대 크기는 실제 값에 따라 달라요.

예를 들어 $R_S=1/g_m$이면 같은 저항 두 개의 병렬이라 등가 저항이 $1/(2g_m)$이 돼요. 같은 $C_{in}$에서 저항이 절반이 되면 코너 각주파수는 2배예요.

CG 단의 입력 극점처럼 그림의 두 커패시터는 각각 접지에 연결되고, 게이트 전도 전류는 무시해요. $\lambda=0$에서는 드레인 전압이 소스 전류를 바꾸지 않으므로 출력의 움직임이 입력 저항에 되돌아오지 않아요.

종이에 쓸 첫 줄

독립 입력원을 0으로 놓아 $R_S$의 왼쪽을 접지로 연결해요. 고정 바이어스 $V_b$와 전원 $V_{DD}$도 AC 접지로 봐요.

$$v_{in}=0$$

저항 경로를 읽을 때 커패시터 자체는 개방해서 생각해요. 소스 노드 X에는 $R_S$로 가는 경로와 $M_1$의 소스 쪽을 보는 경로가 함께 남아요.

이렇게 풀어요

입력 노드 $v_X$

먼저 게이트가 AC 접지이고 몸체효과를 무시하는 $\lambda=0$ 모델에서, 소스를 바라보는 알려진 저항 블록을 써요.

$$R_{in,S}=\frac1{g_m}$$

입력을 단락한 뒤 $R_S$와 이 소스 쪽 저항은 모두 X에서 AC 접지로 보이므로 병렬이에요.

$$R_{eq,in}=R_S\parallel\frac1{g_m}$$

같은 X–접지 두 노드에 $C_{in}$이 연결되므로 입력 코너가 정해져요.

$$\omega_{p,in}=\frac1{(R_S\parallel1/g_m)C_{in}}=\frac{1+g_mR_S}{R_SC_{in}}$$

$R_D$와 $C_L$은 이 소스 쪽 저항에 들어가지 않아요. $\lambda=0$에서는 드레인 전압 변화가 소스 전류로 되돌아오지 않기 때문이에요.

출력 노드 $v_{out}$

출력의 저항을 읽는 단계에서는 커패시터를 개방하고 독립 입력을 0으로 두어요. 소스는 입력의 접지 경로를 통해 0이 되고 게이트도 AC 접지라 제어 전압이 0이에요. $\lambda=0$에서 소자의 드레인 저항은 무한대이므로 출력의 저항 경로는 $R_D$예요.

$$R_{eq,out}=R_D$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

이 두 식은 소스 쪽 저항이 드레인 전압에 의존하지 않는 선택 모델에서의 극점이에요. 모든 접지 커패시터 회로가 노드별로 분리된다는 뜻은 아니에요.

완성 답과 검산

양의 코너 각주파수는 다음과 같아요.

$$\omega_{p,in}=\frac1{(R_S\parallel1/g_m)C_{in}}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

$\lambda=0$·게이트 AC 접지·몸체효과와 게이트 전도 전류 무시 조건이에요.

$s$ 평면의 극점은 각 양의 코너에 음의 부호를 붙인 위치예요.

$$s_{p,in}=-\frac1{(R_S\parallel1/g_m)C_{in}}$$ $$s_{p,out}=-\frac1{R_DC_L}$$

동일한 병렬 저항으로 검산해요. $R_S=1/g_m$을 넣으면 다음과 같아요.

$$R_{eq,in}=\frac1{g_m}\parallel\frac1{g_m}=\frac1{2g_m}$$ $$\omega_{p,in}=\frac{2g_m}{C_{in}}$$

두 경로가 병렬이라 한 경로만 있을 때보다 저항이 절반이고, 같은 커패시턴스의 코너는 2배라는 예상과 맞아요.

단위와 순서를 확인해요. 두 등가 저항에 각각 커패시턴스를 곱하면 단위는 $\Omega\cdot\mathrm F=\mathrm s$예요. 역수인 코너 각주파수는 $\mathrm{rad/s}$이고, 입력과 출력 중 어느 코너가 더 낮은지는 소자값으로 정해요.

주의할 점

  • 독립 입력 $v_{in}$을 0으로 두는 것과 실제 소스 전압 $v_X$를 바로 0으로 놓는 것은 달라요. $R_S$가 남은 연결을 먼저 읽어요.
  • 게이트가 AC 접지라는 이유로 소스 쪽 $1/g_m$ 경로를 없애지 않아요. 이번에는 게이트가 아니라 소스를 바라봐요.
  • $1/g_m$은 내부 소신호 저항이에요. 외부 축퇴 저항의 $g_mR_e\gg1$ 조건을 이 값에 적용하지 않아요.
  • $1+g_mR_S$의 1을 조건 없이 지우지 않아요. $R_S=1/g_m$인 경우에는 그 두 항이 같은 크기예요.
  • 입력 코너가 CS의 같은 $R_S$·$C_{in}$보다 높아져도, 출력 코너보다 반드시 높거나 낮다고 정할 수는 없어요.

조건을 바꾸어 생각해요

  1. $g_m$·$C_{in}$·$R_D$·$C_L$을 고정하고 $R_S=1/g_m$인 상태에서 $R_S\gg1/g_m$인 상태로 바꾸면, 입력 코너는 처음의 약 몇 배로 가까워질까요? 같은 $\lambda=0$ 모델을 사용해요.

CG 소스 노드의 $R_S\parallel1/g_m$과 입력 커패시턴스가 입력 극점을 정해요.

$\lambda=0$·게이트 AC 접지·몸체효과와 게이트 전도 전류 무시 조건이에요.

$$\omega_{p,in}=\frac1{(R_S\parallel1/g_m)C_{in}}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

내부 $1/g_m$에 외부 축퇴 저항의 큰 곱 근사를 적용하지 않아요.

양의 코너와 음의 $s$ 평면 근을 구별해요.
