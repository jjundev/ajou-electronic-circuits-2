# 시험점에서 구한 루프 곱의 폐루프 분모 대입

2026-11-28 사용자는 1106 P7·P8처럼 시험점부터 부호 있는 노드 전압비를 곱하고, 그 루프 곱을 폐루프 이득의 분모에 바로 넣도록 요청했다. 적용 예제는 [1106 해설 P7·P8](../../../복습노트/1106/문제설명_1106_Negative_Feedback.html#p7)이다.
