# 장말문제 10.43 — 식 10.139를 I_D1 = 0, I_SS/2, I_SS 세 경우에 대해 검토

## 조건
- MOS 차동쌍의 대신호 식 (10.139)
- 세 경우: (a) $I_{D1} = 0$, (b) $I_{D1} = I_{SS}/2$, (c) $I_{D1} = I_{SS}$

## 구할 것
- (a), (b), (c) 각 경우에 식 (10.139)를 검토
- 각 경우의 의미 설명

## 상속·참조
- 식 (10.139) (교재 531쪽):
  $$(V_{in1} - V_{in2})^2 = \frac{2}{\mu_n C_{ox}\dfrac{W}{L}}\left(I_{SS} - 2\sqrt{I_{D1} I_{D2}}\right) \qquad (10.139)$$
- 유도 가정 (교재 530쪽): 채널 길이 변조 무시($\lambda = 0$), 제곱 법칙 $I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$, 두 트랜지스터 동일. KVL $V_{in1} - V_{GS1} = V_{in2} - V_{GS2}$ (10.133), KCL $I_{D1} + I_{D2} = I_{SS}$ (10.134)
- 식 (10.131)–(10.147)의 회로: 본문 Fig 10.31 (교재 530쪽, PDF 18, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-31.png, "대신호 분석을 위한 MOS 차동쌍"). 연결: `R_D: VDD – Vout1`, `R_D: VDD – Vout2`, `M1: D = Vout1, G = Vin1, S = 공통 소스 노드`, `M2: D = Vout2, G = Vin2, S = 공통 소스 노드`, `I_SS: 공통 소스 노드 → 접지` (공통 소스 노드 라벨 없음)
