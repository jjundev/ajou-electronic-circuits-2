# 교과서 문제 MD 형식

목표: **md 파일 하나만 보고 원본 문제(조건, 질문, 회로도)를 그대로 복원**할 수 있게 한다.
그림 PNG는 대조용이다. md는 이미지 없이도 완결돼야 한다.

## 폴더와 파일 이름
```
교과서/마이크로전자회로/
  FORMAT.md
  _tools/crop_figures.py      # figures.yaml → 그림 PNG
  _tools/check_md.py          # 형식 검사
  _tools/make_index.py        # frontmatter → ch<장>/README.md 문제 인덱스
  _tools/verify_chapter.py    # 장 단위 정합성 검사 (번호, 그림, 절 순서, README, --recrop)
  ch<장>/
    README.md                 # 문제 인덱스 (make_index.py로 생성, 손으로 고치지 않음)
    예제/E<장>.<NN>.md        # 본문 예제
    연습문제/X<장>.<NN>.md    # 예제 <장>.<NN> 바로 뒤의 연습문제
    장말문제/P<장>.<NN>.md    # 장말 PROBLEMS
    figures/figures.yaml, figures/fig<장>-<NN>.png, figures/fig<장>-<NN>-<크롭>.png
```
번호는 두 자리로 채운다 (9.1 → `9.01`).
원문에서 예제 바로 뒤에 연습문제가 없으면 X 파일을 만들지 않는다 (예: 예제 11.29). `verify_chapter.py`가 이런 예제를 참고(INFO)로 알려 주니, 원본에서 한 번 더 확인한다.

## frontmatter
```yaml
id: P9.04                 # E/X/P + 장.두자리
kind: 장말문제            # 예제 | 연습문제 | 장말문제 (id 접두어와 일치)
number: "9.4"             # 반드시 따옴표, id 와 일치 (P9.04 → "9.4", P9.10 → "9.10")
section: "9.1.1 전류원으로서의 캐스코드"   # 절 번호가 없는 머리는 원문 머리 그대로 (예: "Design Problems")
book_page: 485            # 교재 쪽
pdf_page: 20              # PDF 페이지(1부터)
difficulty: 1             # 장말문제만: * 개수 (0, 1, 2)
sol: false                # 장말문제만: SOL 마크 여부
source_lang: en           # 원문 언어 (ko | en)
figures:                  # 크롭 이미지가 있는 그림만. id 는 반드시 따옴표 ("9.30" 이 숫자 9.3 으로 바뀌는 것 방지)
  - {id: "9.42", role: problem, panels: [a, b, c, d]}   # role: problem | answer
depends_on: []            # 전제로 하는 문제·예제 id (예: [E9.15])
refs: []                  # 참조하는 식·그림·장 (자유 문자열, 예: "식 9.88")
```

- 같은 그림 id인데 패널마다 role이 다르면 figures 항목을 두 줄로 나눈다 (예: E9.07 `"9.13"` (a) problem, (b) answer)
- 이미지에 이 문제가 쓰지 않는 패널(본문 패널, 풀이 패널)이 있으면 `role: problem` 항목에 `crop: <이름>`을 단다. `figures.yaml`의 그 그림 항목에 `crops: {<이름>: [x0, y0, x1, y1]}`(같은 쪽)을 두면 `crop_figures.py`가 `fig<장>-<NN>-<이름>.png`를 만든다
  - 이름은 소문자·숫자만. 패널 하나면 그 글자(`a`), 여럿이면 이어서(`abc`), 등가회로가 붙으면 대표 패널(`a`), 패널 글자가 없는 분할은 뜻 이름(`ce`, `cs`)
  - `panels`는 그대로 문제가 쓰는 패널이다. `crop`은 링크할 이미지만 고른다
  - `role: answer` 항목에는 `crop`을 달지 않는다 (`check_md.py`가 막음)
  - 쓰는 패널을 한 직사각형으로 깔끔하게 자를 수 없고, 그 그림에 답 패널이 없으면 크롭하지 않고 전체 PNG와 `> 참고:` 줄을 둔다
  - 쓰는 패널을 한 직사각형으로 깔끔하게 자를 수 없고 답 패널이 있으면(전체 PNG를 두면 답이 보임), 같은 그림을 `role: problem` 항목 여러 줄로 나눠 각각 다른 `crop`과 이미지 링크를 단다 (예: E10.09·X10.09 `"10.16"` `crop: a`는 [a] 패널, `crop: bc`는 [b, c] 패널)
  - 이웃 패널 몇 픽셀 없이는 깔끔한 직사각형이 안 나오면(예: fig11-56-a의 (b) 식 글자 조각, E11.27·X11.27) 그 조각을 넣고 `> 참고:` 줄에 적는다
  - 같은 그림의 `role: answer` 패널이 이 문제 `panels`에 없는데 `crop`이 없으면 `verify_chapter.py`가 오류로 본다 (문제 이미지에 풀이가 보이면 안 됨). 이 검사는 `panels`를 적은 answer 항목만 본다 — `panels: []`(그림 전체)인 answer 항목은 검사하지 않는다
- 문제가 여러 쪽에 걸치거나 그림이 다음 쪽에 인쇄돼 있으면 `book_page`, `pdf_page`는 문제 문장이 **시작하는** 쪽으로 적고, 이미지 아래 `> 참고:` 줄에 그림 위치를 적는다
- `depends_on`은 같은 장 안의 id만 쓴다 (도구가 같은 장만 찾음). 다른 장(예: 10장 문제가 9장 식)을 참조하면 `refs`와 `## 상속·참조`에만 적는다
- 영문 PROBLEMS의 "Repeat Problem N"은 `depends_on: [P<장>.NN]`으로 두고, 앞 문제의 요구를 `## 상속·참조`에 풀어 적는다. 같은 그림을 다시 쓰면 넷리스트와 bullet까지 그대로 복사한다 (role problem)
- 영문 PROBLEMS의 "Example 10-9"처럼 하이픈으로 적힌 예제 번호는 예제 10.9로 보고 `depends_on: [E10.09]`, 원문 표기는 메모로 남긴다

## 본문 절 (순서 고정)
1. `# <종류> <번호> — <짧은 제목>`
2. `## 조건` — 주어진 값, 가정, 회로 설명. 원문을 옮기지 않고 bullet로 재구성. 수치·단위는 빠짐없이
3. `## 구할 것` — 소문항 (a)(b)… 모두
4. `## 상속·참조` — (있을 때만) depends_on 문제의 조건, 참조 식(LaTeX), 공통 가정을 **이 파일 안에 풀어서** 적음
   - 문제를 풀 때 필요한 식·조건만 적는다. 답 줄에서 출처로만 쓰는 식 번호는 frontmatter `refs`에만 둔다
   - 예제 풀이의 결과를 이어받을 때는 그 결과가 쓴 가정($V_T$ 등)도 함께 적는다
   - 크롭하지 않은 참조 그림(본문 그림)도 여기에 적는다. 연결은 `Q_F: C = VCC, B = P, E = X` 형태로 쓴다
   - 본문 그림은 문제가 **바로 그 회로를 쓸 때만** 크롭해서 `role: problem`으로 넣는다. 풀이에 참고만 하는 그림은 크롭하지 않고 여기에 글로 풀어 적는다 (`크롭 안 함`). 그 그림이 다른 문제용으로 이미 크롭돼 있으면 `이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-31.png`처럼 적는다
   - Design Problems 머리에 공통 가정이 인쇄돼 있으면 그 블록을 모든 설계 문제 파일에 **글자 하나까지 같게** 복사한다 (9장 P9.54–P9.68). 인쇄돼 있지 않으면 (10장·11장) 넣지 않는다
5. `## 회로 — Fig <번호>(<패널>)` — 패널마다 하나씩. 넷리스트 + bullet 3개. 마지막 패널 뒤에 이미지 링크
   - 패널이 없는 그림은 `(<패널>)`을 생략하고 frontmatter는 `panels: []`
   - 크롭 이미지에 대한 메모(예: "이미지 오른쪽 (b)는 본문 등가회로")는 bullet이 아니라 이미지 링크 바로 아래 `> 참고: …` 한 줄에 둔다. `crop`이 있으면 이미지 링크는 크롭 PNG(`../figures/fig10-16-a.png`)를 가리키고, 쓰지 않는 패널을 설명하는 참고 줄은 두지 않는다
   - **문제에 회로 그림이 없으면** `## 회로 — 없음 (<이유>)` 한 줄만 둔다 (예: `## 회로 — 없음 (설계 문제, 그림은 풀이에만 있음)`). 이때 넷리스트와 bullet은 적지 않는다
   - **문제 그림이 회로 없이 그래프·파형·영상뿐이면**: 크롭해서 `role: problem`으로 두고 `## 회로 — 없음 (특성 그래프 문제, …)` 한 줄만 둔다. 곡선·레벨·축 설명과 이미지 링크는 `## 상속·참조` 끝에 둔다 (예: P10.17, P10.24)
   - 한 그림에 회로 패널과 파형 패널이 섞여 있으면 넷리스트는 회로 패널에만 쓰고, 파형 패널은 `## 조건`과 `> 참고:` 줄에 글로 적는다 (예: E10.09)
   - 연습문제가 회로와 상관없는 일반 질문이면 `## 회로 — 없음 (…)`으로 둔다. 예제 회로를 다시 쓰는 연습문제는 X9.01처럼 넷리스트까지 적는다
6. `## 답 (검증용)` — 예제만. 최종 답 1–2줄. 풀이에 설계 결과 회로가 있으면 `### 정답 회로 — Fig <번호>`로 넷리스트 + bullet 3개 + 이미지
   - 풀이 그림이 그래프뿐이면 넷리스트 없이 축·곡선을 답 절에 글로 적고 이미지를 단다 (예: E10.19)

**원문에 없는 보충:** 작성자가 해석해서 덧붙인 내용(원문에 없는 단위, "두 트랜지스터 동일" 같은 가정, 답의 형태 등)은 그 줄 끝에 `(원문에 없음)`을 붙인다.
- 줄의 일부만 보충이면 `(괄호 안은 원문에 없음)`처럼 범위를 밝힌다
- 원문이 "설계하라"만 적은 문제는 구할 것에 정할 값을 예로 적는다: `- 회로 설계 (정할 값 예: $I_{EE}$, $R_C$) (원문에 없음, 원문은 "설계하라"만 적음)`
- 원문의 "Note that …" 같은 메모 문장은 `## 조건` 끝에 `(원문의 메모)`를 붙여 적는다

**원문 오식:** 인쇄된 그대로 적는다 (식·번호·라벨 모두 조용히 고치지 않는다). 해석은 **별도 줄**에 `문맥과 맞지 않음(오식으로 보임) … (원문에 없음)`으로 적는다 (예: P9.26, P10.10, E11.11).
- 확인할 수 없는 추정("영문판 번호가 남은 듯" 등)은 쓰지 않는다
- 문맥상 성립할 수 있으면 오식으로 단정하지 않는다. 인쇄대로 따르고, 비슷한 문제가 있으면 참고 한 줄만 `(원문에 없음)`으로 단다 (예: P10.56 "Repeat Problem 10.53")
- 식이 겉보기에 다르더라도 전개해서 같은 식이면 오식이 아니다 (예: 식 10.177은 식 9.4 꼴)

## 넷리스트 (```spice 블록)
| 소자 | 형식 | 비고 |
|---|---|---|
| BJT | `Q<이름> C B E npn\|pnp [area=k] [m=k]` | area = 이미터 면적 배수 (10A_E → `area=10`, nA_E → `area={n}`) |
| MOSFET | `M<이름> D G S nmos\|pmos [W/L=a/b] [m=k]` | 바디 단자는 적지 않음. 크기 라벨이 기호면 `W/L={(W/L)_n}`, 배수가 붙으면 `m=3` (3(W/L)_n → `W/L={(W/L)_n} m=3`) |
| R / C / L | `R<이름> n1 n2 [값\|{기호}]` | 값이 기호뿐이면 중괄호 `{R_P}` |
| 전류원 | `I<이름> from to [값]` | **그림의 화살표가 from → to** (SPICE 규약과 같음) |
| 전압원·배터리 | `V<이름> + - [값]` | 첫 노드가 + 단자 |
| 블랙박스 | `X<이름> 노드… box "라벨"` | "Circuit", "Current Mirror", "?" 상자 |
| 연산증폭기 | `X<이름> in+ in- out opamp` | |

- 값은 공백 없는 한 토큰으로 쓴다 (예: `0.2mA`, `1k`, `{R_P}`). `area`, `W/L`, `m`에 숫자가 아닌 기호가 오면 중괄호 `{…}`로 감싼다
- 주석: 줄 앞 `*` 또는 줄 뒤 `; …`
- **노드 이름**
  - 그림에 라벨이 있으면 그대로, 첨자는 붙여 씀: `X`, `P`, `Vout`, `Vin`, `Vb1`, `VREF`, `V1`, `VCC`, `VDD`
  - 라벨 없는 내부 노드: `n1`, `n2`, …
  - 라벨 없는 측정 단자(R_out, I_copy, I_X, C_in, Z_in 화살표가 붙은 개방 단자): `out` (여럿이면 `out1`, `out2`). 입력 쪽 측정 단자여도 `out`을 쓰고, 단자 bullet에 "입력 쪽 측정 단자"라고 적는다
  - 두 개방 원 사이에 "V_out" 라벨이 **하나만** 인쇄된 차동 출력: `out1`/`out2` + 주석 (`(차동 출력)`). 인쇄되지 않은 `V_out = V_out1 − V_out2` 같은 이름·부호는 만들지 않는다
  - 개방 원이 이미 라벨(X, Y 등)이 붙은 노드에 선으로 이어지면 그 라벨을 노드 이름으로 쓴다 (`out1`/`out2`보다 우선)
  - 원도 라벨도 없는 출력 노드: `n2` 같은 내부 노드 이름 + `(원문에 없음)`
  - 그림에 소문자로 인쇄된 소신호 라벨(v_in)은 `vin`, 대문자(V_in1)는 `Vin1`. "+v_in"/"−v_in"은 `vinp`/`vinm` + 인쇄 라벨 주석
  - 같은 라벨이 두 번 인쇄된 소자(예: R_D, C_L 둘)는 `RD1`/`RD2`처럼 번호를 붙이고 주석에 인쇄 라벨을 적는다. 라벨이 인쇄되지 않은 전류원은 `I1`, `I2` + `라벨·값 없음` 주석
  - 접지: `0`. 옆으로 누운 접지 기호, 접지 기호에 바로 이어진 노드도 `0` + 주석
- **교류 접지 단락(ac GND) 선에 전류 화살표가 붙어 있으면** 그림에 없는 0 V 전압원으로 적는다: `VAC 0 n1 0`. 노드 순서는 화살표 방향(접지 → 노드)에 맞추고, 주석 두 줄("그림에 없는 소자", "소신호 단락만 의미")을 단다 (예: E9.07, E9.08). 화살표가 없으면 VAC 없이 노드 `0`
- 기호가 분수·식인 값은 중괄호로 그대로 적는다: `{R_E/2}`, `{r_O3||(1/g_m3)}`. 소문자로 시작하는 소자(r_O)는 `RO X Y {r_O}`처럼 대문자 이름을 쓴다
- 변압기처럼 자기 결합된 코일은 L 두 개(가운데 탭이 있으면 탭 양쪽으로 나눈 L)로 적고, 결합 관계는 SPICE K 문 대신 주석으로 적는다: `* LP와 LS는 자기 결합된 변압기 (결합은 K 문 대신 주석, 원문에 없음)` (예: E10.01, E10.02)
- 그림에 ⇒로 이어진 등가회로가 문제 그림 안에 있으면 별도 패널(`(a-eq)`)로 적는다. 패널 글자가 없는 그림이면 `(eq)`로 쓴다 (`panels: [eq]`).

## 넷리스트 뒤 bullet 3개 (필수)

### `- 단자:` 개방 단자·전원의 의미와 **기호**
각 단자를 `이름 = 의미 (기호)` 형식으로 적는다. 기호는 아래 어휘 중 하나만 쓴다.

| 기호 | 그림 모양 |
|---|---|
| `점 단자` | 채운 점 ● 에서 선이 시작 (바이어스 Vb1, VREF 등) |
| `개방 원` | 빈 원 ○ 단자 (Vin, Vout, R_out 측정 단자 등) |
| `선 끝` | 원·점 없이 선이 끝남 (I_copy, I_X 화살표만 붙은 컬렉터 등) |
| `T 전원 기호` | 짧은 가로 막대(ㅜ) + 라벨 |
| `가로 레일` | 여러 소자가 매달리는 긴 가로선 + 라벨 |

예: `- 단자: Vb1, Vb2 = 이상적 DC 바이어스 (점 단자) / out = 출력 (개방 원) / VCC = 2.5 V 전원 (T 전원 기호)`

### `- 표시:` 그림 위의 글자·화살표 (순서 고정)
`노드 라벨 … / 소자 라벨 … / 부호 … / 화살표 … / 수치·면적 라벨 …` 다섯 칸을 이 순서로 적는다. 칸에 해당하는 것이 없으면 `없음`.
- 노드 라벨: 그림에 인쇄된 노드·단자 이름 전부 (Vb1, X, P, VCC …)
- 소자 라벨: 그림에 인쇄된 소자 이름 전부 (Q1, R_P, Q_F, M1 …). 라벨이 인쇄되지 않은 소자는 `QR1–QR4 (라벨 없음)`처럼 적는다. 라벨 없는 전류원도 이 칸에 `I1, I2 (라벨 없음)`으로 적는다 (수치 칸이 아님)
- 부호: 그림에 인쇄된 +/− 표시와 그 위치 — 연산증폭기 입력(− 위, + 아래), 배터리 양쪽, 전압 극성(+ V_BE −) 등
- 화살표: 각 화살표마다 `이름: 대상, 방향, 모양`
  - 이름이 그림에 **인쇄돼 있으면 따옴표**로 적는다 (`"I_copy1"`). 인쇄돼 있지 않으면 따옴표 없이 적고 `(라벨 없음)`을 붙인다
  - 모양은 `도선 위` (도선 자체에 화살촉) 또는 `도선 옆 별도 화살표 (┌ 꺾임 / L자 / 직선)` 중 하나
  - 어휘에 없는 모양은 가장 가까운 어휘로 풀어 쓴다: `L자를 좌우 반전`, `┌ 꺾임을 좌우 반전`, `곡선`, `U자, 회색`
  - **소자 기호의 일부인 화살표는 적지 않는다** (전류원 원 안의 화살표, BJT 이미터 화살표, MOSFET 소스 화살표). 전류원 방향은 넷리스트 `I from to`가 이미 정한다
- 수치·면적 라벨: "0.2 mA", "4A_E", "10A_E" 등과 그 위치

### `- 배치:` 그림 모양
- 위→아래 적층 순서, 좌우 위치, 레일·접지 위치, 선이 꺾이는 모양
- 소자가 좌우 반전되어 그려졌으면 (예: 베이스가 오른쪽) 적는다
- **접속점:** 세 갈래 이상 선이 만나는 곳은 원본 표기대로 `(점)` 또는 `(점 없음)`을 적는다. 두 선이 이어지기만 하는 꺾임·끝점, 선이 T 전원 기호·접지에 닿는 곳, 가로 레일에서 아래로 갈라지는 곳은 적지 않는다 (점 없음이 기본)
- **교차:** 마지막에 `교차: 없음` 또는 점 없이 지나가는 교차 목록을 적는다
- **선 경로:** 공통선(베이스 공통선, 컬렉터 공통선 등)은 어느 높이로 지나가는지 적는다 (예: "베이스 공통선은 각 트랜지스터의 베이스 높이로 가로지름")

## 풀이 그림
- 풀이 안의 그림(설계 결과)은 `role: answer`, `## 답 (검증용)`에만 둔다.
- 다른 문제가 그 그림을 문제 그림으로 쓰면, 그 문제에서는 `role: problem`이다 (예: E9.16의 Fig 9.30).

## 문제집용 절 (선택)
문제지·답안지 PDF(`workbook/`)에 쓰는 절이다. 없어도 된다. 있으면 `check_md.py`가 위치와 모양을 검사한다. 기출도 같다.

| 절 | 위치 | 내용 |
|---|---|---|
| `## 원문` | H1 바로 다음 (첫 절) | 인쇄된 문제 문장을 글자 그대로 옮긴다. 문단은 빈 줄로 나누고 수식은 `$…$`로 쓴다. 소문항 (a)(b)…도 원문 그대로 |
| `## 힌트` | 본문 끝 (`## 풀이`보다 앞) | 힌트 하나 = `### <이름표>` 소절. 소절 안에 `> 띠: $<LaTeX>$` 줄을 두면(선택) 문제 쪽 Hint 띠에 이름표 대신 그 식이 보인다. 나머지 줄은 답안지 Hint 쪽 본문이다 |
| `## 풀이` | 본문 맨 끝 | 단계 하나 = `### <이름표>` 소절. 마지막 소절 하나만 `### 답` |

```markdown
## 힌트
### 식 9.5
> 띠: $R_{out} = [1 + g_{m1}(r_{O2} \parallel r_{\pi 1})] r_{O1} + r_{O2} \parallel r_{\pi 1}$
- 바이폴라 캐스코드의 출력 저항

## 풀이
### 소신호 파라미터
- $g_{m1} = I_{C1}/V_T$
### 답
$R_{out} \approx 490\ \text{k}\Omega$
```
- 쓸 수 있는 문법: `- ` 목록(2칸 들여쓰기로 한 단계), 목록 아래 들여쓴 이어지는 줄, 일반 문단(빈 줄로 나눔), `**굵게**`, `$…$`, `$$…$$`. 이미지 줄은 빠지고, 표와 코드 블록은 그대로 글자로 나오므로 쓰지 않는다.
- PDF에서는 `## 조건`의 `- 회로:` 줄(문제 그림이 있고, 그 줄과 아래 들여쓴 줄에 값(`=`, `%`, `≈`, 수식 속 숫자)이 없을 때만)과 `(원문에 없음)`, `(원문의 …)`, `(보조 출처: …)` 표시가 빠진다. md에서는 지우지 않는다.
- `## 원문`에는 인쇄된 문제 문장만 둔다. 예제는 "풀이" 앞 문장, 연습문제는 그 문장, 장말문제는 번호를 뺀 본문과 소문항이다. 그림 캡션과 그림 안 글자는 넣지 않는다. 원문 오식은 그대로 두고, 오식 메모는 `## 조건`에 적는다.
- `## 원문` 안에는 작성자 표시(`원문에 없음`, `(원문의 …`, `보조 출처`), `*기울임*`, `###` 소절, 이미지 줄을 쓰지 않는다. 원문은 PDF에 그대로 나오기 때문이다(`check_md.py`가 막는다). 굵게는 인쇄물이 굵을 때만 쓴다. 곱셈 기호 `*`는 수식(`$…$`) 안에 쓴다(수식 밖의 `a*b*c`는 기울임으로 잘못 걸린다).
- 예제에 `## 풀이`가 없으면 답안지 답 칸에 `## 답 (검증용)`의 글(`### 정답 회로`, 코드 블록, `> 참고:`는 뺌)이 들어간다.

## 수식
- `$…$` / `$$…$$` LaTeX. 단위는 SI (μA, kΩ, V⁻¹ → `\text{V}^{-1}`).
- 조건·구할 것·상속·참조·답 문장의 기호는 LaTeX로 쓴다. 제목과 `단자`·`표시`·`배치` bullet은 넷리스트 이름·그림 라벨을 plain text로 쓴다 (예: R_P, I_copy1).
