# 두 극점과 보데 근사
선정: 조작 관계 +2, 노드 연결 +2, 해석 단계 +2, 기존 위젯 대비 노드 손실 합/전체 대역폭 구별 +1 = 7점.
근거: 1014 STT Part05–07; 정리노트 s1-bode·s2-cs-two-poles; L05 s8–9; Razavi p578–581 보데 규칙·폴과 노드의 관계(그림11.11).
모델: Vout/Vin=-gm RD/((1+jω RS Cin)(1+jω RD CL)). gm=5mS, ro=∞, 몸체 효과/Cgd 제외. 입력 RC와 출력 RC 독립.
조작: RS100Ω–10kΩ, Cin10fF–1pF, RD100Ω–100kΩ, CL10fF–1pF, 주파수/낮은극점 .01–100. 기본/입력극점먼저/극점겹침/RD증가. 응답·기여 모드, 단계4개.
기본: RS1kΩ Cin100fF RD2kΩ CL500fF. 입력 1e10rad/s 출력 1e9rad/s.
구별: 극점이 겹치면 극점에서 상대 -6.0206dB; 전체 -3.0103dB 주파수는 더 낮음. 각 노드 손실 dB의 합을 표시. 근사 점선/정확 실선.
정리노트 연결: s2-cs-two-poles와 s1-bode의 formal 뒤; 각 극점/전체대역폭과 근사오차 관찰.
