## p6(1)

원회로의 $Q_3$은 출력 컬렉터에서 $R_1$을 거쳐 베이스로 돌아가고 이미터는 $V_{CC}$의 AC 접지다. 다른 베이스 연결이 없으므로 새 CIRCUIT-01의 두 단자 알려진 블록이 성립한다. 원문은 정확식을 요구하지 않고 $\beta=100$은 기본 큰 $\beta$ 식의 $R_1/\beta$에 쓴다. 업데이트된 기본식은 다음과 같으며 내부 $1/g_m$을 **합의 독립 항으로 보존**한다.

$$R_{Q3}\approx\left(\frac1{g_{m3}}+\frac{R_1}{\beta}\right)\parallel r_{O3}.$$

나머지 입력 소자 저항을 마지막에 병렬로 붙인다.

$$R_{out,1}\approx r_{O1}\parallel R_{Q3}.$$

독립 스크립트에서 $g_m=1/52\,\mathrm S$, $1/g_m=52\,\Omega$, $R_1/\beta=100\,\Omega$, $r_{O1}=r_{O3}=20\,\mathrm{k\Omega}$를 사용했다. 반올림 전 결과는 $R_{Q3}=380000/2519\,\Omega$, $R_{out,1}=190000/1269\,\Omega$, $R_{out,12}=380000/1269\,\Omega$, $A_v=-47500/16497\,\mathrm{V/V}$이다.

| 출력 | 기본식 결과 |
|---|---:|
| $R_{Q3}$ | $150.85\,\Omega$ |
| $R_{out,1}$ | $149.72\,\Omega$ |
| $R_{out,12}$ | $299.45\,\Omega$ |
| $G_m$ | $1/52\,\mathrm S\approx19.23\,\mathrm{mS}$ |
| $A_v$ | $-2.88\,\mathrm{V/V}$ |

**내부 모델 비교 전용:** hybrid-π KCL을 독립으로 풀면 보정 블록은 $r_{O3}\parallel[(R_1+r_{\pi3})/(\beta+1)]$이고 전체 한쪽 저항 $148.26\,\Omega$, 이득 $-2.85$다. 문제은행 MD의 수치도 이 보정 모델에 해당한다. 기본식은 $\beta\gg1$ 주항이고 원문은 정확식을 요구하지 않는다. $r_\pi=\beta/g_m$를 대입하면 보정 내부저항/기본 내부저항은 $\beta/(\beta+1)$이며, SymPy로 이 비와 전체 병렬 $R_{out}$·$A_v$ 비의 $\beta\to\infty$ 극한이 모두 1임을 확인했다. 따라서 두 자리의 $149.72/-2.88$ 대 $148.26/-2.85$ 차이는 **모델 근사 차이**이고 disputed가 아니다. 새 명세는 유한 $\beta$가 존재한다는 이유만으로 보정식을 통상 본문에 노출하지 않도록 했으므로 새 원고의 기본식 선택이 맞다.

새 원고 `work/explicit-gm/p6.html`의 p6(1)을 독립 결과 저장 후 확인했다. 알려진 블록을 시험원 그림·분압 유도 없이 사용하고 $1/g_{m3}$와 $R_1/\beta$를 모두 보인다. 한쪽 $149.72\,\Omega$, 두 출력 사이 $299.45\,\Omega$, 이득 $-2.88$이 독립 기본식과 일치한다.
