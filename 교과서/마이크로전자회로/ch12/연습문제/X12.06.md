# 연습문제 12.6 — 식 12.27과 12.29로 구한 단일 이득 대역폭 비교 (예제 12.6 변형)

## 원문
$A_0 = 1000$, $\omega_0 = 2\pi \times (10\ \text{MHz})$, $K = 0.5$일 때 식 (12.27)과 (12.29)로부터 단일 이득 대역폭을 구하고 결과를 비교하라.

## 조건
- 예제 12.6과 같은 시스템: 단일 극점 개루프 증폭기 $A_1(s) = \dfrac{A_0}{1 + s/\omega_0}$에 귀환율 $K$인 부귀환을 건 시스템 (식 12.22) (원문에 없음)
- $A_0 = 1000$
- $\omega_0 = 2\pi \times (10\ \text{MHz})$
- $K = 0.5$
- 식 (12.27): $\omega_u = \omega_0\sqrt{A_0^2 - (1 + KA_0)^2}$ (본문 식, 원문에 없음)
- 식 (12.29): $\omega_u \approx \omega_0A_0$ (본문 식, 원문에 없음)

## 구할 것
- 식 (12.27)로 구한 단일 이득 대역폭 $\omega_u$
- 식 (12.29)로 구한 단일 이득 대역폭 $\omega_u$
- 두 결과 비교

## 상속·참조
- 예제 12.6 (E12.06): 식 (12.22)의 크기를 1로 놓아 $\left(\dfrac{A_0}{1 + KA_0}\right)^2 = 1 + \dfrac{\omega_u^2}{(1 + KA_0)^2\omega_0^2}$ (식 12.26) → $\omega_u = \omega_0\sqrt{A_0^2 - (1 + KA_0)^2}$ (식 12.27) $\approx \omega_0\sqrt{A_0^2 - K^2A_0^2}$ (식 12.28, $1 + KA_0 \gg 1$) $\approx \omega_0A_0$ (식 12.29, $K^2 \ll 1$)
