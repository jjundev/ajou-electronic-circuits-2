# 전자회로2 개인 풀이 방식

버전 기준일: 2026-11-26 (연쇄 이득 곱·테브난 변환·부하 기준 접지 연결 직렬 판정 및 공통 베이스 저항 블록 반영). 손풀이의 관찰 기록과 사용자가 확정한 출력 순서를
작성자·내용 리뷰어가 함께 적용하기 위한 명세다. 학생 능력을 평가하는 문서가 아니다.

문제 해설 HTML·동반 MD는 아래 **확정한 해설 순서**를 따른다. 사용자 방식의 풀이를
정식 본문에 통합하고, 이유·개념·유도는 해당 단계에 연결한다. 답안 PDF는 같은 경로에서
핵심 회로·판단·계산·최종 답을 압축하되, HTML에 별도 핵심 풀이를 앞세우지 않는다.
원문 조건·회로·문항 ID·소문항·정답의 정확성이 개인 표기 취향보다 우선한다.
workbook 원본 MD의 `## 풀이`를 교체하도록 요청받으면 같은 풀이 경로로 동기화하고
그 앞의 문제·조건·그림은 보존한다. 일반 생성 요청만으로 원본 MD 풀이를 자동 교체하지 않는다.
원본 PDF·그림·손풀이 PDF는 수정하지 않는다. 답안 PDF는 기존 video-16x9 규격과
1920×1080 기준 하단 180px 자막 여백을 유지한다.

**수업 기본 근사(2026-10-22 사용자 확정):** 학습 본문·요약·정리노트·MD·답안 PDF에서 $g_mr_o\gg1$, $g_mR_e\gg1$을 기본 가정으로 쓴다. $R_e$는 외부 소스/이미터 축퇴 저항이며, BJT 내부 소신호 저항 $r_e=1/g_m$에는 이 가정을 적용하지 않는다. 유한 $r_\pi$가 필요한 모델에서는 $R_e^*=R_e\parallel r_\pi$를 먼저 구하고 $g_mR_e^*\gg1$의 주항으로 정리한다. $[1+g_mR_e^*]r_o$는 $R_{out}\approx g_mR_e^*r_o$로 쓴다. 캐스코드는 기존 출력저항에 캐스코드 소자의 $g_mr_o$를 곱하며 어느 소자의 인자인지 아래첨자로 밝힌다. 원문에 큰 곱 조건이 따로 없다는 이유로 1을 유지하거나 추가 조건 미제시를 경고하지 않는다. 원문이 정확식 또는 이 기본 가정과 반대인 조건·수치를 명시한 경우에는 해당 요구와 필요한 모델을 짧게 밝힌다. 유한 $\beta$·$r_\pi$ 자체는 큰 곱 근사를 취소할 근거가 아니다.

## 간결한 풀이의 우선순위 (2026-10-22 사용자 확정)

1. 원 회로의 연결과 측정 조건을 읽고 알려진 저항 블록으로 풀 수 있는지 먼저 판단한다.
   직접 연쇄 합성이 가능하면 MOS/BJT 기호를 유지한 간략 회로와 식을 쓴다.
   $g_mv_{gs}$·$g_mv_\pi$ 등으로 펼친 소신호 등가회로는 직접 판단으로 부족할 때만 그린다.
   이 우선순위는 아래의 회로 배치·시험원 표기가 불필요한 그림 생성을 강제하는 것으로 해석되지 않게 한다.
2. $R_{out}$은 독립원을 영점화한 회로에서 출력으로부터 먼 부분의 유효 저항을 먼저
   구하고, 캐스코드·축퇴 블록을 거쳐 출력까지 차례로 합성한다. 위·아래 가지는 마지막에 병렬로 묶는다.
   독립 전압원은 단락, 독립 전류원은 개방하며 실제 전류원 소자의 유한 $r_o$는 유지한다.
   $R_{out}$ 측정에서는 입력 소신호도 0이다. 입력 신호를 유지하는 조건은 이득·$G_m$ 측정과 구별한다.
3. 식의 약분·병렬 합성·배율 정리를 먼저 마치고 수치 대입은 가능한 한 마지막에 한다.
   중간량이 필요하면 기호·분수로 정의하고, 최종 계산에 반올림한 중간 소수를 재사용하지 않는다.
4. 다이오드 접속 MOS 등 익숙한 블록은 성립 조건을 확인한 뒤 바로 치환한다.
   몸체효과를 무시하는 저주파 모델의 게이트–드레인 결선 MOS는 $R_d=(1/g_m)\parallel r_o$다.
   반대 단자가 AC 접지이면 게이트–드레인 쪽 또는 소스 쪽에서 같은 저항을 본다.
   소자의 물리적 위아래 대칭성을 일반 법칙으로 삼지 않는다(CIRCUIT-01의 예외 참조).
   베이스–컬렉터 연결에 저항이 포함된 BJT도 아래 CIRCUIT-01의 조건부 블록으로 바로 계산한다.
5. 추가 확인된 선호: 대칭 차동 입력은 가상 접지와 반회로부터 판단하고,
   설계 문제는 제약 부등식 → 허용 범위 → 값 선택 이유 → 역산 → 전체 제약 검산으로 쓴다.
6. 연립방정식 회피와 블록 연쇄 우선(2026-11-26 사용자 확정): 전류·전압 연립방정식을 새로 세워
   이항·정리하기보다, 중간 노드($V_X, V_{out}$) 기준 연쇄 이득 곱·알려진 기본 단 블록·직렬 로딩
   치환($R_L\to R_L+R_M$)·전류 입력의 노턴→테브난 변환($I_{in}\parallel R_p\to V_{in}=I_{in}R_p$와 직렬 $R_p$)·부하 양단의
   교류 접지 연결 직렬 판정을 우선한다.

명시적 선호 1–4와 추가 후보 C5·C6의 사용자 선택·44쪽 시각 검토 근거는
[간결한 풀이 업데이트 기록](../../../../docs/learning/solution-style-updates/2026-10-22-clean-circuit-solving.md)에,
1125 수업 필기 기반 연쇄 블록·테브난·접지 연결 풀이 선호와 검산 근거는
[연쇄 블록·테브난·접지 연결 풀이 업데이트 기록](../../../../docs/learning/solution-style-updates/2026-11-26-block-chain-solving.md)에 보관한다.

## 문제 해설 본문 (2026-11-26)

회로에서 내린 판단 → 첫 식 → 필수 중간식 → 소문항별 답을 한 번씩 제시한다. 10월 중순까지의 중간고사 범위는 이미 혼자 풀 수 있는 범위로 보고 기본 개념과 반복 대입은 생략한다. 이후 범위도 새 판단과 답에 영향을 주는 조건만 해당 식 곁에 한두 문장으로 설명한다. 문제 설명 패널이 제공하는 조건·원문·그림을 본문에서 되풀이하지 않는다. 결과를 판별하는 짧은 검산을 쓸 수 있다. 상세 독립 검산은 별도로 남긴다. 구체 형식은 [문제설명 저작 규칙](../../ec2-problem-explain/references/authoring.md)을 따른다. 기존 일곱 구역 자료는 읽기·재조립을 지원한다.

## 한 행에 하나의 식

기본은 **독립된 계산 대상 하나당 한 행**이다. $g_m$, $r_\pi$, $r_o$나 NMOS·PMOS의
서로 다른 계산을 쉼표·\quad·\qquad로 한 display 수식에 나열하지 않는다.
HTML·동반 MD는 각각 별도 display 블록으로, workbook 풀이·답안 PDF는 별도 줄/항목으로 쓴다.
같은 양을 구하는 `식 = 대입 = 결과` 연속 등식과, 실제 값이 같은 소자를 하나의 등식으로
묶는 표기는 유지할 수 있다. 연속 등식도 화면 폭을 넘으면 계산 단계별로 세로로 나눈다.
설명문 속 짧은 기호·적용 조건은 인라인으로 쓸 수 있다. 서로 다른 계산을 한 문장에 몰아넣지 않는다.
예를 들어 다음처럼 각 계산을 별도 display 블록으로 쓴다. 브라우저의 우연한 자동 줄바꿈으로 대신하지 않는다.

$$g_m=I_C/V_T=1000/26\,\mathrm{mS}$$

$$r_\pi=\beta/g_m=2.6\,\mathrm{k\Omega}$$

$$r_o=V_A/I_C=5\,\mathrm{k\Omega}$$

## 적용 규칙

각 규칙의 적용 여부는 문항별로 판단한다. 적용할 이유가 없으면 이유를 적고
`not_applicable`로 기록한다. 실제 의미 검토를 마친 리뷰어가 적용 위치·내용 또는
비적용 이유를 남긴다. 해시와 자동 형식 검사만으로 명세를 읽거나 반영했다고 주장하지 않는다.

### UNIT-01: 공학 단위와 환산

- **관찰:** MOS 계산에 V·mA·kΩ·mS 조합을 반복한다. 100 μA/V²를 0.1 mA/V²로,
  500 Ω를 0.5 kΩ로, 25 μA를 $\frac{1}{40}\ \mathrm{mA}$로 바꾸고 인자 옆·아래에도
  $\left[\frac{\mathrm{mW}}{\mathrm{V}}\right]=[\mathrm{mA}]$, $\left[\frac{\mathrm{mA}}{\mathrm{mV}}\right]=[\mathrm{S}]$,
  $\left[\frac{\mathrm{V}}{\mathrm{mA}}\right]=[\mathrm{k}\Omega]$, $[\mathrm{V/V}]$처럼 단위를 적는다.
  BJT에서 $g_m=\frac{1}{50}\ \mathrm{S}$와 $R_{out}=5\ \mathrm{k}\Omega$을 곱할 때
  $-\frac{1000}{50}\cdot 5=-100\ [\mathrm{V/V}]$처럼 $10^3$ 환산 인자를 분자에 직접 기입한다.
- **근거:** H0909 p1·2·3·6·8, H0918 p9·10, H0923 p4·6. BJT의 S 단위 사용은 H0911 p6, H0916 p6, H0918 p10.
- **확신도:** 높음. MOS에서 반복 관찰했으나 항상 mS를 쓰는 것은 아니다.
- **생성 규칙:** 첫 사용에서 환산을 보이고 mA×kΩ=V, mS×kΩ=1,
  mS×kΩ²=kΩ를 유지한다. 식의 각 인자와 최종 답에 필요한 단위를 표시한다.
- **예외:** BJT의 $g_m=1/26\ \mathrm{S}$, $1/50\ \mathrm{S}$도 허용하되 $\mathrm{k}\Omega$과 곱할 때 $10^3$ 환산을 명시한다. 다른 규모에는 적절한 단위를
  쓰며 정성 문항에 수치를 억지로 넣지 않는다.
- **검토 기준:** 환산 계수와 차원이 맞는가? S·kΩ를 섞은 곱에서 $10^3$을 빠뜨리지 않았는가?

### CALC-01: 중간값과 역산

- **관찰:** 소자별 $r_o$, $g_m$, $r_\pi$를 먼저 구해 조립한다. 목표 $R_{out}$에서
  $g_m$, 이어 $W/L$을 역산하고 같은 소자는 등식으로 묶는다. 축퇴 저항 $R_P$가 있는
  전류 거울에서는 $\frac{I_{REF}}{I_1}$ 전류비 식과 루프 전압식을 연립해 $R_P$를 구하고,
  $\lambda\ne 0$ 거울에서는 $\frac{I_{copy1}}{I_{REF}}$ 비에서 상대 오차 $\varepsilon$을 구한다.
- **근거:** H0909 p2·3·6, H0911 p6·10, H0918 p1·2·10·12, H0923 p6.
- **확신도:** 높음.
- **생성 규칙:** 목표 식 → 필요한 중간값 → 대입 → 최종 답 순서로 연결한다.
  한 식에 모든 소자식을 무리하게 대입하지 않는다. 독립된 중간값은 위의 한 행 규칙에 따라 분리한다.
  **설계 제약에서 역산(2026-10-22 C6 사용자 확정):** 전력·출력 CM·이득·동작 영역 같은
  요구를 먼저 부등식/관계식으로 세우고 허용 범위를 구한다. 자유롭게 고를 수 있는 값은
  범위 안에서 선택 이유와 함께 정한 뒤 나머지를 역산한다. 경계값을 반드시 고르거나
  주어지지 않은 설계값을 유일한 답처럼 쓰지 않는다. 마지막에 원래의 모든 제약에 대입해 확인한다.
  **전류 거울 축퇴 저항·복사 오차(2026-10-22 사용자 확정):** 소스/이미터 축퇴 저항 $R_P$로 복사 전류비를 정하는 문항에서는 기준·복사 소자의 전류비 식($\frac{I_{REF}}{I_1}=\frac{(V_{GS,REF}-V_{TH})^2}{(V_{GS1}-V_{TH})^2}$ 또는 $\frac{I_{REF}}{I_1}=\exp\left(\frac{V_{BE,REF}-V_{BE1}}{V_T}\right)$)과 공통 게이트/베이스 루프의 전압 관계($V_{GS1}=V_{GS,REF}-I_1R_P$, $V_{BE1}-V_{BE,REF}=I_{REF}R_P$ 등)를 연립해 $R_P$를 구한다. 채널 길이 변조($\lambda\ne 0$)나 유한 $\beta$에 따른 복사 오차는 먼저 $\frac{I_{copy}}{I_{nom}}$(단위 복사면 $\frac{I_{copy}}{I_{REF}}$) 비를 구한 뒤 상대 오차 $\varepsilon=\frac{I_{copy}-I_{nom}}{I_{nom}}$으로 정리한다.
- **예외:** 원문의 서로 다른 소자·전류를 편의상 같다고 두지 않는다. 정성 문항에는
  불필요한 수치 계산 대신 필요한 관계를 쓴다.
- **검토 기준:** 각 중간값의 소자 번호·조건이 분명하고 역산 결과를 목표 식에 대입해 확인했는가?

### CIRCUIT-01: 역할과 바라보는 방향

- **사용자 확정(2026-10-22 명시적 선호 2·4):** $R_{out}$은 원 회로에서 먼 부분부터
  바라보는 저항을 차례로 합성한다. 다이오드 접속 MOS는 조건이 맞으면 바로 저항 블록으로 쓴다.
  새 시각 근거는 H0930 p3(E10.22), p4·5(P10.52), p7(X10.24)이며 기존 H0916 p1·4와도 부합한다.
- **연쇄 합성:** 측정 조건을 적용한 원 회로에서 각 단계의 관찰 단자·반대쪽 연결을 정의한다.
  먼 가지의 $R_s^*$ 또는 $R_e^*$ → 해당 캐스코드의 $g_mr_o$ 증대 → 출력 쪽 가지 저항 순으로
  진행한다. BJT에서 필요한 $r_\pi$는 먼저 $R_e^*=R_e\parallel r_\pi$에 포함한다.
  출력 위·아래 저항과 외부 부하는 같은 두 소신호 노드에 연결되는지 확인해 마지막에 병렬로 묶는다.
  원 회로·이미 그린 간략 회로 위에 바라보는 방향과 중간 저항을 표시하면 충분하며 단계마다 그림을 복제하지 않는다.
- **다이오드 접속 MOS 블록:** 저주파·몸체효과 무시 모델에서 게이트–드레인 결선을 확인하고
  $R_d=(1/g_m)\parallel r_o$로 바로 치환한다. 반대 단자가 AC 접지인 구동점 저항이라면
  게이트–드레인 쪽이나 소스 쪽에서 같은 값을 쓴다. 기본 큰 곱 근사에서는 필요에 따라 $R_d\approx1/g_m$로 줄인다.
  몸체가 AC 접지인 상태에서 소스 쪽을 흔들고 몸체효과를 포함하면
  $R_{in,S}=[1/(g_m+g_{mb})]\parallel r_o$이므로 양쪽이 같다는 규칙을 적용하지 않는다.
  반대 단자가 유한 임피던스로 움직이거나 다른 가지가 결합되면 전체 연결을 함께 고려한다.
  일반 MOS의 드레인·소스, 다이오드 접속이 아닌 BJT 컬렉터에 이 공식을 확대하지 않는다.

- **저항을 포함한 다이오드 접속형 블록(2026-10-22 사용자 명시적 선호):**
  `Notes_261022_164633.jpg`의 두 구조도 알려진 블록으로 취급해 소신호 등가회로를 새로 그리지 않고
  연결 확인 → 적용 조건 한 줄 → 근사식으로 푼다. 아래 $x$는 위 단자, $e$는 이미터 단자다.
  저주파·BJT 활성 영역에서 외부 연결이 $x,e$ 두 단자뿐이고 반대 단자가 AC 접지인 구동점 저항에 적용한다.
  그림 위·아래의 화살표는 이 두 단자에서 바라보는 방향이며 일반 BJT의 컬렉터·이미터 대칭성을 뜻하지 않는다.
  1. **베이스 경로에 $R_P$:** $x=C$, $x$에서 $R_P$를 거쳐 $B$로 연결되고 $E=e$인 구조다.
     $\beta\gg1$에서 베이스 경로의 저항을 $R_P/\beta$로 반영해 바로 쓴다.

     $$R_{xe}\approx\left(\frac1{g_m}+\frac{R_P}{\beta}\right)\parallel r_o.$$

     **$1/g_m$ 명시(2026-10-22 사용자 추가 확정):** 이 구조의 본문·요약·보충·MD·답안 PDF는
     위 $(1/g_m+R_P/\beta)\parallel r_o$를 기본식으로 쓴다. $1/g_m$을 삭제하거나
     $r_\pi$ 안에 숨긴 블록으로 대체하지 않는다. $g_mR_P\gg1$이나 유한 $\beta$의 존재만으로
     이 표기 원칙을 바꾸지 않는다. 유한 $\beta$ 보정 전체식은 기본적으로 내부 검산에만 둔다.
     원문이 정확식을 요구하거나 큰 $\beta$ 근사가 실제로 성립하지 않아 보정이 필요한
     CIRCUIT-02의 예외에서도 $1/g_m$이 보이는 다음 동치형으로 제시한다.

     $$R_{xe}=\left[\frac{\beta}{\beta+1}\left(\frac1{g_m}+\frac{R_P}{\beta}\right)\right]\parallel r_o.$$

     이는 정확식 예외의 표기 규칙이며 통상 풀이에 보정식·유도를 덧붙이라는 뜻이 아니다.
     ([추가 선호·동치 검산 기록](../../../../docs/learning/solution-style-updates/2026-10-22-explicit-inverse-gm.md)).
  2. **컬렉터 경로에 $R_P$:** $x=B$, $x$에서 $R_P$를 거쳐 $C$로 연결되고 $E=e$인 구조다.
     $R_P\ll r_o$이고 $\beta\gg1$이면 필기의 근사식으로 바로 쓴다.

     $$R_{xe}\approx\frac1{g_m}\parallel r_o.$$

     유한 베이스 전류를 유지할 때는 같은 조건에서 $R_{xe}\approx(1/g_m)\parallel r_\pi\parallel r_o$다.
     $R_P$가 $r_o$와 비슷하거나 더 크면 $R_P$의 영향을 없애지 않는다. 수업 기본 $g_mr_o\gg1$ 아래
     다음 근사 블록으로도 등가회로 없이 계산할 수 있다.

     $$R_{xe}\approx r_\pi\parallel\frac{1+R_P/r_o}{g_m}.$$

     “전류원과 직렬인 저항은 영향을 주지 않는다”는 판단은 이상적 출력저항 모델 또는
     위 생략 조건에서만 사용한다. $g_mr_o\gg1$만으로 $R_P/r_o$가 작아지지는 않는다.
  3. **MOS 대응:** 저주파·게이트 전류와 몸체효과를 무시하는 모델에서 베이스를 게이트,
     컬렉터를 드레인, 이미터를 소스로 대응시킨다. 게이트 경로의 $R_P$는 전압 강하가 없어
     $R_{xe}=(1/g_m)\parallel r_o$이고, 드레인 경로의 $R_P$는 위 2번과 같이 $R_P/r_o$를 확인한다.
     $\beta\to\infty$는 이 제한된 모델의 대응 설명이며 MOS의 모든 성질에 대한 동일시가 아니다.
  외부의 제3 연결·몸체효과·고주파 기생성분·바이어스 변화가 있으면 이 두 단자 블록을 그대로 확대하지 않는다.
  $R_P$로 DC 바이어스가 달라지면 바뀐 동작점의 $g_m,r_o,r_\pi$를 사용한다.
  **근거·확신도:** 두 회로와 수식은 이미지 1장 전체에서 확인했고, 그림 생략 선호는 사용자 본문으로 확정했다.
  수식의 보완 조건은 사용자 취향 추론이 아닌 독립 KCL 검산 결과다
  ([입력 해시·비교·내부 검산 기록](../../../../docs/learning/solution-style-updates/2026-10-22-diode-connected-resistor.md)).

- **관찰:** 입력 소자·출력 노드·위아래로 바라보는 저항·전류 경로를 회로에 표시한다.
  $R_{out}=R_{on}\parallel R_{op}$로 합치거나 입력 아래를 $R_s^*$로 묶는다.
  원문에 그림이 없는 차동쌍·전류 거울 문항에서도 회로를 직접 그리고 각 가지 전류($\frac{1}{2}I_{SS}\downarrow$, $I_1,I_2,I_3\downarrow$)와
  핵심 노드 전압($V_P,V_D,V_x$)을 표시한다.
- **근거:** H0916 p4·8, HGM p1, H0918 p1·4·8·11, H0923 p3·4·6·7.
- **확신도:** 높음.
- **생성 규칙:** 원문 소자 번호를 유지하고 역할로 설명한다. 저항을 보는 화살표와
  전류 방향을 구별한다. $R_s^*$를 쓰기 전에 어느 회로 부분을 묶는지 정의한다.
  다단·다중 가지 회로에서는 각 가지 전류($I_1,I_2,\dots$)와 방향을 회로에 먼저 정의한 뒤 식을 세운다.
  1. **부하 양단 출력 임피던스의 교류 접지 연결 직렬 판정(2026-11-26 사용자 확정):** 두 노드 사이에
     부하(예: C-V·C-C 귀환의 레이저 $R_L$)가 놓인 출력 포트의 개루프 출력 임피던스는 시험원 노드 방정식을
     길게 세우지 않고, 부하 양단에서 위·아래로 보이는 교류 접지까지 저항(예: $1/g_{m2}$와 $R_M$,
     $r_{O2}$와 $R_F\parallel R_M$)이 같은 교류 접지로 하나로 이어짐을 확인해 곧바로 직렬 합으로 판정한다.
  2. **전류 입력의 노턴→테브난 변환(2026-11-26 사용자 확정):** 입력 전류원 $I_{in}$과 병렬 저항

     소스 저항 $R_p$의 테브난 등가로 변환해 $\frac{V_X}{I_{in}}=R_p\cdot\frac{V_X}{V_{in}}$으로 바로
     계산하는 경로를 허용·우선한다.
- **예외:** 회로마다 입력 위치와 관찰 단자가 다르다. 위쪽 소자가 항상 같은 역할이라고 가정하지 않는다.
- **검토 기준:** 화살표가 뜻하는 측정 단자·방향·회로 범위가 명확한가?

### CIRCUIT-02: 측정 조건을 적용한 회로에서 식으로

- **그림 선택의 우선순위(2026-10-22 명시적 선호 1·2):** 먼저 원 회로에 측정 조건만
  적용하고 CIRCUIT-01의 알려진 블록으로 직접 합성한다. 이 방법으로 충분하면 제어 전류원까지
  펼친 소신호 등가회로를 본문·보충에 자동 추가하지 않는다. 물리적으로는 소신호 해석이며
  생략하는 것은 불필요한 등가회로 그림이다. 결합된 제어 전압·귀환·미지 블록 때문에 직접
  합성이 성립하지 않거나 원문이 모델 유도를 요구하면 필요한 부분만 등가회로로 펼친다.
  입력 위치가 바뀌어 제어 전압을 직접 확인해야 했던 H0916 p3(P9.23)은 필요한 그림의 실제 예다.
  자세한 이유는 현재 계산 단계 곁에서 설명하되, 설명량을 늘리기 위해 같은 회로·계산을 반복하지 않는다.
  베이스–컬렉터 연결에 저항이 포함되어도 CIRCUIT-01의 두 블록에 해당하면 등가회로·시험원 그림을 자동 추가하지 않는다.
  $R_P$가 있다는 사실만으로 미지의 귀환 구조라고 분류하지 않는다. 근사 보완도 먼저 알려진 블록 식으로 처리한다.
- **독립원의 처리:** DC 전압원·고정 바이어스 전압은 AC 접지로, 이상적인 DC 전류원은
  개방으로 바꾼다. 트랜지스터 전류원의 $r_o$와 종속원의 효과는 영점화하지 않는다.
  $G_m$은 입력 신호를 유지하고 출력을 단락한다. $R_{out}$은 입력 독립원도 영점화하고
  출력에서 바라본다. 직접 합성할 수 없을 때 출력 시험원을 두고 $v_t/i_t$를 구한다.
  출력 시험원은 제거할 독립 입력원이 아니며, 원문의 출력저항 정의·부하 포함 여부를 먼저 확인한다.
- **차동 모드 반회로(2026-10-22 C5 사용자 확정):** 대칭 소자·바이어스·부하와 순수
  차동 입력($+v_{id}/2,-v_{id}/2$)이면 반대칭 동작에서 대칭면의 소신호 전압이 0임을 먼저
  판단하고 반회로를 쓴다. 양쪽 대응 노드 사이의 저항 $R$은 반회로에서 $R/2$다.
  따라서 H0930 p6의 $R_{DD}$·$R_{SS}$는 각각 $R_{DD}/2$·$R_{SS}/2$로 바꾼다.
  반회로의 $G_m$ → 부하 포함 $R_{out}$ → 부호 있는 이득으로 연결한다. $v_{od}$의 차 순서와
  반회로의 입력 $v_{id}/2$·출력 $v_{od}/2$를 확인해 단일 출력 이득의 1/2를 혼동하지 않는다.
  공통 모드에서는 이 가상 접지를 쓰지 않으며 아래의 공통 테일 $2R_{SS}$ 규칙과 구별한다.
  전류 거울 결합·비대칭·다른 모드가 섞인 회로에서는 실제 연결이 반회로를 허용하는지 다시 판단한다.

- **기본 근사:** 문서 앞의 수업 기본 근사를 모든 학습 표면에 적용한다. 축퇴 저항/유한 $r_\pi$를 반영한 뒤 주항을 쓰고 캐스코드의 곱 인자에는 소자 번호를 붙인다.
- **공통 모드의 기본 풀이(2026-10-22 사용자 확정):** 대칭 입력 쌍의 같은 공통 모드 입력과 같은 가지 전류를 보장하는 모델이면 **성립 조건 → $2R_{SS}$ 반회로 → 출력 단락에서 $G_m$ → 입력 영점에서 부하 포함 $R_{out}$ → 부호 있는 $A_v=-G_mR_{out}$**를 본풀이 경로로 쓴다. 가지 전류를 $i$로 정의하면 $v_P=(2i)R_{SS}=i(2R_{SS})$이므로 반쪽의 축퇴 저항은 $2R_{SS}$다. CM 대칭선은 가상 접지가 아니다. 입력 $r_o$를 생략하는 MOS 저항 부하 모델에서는 출력 단락에서 $G_{m,CM}=g_m/(1+2g_mR_{SS})\approx1/(2R_{SS})$를 먼저 구하고, 입력 영점에서 $R_{out}\approx R_L$을 확인한 뒤 $A_{CM,SE}\approx-G_{m,CM}R_{out}\approx-R_L/(2R_{SS})$로 연결한다. BJT에서 유한 $\beta$가 필요하면 컬렉터 전류와 이미터 전류 관계를 보존한다.
  테일 $R_{SS}$는 필요한 유효 근사 블록값을 먼저 정의한다. 알려진 블록으로 충분하면 테일 출력저항의 시험 회로·긴 유도를 추가하지 않는다. 추가 도출이 필요한 경우에만 별도 보충 설명으로 분리하며 반회로 본풀이 앞에 두지 않는다. 보충에도 위 $R_{out}$ 정확식 제한과 큰 곱 근사를 적용한다. 요약·MD·답안 PDF도 반회로 판단과 첫 식을 유지한다.
  부하 불일치는 선택 모델에서 두 가지 전류가 같음을 먼저 확인한 뒤 각 출력과 차를 계산한다. 출력전압에 따른 전류 귀환·유한 입력 $r_o$ 등으로 그 전제가 깨지면 전체 연결을 보존한다. 능동 부하·전류 거울은 좌우 결합 때문에 회로별로 반회로 가능 여부를 판단한다. 원문이 특정 증명·정확식·다른 방법을 명시하면 그 요구를 본풀이에 유지하고 반회로 직관은 보조로 둔다. 불일치·거울 결합에서 독립된 동일 반회로를 강제하지 않는다.
- **유한 $\beta$ 전류 거울의 전류 분기와 KCL(2026-10-22 사용자 확정):** 베이스 전류를 고려하는 바이폴라 전류 거울(H0918 p5·p6)에서는 결과 공식을 바로 대입하지 않고, 기준 노드에서 기준 컬렉터 전류($I_{C0}$)와 베이스 공통선으로 갈라지는 각 소자 베이스 전류($I_{C,k}/\beta$)의 분기 흐름을 도식이나 회로에 먼저 표시한다. 이어서 기준 노드의 KCL 식 $I_{REF}=I_{C0}+\sum_k(I_{C,k}/\beta)$을 세우고, 이미터 면적비로 각 컬렉터 전류를 목표 출력 전류($I_{copy}$)로 치환해 $I_{copy}$와 공칭값 대비 정규화 오차 $\varepsilon$을 구한다.


- **관찰:** 구할 값의 측정 조건을 회로에 먼저 적용하고, 무시하는 가지를 곁에 적은 뒤
  남은 노드에 전압·전류 관계를 직접 붙인다. MOS/BJT 기호와 저항의 단계별 간략 회로(H0909 p4, H0918 p11)도 쓰며,
  유한 $\beta$ 전류 거울에서는 전류 분기 화살표 도식과 KCL 식을 대응시키고(H0918 p5·6),
  제어 전류원까지 펼친 회로에서는 연결 관계와 식이 같은 위치에서 대응한다.
- **근거:** 간략화는 H0909 p4/H0916 p1(같은 문항)·H0918 p11, 전류 분기 도식은 H0918 p5·6, 상세 전개는 H0911 p8/H0916 p3.
  인접 노드 파랑·빨강(분홍) 구분은 H0918 p1·2에서도 확인된다.
  특히 H0916 p3의 P9.23에는 출력 단락 접지, 접지 쪽에서 들어오는 $i_{out}$,
  왼쪽 입력 가지·가운데 이미터·오른쪽 제어 전류원·아래 $r_{o1}$,
  이미터의 $i_{out}r_{o1}$ 및 베이스 전류와 $r_{o2}$ 가지를 무시하는 메모가 함께 있다.
- **확신도:** 이 문제의 측정 조건·배치·관계 표시는 높음. 모든 토폴로지의 고정 배치나
  전류원 외곽 기호·필기체 선호까지 확인한 것은 아니다.
- **사용자 확인:** 2026-10-22 추가 피드백으로 출력은 오른쪽, 병렬 제어 전류원은 왼쪽·$r_o$는 오른쪽이라는 배치 선호를 직접 확인했다. H0911 p8에도 전류원 왼쪽·$r_o$ 오른쪽·출력 맨 오른쪽이 보인다. H0916 p3은 $r_{o2}$ 생략 모델이므로 그곳의 제어원 위치를 병렬쌍 전체에 일반화한 이전 해석을 철회한다.
- **생성 규칙:** 입력은 왼쪽, 출력 단자·출력 라벨·출력 시험원/단락 접속은 오른쪽에 둔다. 회로로 유입하는 시험전류는 오른쪽에서 왼쪽으로 그리며, 내부 제어 전류원의 방향·전압 극성·실제 접속은 유지한다. 전기적으로 같은 노드라는 이유로 출력 접속을 왼쪽이나 중앙에 두지 않는다. 풀이 본문·HTML·PDF에서 각각 확인한다.
  접지 표기만 하는 비분기 단자와 접지 기호의 직접 접속점을 제외하고, 입력·출력·시험 노드와 이름을 붙인 전압 노드에는 연결 위치가 분명한 눈에 보이는 점을 찍는다. 출력 시험전압 노드의 점은 출력 도선의 실제 맨 끝이자 가장 오른쪽 단자에 둔다. 점 오른쪽으로 도선(ink)이 더 이어지거나 연장된 도선 중간에 점이 놓이면 안 된다. 시험 노드 전압 $V_t(+)$는 그 끝점 위에 둔다. 유입 시험전류는 오른쪽에서 왼쪽으로 흐르며, 왼쪽을 향하는 $i_t$ 화살표는 $V_t$ 점 왼쪽의 도선 구간에 둔다. $i_t$ 라벨도 점 왼쪽에서 그 화살표 아래나 곁에 둔다. 화살표 전체가 점 왼쪽에 머물고 점을 덮지 않도록 화살표 꼬리와 점 사이에 작은 간격을 남긴다. 화살표나 전류 라벨을 점 오른쪽에 놓지 않는다. 다른 시험 기호($v_x/i_x$ 등)를 쓰면 같은 배치와 정의를 적용한다. 선 교차만 있고 연결되지 않은 곳에는 점을 찍지 않는다. 라이트·다크 HTML과 실제 답안 PDF에서 점·라벨·화살표의 분리와 가시성을 각각 확인한다.
  $R_{out}$은 처음부터 유효한 근사식으로 시작하고 조건과 $\approx$를 유지한다. 이 규칙은 생성하는 풀이 본문(start/solve/verify·formal/보충 포함) HTML·요약·동반 MD·답안 PDF 모두에 적용한다. 정확식 → 근사식 유도나 정확식과 수치 비교를 학습 본문에 추가하지 않는다. 정확한 $R_{out}$의 전체 모델·유도·수치/극한 대조는 내부 독립 검산 evidence에만 둔다. 원문이 정확식·유한 β 전체 결과 또는 수업 기본 큰 곱 근사와 반대인 조건·수치를 명시하면 예외 이유를 짧게 밝히고 필요한 모델과 결과를 제시한다. 유한 β 또는 $r_o$가 있다는 사실만으로 예외를 선언하지 않는다. 이 제한은 $R_{out}$에 한정하며 다른 개념의 필요한 상세 유도를 줄이지 않는다.
  풀이 본문의 회로는 **측정 조건 → 단순화 근거 → 노드 관계 → 첫 식**을 보인다.
  1. $G_m$ 측정 회로를 그릴 때는 출력에서 접지까지 단락선을 실제로 그리고 $v_{out}=0$과 출력 전류의
     양의 방향을 표시한다. 단락을 글로만 말한 일반 출력 노드 그림으로 대신하지 않는다.
     직접 연쇄 합성으로 충분하면 $R_{out}$에는 입력 영점과 관찰 방향만 표시해도 된다.
     두 노드 사이 부하 포트의 출력 임피던스에서도 위·아래 접지 연결로 직렬 합이 바로 읽히면
     시험원 노드 방정식($V_{S2}, V_F, V_X$ 연립)을 반복 전개하지 않는다.
     입력에 $I_{in}\parallel R_p$가 걸린 단은 노턴→테브난 등가로 치환해 알려진 단 이득으로 처리할 수 있으면
     전체 소신호 KCL 연립을 펼치지 않는다.
     시험원으로 도출하는 $R_{out}$ 측정 회로를 그리는 경우에는 입력 영점 연결과 출력 시험원 $v_x$ 또는 $i_x$를 보이며
     $R_{out}=v_x/i_x$의 방향을 맞춘다. 전압이득 회로는 실제 부하 조건을 보인다. 이미 알려진 블록 공식을
     적용하는 모든 단계에 측정 회로를 새로 그리도록 강제하는 것은 아니다.
  2. 제어 전류원과 $r_o$가 병렬이면 반드시 **제어 전류원 왼쪽 → $r_o$ 또는 병렬 합성 저항 오른쪽 → 출력 접속 맨 오른쪽** 순서로 그린다. 입력은 그 왼쪽, 이미터/소스 축퇴 저항은 해당 노드 아래에 둔다. $r_o$를 생략한 축약 모델에는 없는 저항을 추가하지 않는다. 그 모델의 제어원 위치를 병렬쌍의 배치 규칙으로 일반화하지 않는다. 풀이 본문의 모든 SVG와 답안 PDF에서 소자·단자 전체 배치를 대조하고, 전기적 등가성만으로 위치 불일치를 승인하지 않는다. 원문 소자 번호와
     실제 접속은 유지한다. 가지를 줄였으면 그림·caption 바로 곁에 무엇을 어떤 근사로
     무시했는지 쓴다. 그림을 단순히 회전하거나 글꼴만 바꾸는 것으로 충족하지 않는다.
  3. 노드에 $v_e$만 두는 대신, 도출에 쓰는 관계도 가까이 적는다. 예를 들어 출력 단락,
     큰 β와 $g_{m2}r_{o2}\gg1$, $r_{o1}\ll\beta r_{o2}$ 아래 $G_m$ 주항을
     얻기 위해 $r_{o2}$ 가지를 생략한 P9.23 축약 모델에서
     $v_e\approx i_{out}r_{o1}$, $i_{out}\approx g_{m2}(v_{in}-i_{out}r_{o1})$를
     회로와 이어 쓴다. 전류원 라벨은 $g_{m2}v_{\pi2}$와 제어 전압 관계를 함께 쓰거나
     $g_{m2}(v_{in}-i_{out}r_{o1})$로 적어도 된다. 생략 근사를 정확한 등호로 포장하지 않는다.
  4. 유한 β·$r_o$가 답에 필요한 경우 풀이도 그 모델의 $r_\pi$·$r_o$를 유지한다.
     이때 $v_e=i_{out}r_{o1}$를 강제하지 않고 올바른 가지 전류 관계를 붙인다.
     직접 판단으로 부족할 때만 상세 설명에 필요한 부분의 소신호 모델과 KCL/KVL 유도를 보존한다.
     $R_{out}$의 전체 정확 모델은 위 예외에 해당하지 않으면 내부 검산에만 둔다.
     측정 단계에 따라 모델이 다르면 각 모델의 조건과 결과 대응을 명시한다.
- **예외:** $G_m$·$R_{out}$을 구하지 않는 문항에는 시험 조건을 억지로 넣지 않는다.
  다른 토폴로지는 식을 읽기 쉬운 배치를 고른다. 순수 DC 계산에 소신호 그림을 강제하지
  않는다. 알려진 블록으로 충분하면 핵심 블록을 써도 되지만 실제 필요한 유도를 숨기지 않는다.
  손메모의 “$r_{o2}$ 전류 없음”은 유한 $r_{o2}$의 정확한 성질이 아니므로 그대로 일반화하지
  않는다. 가지 생략은 $G_m$ 주항을 얻는 축약이지 실제 가지 전류가 작다는 주장이 아니다.
  $G_m$의 전체 모델은 $i_{out}=g_{m2}(v_{in}-v_e)-v_e/r_{o2}$와
  $v_e=r_{o1}(i_{out}+i_b)$로 대조한다. 전류원의 원·마름모는 고정 개인 취향으로 선언하지 않고 종속성과 방향을 분명히 한다.
- **검토 기준:** 병렬쌍이 있으면 제어 전류원 → $r_o$/합성 저항 → 출력이 왼쪽에서 오른쪽 순서인가? 풀이 본문의 모든 SVG를 열거해 각각 확인했는가? $r_o$ 생략 모델은 비적용 이유를 구분했는가?

  직접 합성으로 충분한데 등가회로·시험원 그림을 불필요하게 추가하지 않았는가?

  다른 경우 그림도 그 조건을 구별하는가? HTML 풀이와 거기서 추출한 답안 PDF의 실제 그림을
  각각 보았는가? 그림이 비적용이면 구체적 이유를 개인화 감사에 쓴다.

- 회로 안 글자와 점의 정돈: SVG 안에는 소자 이름·값·제어 전류원 라벨(예: $g_mv_\pi$), 노드 이름·극성·방향처럼 실제 회로를 읽는 표기를 남긴다. 분석용 $G_m$ 제목·측정 조건 문구·유도 설명은 그림 아래 figcaption이나 수식 문단에 둔다. 출력 단락·입력 영점의 실제 연결은 그림에 보존한다. 접지 입력 위의 독립 제목 `Rout`처럼 불필요한 제목은 옮겨 중복하지 않고 삭제한다. 가까운 노드 관계는 유도 설명이 아니고 겹치지 않을 때만 남길 수 있다. 접지 표기만 하는 비분기 단자·접지 기호의 직접 접속점은 제외하고 입력·출력·시험 단자, 이름 붙인 내부 전압 노드, 실제 분기 접속점의 점은 유지하되 이름도 분기도 없는 직선 도선 중간의 장식 점은 없앤다. 모든 도선에 점을 추가하라는 규칙이 아니다. $V_{out}(+)$·$V_t$ 등 라벨은 아래첨자까지 포함한 실제 글리프 경계상자가 도선에서 최소 0.6em(보통 화면에서 약 8px) 떨어지게 배치한다. 텍스트 기준선 간격만 확인하지 않는다. 필요하면 라벨을 옮기고 viewBox 위쪽 여백을 늘린다. 풀이 본문의 모든 SVG를 열거하여 라이트·다크 HTML과 실제 답안 PDF의 보통 보기 크기에서 이 간격·클리핑·겹침을 확인한다. 병렬 제어원 왼쪽/$r_o$ 오른쪽/출력 맨 오른쪽, 맨 끝 $V_t$ 점 오른쪽 도선 없음, 점 왼쪽의 왼쪽 방향 $i_t$와 라벨 배치도 유지한다.
- 정리노트와 문제설명 위치 표시 예외: 정리노트와 간략 문제설명의 `figure.circuit`에는 본문이 짚는 위치 표시 ㉠㉡㉢㉣(`fig-loc`)을 둘 수 있다. 회로를 읽는 표기이며 제목·유도 설명이 아니다. 도선과의 간격은 글자 크기의 0.25em 이상이고, 다른 라벨의 0.6em 규칙은 그대로다. 문제설명에서는 본문의 같은 표지 바로 옆에서 해당 위치가 첫 식에 주는 영향을 설명한다. 답안 PDF의 정책은 기존과 같다.
- 접지·전압 라벨·노드 색 대응: 접지 기호에 직접 닿는 점과 접지만 표시하는 비분기 입력 단자의 점은 생략한다. 접지로 이어지는 회로라도 별도의 실제 분기 접속점·이름 있는 비접지 노드는 유지한다. $v_e$ 등 전압 이름은 다른 소자나 저항 옆으로 멀리 밀지 않고 해당 노드 바로 곁에 둔다. 아래첨자·극성을 포함한 실제 글리프 경계로 도선과 최소 0.6em 간격을 확보하면서 가능하면 0.6–1em 정도의 가까운 간격을 목표로 한다. 혼잡 때문에 더 벌리면 배치 이유를 검토에 기록한다. 노드 점과 해당 전압 이름·극성은 같은 파랑 또는 빨강으로 묶는다. 주요 신호 경로를 따라 파랑·빨강을 교대하고 가까운 전압 라벨끼리 최대한 다른 색을 쓴다. 같은 전기적 노드는 다른 위치의 점도 같은 색이며, 모든 인접 노드를 반대색으로 만드는 그래프 채색을 강제하지 않는다. 접지 표기·도선·소자/제어원 라벨·전류 화살표/라벨·본문 수식의 색은 이 노드 색 규칙으로 바꾸지 않는다. 색 없이도 노드 이름과 극성으로 구분되어야 한다. SVG에는 대응 노드 식별자와 색을 명시하고, HTML 테마와 PDF에서 실제 계산된 색이 파랑/빨강인지 확인한다. PDF의 문항 종류별 초록/주황 `--kind`를 노드 파랑의 대체값으로 사용하지 않는다. 풀이 본문의 모든 SVG와 MD에 참조된 같은 그림, 라이트·다크 HTML 및 실제 답안 PDF에서 접지 점 생략·가까운 라벨·점/전압 색 일치를 검토한다.

### GAIN-01: 단별 이득의 연쇄 곱과 Gm·Rout 분리

- **관찰:** $G_m$과 $R_{out}$을 따로 구해 $A_v=-G_mR_{out}$으로 연결한다.
  입력의 전류 생성과 출력저항 증대 역할을 구분한다. 전류 거울 바이어스가 결합된 증폭기(H0918 p10·11)에서는
  DC 복사 전류를 먼저 구한 뒤 구분선을 긋고 $G_m$, $R_{out}$, $A_v=-G_mR_{out}$을 계산한다.
- **근거:** H0911 p10, H0916 p3·4·5·6, HGM p1, H0918 p10·11.
- **확신도:** 매우 높음.
- **단별 전압이득 우선(사용자 확정):** 원문이 풀이법을 지정하면 그 방법을 따른다. 그 외의 새·수정 전압이득 풀이는 먼저 선택한 소신호 모델에서 신호가 중간 노드 $X$를 차례로 거치고, 단 사이의 로딩을 포함해 각 단 이득을 구할 수 있는지 확인한다. 그러면 $A_v=(v_X/v_{in})(v_{out}/v_X)$를 먼저 세우고 각 단의 부호와 실제 부하를 보인다. 피드백의 개루프 계산에는 루프를 끊은 뒤 남는 양쪽 종단을 포함한다. 우회 전달이나 역결합으로 중간 노드 하나만으로 다음 단 입력을 정할 수 없으면 실제 경로와 결합을 유지해 푼다.
  **예시:** 1120 P5(E12.28)는 $M_2$ 게이트 전류가 0이므로 첫 단 부하가 $R_{D1}$이다. 감지 복제는 둘째 단의 출력에 $R_1+R_2$를 병렬로 붙인다. 두 공통 소스 이득을 각각 구해 곱하고, 문제에서 따로 묻는 출력저항에는 같은 $R_{\mathrm{out,open}}$을 쓴다.
- **Gm·Rout 경로:** 위 연쇄 곱으로 바로 읽을 수 없는 증폭기의 전압이득을 이 방법으로 구할 때는 **성립 조건·입출력 정의 → 출력 단락에서 $G_m$ → 입력 영점에서 출력 방향의 연쇄 합성(필요할 때만 시험원)으로 $R_{out}$ → 부호 있는 이득** 순서로 쓴다. $G_m=i_{out,sc}/v_{in}$의 전류 양의 방향과 $v_{out}=0$을 먼저 정한다. $R_{out}$에는 같은 출력에서 보이는 증폭기 쪽 근사 저항과 외부 부하의 병렬을 보이고, 같은 입출력 정의로 $A_v=-G_mR_{out}$을 연결한다. 전류 방향을 다르게 정의했다면 대응하는 부호를 명시한다.
  짧은 풀이는 대수 전개를 줄이는 것이며 $G_m$·$R_{out}$·곱의 중간 단계를 생략하는 것이 아니다. 이미 아는 근사 블록을 사용해도 각 중간량·성립 조건·간단한 대입을 보인다. 수업의 $g_mr_o\gg1$, 외부 $g_mR_e\gg1$ 주항을 쓰되 필요한 유한 $r_\pi$·$r_o$와 원문 조건은 유지한다. 내부 $r_e=1/g_m$에 큰 곱을 가정하지 않는다. $R_{out}$ 정확 전체식·긴 노드방정식은 CIRCUIT-02의 예외가 아니면 내부 검산에만 둔다.
  대칭 CM에서는 $2R_{SS}$ 판단 뒤 위 세 계산을 같은 반회로로 연결한다. 부하 불일치·전류 거울 결합은 실제 연결과 정의를 유지하고 전체 출력의 $G_m$·$R_{out}$ 또는 전류 합성/누출 경로를 구분한다. 기존의 미수정 문항 전체를 이 규칙만으로 재작성하지 않는다.
  **다단 트랜스컨덕턴스·전류 이득의 연쇄 곱과 로딩 치환(2026-11-26 사용자 확정):** $I_{out}/V_{in}$·$I_{out}/I_{in}$ 같은 다단 이득에서는 $I_D=g_m(V_G-V_S)$ 연립방정식을 매번 새로 세워 이항·정리하기보다, 중간 노드($V_X, V_{out}$) 기준의 단별 전압 이득 연쇄 곱과 옴의 법칙($1/R_L$), 직렬 로딩 치환($R_L\to R_L+R_M$), 전류 입력의 노턴→테브난 변환($R_p\cdot V_X/V_{in}$), 출력 노드 전류 분배($I^*=I_{out}+I'$)를 우선 적용한다. 귀환 폐루프 단계에서는 개루프 대비 배율($\frac{1}{1+KA_0}$배, $(1+KA_0)$배) 관점을 함께 짚어 일관되게 정리한다.
  **공통 베이스의 알려진 저항 블록 (2026-11-26 사용자 확정):** 저주파 활성 영역에서 $r_o$를 생략할 수 있고, 베이스가 $R_B$를 거쳐 교류 접지로 이어지는 이미터 입력 단은 $1/g_m+R_B/\beta$부터 읽는다. $R_B$는 해당 측정 조건에서 베이스가 보는 외부 저항이다. 출력 단락에서 컬렉터 유입 전류를 양으로 두면 $G_m=-1/(1/g_m+R_B/\beta)$다. $R_B=0$이면 $G_m=-g_m$으로 줄어든다. 큰 $\beta$에서는 같은 합이 이미터 쪽 입력저항의 근사다. $G_m$의 첫 식에는 두 항을 직접 표시하고, 후속 식에는 이미 구한 $R_{\mathrm{in,open}}$이나 $A_{\mathrm{open}}$처럼 회로에서 구한 양을 쓴다. 조건과 첫 판단을 짧게 붙이고, 유한 $r_o$나 다른 입력·귀환 경로가 결과에 영향을 주면 그 모델에서 다시 판단한다.
- **예외:** 순수 DC·저항만 묻는 문제, 전류 전달/트랜스임피던스, 원문이 지정한 다른 증명은 그 목표와 방법을 유지하고 비적용 이유를 적는다. 전류 거울의 전류 합성을 두 독립 반회로로 바꾸지 않는다. 상단 소자의 $G_m$ 영향이 항상 0이라는 일반 법칙으로 확대하지 않는다.
  다른 전달 특성·주파수 범위에서는 해당 모델과 부호 정의를 다시 확인한다.
- **검토 기준:** 새·수정 전압이득에서 중간 노드, 단별 로딩, 우회·역결합 여부를 보고 경로 선택의 근거를 남긴다. 연쇄 곱을 썼으면 같은 모델과 종단에서 구한 각 단의 이득·부호·최종 곱을 확인한다. 단별 곱으로 충분한 본풀이를 전체 $G_m$의 출력 단락 계산으로 돌리면 수정한다. $G_m$·$R_{out}$ 경로를 썼으면 보이는 $G_m$ → 부하 포함 $R_{out}$ → 이득 순서와 각 중간 식이 있는가? 짧다는 이유로 하나를 건너뛰지 않았는가? 입출력·부호 정의가 같은가? 두 측정 조건을 섞지 않았는가? $G_m$과 $g_m$을 구별하고
  $-G_mR_{out}$의 조건·차원·부호를 검산했는가? 공통 베이스에 이 블록을 적용했다면 $1/g_m$과 $R_B/\beta$가 첫 식에 보이고, 후속 식의 기호는 앞에서 구한 회로량인가?

### DEGEN-01: 제어 전압과 저항 합 형태

- **예외:** 위 제어 전압 식은 모든 BJT의 정확식이 아니다. 베이스 전류와 해당
  $r_o$ 경로 등을 무시했다면 큰 β·큰 $g_mr_o$ 등 필요한 조건을 밝힌다.

### FREQ-01: 팔로워 출력 임피던스의 저주파 값 기반 꼴

- **관찰:** 사용자가 “캡을 고려하지 않았을 때의 임피던스를 분모 $=A$, 분자 $=B$라고 하면,
  캡을 고려한 임피던스는 $(R_SC_{GS}s+B)/(C_{GS}s+A)$”라는 꼴로 소스·이미터 팔로워를 묶어 이해했다.
  커패시턴스 없는 값 → 커패시터 항 추가 → $s\to0$, $s\to\infty$ 극한의 순서로 읽는다.
- **근거:** 2026-11-04 사용자 명시적 선호(L05 s47–49 대화, [기록](../../../../docs/learning/solution-style-updates/2026-11-04-follower-impedance-form.md)).
- **확신도:** 사용자 확정. 적용 범위(팔로워 출력 임피던스)와 역할(조건부 지름길)도 사용자 선택이다.
- **생성 규칙:** 소스·이미터 팔로워의 출력 임피던스 $Z_{out}(s)$에 적용한다.
  1. 커패시턴스를 뺀 저주파 값 $Z_{out}(0)$을 먼저 쓴다. 이미터 팔로워는 $1/g_m+R_S/(\beta+1)$처럼 $1/g_m$이 보이게 쓴다.
  2. $A$는 출력 노드로 들어오는 총 컨덕턴스, $B=A\cdot Z_{out}(0)$(무차원)로 정규화한다.
     소스 팔로워는 $A=g_m$, $B=1$이고, 이미터 팔로워는 $A=g_m+1/r_\pi=(\beta+1)/r_\pi$, $B=1+R_S/r_\pi$다.
  3. 제어 포트 커패시터 $C$($C_{GS}$ 또는 $C_\pi$)를 넣어 $Z_{out}(s)=(R_SCs+B)/(Cs+A)$로 쓴다.
     소스 팔로워는 이미터 팔로워에서 $r_\pi\to\infty$인 특수한 경우라고 한 줄로 연결할 수 있다.
  4. 검산 구역에서 $s\to0$이면 $B/A$, $s\to\infty$이면 $R_S$가 되는지 확인한다.
     $R_S$가 저주파 값보다 크면 크기가 주파수와 함께 올라가 유도성으로 보인다는 판단을 붙인다.
  - **지름길 조건:** 게이트/베이스 쪽이 저항 $R_S$(입력 영점 후) 하나이고 커패시터가 제어 포트에만 있으며
    $r_o$를 무시하는 모델이면 KCL 유도 없이 위 꼴로 바로 쓴다.
  - **그 밖의 모델:** $C_\mu$·$C_{GD}$처럼 게이트/베이스 쪽 임피던스가 바뀌거나 $r_o$가 있으면 KCL 유도를 유지한다.
    이때 이 꼴은 검산에 쓴다: 추가 소자를 지우면 위 꼴로 돌아가는지, 일반형
    $(1+Z_BY_c)/(g_m+Y_c)$($Z_B$: 게이트/베이스 쪽 임피던스, $Y_c$: 제어 포트 어드미턴스)와 같은지 확인한다.
    $r_o$는 꼴을 만든 뒤 마지막에 병렬로 붙인다.
- **예외:** 팔로워 출력 임피던스가 아닌 입력 임피던스·이득·극점 계산과 다른 증폭단 임피던스에는 확대하지 않는다.
  원문이 특정 유도 방법을 지정하면 그 방법을 따르고 이 꼴은 검산에만 쓴다.
  $A$, $B$는 비율만 정해지는 양이므로 정규화하지 않은 $(\beta+1)$, $(r_\pi+R_S)$를 그대로 $A$, $B$로 넣지 않는다.
- **검토 기준:** 적용 문항에서 저주파 값 → $A$, $B$ 정규화 → 꼴 → 두 극한 순서가 보이는가?
  지름길 조건을 확인하고 썼는가? 추가 소자가 있는 문항에서 KCL 유도를 생략하지 않았는가?
  $r_o$ 병렬과 $1/g_m$ 명시가 지켜졌는가?

## 근거를 이용한 적용 예시

다음은 표기와 전개 방식의 모범 예시다. 해당 문제의 전체 해설을 대체하지 않는다.
소자 번호·입력 위치는 각 workbook 원문 MD와 대조했으며 원본은 변경하지 않았다.
기본 모델은 저주파 소신호 모델이다. 포화/활성 동작과 각 근사 조건을 별도로 확인한다.

#### 1. E9.05 — 목표 출력저항에서 W/L 역산

Fig 9.8의 상단은 $M_1$, 하단은 $M_2$다. 두 소자가 같고
$I_D=0.5\ \mathrm{mA}$, $\lambda=0.1\ \mathrm{V}^{-1}$이면
$r_{o1}=r_{o2}=1/(\lambda I_D)=20\ \mathrm{k}\Omega$다.
먼저 $100\ \mu\mathrm{A/V^2}=0.1\ \mathrm{mA/V^2}$로 환산한다.

주항 모델 $R_{out}\approx g_{m1}r_{o1}r_{o2}$로 목표 $500\ \mathrm{k}\Omega$를 맞추면

$$g_{m1}=\frac{500\ \mathrm{k}\Omega}{(20\ \mathrm{k}\Omega)^2}
=\frac54\ \mathrm{mS}$$

$$\frac WL=\frac{(5/4)^2}{2\times0.1\times0.5}
=\frac{25/16}{2\times0.1\times0.5}=15.625.$$

**주항 근사 설계 답은 두 소자 모두 $W/L=15.625\approx15.6$**이다.
$g_mr_o=25\gg1$인 주항 모델의 설계값이며, 목표 저항도 근사값으로 표기한다.
정확 모델과의 수치 대조는 아래 내부 검산 전용 부록에만 둔다.

#### 2. E9.06 — 같은 두 노드의 병렬 인식

Fig 9.11의 $R_P$는 상단 **$M_1$의 드레인–소스** 사이이므로
$r'_{o1}=r_{o1}\parallel R_P$다. 하단 $M_2$는 해당 바이어스의 소신호 모델에서
$r_{o2}$로 보인다. 이 연결을 MOS 기호와 저항의 간략 회로로 먼저 보여준다.

$$R_{out}\approx g_{m1}(r_{o1}\parallel R_P)r_{o2}.$$

이 근사는 $g_{m1}r'_{o1}r_{o2}\gg r'_{o1},r_{o2}$일 때만 쓴다.
$R_P\to\infty$이면 원래 캐스코드 식으로 돌아가는지 확인한다.
인쇄 힌트가 있었던 관찰이므로 이 병렬 인식을 독자적인 발명으로 설명하지 않는다.

#### 3. E9.01 — BJT 단위와 병렬 중간값

Fig 9.2(a)는 상단 $Q_1$, 하단 $Q_2$다. $I_C=1\ \mathrm{mA}$,
$V_T=26\ \mathrm{mV}$, $\beta=100$, $V_A=5\ \mathrm{V}$이면

$$g_m=\frac1{26}\ \mathrm{S}=\frac{1000}{26}\ \mathrm{mS}$$

$$r_\pi=\frac\beta{g_m}=2.6\ \mathrm{k}\Omega$$

$$r_o=5\ \mathrm{k}\Omega.$$

$$r_{o2}\parallel r_{\pi1}=\frac{5\times2.6}{5+2.6}\ \mathrm{k}\Omega
=1.710526\ldots\ \mathrm{k}\Omega.$$

큰 주항 모델에서
$$R_{out}\approx\frac{1000}{26}\ \mathrm{mS}\times5\ \mathrm{k}\Omega
\times\frac{5\times2.6}{5+2.6}\ \mathrm{k}\Omega
=328.947368\ldots\ \mathrm{k}\Omega.$$

**$R_{out}\approx328.947\ \mathrm{k}\Omega$**는 주항의 계산값이다.
$g_{m1}(r_{o2}\parallel r_{\pi1})=65.789\ldots\gg1$임을 확인하며,
유한한 β와 $r_o$의 모든 항을 포함한 정확식이라고 부르지 않는다.
$1/26$을 그대로 mS 값으로 대입하면 빠지는 $10^3$을 명시했다.

#### 4. P9.23 — 입력 위치 변경과 축퇴

Fig 9.56은 상단 **$Q_2$의 베이스에 입력**을 넣는다. 하단 $Q_1$은 베이스와
이미터가 AC 접지여서 $r_{o1}$로 보인다. 큰 축퇴 저항 때문에 이미터 전압이 입력을
따라가므로 제어 전압이 작아진다는 판단을 먼저 적는다.

출력 단락 시 **큰 β, $g_{m2}r_{o2}\gg1$, $r_{o1}\ll\beta r_{o2}$에서
$G_m$ 주항을 얻기 위해 $Q_2$의 $r_{o2}$ 가지를 생략한 축약 모델**에서는
$$v_e\approx i_{out}r_{o1}$$

$$i_{out}\approx g_{m2}(v_{in}-i_{out}r_{o1})$$

$$G_m\approx\frac{g_{m2}}{1+g_{m2}r_{o1}}
=\frac1{1/g_{m2}+r_{o1}}\approx\frac1{r_{o1}}.$$

이 가지 생략은 실제 $r_{o2}$ 전류가 작다는 뜻이 아니다. 전체 모델의 출력 전류에는
$-v_e/r_{o2}$가 포함된다. 마지막 단계는 추가로 $g_{m2}r_{o1}\gg1$을 쓴다. 같은 큰 β·큰 $g_mr_o$의 주항 모델에서
**추가로 $r_{o1}\ll r_{\pi2}$, 즉 $\beta\gg g_{m2}r_{o1}$일 때만**
입력 영점의 $R_{out}\approx g_{m2}r_{o2}r_{o1}$로 줄일 수 있고,
**$A_v=-G_mR_{out}\approx-g_{m2}r_{o2}$**를 쓴다. 큰 β만으로 이 추가 조건이 보장되지는 않는다.
원문의 $g_mr_o\gg1$만으로 큰 β까지 보장되지는 않으므로, 유한 β가 중요한 실제
풀이에서는 $r_{\pi2}$와 $r_{o2}$를 포함한 소신호 회로에서 $G_m$과 $R_{out}$을
각각 다시 구한다. $R_{out}$은 조건에 맞는 근사식부터 제시하고, 그 근사가 유효하지
않거나 원문이 유한 β 전체 결과를 명시적으로 요구할 때만 위 예외를 적용한다.
단순 제어 전압 식을 모든 조건의 정확식으로 재사용하지 않는다.

#### 5. E9.11 — 위아래 저항과 Gm의 역할

Fig 9.20(b)는 아래 $M_1,M_2$, 위 $M_3,M_4$다. 입력 영점에서 출력 아래와 위를
따로 바라보고, 각 캐스코드의 곱 항이 나머지 저항 항보다 큰 조건에서

$$R_{on}\approx g_{m2}r_{o2}r_{o1}$$

$$R_{op}\approx g_{m3}r_{o3}r_{o4}$$

$$R_{out}=R_{on}\parallel R_{op}.$$

별도로 출력 단락에서 $G_m\approx g_{m1}$의 조건
$(1/g_{m2}\ll r_{o1})$을 확인한 뒤 **$A_v\approx-g_{m1}(R_{on}\parallel R_{op})$**로 연결한다.
출력 단락·고정 바이어스의 저주파 소신호 모델에서 PMOS 부하 가지를 구동하는
소신호가 없어 $G_m$ 측정에 기여하지 않는 상황과, 출력에 시험 전압을 걸어
$R_{out}$을 구할 때 그 가지가 $R_{op}$로 기여하는 상황을 구별한다.
이를 “PMOS가 DC에서 꺼졌다”라고 설명하지 않는다.

#### 6. P9.30 — W 배율에서 이득 배율

Fig 9.20(a)의 $M_1,M_2$ 폭을 각각 $N$배로 늘린다. **$I_D,L,\lambda$와
이동도·산화막 파라미터는 고정**하고 같은 포화 영역의 장채널 모델을 사용한다.

$$g_m\propto\sqrt{(W/L)I_D}\ \Rightarrow\ g_{m1},g_{m2}\to\sqrt N\text{배}$$

$$r_o=\frac1{\lambda I_D}\ \Rightarrow\ \text{그대로}.$$

$$A_v\approx-g_{m1}g_{m2}r_{o1}r_{o2}
\ \Rightarrow\ \frac{A'_v}{A_v}\approx\sqrt N\sqrt N=N.$$

**이득의 크기는 약 $N$배**, 반전 부호는 유지된다. 출력저항 주항만은
$\sqrt N$배이고, 여기에 입력 $g_{m1}$의 $\sqrt N$배가 더해진다.
새 바이어스에서도 포화·주항 근사가 유효한지 확인하며, 이 저주파 결과를
커패시턴스가 바뀌는 주파수 응답 전체로 확장하지 않는다.

## 내부 리뷰어 부록 — 학습 산출물 전재 금지

이 부록은 작성자용 모범 풀이가 아닌 내부 검산 근거다. 아래 정확식·수치 대조를
풀이 본문 HTML·요약·MD·답안 PDF의 예시나 보충에 복사하지 않는다.

- E9.05: 저주파 정확 모델은 $R_{out}=(1+g_{m1}r_{o2})r_{o1}+r_{o2}$다.
  위 근사 설계값을 대입하면 $540\ \mathrm{k}\Omega$이므로 정확 모델에서 목표
  $500\ \mathrm{k}\Omega$를 만족한다고 주장하지 않는다.
- E9.06: $R_{out}=(1+g_{m1}r_{o2})r'_{o1}+r_{o2}$를 내부에서 유도하고,
  $g_{m1}r'_{o1}r_{o2}\gg r'_{o1},r_{o2}$에서 표시한 주항 근사와 대조한다.

## 미확인 범위와 적용 감사

이 관찰로 주파수 응답(FREQ-01의 팔로워 출력 임피던스 제외)·미관찰 소신호 차동 문항(H0923 p1·2·5·8·9·10 빈칸)·모든 트랜지스터 회로의 풀이 선호를 확정하지 않는다.
실제 사고의 시간 순서, 고정 유효숫자·확정한 노드 대응 밖의 고정 색, 빈칸이나 계산 생략의 원인도 미확인이다.
상세 설명 자체를 원하지 않는다는 해석은 하지 않는다. 소신호 등가회로의 사용 우선순위는
2026-10-22 명시적 선호로 확정되었으며, 필요한 등가회로까지 금지하는 뜻이 아니다.
H0930에서 대칭 차동 반회로는 추가 확인했지만 빈칸 문항·주파수 응답·모든 결합 회로로 확대하지 않는다.

작성자와 내용 리뷰어는 이 파일을 읽고 문항별 모든 규칙의 적용 위치·내용 또는
비적용 이유를 기록한다. 실제 검토 없이 `pass`를 채우지 않는다. 필수 명세가 없거나
검토가 실패하면 기존 풀이로 조용히 대체하지 않는다. 명세는 원본 바이트의 SHA-256으로
고정하며 한 바이트라도 바뀌면 이전 개인화 검토를 새 발행에 재사용하지 않는다.
과거 발행물은 계속 열 수 있으나 구버전 검토가 새 발행을 승인하지는 않는다.
형식 검사는 수학 검산·원문 대조·내용 검토·화면 검토를 대체하지 않는다.
