# 문제풀이 영상의 구도·필기 순서·설명 흐름 설계

## 의도와 범위

회로에서 풀이로 돌아올 때 다음 줄 전체를 고려해 화면을 잡고, 같은 줄은 왼쪽부터 공개하며, 작성 중에는 해당 내용의 설명을 이어간다. 기존 카메라·필기·발화가 공유하는 재생 흐름의 bounded 개선이다. 2026-10-07 grill-yourself 결과를 저장한 설계다. 사용자 후속 writing-plans 호출에 따라 설명 밀도 결정 #8은 권장안으로 confirmed by default. 기존 Native 실행 선택을 유지하되 새 계획 검토 전에는 구현하지 않는다.

## 확인된 현재 상태

- `scripts/solution_video/composition.py:pencil_camera_keys`는 현재 글자와 연필만 들어오는지 확인하며, 뒤 글자가 벗어나면 카메라를 다시 잡는다.
- `scripts/solution_video/focus.py:compile_focus_keys`는 다음 write의 첫 span에 해당하는 base camera로 복귀한다.
- `scripts/solution_video/reveal.py:build_timeline`은 `step.glyph_ids` 순서대로 공개한다. E10.13 원자료에서는 본문 이후 첨자·기호를 공개하여 같은 줄을 역행한다.
- `scripts/solution_video/manifest.py:validate_manifest`는 glyph_ids 연결 문자열과 coverage.pdf_text를 비교한다. 화면 순서를 바꾸면서 원문 순서까지 바꾸면 안 된다.
- `scripts/solution_video/media.py:render_master`는 구간 시작에 WAV를 배치하고 나머지를 0으로 채운다. 전달된 E10.13 샘플은 각 발화가 1초인 무음 테스트 PCM이다. 실제 TTS 청취 품질의 증거가 아니다.

## 완료 동작

1. 복귀 카메라는 다음 줄 전체 경계와 연필 여백으로 계산한다. 들어오는 줄은 작성 중 구도를 고정한다.
2. 본문·수식은 같은 줄에서 왼쪽→오른쪽으로 공개한다. 새 줄에서만 왼쪽으로 돌아가고, 줄 내부 같은 가로 영역의 첨자·위첨자·분수 위아래 이동은 허용한다.
3. 분수는 분자 전체→분모 전체 왕복 대신 가로 영역별로 위아래 요소를 처리한다. 긴 분수선·근호선은 영역별로 공개한다.
4. 최소 본문 높이 26px와 연필 bounds를 지키며 줄 전체가 안 들어오면 항·등호 등 명시적인 의미 경계에서 가로 구간을 나눈다. 이동은 다음 구간 작성 전 완료한다.
5. 작성 동안 원자료에 근거한 이유·항의 의미·직전 회로와의 연결을 설명한다. 발화 목표는 필기 시간의 약 70–85%; 짧은 읽기 여유를 남긴다.
6. 필기 중 2초를 넘는 연속 음성 공백은 검토 대상으로 표시한다. 의도적인 읽기 대기는 별도 기록한다.

## 구조와 경계

- PageMap의 기존 glyph_ids/shape_ids는 원문 대응·완성 화면 검사에 유지한다.
- PageMap에 명시적인 writing_units를 추가한다. 줄·열·가로 영역을 사람이 확인해 저작하며 전체 glyph를 x좌표로 단순 정렬하지 않는다.
- 공개용 단위를 별도 compiler로 정규화한다. 본문·첨자·shape를 원본 SVG의 clip으로 공개하고 SVG outline/배치를 재조판하지 않는다.
- 같은 단위를 timeline, camera, 설명 대응에 사용한다. 여러 발화로 나눌 때는 기존 규칙대로 PageMap step 자체를 작게 나누고 각 step에 하나의 write segment를 둔다.
- 기존 typing 실행의 순서는 유지한다. 새 pencil 생성/retime에는 writing_units가 필요하며 누락·모호함은 author-required/입력 오류로 드러낸다. 오래된 결과를 조용히 다른 순서로 바꾸지 않는다.
- 프레임을 유일한 상태 기준으로 사용한다. 1920×1080, 30fps, 24kHz mono, 자막 영역 y=900..1080, 연필 기본 길이 160px와 최대 ±2°는 유지한다.
- 회로 전환은 기존 12프레임 smoothstep을 유지한다. 구간 카메라 이동도 12프레임으로 예약하고 이동 중 필기를 시작하지 않는다.
- 원본 풀이·PDF·복습노트·ec2-review-video는 수정하지 않는다. 새 계산·답 수정·단어별 강제 음성 정렬·실제 손글씨 획 재현은 제외한다.
- 전역 설치/업그레이드 없이 현재 로컬 도구를 사용한다. fake PCM은 자동 테스트에만 사용하며 실제 음성 검토/게시 완료로 승인하지 않는다.
- 대본 변경은 기존 내용/음성 리뷰와 TTS 캐시 정책을 따른다. 공백 지표를 맞추기 위한 무제한 자동 유료 재생성은 하지 않는다.

## 검증

- E10.13 회로→풀이 복귀에서 다음 줄 전체가 보이고, 들어오는 줄 작성 중 재이동이 없다.
- 첨자·위첨자·분수·근호·2단 풀이에서 가로 영역이 역행하지 않는다. 줄바꿈/열 전환은 명시적으로 구분한다.
- 완성 화면 원본 픽셀 비교, 임의 seek/역방향 seek, 현재/미래 공개 상태, 연필 bounds, 회로 주석 검증을 유지한다.
- 실제 WAV의 내부 무음과 구간 뒤 padding을 모두 포함한 공백 지표를 측정한다. 2초 초과 공백은 설명 또는 명시적인 검토 처리를 요구한다.
- 유성 E10.13 샘플을 전달하고 원자료와 설명의 의미를 검토한다. 실제 음성 청취가 불가능하면 audio meaning은 unverified로 두고 사람이 확인하도록 전달한다.
- 검증용 샘플은 정식 latest/게시 결과와 구분하고 기존 샘플을 보존한다.
