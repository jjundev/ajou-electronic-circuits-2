# 연습문제 11.14 — 45 nm, 이동도 300 cm²/(V·s)일 때의 f_T (예제 11.14 변형)

## 조건
- 채널 길이 $L = 45\ \text{nm}$
- 이동도 $\mu_n = 300\ \text{cm}^2/(\text{V}\cdot\text{s})$
- 과구동 전압 $V_{GS} - V_{TH} = 100\ \text{mV}$ (예제 11.14의 값을 그대로 씀) (원문에 없음)

## 구할 것
- $f_T$

## 상속·참조
- 예제 11.14 (E11.14): $2\pi f_T = \dfrac{3}{2}\dfrac{\mu_n}{L^2}(V_{GS} - V_{TH})$ (식 11.53). $\mu_n = 400\ \text{cm}^2/(\text{V}\cdot\text{s})$, 과구동 전압 $100\ \text{mV}$, $L = 65\ \text{nm}$이면 $f_T = 226\ \text{GHz}$
