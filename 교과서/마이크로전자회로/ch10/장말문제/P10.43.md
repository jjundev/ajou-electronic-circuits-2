# 장말문제 10.43 — 식 10.139를 I_D1 = 0, I_SS/2, I_SS 세 경우에 대해 검토

## 원문
Examine Eq. (10.139) for the following cases: (a) $I_{D1} = 0$, (b) $I_{D1} = I_{SS}/2$, and (c) $I_{D1} = I_{SS}$. Explain the significance of these cases.

## 조건
- MOS 차동쌍의 대신호 식 (10.139)
- 세 경우: (a) $I_{D1} = 0$, (b) $I_{D1} = I_{SS}/2$, (c) $I_{D1} = I_{SS}$

## 구할 것
- (a), (b), (c) 각 경우에 식 (10.139)를 검토
- 각 경우의 의미 설명

## 상속·참조
- 식 (10.139) (교재 531쪽):
  $$(V_{in1} - V_{in2})^2 = \frac{2}{\mu_n C_{ox}\dfrac{W}{L}}\left(I_{SS} - 2\sqrt{I_{D1} I_{D2}}\right) \qquad (10.139)$$
- 유도 가정 (교재 530쪽): 채널 길이 변조 무시($\lambda = 0$), 제곱 법칙 $I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$, 두 트랜지스터 동일. KVL $V_{in1} - V_{GS1} = V_{in2} - V_{GS2}$ (10.133), KCL $I_{D1} + I_{D2} = I_{SS}$ (10.134)
- 식 (10.131)–(10.147)의 회로: 본문 Fig 10.31 (교재 530쪽, PDF 18, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-31.png, "대신호 분석을 위한 MOS 차동쌍"). 연결: `R_D: VDD – Vout1`, `R_D: VDD – Vout2`, `M1: D = Vout1, G = Vin1, S = 공통 소스 노드`, `M2: D = Vout2, G = Vin2, S = 공통 소스 노드`, `I_SS: 공통 소스 노드 → 접지` (공통 소스 노드 라벨 없음)

## 회로 — 없음 (식에서 출발하는 문제, 문제 그림 없음)

## 풀이
### 식 정리
- $K = \mu_n C_{ox} W/L$로 두고 KCL $I_{D2} = I_{SS} - I_{D1}$을 넣으면 $(V_{in1} - V_{in2})^2 = \dfrac{2}{K}\left(I_{SS} - 2\sqrt{I_{D1}(I_{SS} - I_{D1})}\right)$
- 평형 과구동 $(V_{GS} - V_{TH})_{equil} = \sqrt{I_{SS}/K}$ (각 소자가 $I_{SS}/2$)와 견준다
### (a) $I_{D1} = 0$
- 근호 항이 0이라 $(V_{in1} - V_{in2})^2 = 2I_{SS}/K$, $M_2$가 전류를 모두 흘리려면 $V_{GS2} > V_{GS1}$이므로 $V_{in1} - V_{in2} = -\sqrt{2I_{SS}/K} = -\sqrt{2}(V_{GS} - V_{TH})_{equil}$
### (b) $I_{D1} = I_{SS}/2$
- $2\sqrt{(I_{SS}/2)^2} = I_{SS}$라 우변이 0: $V_{in1} = V_{in2}$
### (c) $I_{D1} = I_{SS}$
- (a)와 대칭으로 $I_{D2} = 0$이고 $V_{in1} - V_{in2} = +\sqrt{2I_{SS}/K} = \sqrt{2}(V_{GS} - V_{TH})_{equil}$
### 답
- (a) $V_{in1} - V_{in2} = -\sqrt{2I_{SS}/(\mu_n C_{ox} W/L)}$: $M_1$이 막 꺼지는 경계. 이보다 음으로 더 가면 $M_2$가 $I_{SS}$를 모두 흘리고 식은 더 이상 쓸 수 없다
- (b) $V_{in1} - V_{in2} = 0$: 평형, 두 소자가 $I_{SS}/2$씩 흘린다
- (c) $V_{in1} - V_{in2} = +\sqrt{2I_{SS}/(\mu_n C_{ox} W/L)}$: $M_2$가 막 꺼지는 경계. (a)와 합쳐 두 소자가 모두 켜져 전류를 나누는 입력 범위는 $|V_{in1} - V_{in2}| \le \sqrt{2}(V_{GS} - V_{TH})_{equil}$
