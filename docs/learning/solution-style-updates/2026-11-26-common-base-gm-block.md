# 공통 베이스의 이미터 저항 블록으로 Gm 읽기

기록일은 2026-11-26(Asia/Seoul)이다. 이후 해설에 적용할 규칙은 [개인 풀이 명세의 GAIN-01](../../../.claude/skills/ec2-review-pack/references/solution-style.md#gain-01-gm과-rout-분리)에 둔다.

## 입력과 비교

사용자는 1120 P4에서 새 기호 `D`가 갑자기 등장한다고 지적했고, MOS 공통 게이트에서 쓰던 `-gm1`과 연결해 익숙한 식으로 기억하고 싶다고 했다. 기존 MD 확인 뒤 이 풀이를 새 MD에 저장하고 이후 해설과 1120에 적용해 달라고 요청했다.

| 근거 | 기존에 쓰던 풀이 | 이번 반영 |
|---|---|---|
| [1002 P6(1) 해설 MD](../../../복습노트/1002/.assets/문제설명_1002_Differential_Amplifiers.md#p6) | $Q_3$의 부하를 $(1/g_{m3}+R_1/\beta)\parallel r_{O3}$로 읽었다. | 1120 P4에서도 두 저항 항을 회로에서 직접 읽는다. 두 문항의 접속과 계산 목표는 각각의 원문 조건을 따른다. |
| [기존 $1/g_m$ 표기 기록](2026-10-22-explicit-inverse-gm.md) | 익숙한 베이스 경로 블록에 $1/g_m$을 보이게 썼다. | 공통 베이스의 단락 $G_m$ 첫 식에도 $1/g_m+R_B/\beta$를 표시한다. |
| [1120 P4 원문](../../../교과서/마이크로전자회로/ch12/장말문제/P12.42.md) | $1\ll\beta<\infty$, $V_A=\infty$인 바이폴라 회로에서 폐루프 이득과 입출력 임피던스를 구한다. | 첫 식에 베이스 저항의 영향을 남기고 폐루프 식에는 앞에서 계산한 개루프 양을 쓴다. |

새 손풀이 첨부는 없었다. 1002 근거 MD의 SHA-256은 `c8b784e82edd1258909f5ecea9da54ad072cf0644bb605d86601b29d6e253b69`이다. 명세의 변경 전 SHA-256은 `d95b639ad68e586dd935b02413cd688cd3167be108027480ee5302f650e84048`, 변경 후 SHA-256은 `b86ffed624375cc99029088fea1fcbccb78e4855917a76a3d1698c379c157734`다.

## 기억할 식

저주파 활성 영역에서 $r_o$를 생략할 수 있고 베이스가 $R_B$를 거쳐 교류 접지에 이어지는 공통 베이스 단이다. 1120 P4의 ㉠에서 $R_B=R_1\parallel R_2$를 구하고, ㉢ 이미터 쪽에서 $1/g_m$과 $R_B/\beta$가 더해지는 걸 읽는다.

출력을 단락하고 컬렉터로 들어가는 전류를 양으로 정하면 다음과 같다.

$$G_m=-\frac{1}{1/g_m+R_B/\beta}.$$

컬렉터 전류를 기준으로 베이스 저항의 전압 강하는 $i_bR_B=i_cR_B/\beta$다. 이 항이 내부 $1/g_m$에 더해진다. 베이스가 바로 교류 접지면 $R_B=0$이라 $-g_m$으로 줄어든다. 이는 게이트가 교류 접지인 MOS 공통 게이트 단에서 익숙한 형태다.

입력 포트 전류는 이미터 전류이므로, 개루프 입력저항에는 유한 $\beta$ 보정이 있다.

$$R_{\mathrm{in,open}}=\frac{\beta}{\beta+1}\left(\frac{1}{g_m}+\frac{R_B}{\beta}\right).$$

큰 $\beta$에서는 같은 저항 합으로 근사한다. 이후 폐루프 계산은 구해 둔 $R_{\mathrm{in,open}}$, $A_{\mathrm{open}}$, $R_L$과 귀환 배율로 이어진다. 유한 $r_o$ 또는 다른 신호 경로가 결과에 영향을 주는 회로에서는 해당 측정 조건에서 다시 판단한다.

## 검증

- GAIN-01을 보완했고 기존 13개 규칙 ID를 유지했다. 명세 검사 테스트 29개를 통과했다.
- 원문 Fig. 12.105와 $1\ll\beta<\infty$, $V_A=\infty$ 조건을 대조했다. 별도 검산자가 원문 회로의 KCL과 두 복제 회로를 풀어 출력 단락 $G_m$의 부호, 유한 $\beta$의 입력저항, 폐루프 세 결과의 근사 조건을 확인했다.
