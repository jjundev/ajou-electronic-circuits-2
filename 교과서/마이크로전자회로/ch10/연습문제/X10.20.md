# 연습문제 10.20 — 한계 전력 소모가 5 mW일 때의 설계 (예제 10.20 변형)

## 원문
한계 전력 소모가 $5\ \text{mW}$로 증가된다면 위의 설계는 어떻게 되겠는가?

## 조건
- 예제 10.20의 NMOS 차동쌍 설계에서 한계 전력 소모를 $5\ \text{mW}$로 늘림 (예제는 $3\ \text{mW}$)
- 나머지 조건은 예제 10.20과 같음: $\Delta V_{in,max} = 500\ \text{mV}$, $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $V_{DD} = 1.8\ \text{V}$ (원문에 없음)

## 구할 것
- 위의 설계($I_{SS}$, $W/L$)가 어떻게 되는지 (괄호 안은 원문에 없음)

## 상속·참조
- 예제 10.20 (E10.20): 테일 전류 상한 = 전력 / $V_{DD}$ ($3\ \text{mW}$이면 $1.67\ \text{mA}$). $\dfrac{W}{L} = \dfrac{2I_{SS}}{\mu_n C_{ox}\Delta V_{in,max}^2}$ (식 10.152, 식 10.150에서) → 예제 값 $133.6$. 부하 저항은 요구 전압 이득으로 정함

## 회로 — 없음 (그림 없는 글 문제)

## 풀이
### 테일 전류
- $I_{SS} = 5\ \text{mW}/1.8\ \text{V} = 2.78\ \text{mA}$ (예제 $1.67\ \text{mA}$의 5/3배)
### 종횡비
- $\Delta V_{in,max} = \sqrt{\dfrac{2I_{SS}}{\mu_n C_{ox} W/L}}$를 풀면 $\dfrac{W}{L} = \dfrac{2I_{SS}}{\mu_n C_{ox}\Delta V_{in,max}^2}$
- $\dfrac{W}{L} = \dfrac{2 \times 2.78\ \text{mA}}{100\ \mu\text{A/V}^2 \times (0.5\ \text{V})^2} = 222$ ($\Delta V_{in,max}$가 같으므로 $I_{SS}$처럼 5/3배)
### 트랜스컨덕턴스와 부하
- 평형에서 $g_m = \sqrt{\mu_n C_{ox}\dfrac{W}{L} I_{SS}} = \sqrt{2}\,I_{SS}/\Delta V_{in,max} = 7.86\ \text{mS}$ (예제의 $4.71\ \text{mS}$보다 5/3배)
- 같은 이득 $g_m R_D$를 원하면 $R_D$는 예제의 $3/5 = 0.6$배로 줄이면 된다
### 답
- $I_{SS} = 2.78\ \text{mA}$, $W/L \approx 222$로 둘 다 예제의 5/3배가 된다. $g_m$도 5/3배($7.86\ \text{mS}$)라 같은 이득이면 $R_D$를 0.6배로 줄일 수 있다
