## 내부 검산 메모

게이트 AC 접지, 드레인 부하 $R_D$, 소스 시험 전류로 KCL을 세우면 $R_S=(R_D+r_o)/(1+g_mr_o)=[(1/g_m)\parallel r_o](1+R_D/r_o)$다. $R_D=0$이면 수업 규칙과 정확히 같고, $R_D\ll r_o$이면 오차는 대략 $R_D/r_o$다. 예: $g_m=1\ \mathrm{mS}$, $r_o=50\ \mathrm{k\Omega}$에서 $R_D=5\ \mathrm{k\Omega}$이면 약 10%, $R_D=r_o$이면 약 2배다. 이 차이는 학습 본문이 아니라 문항별 내부 검산에 둔다.

## 기존 해설 반영 (1120 P11)

- 발행 문제설명 fragment 전체를 검색한 결과 $(1+R_D/r_o)$ 꼴은 1120 P11 하나뿐이었다. 1104 P2의 $r_{O3}/(1+g_{m3}r_{O3})$는 $R_D=0$인 경우로 규칙과 같다.
- P11 R_S1 단락을 $R_{S1}\approx(1/g_{m1})\parallel r_{O1}$($R_{D1}\ll r_{O1}$, 수업 규칙)로 바꾸고 $R_{in,\mathrm{open}}$·테브난 분압에 같은 $R_{S1}$을 유지했다. 테브난 저항 기호는 사용자 선택에 따라 $R_A$다.
- 정식 절차(extract → build → check → 네 검토 → publish)로 재발행했다. 명세 바이트가 바뀌었으므로 11문항 15소문항 전체의 내용 검토와 개인화 감사(13규칙)를 새로 수행해 모두 pass였다. 원문 대조 11문항 일치, 브라우저 네 조합 통과.
- 독립 검산: P11은 해설을 보지 않은 새 검산자가 SymPy로 다시 풀었고, 수업 규칙식과 정확식의 비가 $R_{D1}/r_{O1}\to0$에서 1로 수렴함을 확인했다. p1–p10은 조각·입력이 바이트 동일하여 기존 독립 검산 스크립트를 재실행해 출력 동일(머리 요약 한 줄 제외)을 확인했다.
