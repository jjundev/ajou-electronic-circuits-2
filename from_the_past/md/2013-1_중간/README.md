# 2013-1 중간고사 — 문제 인덱스

2013-1 중간고사 문제를 md로 옮긴 파일의 목록이다. 형식은 [FORMAT-EXAM.md](../FORMAT-EXAM.md)를 따른다.
이 표는 각 파일의 frontmatter와 `exam.yaml`에서 `_tools/make_exam_index.py`로 만들었다. PDF 열은 원본 PDF의 페이지(1부터)다.

- 시험지 머리: Closed book, 과정 필수
- 원본: `2013-1_중간_모범답안.pdf`
- 문제 5개, 배점 합계 100점
- 원본은 사진 5장(jpg)을 PDF로 묶은 것이다 (원래 이름 2013-1.jpg … 2013-5.jpg, 같은 폴더의 2013-1_중간_모범답안_p1.jpg … p5.jpg). 쪽마다 휴대폰 사진이라 조금 기울고 원근 왜곡이 있으며, 가장자리에 다른 책 페이지가 비친다. 크롭에서는 다른 책 페이지를 뺐다.
- 국문 시험지 "전자회로2 중간시험 (2013년 1학기)"다. 1쪽 배점표로 5문항 각 20점(총 100)을 확인했다. 한 쪽에 한 문항씩 있다.
- 원본은 모범답안이다. 문항 아래 빈칸에 손글씨 풀이가 있고, 일부 인쇄 글자 위에도 손글씨가 겹친다. 손글씨는 옮기지 않았다 (FORMAT-EXAM.md의 스캔 답안지 규칙). 1번 λ_p 값은 인쇄된 0.2에 손글씨로 줄을 긋고 0.1을 적었다 (Q1.md 조건 참고).
