# 장말문제 15.29 — KHN에서 귀환 저항 R5를 제거한 경우

## 조건
- Fig 15.36(b)에서 $R_5$를 빠뜨려 해당 귀환 가지가 개방된다.

## 구할 것
- 변경된 $V_{out}/V_{in}$을 유도하고 $\alpha,Q,\omega_n$을 구한다.

## 상속·참조
- $\alpha,Q,\omega_n$은 고역통과 전달 함수 $\alpha s^2/[s^2+(\omega_n/Q)s+\omega_n^2]$의 분자 계수, 양호도, 고유 각주파수이다. 원래 회로의 합산 관계는 $V_{out}=[(V_{in}R_5+V_XR_4)/(R_4+R_5)](1+R_6/R_3)-V_YR_6/R_3$이다. $R_5$는 첫 비반전 입력과 첫 적분기 출력 $X$ 사이에 연결되어 있다.

## 회로 — Fig 15.36(b)
```spice
R4 Vin n1 {R_4}
R5 X n1 {R_5}
R3 Y n2 {R_3}
R6 Vout n2 {R_6}
XA n1 n2 Vout opamp
R1 Vout n3 {R_1}
C1 X n3 {C_1}
XB 0 n3 X opamp
R2 X n4 {R_2}
C2 Y n4 {C_2}
XC 0 n4 Y opamp
```
- 단자: Vin = 입력 (개방 원) / Vout = 출력 (개방 원)
- 표시: 노드 라벨 V_in, V_out, X, Y / 소자 라벨 R_1–R_6, C_1, C_2, XA, XB, XC (증폭기 라벨 없음) / 부호 세 연산증폭기의 왼쪽 위 −, 아래 + / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 합산 증폭기의 비반전 입력 분기(점)에는 입력의 R_4와 아래쪽으로 X에서 돌아오는 R_5가 연결된다. 반전 입력 쪽(점)에는 옆 R_6 및 맨 위 Y에서 돌아오는 R_3이 닿는다. R_6 오른쪽 V_out 원의 분기(점)와 그 아래 합산기 출력 분기(점)를 세로선이 잇는다. 가운데와 오른쪽 적분기는 비반전 입력이 접지이며, 각 반전 입력의 분기(점)에는 가로 R_1·R_2와 위쪽 되먹임 C_1·C_2가 연결된다. X 출력 분기(점)에는 C_1, R_2, R_5 선이 닿고 Y 위쪽 분기(점)는 C_2와 R_3으로 이어진다. 교차: 없음
