  - 출력 복제 $R_M$ 토글 및 정확식 vs 근사식 곡선 대조로 오개념 해소 (+2)
  - 기존 위젯(`widget-s1-cv-closed`)의 감도 막대를 회로도 기반 개루프 로딩 토글·폐루프 $1/R_M$ 근사 붕괴 실험으로 확장 (+1)

## 기존 `.widget` 관계 및 처리 계획
- 관련 절 `s1-cv-open`에는 위젯이 없다. 이웃 절 `s1-cv-closed`에 `widget-s1-cv-closed`(공칭 $g_{m1}$ ±20% 변동 시 개루프/폐루프 변화율과 $R_{out}$ 막대)가 있다.
- 본 실험은 개루프 회로에서 출력 복제 $R_M$의 유무를 직접 토글(`data-elem`)하고, $R_M$ 변화에 따른 로딩 오차 곡선과 폐루프 $1/R_M$ 근사 붕괴 곡선(`plotData`)을 MNA 회로도와 연동한다.
- 예측 질문은 개루프에서 출력 복제 $R_M$을 연결했을 때의 이득 변화 방향이므로 `widget-s1-cv-closed`가 예측 답을 미리 노출하지 않으며, `widget-s1-cv-closed`는 본문 자리에서 $g_{m1}$ 변동 둔감화를 빠르게 확인하는 고유 쓰임이 남는다.
- **처리:** `widget-s1-cv-closed` **유지**.

## 모드·조작·대표 설정·인과 단계
- **모드 1 (`open` — 개루프 로딩 비교):**
  - 회로: 공통 게이트 $M_1$(소신호: $1/g_{m1}$ 입력 저항, $g_{m1}v_{in}$ 전류원, $R_D$) → 노드 $X$ → 소스 팔로워 $M_2$($g_{m2}(v_X - v_S)$) → 부하 $R_L$ → 출력 복제 $R_M$(토글 소자 `rm_load`: ON이면 $R_M$ 직렬 삽입, OFF이면 단락=$0\ \Omega$ 이상 개루프).
  - 파라미터: `gm1` ($0.5$–$5\text{ mS}$, 기본 $2$), `rd` ($1$–$10\text{ k}\Omega$, 기본 $5$), `rm` ($0.05$–$4\text{ k}\Omega$, 기본 $1$), `rl` ($0.1$–$2\text{ k}\Omega$, 기본 $0.5$). 고정: $g_{m2} = 4\text{ mS}$ ($1/g_{m2} = 0.25\text{ k}\Omega$), $v_{in} = 10\text{ mV}$.
  - `plotData`: $R_M$ ($0.05$–$4\text{ k}\Omega$)에 따른 로딩 포함 정확 개루프 이득 $A_0(R_M) = \frac{g_{m1}R_D}{1/g_{m2}+R_L+R_M}$(실선) vs $R_M$ 무시 이상 근사 $A_{0,\text{ideal}} = \frac{g_{m1}R_D}{1/g_{m2}+R_L}$(점선), 오차율 `errPct`.
- **모드 2 (`closed` — 폐루프 $1/R_M$ 근사):**
  - 회로: 폐루프 C-V 귀환 회로 ($M_1$ 게이트에 $V_F = I_{out} R_M$ 반송, `fb_loop` 토글로 귀환 ON/OFF 비교 가능).
  - 파라미터: `gm1` ($0.5$–$5\text{ mS}$, 기본 $2$), `rd` ($1$–$10\text{ k}\Omega$, 기본 $5$), `rm` ($0.1$–$4\text{ k}\Omega$, 기본 $1$), `rl` ($0.1$–$2\text{ k}\Omega$, 기본 $0.5$).
  - `plotData`: $g_{m1}$ ($0.5$–$5\text{ mS}$)에 따른 정확 폐루프 이득 $G_{m,\text{closed}} = \frac{A_0}{1 + R_M A_0}$(실선) vs 이상 근사 $1/R_M$(점선), 오차율 `errPct`.
- **대표 설정(`presets`):**
  - `open`: `수업 예시 (R_M = 1 kΩ)`, `이상 근사 성립 (R_M = 0.05 kΩ)`, `큰 로딩 (R_M = 3 kΩ)`
  - `closed`: `수업 예시 (KA0 = 5.71)`, `큰 루프 이득 (1/R_M 근접)`, `작은 루프 이득 (근사 붕괴)`
- **인과 단계(`causalSteps`, 모드별 3단계):**
  - `open`: 1) 입력 $v_{in}$ 인가 → $V_X = g_{m1}R_D v_{in}$, 2) $M_2$ 소스 전압 상승($R_L+R_M$ 직렬 로딩), 3) $V_{GS2}$ 감소로 $I_{out}$ 결정.
  - `closed`: 1) 입력 $v_{in}$과 $V_F$의 차로 $V_X$ 형성, 2) $I_{out}$이 $R_L$과 $R_M$을 통과해 $V_F = I_{out}R_M$ 생성, 3) $V_F$가 $M_1$ 게이트로 반송되어 $I_{out}/V_{in} \to 1/R_M$ 안정화.

## 예측 질문 및 오개념
- **예측 질문 (`predict`, `mode: 'open'`):**
  - 질문: "개루프 회로에서 출력 쪽 복제 $R_M = 1\text{ k}\Omega$을 켜면 레이저 전류 이득 $I_{out}/V_{in}$은 어떻게 바뀔까요?"
  - 보기: `drop`("줄어든다"), `same`("변하지 않는다"), `rise`("커진다") — 정답: `drop`.
  - `check`: `before: { params: { gm1: 2, rd: 5, rm: 1, rl: 0.5 }, disabledElems: ['rm_load'] }`, `after: { disabledElems: [] }`, `tiles: ['개루프 이득', '출력 임피던스']`.
- **모드별 오개념 (`mistakes`, 각 3개):**
  - `open`: (1) $R_M$을 지우고 구한 이상 개루프 이득이 실제와 같다고 착각, (2) 출력 쪽 $1/g_{m2}$와 $R_M$을 병렬로 계산하는 오류, (3) 입력 쪽 $R_M$ 복제도 첫 단 이득 $V_X/V_{in}$을 바꾼다고 오해.
  - `closed`: (1) 루프 이득 $KA_0$가 작아도 무조건 $1/R_M$이 맞다고 착각, (2) $R_M$ 하나로 정한 $1/R_M$이 공정 변동에 완전히 무관하다고 오해(절댓값 변동 대가), (3) C-V 귀환에서 출력 임피던스가 작아진다고 혼동(전류 감지이므로 $(1+KA_0)$배 커짐).
