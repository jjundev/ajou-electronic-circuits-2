# 예제 10.10 — 이상적 전류원 부하를 가진 바이폴라 차동쌍의 차동 이득

## 원문
그림 10.18(a)에 보인 회로의 차동 이득을 계산하라. 이득을 최대로 하기 위해 이상적인 전류원이 사용되었다.

## 조건
- 회로: Fig 10.18(a) — 바이폴라 차동쌍 ($Q_1$, $Q_2$, 테일 전류원 $I_{EE}$), 컬렉터 부하가 $V_{CC}$에서 내려오는 이상적인 전류원 두 개
- 이득을 최대로 하려고 이상적인 전류원을 사용함
- 소자 값은 주어지지 않음 (답은 소신호 파라미터 기호로) (원문에 없음)

## 구할 것
- 차동 이득 $\dfrac{v_{out1} - v_{out2}}{v_{in1} - v_{in2}}$

## 상속·참조
- 차동 소신호 입력에서 $P$ 노드는 가상 접지 ($v_P = 0$, 식 10.91). 차동쌍은 두 개의 '절반 회로'로 나뉘고 각 절반 회로는 CE 단과 같음 (본문 Fig 10.17(b), (c)). $R_C$ 부하일 때 차동 이득 $-g_m R_C$ (식 10.94)
- $r_O$: 트랜지스터 출력 저항 (얼리 효과, $r_O = V_A/I_C$)

## 회로 — Fig 10.18(a)
```spice
I1   VCC   out1   ; 이상적 전류원 (라벨·값 없음)
I2   VCC   out2   ; 이상적 전류원 (라벨·값 없음)
Q1   out1  Vin1   P  npn
Q2   out2  Vin2   P  npn
IEE  P     0      {I_EE}
* out1, out2 = 두 출력 원. 원 사이에 V_out 라벨 하나 (차동 출력)
```
- 단자: VCC = 전원, 값 미지정 (가로 레일) / Vin1, Vin2 = 입력 (개방 원) / out1, out2 = 차동 출력 V_out의 두 단자 (개방 원, 각각에는 라벨 없음)
- 표시: 노드 라벨 VCC (레일 오른쪽 끝), V_out (두 출력 원 사이), V_in1 (왼쪽 입력 원 왼쪽), V_in2 (오른쪽 입력 원 오른쪽), P (P 점 왼쪽 아래) / 소자 라벨 Q1 (Q1 오른쪽), Q2 (Q2 왼쪽), I_EE (테일 전류원 오른쪽), 위쪽 전류원 두 개 (라벨 없음) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 맨 위 굵은 가로 레일 VCC, 왼쪽 전류원보다 조금 왼쪽에서 오른쪽 전류원보다 조금 오른쪽까지 / 왼쪽 세로줄 위→아래 전류원(화살표 아래), out1 접속점, Q1 / 오른쪽 세로줄 위→아래 전류원(화살표 아래), out2 접속점, Q2 / out1 접속점에서 가로선이 오른쪽 출력 원, out2 접속점에서 가로선이 왼쪽 출력 원 (두 원이 가운데에서 마주 보고 그 사이에 V_out) / Q1 npn 보통 방향(베이스 왼쪽), Q2 npn 좌우 반전(베이스 오른쪽, 컬렉터 왼쪽 위, 이미터 왼쪽 아래) / V_in1 원 → 가로선 → Q1 베이스, V_in2 원 → 가로선 → Q2 베이스 / 두 이미터는 아래로 내려가 가로선으로 가운데 P 점에서 만남, P에서 아래로 I_EE(화살표 아래), 그 아래 접지 / 접속점 (세 갈래 이상, 3곳): ① out1 = 위 전류원 + 아래 Q1 컬렉터 + 오른쪽 출력선 (점) ② out2 = 위 전류원 + 아래 Q2 컬렉터 + 왼쪽 출력선 (점) ③ P = 왼쪽 Q1 이미터 선 + 오른쪽 Q2 이미터 선 + 아래 I_EE (점) / 교차: 없음

## 답 (검증용)
- 이상적 전류원이면 $Q_1$, $Q_2$의 얼리 효과를 무시할 수 없고 절반 회로는 Fig 10.18(b) → $v_{out1} = -g_m r_O v_{in1}$, $v_{out2} = -g_m r_O v_{in2}$ (식 10.95–10.96) → $\dfrac{v_{out1} - v_{out2}}{v_{in1} - v_{in2}} = -g_m r_O$ (식 10.97)

### 정답 회로 — Fig 10.18(b)
```spice
Q1   out1  vin1  0  npn
RO1  out1  0     {r_O1}
Q2   out2  vin2  0  npn
RO2  out2  0     {r_O2}
* out1, out2 = 두 출력 원. 원 사이에 v_out 라벨 하나 (차동 출력)
```
- 단자: vin1, vin2 = 소신호 입력 (개방 원) / out1, out2 = 차동 출력 v_out의 두 단자 (개방 원, 각각에는 라벨 없음)
- 표시: 노드 라벨 v_out (두 출력 원 사이), v_in1 (왼쪽 입력 원 왼쪽), v_in2 (오른쪽 입력 원 오른쪽) / 소자 라벨 Q1 (Q1 이미터 왼쪽 아래), r_O1 (왼쪽 저항 오른쪽), r_O2 (오른쪽 저항 왼쪽), Q2 (Q2 이미터 오른쪽 아래) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 절반 회로와 오른쪽 절반 회로가 떨어져 좌우 대칭으로 그려짐 / 왼쪽: Q1 npn 보통 방향(베이스 왼쪽), v_in1 원 → 가로선 → 베이스, 이미터 아래 접지. 컬렉터 위 접속점에서 가로선이 오른쪽으로 가다 아래로 꺾여 r_O1(세로), 그 아래 접지. 컬렉터 접속점에서 세로선이 더 올라가 위쪽 모서리 점에서 오른쪽으로 꺾여 출력 원 / 오른쪽: 거울 대칭 — Q2 npn 좌우 반전(베이스 오른쪽), v_in2 원 → 베이스, 이미터 아래 접지, 컬렉터 접속점에서 왼쪽으로 r_O2(세로) → 접지, 세로선이 위쪽 모서리 점에서 왼쪽으로 꺾여 출력 원 / 접지 기호 4개(Q1 이미터, r_O1, r_O2, Q2 이미터) / 접속점 (세 갈래 이상, 2곳): ① Q1 컬렉터 위 = 아래 컬렉터 + 오른쪽 r_O1 선 + 위 출력 쪽 선 (점) ② Q2 컬렉터 위 = 아래 컬렉터 + 왼쪽 r_O2 선 + 위 출력 쪽 선 (점) / 위쪽 꺾임 모서리(세로선이 출력선으로 꺾이는 곳) 두 곳에도 점이 찍혀 있음 (두 선만 만남) / 교차: 없음

## 풀이
### 절반 회로로 나누기
- 차동 소신호 입력에서는 $v_{in1} = -v_{in2}$라 두 이미터 전류 변화가 서로 상쇄되어 $P$가 가상 접지($v_P = 0$)다
- 따라서 각 쪽은 이미터가 접지된 CE 단으로 볼 수 있다
### 절반 회로의 부하
- 이상적 전류원은 소신호로 개방이므로 컬렉터에 남는 저항은 트랜지스터 자신의 $r_O$뿐이다
- $v_{out1} = -g_m r_O\, v_{in1}$, $v_{out2} = -g_m r_O\, v_{in2}$
### 차동 이득
- $\dfrac{v_{out1} - v_{out2}}{v_{in1} - v_{in2}} = -g_m r_O$
- $g_m = \dfrac{I_{EE}/2}{V_T}$, $r_O = \dfrac{V_A}{I_{EE}/2}$이므로 $g_m r_O = V_A/V_T$($V_A$: 얼리 전압)로 바이어스 전류에 무관
### 답
- $\dfrac{v_{out1} - v_{out2}}{v_{in1} - v_{in2}} = -g_m r_O$
