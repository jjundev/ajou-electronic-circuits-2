# 독립 결과와 원고·workbook 대조
- p1: 블라인드 입력/출력 극점은 몸체효과 무시 시 MD 및 조각의 C_GS1+C_SB1, 출력 합과 일치. 교재 인쇄 C_GD1은 그림의 X 단자 연결과 불일치하며 MD에도 오식으로 명시.
- p2: 세 GL 및 각 CY는 몸체효과 무시 모델에서 MD·조각의 RL,CY와 일치. M2의 유한 ro 유지. s=0, Rs=0 및 고주파 극한은 검산 파일 참조.
- p3: gmb1=Cgb1=0이면 독립 저주파 입력 커패시턴스가 MD·조각의 Cgd1+Cgs1/(1+gm1(ro1||ro2))와 일치.
- p4: gmb1=0이면 독립 저주파 입력 커패시턴스는 MD·조각의 Cgs1/(1+gm1(1/gm2||ro1||ro2))와 일치.
- 네 문항 모두 새 블라인드 검산자의 SymPy 스크립트와 출력 및 독립 보고서 참조. 기호 모델 차이는 명시된 몸체효과 무시 조건으로 해소.

- 글꼴 수정 시 p1–p4 SymPy를 독립 담당자가 다시 실행했고 결과를 MD·조각과 재대조했다. p4의 SVG 글자만 바뀌며 회로와 식은 같다.
