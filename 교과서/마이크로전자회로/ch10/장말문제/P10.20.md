# 장말문제 10.20 — 트랜스컨덕턴스 변화를 10 % 이내로 제한하는 최대 입력 (식 10.63 이용)

## 원문
Suppose the input differential signal applied to a bipolar differential pair must not change the transconductance (and hence the bias current) of each transistor by more than $10\ \%$. From Eq. (10.63), determine the maximum allowable input.

## 조건
- 바이폴라 차동쌍에 차동 입력 신호를 걺
- 입력이 각 트랜지스터의 트랜스컨덕턴스(따라서 바이어스 전류)를 $10\ \%$보다 많이 바꾸면 안 됨
- 식 (10.63)을 이용
- 참고 회로 (본문 Fig 10.14): 두 부하 $R_C$가 $V_{CC}$에서 각 컬렉터로, $Q_1$ 베이스 $V_{in1}$, $Q_2$ 베이스 $V_{in2}$, 공통 이미터 노드 P에서 접지로 테일 전류원 $I_{EE}$ (원문에 없음)
- 식 (10.63): $\alpha = 1$, $V_A = \infty$일 때 $I_{C2} = \dfrac{I_{EE}}{1 + \exp\dfrac{V_{in1} - V_{in2}}{V_T}}$ (본문 식, 원문에 없음)
- 기준은 평형 상태 $V_{in1} = V_{in2}$에서의 바이어스 전류 $I_{EE}/2$, 그리고 $g_m = I_C/V_T$ (원문에 없음)

## 구할 것
- 허용되는 최대 입력 (차동 입력 $V_{in1} - V_{in2}$) (괄호 안은 원문에 없음)

## 상속·참조
- 식 (10.63) (교재 514쪽, Fig 10.14, $\alpha = 1$, $V_A = \infty$ 가정):
  $$I_{C2} = \frac{I_{EE}}{1 + \exp\dfrac{V_{in1} - V_{in2}}{V_T}}$$
- 기준은 평형 상태 $V_{in1} = V_{in2}$에서의 바이어스 전류 $I_{EE}/2$ (원문에 없음)
- $g_m = I_C/V_T$
- 식 (10.63)의 회로: 본문 Fig 10.14 (교재 514쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-14.png). 연결: `R_C: VCC – Vout1`, `R_C: VCC – Vout2`, `Q1: C = Vout1, B = Vin1, E = P`, `Q2: C = Vout2, B = Vin2, E = P`, `I_EE: P → 접지`

## 회로 — 없음 (식에서 출발하는 문제, 문제 그림 없음)

## 풀이
### 허용 전류 범위
- 기준은 평형($V_{in1} = V_{in2}$)의 바이어스 전류 $I_{EE}/2$이고 $g_m = I_C/V_T$는 전류에 비례한다
- 한쪽이 $10\ \%$ 줄면 다른 쪽이 $10\ \%$ 늘므로($I_{C1} + I_{C2} = I_{EE}$) 조건 하나로 충분하다: $I_{C2} \ge 0.9 \times I_{EE}/2 = 0.45\, I_{EE}$
### 입력 한계
- $I_{C2} = \dfrac{I_{EE}}{1 + \exp[(V_{in1} - V_{in2})/V_T]} \ge 0.45\, I_{EE}$ → $\exp\dfrac{V_{in1} - V_{in2}}{V_T} \le \dfrac{11}{9}$
- $V_{in1} - V_{in2} \le V_T \ln\dfrac{11}{9} = 0.201\, V_T = 5.22\ \text{mV}$ ($V_T = 26\ \text{mV}$로 둠)
- 대칭이라 음의 입력도 같은 크기까지 허용된다
### 답
- $|V_{in1} - V_{in2}|_{max} = V_T \ln(11/9) \approx 5.22\ \text{mV}$
