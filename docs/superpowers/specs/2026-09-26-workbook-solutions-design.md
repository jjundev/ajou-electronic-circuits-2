# 문제집 풀이 (④) — 설계

## 목적
399문제(교과서 ch09–11 377개, 기출 22개)의 md 끝에 `## 풀이`를 쓴다. 답안지 PDF의 풀이·답 칸에 단계별 풀이와 최종 답이 나온다. 독자는 이 문제집으로 공부하는 학생이다.

완료 기준:
- 모든 문제 md에 `## 풀이`가 있다.
- 예제는 `## 답 (검증용)`과 대조했고, 연습문제·장말문제·기출은 리뷰어가 독립 풀이로 다시 풀어 대조했다.
- `build_workbook.py --all`에서 OVERFLOW가 0이다.
- 세 테스트 묶음이 통과하고, 결과가 main에 병합되어 있다.

이미 있는 것: 형식 검사(`check_md.py:167-170`), 렌더링(`workbook/problem.py:208-218`, `answer.html` `solutionArea`), 쪽 맞춤(`SOL_FIT_STEPS`). 조건 수정 작업은 main에 들어가 있다(`dbe1176`, `021e062`, `bb013ca`, `6192e71`).

## 방식: 프로젝트 스킬 `workbook-solution`
풀이 절차와 내용 규칙을 계획서 부록이 아니라 저장소에 추적되는 스킬 `.claude/skills/workbook-solution/`에 둔다. 앞선 `textbook-to-md` 스킬과 같은 모양이다.

| 파일 | 역할 |
|---|---|
| `SKILL.md` | 오케스트레이터 절차: 입력, 워크트리, 배치 루프, 완료 검사, 자리표시자 표 |
| `references/rules.md` | 풀이 내용 규칙의 유일한 기준 (작성자와 리뷰어가 같이 읽음) |
| `references/writer.md` | 작성자 지시 템플릿 |
| `references/reviewer.md` | 리뷰어 지시 템플릿 |
| `references/lessons.md` | 배치 리뷰에서 쌓이는 좁은 교훈, 기출 해석, 참고 수치 |

- 모양(소절, 마지막 `### 답`, 쓸 수 있는 문법)은 FORMAT.md '문제집용 절'과 `check_md.py`가 정한다. 스킬은 모양을 다시 정의하지 않고 가리킨다.
- 규칙은 파일럿에서 굳힌다. 파일럿 뒤에 규칙이 바뀌면, 이미 쓴 풀이에 소급할지 그때 사용자에게 묻는다.
- 스킬 수정(규칙, 교훈)은 오케스트레이터만 한다. 파일럿이 main에 병합된 뒤에는 main에서만 커밋한다. 에이전트는 스킬 파일을 main checkout 경로에서 읽으므로 항상 최신 규칙을 본다.

## 범위 밖
- `role: answer` 그림(풀이 그림)을 답안지에 넣는 일. 풀이는 글로 설명한다.
- 커밋되는 파이썬 검산 스크립트.
- 힌트 작업에서 미뤄 둔 사소한 문제 1~6.
- 교재를 옮긴 `## 상속·참조`와 `## 답 (검증용)`의 긴 식(E9.03 등)은 고치지 않는다. 풀이가 있으면 답(검증용)은 답안지에 나오지 않는다.

## 도구 변경
- `workbook/source_pages.py`: `next`, `missing`에 `--section {원문,풀이}` (기본 원문, 인자는 NFC로 바꿈). `--ledger`와 `--section 풀이`를 함께 주면 `ERROR`와 종료 코드 2. `missing` stderr는 `<절> 없음: N개`.
- `from_the_past/md/FORMAT-EXAM.md`: "`## 풀이`는 아직 쓰지 않는다"를 교과서 규칙을 따른다로 바꾼다. `check_exam.py`의 답 절 오류 문구를 고친다. `## 풀이`/`### 답`이 통과하는지 테스트로 고정한다.
- `교과서/마이크로전자회로/FORMAT.md`: 풀이 내용 규칙은 스킬의 `rules.md`가 정한다는 한 줄.
