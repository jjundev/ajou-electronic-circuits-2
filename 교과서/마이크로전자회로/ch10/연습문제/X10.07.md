# 연습문제 10.7 — 같은 전력·컬렉터 저항·공급 전압에서 두 회로의 이득 비교 (예제 10.7 변형)

## 원문
두 회로가 같은 한계 전력 소모, 같은 컬렉터 저항, 같은 공급 전압을 가질 때, 두 회로의 전압 이득을 비교하라.

## 조건
- 예제 10.7의 두 회로(바이폴라 차동쌍, CE 단)
- 바뀐 가정: 두 회로의 전력 소모 한계, 컬렉터 저항, 공급 전압이 같음 (예제는 전압 이득이 같다고 가정)

## 구할 것
- 두 회로의 전압 이득 비교

## 상속·참조
- 예제 10.7 (E10.07): 차동쌍 $|A_{V,diff}| = g_{m1,2} R_C$ (각 트랜지스터 전류 $I_{EE}/2$, $g_{m1,2} = I_{EE}/(2V_T)$), CE 단 $|A_{V,CE}| = g_m R_C$ ($g_m = I_C/V_T$). 이득이 같으면 $I_{EE} = 2 I_C$ → 차동쌍이 2배 전력
- 공급 전압이 같으면 전력은 공급 전류에 비례 (차동쌍 $V_{CC} I_{EE}$, CE 단 $V_{CC} I_C$)

## 회로 — 없음 (그림 없는 글 문제)

## 풀이
### 같은 전력에서 전류
- 공급 전압이 같으므로 전력이 같으면 공급 전류가 같다: $I_{EE} = I_C$ ($I_C$는 CE 단의 컬렉터 전류)
- 차동쌍의 각 트랜지스터 전류 $= I_{EE}/2 = I_C/2$
### 두 회로의 이득
- CE 단: $|A_{V,CE}| = g_m R_C = \dfrac{I_C}{V_T} R_C$
- 차동쌍: $|A_{V,diff}| = g_{m1,2} R_C = \dfrac{I_C/2}{V_T} R_C$ ($g_{m1,2}$는 $Q_1$, $Q_2$ 각각의 트랜스컨덕턴스)
### 이득 비
- $\dfrac{|A_{V,diff}|}{|A_{V,CE}|} = \dfrac{1}{2}$
- 같은 전류를 두 트랜지스터가 나눠 쓰므로 각 $g_m$이 절반이 된다
### 답
- 차동쌍의 전압 이득은 CE 단의 절반이다: $|A_{V,diff}| = \dfrac{1}{2}|A_{V,CE}| = \dfrac{I_C R_C}{2V_T}$
