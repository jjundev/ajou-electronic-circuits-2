# 장말문제 9.36 — 저항 분배기로 바이어스한 MOS 전류원의 V_DD 감도

## 조건
- 문제 9.35를 식 (9.85)에 대해 다시 풂 ($V_{DD}$ 기준)

## 구할 것
- $I_1$의 $V_{DD}$에 대한 감도 $\partial I_1 / \partial V_{DD}$
- 이 감도가 $M_1$의 트랜스컨덕턴스에 비례하는 이유를 직관적으로 설명 (문제 9.35에서 이어받음, 원문에 없음)

## 상속·참조
- 문제 9.35: 식 (9.83)에서 $I_1$의 $V_{CC}$ 감도 $\partial I_1/\partial V_{CC}$를 구하고, 그 감도가 $Q_1$의 트랜스컨덕턴스에 비례하는 이유를 직관적으로 설명하는 문제
- 본문 Fig 9.22(b) (교재 468쪽, 크롭 안 함): 저항 분배기 바이어스 MOS 전류원
  - `R1: VDD — P`, `R2: P — 0`
  - `M1: D = I_1이 들어가는 단자, G = P, S = 0` (nmos)
- 식 (9.85): $I_1 = \dfrac{1}{2} \mu_n C_{ox} \dfrac{W}{L} \left( \dfrac{R_2}{R_1 + R_2} V_{DD} - V_{TH} \right)^2$
