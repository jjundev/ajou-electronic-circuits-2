# v2 전자회로 주제 선정 및 아키타입 매핑

정리노트(`.assets/정리노트_*.md`)의 H2/H3 본문을 후보로 삼고, 이웃한 같은 회로 설명을 합친다. 정리노트가 없으면 `stts`와 `강의노트/`, `교과서/마이크로전자회로/` 범위로 후보를 만든다.

## 1. 기존 정리노트 `.widget`과의 관계 (중복 방지)

정리노트 HTML에 이미 `<div class="widget" ...>`(직접 해 보기) 블록이 포함된 절은 다음 기준으로 선별한다:
- **선정(확장):** 기존 `.widget`이 단순 열람형(고정 그림 전환, 단일 수식/선택 확인)에 머무는 경우, 이를 회로 소자·포트·매개변수의 **능동 조작**(`+Δv` 인과 맥동, 포트 오조립 진단, 정확식 vs 근사식 오차 비교 등)으로 확장해 새로운 학습 목표를 줄 때만 선정한다.
- **제외(단순 반복):** 기존 `.widget`이나 기존 `인터렉티브_*.html`과 동일한 대상·조작만 반복하는 후보, 단순 정의·역사·다음 시간 예고는 제외한다. 적합한 후보가 없으면 이유를 보고한다.

## 2. 3대 아키타입 매핑 (`probe` / `bench` / `approx`)

후보마다 학습 목표에 가장 잘 맞는 아키타입 하나를 고른다.

| 아키타입 | 언제 고르는가 | 핵심 조작·시각 요소 | 예시 주제 |
|---|---|---|---|
| `probe` | 입력·매개변수 변화가 가지 전류와 노드 전압·이득으로 전파되는 **인과 경로**를 추적할 때 | `params` 슬라이더 + `causalSteps`(`+Δv` 인과 도미노) + `nodes`/`branches` 배지 | CS/차동쌍 신호 경로와 동작점 이동, 2단 증폭기 노드별 이득·극점 추적 |
| `bench` | 귀환 감지·반송 종단, 소신호 시험원 연결 등 **포트 결선 규칙** 자체를 훈련하고 오조립 결과를 확인할 때 | `ports`(`def`, `answer`, `badOption`) + SVG `data-port` 팝오버 + `mna.js` `singular` 진단 | 네 귀환 토폴로지의 복제 종단 조립, $R_{out}$·$G_m$ 시험 회로 결선 |
| `approx` | 이상적 근사식이 기생 소자·로딩·유한 루프 이득 때문에 **언제 맞고 언제 붕괴하는지** 대조할 때 | `elems` 토글(`data-elem`) + `params` + `plotData`(정확 실선 vs 근사 점선·`errPct`) | 귀환망 로딩 포함 정확 이득 vs $1/K$ 근사 비교, 두 극점 보데 근사 오차 |

## 3. 점수 기준과 수량

| 기준 | 점수 |
|---|---|
| 값을 바꾸면 이득·입력/출력 저항·극점·파형이 달라지는 관계 | +2 |
| 소신호 모델→가지 전류→노드 전압처럼 인과·단계별 해석이 필요한 과정 | +2 |
| 포트 종단·전류 경로·로딩 포함/제외를 직접 비교하면 오개념이 풀림 | +2 |
| 기존 `.widget`을 능동 조작·오조립·근사 비교로 확장할 분명한 목표가 있음 | +1 |

- **선정 수량:** 3점 이상을 우선해 날짜(`MMDD` 또는 `MMDD-MMDD`)당 **2–4개**를 만든다(적합 후보가 1개면 1개만 생성). 명시 주제는 **1개**를 만든다.

## 4. `brief.md` 필수 항목

각 주제별 `RUN/<n>/brief.md`에 아래 항목을 기록한다:
1. 제목, 저장 파일명(한국어 위주, 고유명사·기호만 영어 예: `귀환_종단_조립_벤치`), 점수, 아키타입(`probe`/`bench`/`approx`)
2. 기존 정리노트 `.widget` 대비 확장점(해당 절에 `.widget`이 있을 때)
3. 모드(`modes`), 조작 범위(`params`, `ports`, `elems`), 대표 설정(`presets`, `steps`), `+Δv` 인과 단계(`causalSteps`)
4. 부드러운 1초 예측 질문(`predict`) 1개와 모드별 오개념(`mistakes`) 3개
5. 수식·소신호 모델 가정·단순화·근거 절/쪽·`(교과서 보충)` 여부
6. 정리노트 연결 계획: 실제 `noteHtml` 경로, `sectionId`, 선택 `anchorId`, 관찰 포인트를 담은 `before`/`label`/`after`
