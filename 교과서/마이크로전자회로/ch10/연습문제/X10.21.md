# 연습문제 10.21 — 평형 과구동 전압으로 차동 이득 나타내기 (예제 10.21 변형)

## 원문
수식 $g_m = 2I_D/(V_{GS} - V_{TH})$을 이용하여, 평형 과구동 전압의 항으로 위의 결과를 나타내라.

## 조건
- 수식 $g_m = \dfrac{2I_D}{V_{GS} - V_{TH}}$ 이용

## 구할 것
- 예제 10.21의 결과(차동 전압 이득)를 평형 과구동 전압 $(V_{GS} - V_{TH})_{equil}$의 항으로 나타내기

## 상속·참조
- 예제 10.21 (E10.21): $V_{out1} - V_{out2} = -g_m R_D (V_{in1} - V_{in2})$ (식 10.167), 평형에서 각 트랜지스터 $I_D = I_{SS}/2$
- 식 (10.111): 평형 과구동 전압 $(V_{GS} - V_{TH})_{equil} = \sqrt{\dfrac{I_{SS}}{\mu_n C_{ox}\frac{W}{L}}}$ ($\lambda = 0$)

## 회로 — 없음 (그림 없는 글 문제)

## 풀이
### 평형의 트랜스컨덕턴스
- 평형에서 각 트랜지스터 $I_D = I_{SS}/2$이므로 $g_m = \dfrac{2I_D}{(V_{GS} - V_{TH})_{equil}} = \dfrac{I_{SS}}{(V_{GS} - V_{TH})_{equil}}$
### 차동 이득에 대입
- 예제 결과 $V_{out1} - V_{out2} = -g_m R_D (V_{in1} - V_{in2})$에 넣으면
- $\dfrac{V_{out1} - V_{out2}}{V_{in1} - V_{in2}} = -\dfrac{I_{SS} R_D}{(V_{GS} - V_{TH})_{equil}}$
- 분자 $I_{SS} R_D$는 출력 스윙의 끝값이므로, 같은 스윙이면 과구동 전압이 작을수록 이득이 크다
### 답
- $A_v = -\dfrac{I_{SS} R_D}{(V_{GS} - V_{TH})_{equil}} = -\dfrac{2 I_D R_D}{(V_{GS} - V_{TH})_{equil}}$
