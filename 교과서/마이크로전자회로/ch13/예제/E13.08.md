# 예제 13.8 — 교차 결합 발진기와 콜피츠 발진기의 스타트업 조건 비교

## 원문
교차 결합 발진기와 콜피츠 발진기의 스타트업 조건을 비교하라.

## 조건
- 교차 결합 발진기(본문 13.3.2절)와 콜피츠 발진기(본문 13.3.3절)의 스타트업 조건을 비교
- 참고 회로 (본문 Fig 13.20(c)): 교차 결합 발진기. $V_{DD}$에서 내려오는 두 탱크($C_1$, $L_1$, $R_p$ 병렬)가 각각 노드 X, Y에 달리고, $M_1$ 드레인 = X, $M_2$ 드레인 = Y, $M_1$ 게이트 = Y, $M_2$ 게이트 = X(교차 결합), 두 소스를 묶은 노드에서 접지로 테일 전류원 $I_{SS}$ (원문에 없음)
- 식 (13.16): 각 단의 $\omega_1$에서 전압 이득이 $g_m R_p$일 때 $(g_m R_p)^2 \ge 1$ (본문 식, 원문에 없음)
- 참고 회로 (본문 Fig 13.22(a)): 콜피츠 발진기. $Q_1$ 컬렉터 = Y, $V_{DD}$와 Y 사이에 $L_1$, $R_p$ 병렬, 베이스 = 바이어스 $V_b$, 이미터 = X, X에서 접지로 전류원 $I_1$, Y와 X 사이 $C_1$, X와 접지 사이 $C_2$ (원문에 없음)
- 식 (13.26): $g_m R_p = \dfrac{(C_1 + C_2)^2}{C_1 C_2}$ (본문 식, 원문에 없음)

## 구할 것
- 두 발진기의 스타트업 조건($g_m R_p$의 최소값) 비교

## 상속·참조
- 본문 Fig 13.19(a), 13.20(c) (교재 745–746쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig13-19.png, fig13-20-c.png): 교차 결합 발진기는 탱크 부하 CS 단 둘을 고리로 이은 것. 각 단은 $\omega_1$에서 $180^\circ$ 위상과 $g_m R_p$의 전압 이득
- 식 (13.16): $(g_m R_p)^2 \ge 1$. 더 정확히는 $g_m (R_p \parallel r_O) \ge 1$
- 본문 Fig 13.22(a) (교재 748쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig13-22-a.png): `L1: VDD — Y`, `Rp: VDD — Y`, `Q1: C = Y, B = Vb, E = X`, `I1: X → 0`, `C1: Y — X`, `C2: X — 0`
- 식 (13.25): $\omega_1^2 \approx \dfrac{1}{L_1 \dfrac{C_1 C_2}{C_1 + C_2}}$
- 식 (13.26): $g_m R_p = \dfrac{(C_1 + C_2)^2}{C_1 C_2}$. $C_1 = C_2$일 때 우변이 최소이므로 $g_m R_p$는 최소한 4 이상

## 회로 — 없음 (두 발진기 비교 문제, 예제에 그림 없음)

## 답 (검증용)
- 교차 결합 발진기는 $g_m R_p \ge 1$이면 되고 콜피츠 발진기는 $g_m R_p \ge 4$(최소, $C_1 = C_2$일 때)가 필요하다. 교차 결합 토폴로지가 인덕터 손실을 더 잘 견딘다
- 또한 콜피츠 토폴로지는 싱글엔디드 출력만 제공한다 (교차 결합은 X, Y의 차동 출력)
