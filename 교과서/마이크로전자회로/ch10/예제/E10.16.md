# 예제 10.16 — 이득 5, 전력 2 mW, 출력 CM 1.6 V 이상인 NMOS 차동쌍 설계

## 조건
- NMOS 차동쌍, 전압 이득 $5$
- 한계 전력 소모 $2\ \text{mW}$
- 차동쌍 다음 단이 적어도 $1.6\ \text{V}$의 입력 공통 모드 레벨을 요구 (즉 차동쌍의 출력 CM 레벨 $\ge 1.6\ \text{V}$) (원문에 없음)
- $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $\lambda = 0$, $V_{DD} = 1.8\ \text{V}$

## 구할 것
- 위 조건을 만족하는 NMOS 차동쌍 설계
- 정할 값: 테일 전류 $I_{SS}$, 부하 저항 $R_D$, 트랜지스터 종횡비 $W/L$ (원문에 없음, 원문은 "설계하라"만 적음)

## 상속·참조
- 식 (10.110): 평형에서 출력 CM 레벨 $V_X = V_Y = V_{DD} - R_D \dfrac{I_{SS}}{2}$
- 식 (10.122): 차동 전압 이득 $A_v = -g_m R_D$
- 포화 영역 $I_D = \tfrac{1}{2}\mu_n C_{ox}\tfrac{W}{L}(V_{GS} - V_{TH})^2$ → $g_m = \sqrt{2\mu_n C_{ox}\tfrac{W}{L} I_D}$, 평형에서 각 트랜지스터 $I_D = I_{SS}/2$
- 전력 소모 = $V_{DD} I_{SS}$ (원문에 없음, 풀이가 암시)

## 회로 — 없음 (설계 문제, 문제 그림 없음)

## 답 (검증용)
- 전력 한계와 공급 전압에서 $I_{SS} = 1.11\ \text{mA}$ (식 10.123). $V_{CM,out} = V_{DD} - R_D I_{SS}/2$ (식 10.124)가 $1.6\ \text{V}$이려면 각 저항 전압 강하 $\le 200\ \text{mV}$ → 최댓값 $R_D = 360\ \Omega$ (식 10.125)
- $g_m R_D = 5$ → $g_m = 5/(360\ \Omega)$. $g_m = \sqrt{2\mu_n C_{ox}\tfrac{W}{L}\tfrac{I_{SS}}{2}}$ (식 10.126) → $W/L = 1738$ (식 10.127). 부하 저항에 허용된 전압이 작아 종횡비가 큼
