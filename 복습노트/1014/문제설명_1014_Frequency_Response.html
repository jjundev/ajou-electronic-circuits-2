P1. 대역폭이 부족한 영상

E11.03 · 예제 11.3 · 원 문제 보기

주어진 조건

구할 것

  • 영상 시스템의 대역폭이 부족하다면 어떤 일이 생기는지 설명
원문 보기

영상 신호들은 일반적으로 약 $5\ \text{MHz}$의 대역폭을 갖는다. 예를 들어 컴퓨터의 화면에 영상 신호를 전송하는 그래픽 카드는 최소한 $5\ \text{MHz}$ 대역폭을 지원해야 한다. 만약 영상 시스템의 대역폭이 부족하다면 어떤 일이 생기는지 설명하라.

문제를 읽어요

영상 신호에 필요한 대역폭은 약 $5\,\mathrm{MHz}$예요. 화면을 구동하는 시스템이 그 빠른 변화를 충분히 전달하지 못하면 영상이 어떻게 보이는지 묻고 있어요.

구할 것은 회로의 수치 이득이 아니라 밝기가 급히 바뀌는 자리의 화면 모습이에요.

이 개념과 공식을 떠올려요

“대역폭이 부족”하다는 단서에서 대역폭(bandwidth)과 응답 속도를 떠올려요. 대역폭은 회로가 신호의 빠른 변화까지 전달할 수 있는 주파수 범위예요.

밝기가 짧은 시간에 흰색에서 검정색으로 바뀌는 경계에는 높은 주파수 성분이 필요해요. 그 성분이 충분히 통과하지 못하면 출력 밝기가 입력의 급격한 변화를 늦게 따라가요.

여기서 $5\,\mathrm{MHz}$는 원문이 제시한 영상 신호의 대략적인 필요 대역폭이에요. 픽셀 수나 화면 갱신율은 주어지지 않았으므로 계산하지 않아요.

종이에 쓸 첫 줄

왼쪽에서 오른쪽으로 화면을 스캔할 때 한 픽셀의 흰색에서 다음 픽셀의 검정색으로 빠르게 바뀌는 구간은 고주파 성분이 필요해요.

이렇게 풀어요

스캔이 세로 경계를 가로질러 진행하면 화면 구동 신호는 이웃 픽셀 사이에서 밝기를 급히 바꿔야 해요. 경계가 날카로울수록 빠른 신호 변화가 필요해요.

시스템 대역폭이 부족하면 이 빠른 성분이 약해져 출력 밝기가 다음 픽셀에 도달할 때까지 충분히 바뀌지 못해요.

흰색과 검정색 사이에 중간 밝기인 회색이 나타나므로, 스캔 방향을 가로지르는 세로 테두리가 가로 방향으로 번져요.

교과서 그림 11.3의 검은 E를 보면 고대역 구동에서는 테두리가 선명하고, 대역폭이 부족한 경우에는 세로 경계가 흐려져요. 같은 그림에서 가로획의 위아래 경계는 비교적 선명해요.

완성 답과 검산

왼쪽에서 오른쪽으로 스캔하는 이 예에서 대역폭이 부족하면 세로 테두리가 가로 방향으로 회색으로 번져 화면이 흐릿해져요. 화면 구동 회로가 한 픽셀에서 다음 픽셀로 밝기를 충분히 빠르게 바꾸지 못하기 때문이에요.

방향을 확인해요. 왼쪽에서 오른쪽으로 스캔하면 변화가 늦게 따라오는 위치도 가로 방향에 이어지므로, 그림 11.3(b)처럼 세로 경계가 가로로 흐려져야 해요.

대역폭이 충분한 경우에는 빠른 밝기 전환을 따라가 그림 11.3(a)처럼 경계가 선명해져요. 이 반대 경우와 비교해 결론의 방향을 검산할 수 있어요.

주의할 점

대역폭 부족을 모든 픽셀이 똑같이 어두워지는 현상으로 바꾸지 않아요. 특히 빠른 밝기 변화가 필요한 경계가 퍼져요.

약 $5\,\mathrm{MHz}$만으로 화면 해상도나 초당 화면 수를 정할 수 없어요.

조건을 바꾸어 생각해요

  1. 같은 왼쪽→오른쪽 스캔에서 밝기가 검정색에서 흰색으로 급히 바뀌는 세로 경계라면, 대역폭이 부족할 때 중간 밝기는 어디에 어떤 방향으로 나타날까요?

왼쪽에서 오른쪽으로 스캔하는 이 예에서 대역폭이 부족하면 세로 경계가 가로 방향으로 회색으로 번져요.

약 $5\,\mathrm{MHz}$는 원문이 제시한 영상 신호의 대략적인 필요 대역폭이에요.

P2. CS 단의 전달 함수

E11.04 · 예제 11.4 · 원 문제 보기

주어진 조건

  • 채널길이 변조는 무시 (본문 식 (11.1)의 각주)
  • 소자 값은 주어지지 않음 (답은 기호로)

구할 것

  • 전달 함수 $H(s) = \dfrac{V_{out}}{V_{in}}(s)$
  • 주파수 응답
원문 보기

그림 11.5(a)에 보여진 공통 소스(CS) 단의 전달 함수와 주파수 응답을 결정하라.

문제를 읽어요

게이트의 작은 입력 변화가 드레인 출력에서 얼마나 커지고 뒤집히는지 구하는 문제예요.

출력에 달린 $C_L$ 때문에 그 비율이 주파수마다 달라져요.

숫자를 정하는 문제가 아니므로 $M_1$의 트랜스컨덕턴스 $g_m$, $R_D$, $C_L$로 답을 남겨요.

이 개념과 공식을 떠올려요

그림에서 $C_L$의 위쪽은 드레인 출력이고 아래쪽은 접지예요.

$V_{DD}$도 소신호에서는 AC 접지이므로 $R_D$와 $C_L$은 같은 두 노드 사이의 병렬 부하예요.

커패시터의 임피던스(impedance)는 $1/(sC_L)$이므로 주파수가 높아질수록 출력 부하의 크기가 작아져요.

예를 들어 $g_m$과 $R_D$를 그대로 두고 $C_L$만 두 배로 늘리면, 같은 빠른 신호의 출력 진폭은 더 작아질 거예요.

$g_m$은 소자 하나가 게이트–소스 전압 변화를 드레인 전류로 바꾸는 비율이에요.

$G_m$은 단 전체에서 출력 전압을 0으로 고정했을 때의 출력 전류와 입력 전압의 비예요.

이 문제는 채널 길이 변조를 무시하므로 $r_O$를 추가하지 않아요.

소스가 접지된 포화 영역의 소신호 모델에서 $G_m$과 출력 부하를 따로 읽으면 긴 노드방정식 없이 풀 수 있어요.

회로 역할은 부하 커패시턴스가 있는 CS 단과 연결돼요.

종이에 쓸 첫 줄

처음부터 $C_L$을 개방하지 말고, 출력 전류를 만드는 부분과 그 전류를 전압으로 바꾸는 부하를 나눠요.

소스가 AC 접지이므로 $v_{gs}=V_{in}$이에요.

출력을 단락하면 $R_D$와 $C_L$ 양단 전압이 0이므로, 오른쪽에서 들어오는 단락 전류는 $M_1$의 전류가 돼요.

$$i_{out,sc}=g_mV_{in}$$

이렇게 풀어요

입력을 전류로 바꾸는 비율

첫 줄의 단락 전류를 입력 전압으로 나눠요.

$$G_m=\frac{i_{out,sc}}{V_{in}}=g_m$$
입력을 0으로 두고 출력 부하 읽기

$V_{in}=0$이면 $v_{gs}=0$이라 $M_1$이 만드는 소신호 전류는 0이에요.

저주파에서 $C_L$을 개방으로 보면 출력저항은 다음과 같아요.

$$R_{out}\approx R_D$$

주파수 응답을 구할 때는 외부 부하 $1/(sC_L)$을 다시 병렬로 포함해야 해요.

저항과 커패시터의 어드미턴스를 더한 뒤 역수를 취해요.

$$\begin{aligned}Z_{out}(s)&=R_D\parallel\frac{1}{sC_L}\\&=\frac{1}{1/R_D+sC_L}\end{aligned}$$

분자와 분모에 $R_D$를 곱해요.

$$Z_{out}(s)=\frac{R_D}{1+sR_DC_L}$$

이 식은 문제에서 지정한 $R_D$와 $C_L$만의 병렬 임피던스예요.

반전 부호를 붙여 전달 함수 만들기

실제 신호 응답에서는 출력 단락을 풀고 $R_D$와 $C_L$의 부하를 유지해요.

양의 입력은 $M_1$이 드레인에서 끌어내리는 전류를 늘리므로 출력 전압을 낮춰요.

$$\begin{aligned}H(s)&=\frac{V_{out}}{V_{in}}=-G_mZ_{out}(s)\\&=-\frac{g_mR_D}{1+sR_DC_L}\end{aligned}$$
주파수 응답으로 바꾸기

정현파 정상상태 응답은 $s=j\omega$를 넣어서 구해요.

$$H(j\omega)=-\frac{g_mR_D}{1+j\omega R_DC_L}$$

복소수 $1+jx$의 크기는 $\sqrt{1+x^2}$이므로 분모의 실수부와 허수부를 제곱해 더해요.

$$|H(j\omega)|=\frac{g_mR_D}{\sqrt{1+(\omega R_DC_L)^2}}$$

위상 응답(phase response)은 반전의 $-\pi$에서 연속해서 읽어요.

$$\angle H(j\omega)=-\pi-\tan^{-1}(\omega R_DC_L)$$

위 식은 $\omega\ge0$에서 라디안 단위예요.

낮은 주파수에서는 크기가 $g_mR_D$이고, 주파수가 올라가면 분모가 커져 감소해요.

분모를 0으로 만드는 근은 $s=-1/(R_DC_L)$이에요.

−3 dB 경계는 크기가 저주파 값의 $1/\sqrt2$가 되는 양의 주파수예요.

$$\frac{1}{\sqrt{1+(\omega_{3\mathrm{dB}}R_DC_L)^2}}=\frac{1}{\sqrt2}$$
$$\omega_{3\mathrm{dB}}=\frac{1}{R_DC_L}$$ $$f_{3\mathrm{dB}}=\frac{1}{2\pi R_DC_L}$$

완성 답과 검산

채널 길이 변조를 무시한 이 CS 단의 전달 함수와 주파수 응답이에요.

$$H(s)=-\frac{g_mR_D}{1+sR_DC_L}$$ $$|H(j\omega)|=\frac{g_mR_D}{\sqrt{1+(\omega R_DC_L)^2}}$$

반전의 $-\pi$에서 연속해서 읽은 위상은 $\omega\ge0$에서 다음과 같아요.

$$\angle H(j\omega)=-\pi-\tan^{-1}(\omega R_DC_L)$$ $$\omega_{3\mathrm{dB}}=\frac{1}{R_DC_L}$$

저주파 극한을 대입하면 익숙한 반전 이득으로 돌아와요.

$$H(0)=-g_mR_D$$

반대로 $\omega\to\infty$이면 크기는 0으로 가므로 저역통과 응답이 맞아요.

경계 주파수에서는 분모 크기가 $\sqrt2$가 되는지 확인해요.

$$|H(j\omega_{3\mathrm{dB}})|=\frac{g_mR_D}{\sqrt2}$$ $$20\log_{10}\frac{1}{\sqrt2}\approx-3.01\,\mathrm{dB}$$

경계에서의 위상도 $-\pi-\pi/4=-5\pi/4$로 위상식과 맞아요.

단위도 $g_mR_D$는 $\mathrm{S}\cdot\Omega=1$이라 이득이 무차원이에요.

$R_DC_L$은 $\Omega\cdot\mathrm{F}=\mathrm{s}$라 $\omega R_DC_L$도 무차원이에요.

주의할 점

  • $C_L$을 처음부터 개방하면 저주파 이득만 남아서 주파수에 따른 감소를 구할 수 없어요.
  • 커패시터 자체가 아니라 $1/(sC_L)$을 $R_D$와 병렬로 묶어요.
  • 출력 단락의 $G_m$ 측정과 입력을 0으로 둔 출력저항 측정을 섞지 않아요.
  • $\omega_{3\mathrm{dB}}$는 rad/s이고, Hz로 바꾸려면 $2\pi$로 나눠요.
  • 전달 함수의 음수는 반전을 나타내요. 크기를 구할 때 음수가 없어져도 위상의 반전까지 사라진 것은 아니에요.

조건을 바꾸어 생각해요

  1. $g_m,R_D$를 고정하고 $C_L$만 두 배로 하면 저주파 이득과 −3 dB 주파수는 각각 어떻게 바뀔까요?
  2. $g_m,C_L$을 고정하고 $R_D$만 두 배로 하면 같은 두 값은 각각 어떻게 바뀔까요?

출력 단락에서 $G_m$을 구하고, 입력을 0으로 둔 병렬 부하에 반전 부호를 붙여요.

채널 길이 변조를 무시하며 $C_L$은 출력 부하로 유지해요.

  • 전류 생성$$G_m=g_m$$
  • 출력 부하$$Z_{out}(s)=\frac{R_D}{1+sR_DC_L}$$
  • 전달 함수$$\begin{aligned}H(s)&=-G_mZ_{out}(s)\\&=-\frac{g_mR_D}{1+sR_DC_L}\end{aligned}$$

크기는 저주파 값 $g_mR_D$에서 감소해요.

−3 dB 경계는 $\omega_{3\mathrm{dB}}=1/(R_DC_L)$이에요.

P3. 유한 출력저항의 영향

X11.04 · 연습문제 11.4 · 원 문제 보기

주어진 조건

  • 예제 11.4와 같은 회로: Fig 11.5(a) CS 단 ($M_1$, $R_D$, $C_L$)
  • 바뀐 점: $\lambda \neq 0$
  • 즉 채널길이 변조를 고려해 $M_1$의 출력 저항 $r_O$가 유한
  • 소자 값은 주어지지 않음 (답은 기호로)

구할 것

  • $\lambda \neq 0$일 때 예제 11.4의 결과 유도
    • 즉 전달 함수 $V_{out}/V_{in}(s)$, 그 크기 $|V_{out}/V_{in}|$, −3 dB 대역폭
원문 보기

$\lambda \neq 0$일 경우 위 예제의 결과를 유도하라.

문제를 읽어요

같은 CS 단에서 채널 길이 변조를 무시하지 않으면, 출력에 전류가 흐를 길이 하나 더 생겨요.

그 길인 $M_1$ 내부의 유한 출력저항 $r_O$를 반영해 전달 함수·크기 응답·−3 dB 대역폭을 다시 구해요.

이 개념과 공식을 떠올려요

단서는 $\lambda\ne0$이에요.

이는 드레인 전류가 드레인 전압에도 조금 의존한다는 뜻이므로, 소신호에서는 내부 출력저항(output resistance) $r_O$가 남아요.

소스가 접지돼 있으므로 이 $r_O$는 드레인 출력과 접지 사이의 가지예요.

$R_D$는 외부 드레인 저항이고 $r_O$는 $M_1$의 내부 저항이므로 서로 다른 소자예요.

$V_{DD}$를 AC 접지로 보내면 두 저항은 병렬이고, $C_L$도 같은 출력 노드에 연결돼요.

예를 들어 $r_O=R_D$이면 두 저항을 합친 값은 $R_D/2$여서 출력 전류가 만드는 전압이 줄어요.

$g_m$은 소자의 입력 전압–드레인 전류 변환 비율이고, $G_m$은 출력을 단락해 읽는 단 전체의 변환 비율이에요.

포화 영역의 소신호 모델에서 내부 저항을 먼저 합친 뒤, 외부 커패시터 부하를 붙이는 방법을 써요.

부하 커패시턴스가 있는 CS 단에서 유한 $r_O$를 남기는 경우와 같아요.

종이에 쓸 첫 줄

$r_O$가 생겼다고 $G_m$부터 줄어드는 것은 아니에요.

오른쪽에서 회로 안으로 들어오는 단락 전류를 양으로 정해요.

출력 단락에서는 $R_D,r_O,C_L$ 양단 전압이 모두 0이고, 소스가 접지라 $v_{gs}=V_{in}$이에요.

$$i_{out,sc}=g_mV_{in}$$

이렇게 풀어요

단락 전류로부터 단의 변환 비율

$r_O$의 양단 전압이 0인 이 측정에서는 $r_O$로 흐르는 전류도 0이에요.

$$G_m=\frac{i_{out,sc}}{V_{in}}=g_m$$
입력을 0으로 두고 저항부터 합치기

입력 전압원을 단락하면 $v_{gs}=0$이라 입력으로 제어되는 전류는 0이지만, $r_O$ 가지는 남아요.

저주파에서 $C_L$을 개방으로 보아 출력저항을 먼저 써요.

$$R_{out}\approx R_D\parallel r_O$$

반복되는 병렬 저항을 $R$로 묶어요.

$$R=R_D\parallel r_O=\frac{R_Dr_O}{R_D+r_O}$$

이 $R$과 외부 커패시터의 임피던스가 같은 두 노드 사이에서 병렬이에요.

$$\begin{aligned}Z_{out}(s)&=R\parallel\frac{1}{sC_L}\\&=\frac{1}{1/R+sC_L}\end{aligned}$$

분자와 분모에 $R$을 곱하면 시간상수 $RC_L$이 드러나요.

$$Z_{out}(s)=\frac{R}{1+sRC_L}$$
출력 단락을 풀고 반전 이득 만들기

양의 입력은 출력에서 끌어내리는 전류를 늘려 출력 전압을 낮춰요.

$$\begin{aligned}H(s)&=\frac{V_{out}}{V_{in}}=-G_mZ_{out}(s)\\&=-\frac{g_mR}{1+sRC_L}\end{aligned}$$

여기서 $R=R_D\parallel r_O$이므로 $r_O$를 무시한 결과의 $R_D$ 자리에 이 병렬값이 들어갔어요.

크기 응답과 −3 dB 경계

$s=j\omega$를 넣고 복소수 분모의 크기를 취해요.

$$H(j\omega)=-\frac{g_mR}{1+j\omega RC_L}$$
$$|H(j\omega)|=\frac{g_mR}{\sqrt{1+(\omega RC_L)^2}}$$

저주파 이득 크기는 $g_mR$이므로, 그 값의 $1/\sqrt2$가 되는 조건을 풀어요.

$$\frac{1}{\sqrt{1+(\omega_{3\mathrm{dB}}RC_L)^2}}=\frac{1}{\sqrt2}$$ $$1+(\omega_{3\mathrm{dB}}RC_L)^2=2$$
$$\omega_{3\mathrm{dB}}=\frac{1}{RC_L}=\frac{1}{(R_D\parallel r_O)C_L}$$ $$f_{3\mathrm{dB}}=\frac{1}{2\pi RC_L}$$

$g_m,R_D,C_L$을 고정하고 유한 $r_O$를 포함하면 $R$이 $R_D$보다 작아져요.

따라서 저주파 이득 크기는 줄고, 이 단순한 단일 출력 노드 모델의 대역폭은 넓어져요.

완성 답과 검산

유한 $r_O$를 남기면 $R=R_D\parallel r_O$를 사용해요.

$$H(s)=-\frac{g_mR}{1+sRC_L}$$ $$|H(j\omega)|=\frac{g_mR}{\sqrt{1+(\omega RC_L)^2}}$$ $$\omega_{3\mathrm{dB}}=\frac{1}{RC_L}$$

소스가 AC 접지인 포화 영역의 소신호 모델이며 외부 $C_L$을 부하로 유지한 결과예요.

$r_O\to\infty$를 대입하면 $R\to R_D$라서 채널 길이 변조를 무시한 예제로 돌아와요.

$$\lim_{r_O\to\infty}H(s)=-\frac{g_mR_D}{1+sR_DC_L}$$ $$\lim_{r_O\to\infty}\omega_{3\mathrm{dB}}=\frac{1}{R_DC_L}$$

$r_O=R_D$인 특수값에서도 방향을 확인할 수 있어요.

$$R=\frac{R_D}{2}$$

같은 $g_m,R_D,C_L$에서 $r_O$를 무시한 경우보다 저주파 이득 크기는 절반, −3 dB 주파수는 두 배예요.

경계에 대입하면 이득 크기가 저주파 값의 $1/\sqrt2$가 돼요.

$$|H(j\omega_{3\mathrm{dB}})|=\frac{g_mR}{\sqrt2}$$

$g_mR$의 단위는 $\mathrm{S}\cdot\Omega=1$이라 이득이 무차원이에요.

$RC_L$의 단위는 $\Omega\cdot\mathrm{F}=\mathrm{s}$라 시간상수가 맞아요.

주의할 점

  • 입력을 0으로 두어도 $r_O$는 없어지지 않아요. 0이 되는 것은 $v_{gs}$로 제어되는 전류예요.
  • $R_D$와 $r_O$는 같은 출력–접지 사이에 있으므로 직렬이 아니라 병렬이에요.
  • $r_O$를 절반으로 줄였다고 병렬값 $R_D\parallel r_O$까지 무조건 절반이 되지는 않아요.
  • 대역폭은 바뀐 저주파 이득 $g_mR$을 기준으로 −3 dB가 되는 곳이에요.
  • $\omega$는 rad/s이고 $f$는 Hz예요. 두 값을 같은 수로 쓰지 않아요.

조건을 바꾸어 생각해요

  1. $g_m,R_D,C_L$은 고정해요. 처음 $r_O=R_D$였다가 $r_O$만 $R_D/2$로 줄면, 저주파 이득 크기와 −3 dB 주파수는 각각 원래 값의 몇 배일까요?
  2. $g_m,R_D,r_O$를 고정하고 $C_L$만 절반으로 줄이면 같은 두 값은 어떻게 바뀔까요?

입력을 0으로 둬도 남는 $r_O$를 $R_D$와 먼저 병렬로 묶어요.

출력 단락에서는 $G_m=g_m$이에요.

  • 저항 블록$$R=R_D\parallel r_O$$
  • 전달 함수$$H(s)=-\frac{g_mR}{1+sRC_L}$$
  • 3 dB 경계$$\omega_{3\mathrm{dB}}=\frac{1}{RC_L}$$

$g_m,R_D,C_L$이 같으면 유한 $r_O$ 때문에 이득 크기는 줄고 대역폭은 넓어져요.

P4. 이득이 10% 줄어드는 주파수

P11.01 · 장말문제 11.1 · 원 문제 보기

주어진 조건

  • $R_D = 1\ \text{k}\Omega$, $C_L = 1\ \text{pF}$
  • 채널길이 변조와 다른 커패시턴스는 무시

구할 것

  • 이득이 10% ($\approx 1\ \text{dB}$) 떨어지는 주파수
원문 보기

In the amplifier of Fig. 11.62, $R_D = 1\ \text{k}\Omega$ and $C_L = 1\ \text{pF}$. Neglecting channel-length modulation and other capacitances, determine the frequency at which the gain falls by 10% ($\approx 1\ \text{dB}$).

문제를 읽어요

낮은 주파수에서 얻던 전압이득의 크기를 100%로 놓고, 그 크기가 90%로 줄어드는 주파수를 찾아요. 출력의 $C_L$이 높은 주파수에서 출력을 줄이는 CS 회로예요.

“약 $1\,\mathrm{dB}$”는 감소량을 짐작하게 해 주는 말이고, 계산 조건은 정확히 10% 감소예요. 입력은 $M_1$의 게이트, 출력은 드레인의 $R_D$·$C_L$ 접속점이에요.

이 개념과 공식을 떠올려요

채널 길이 변조와 다른 커패시턴스를 무시한다는 단서에서 부하 커패시턴스가 있는 단일 극점 CS 단을 떠올려요. $\lambda=0$이므로 $r_O$ 가지는 없고, 출력에 $R_D$와 $C_L$만 남아요.

$g_m$은 트랜지스터의 트랜스컨덕턴스(transconductance), $G_m$은 출력 단락에서 측정한 단의 전류 생성 비예요. $R_{out}$은 입력을 0으로 놓고 출력에서 본 저항, $Z_{out}(s)$는 그 저항에 $C_L$을 연결한 출력 임피던스예요.

소스가 AC 접지인 소신호 포화 동작에서 $G_m$과 출력 부하를 따로 구하면 반전 부호까지 확인할 수 있어요. 이득 감소율은 $g_m$의 수치가 없어도 저주파 이득으로 나누면 구할 수 있어요.

예를 들어 이득 크기가 100에서 90으로 바뀌면 비는 $90/100=0.9$예요. 전력비가 아니라 전압이득 크기의 비를 사용해요.

종이에 쓸 첫 줄

출력을 단락하고 $i_{out,sc}$의 양의 방향을 오른쪽 출력 단자에서 회로 안으로 정해요.

소스가 AC 접지라 $v_{gs}=v_{in}$이고, 단락된 드레인으로 들어가는 전류는 $g_mv_{in}$이에요.

$$G_m=\frac{i_{out,sc}}{v_{in}}=g_m$$

독립 입력 전압을 0으로 두고 $V_{DD}$를 AC 접지로 봐요. 저주파에서 $C_L$을 개방하면 $R_D$가 출력 부하예요.

$$R_{out}\approx R_D$$

이 문제의 $\lambda=0$ 모델에서 출력의 저항성 경로는 $R_D$뿐이에요. 여기에 같은 출력–접지 두 노드의 $C_L$을 병렬로 연결해요.

$$Z_{out}(s)=R_D\parallel\frac1{sC_L}=\frac{R_D}{1+sR_DC_L}$$

양의 입력은 드레인에서 끌어내리는 전류를 늘리므로 출력이 내려가요. 따라서 이득에는 음의 부호가 붙어요.

$$H(s)=\frac{v_{out}}{v_{in}}=-G_mZ_{out}(s)=-\frac{g_mR_D}{1+sR_DC_L}$$

이렇게 풀어요

먼저 출력 RC 시간과 극점 코너를 구해요. $1\,\mathrm{k\Omega}=10^3\,\Omega$, $1\,\mathrm{pF}=10^{-12}\,\mathrm F$이므로 다음과 같아요.

$$R_DC_L=(10^3\,\Omega)(10^{-12}\,\mathrm F)=10^{-9}\,\mathrm s$$ $$\omega_p=\frac1{R_DC_L}=10^9\,\mathrm{rad/s}$$ $$f_p=\frac{\omega_p}{2\pi}\approx159.15\,\mathrm{MHz}$$

그다음 $s=j\omega$를 대입한 크기를 낮은 주파수의 크기 $|H(0)|=g_mR_D$로 나눠요. 공통 인자 $g_mR_D$가 약분돼요.

$$\frac{|H(j\omega)|}{|H(0)|}=\frac1{\sqrt{1+(\omega/\omega_p)^2}}$$

10% 감소는 원래 크기의 $0.9=9/10$가 남는다는 뜻이에요.

$$\frac1{\sqrt{1+(\omega/\omega_p)^2}}=\frac9{10}$$

양변을 제곱한 뒤 역수를 취해요.

$$1+(\omega/\omega_p)^2=\frac{100}{81}$$ $$\frac{\omega}{\omega_p}=\sqrt{\frac{100}{81}-1}=\frac{\sqrt{19}}9$$

양의 주파수를 고르고, 반올림하지 않은 비를 끝까지 유지해요.

$$\omega=\frac{\sqrt{19}}9\times10^9\,\mathrm{rad/s}\approx4.84\times10^8\,\mathrm{rad/s}$$ $$f=\frac{\sqrt{19}}{18\pi}\times10^9\,\mathrm{Hz}\approx77.08\,\mathrm{MHz}$$

$f$는 반올림한 $4.84\times10^8$을 재사용하지 않고 정확한 $\sqrt{19}/9$에서 계산했어요. $g_m$은 정규화할 때 없어지므로 따로 수치가 필요하지 않아요.

완성 답과 검산

이득 크기가 정확히 10% 감소하는 주파수예요.

$$\omega\approx4.84\times10^8\,\mathrm{rad/s}$$ $$f\approx77.08\,\mathrm{MHz}$$

$R_D=1\,\mathrm{k\Omega}$, $C_L=1\,\mathrm{pF}$이고, 채널 길이 변조와 다른 커패시턴스를 무시한 결과예요.

감소율을 다시 넣어 봐요. 반올림 전 비 $\omega/\omega_p=\sqrt{19}/9$를 넣으면 다음처럼 목표와 정확히 맞아요.

$$\frac{|H(j\omega)|}{|H(0)|}=\frac1{\sqrt{1+19/81}}=\frac9{10}$$

극점과 비교해요. $\sqrt{19}/9\lt1$이므로 목표 주파수는 극점보다 낮아야 해요. 계산한 $77.08\,\mathrm{MHz}$도 $f_p\approx159.15\,\mathrm{MHz}$보다 낮아요.

dB로 확인해요. 전압이득 크기의 비이므로 $20\log_{10}$을 써요.

$$20\log_{10}(0.9)\approx-0.92\,\mathrm{dB}$$

원문의 “약 $1\,\mathrm{dB}$”와 맞지만, 정확히 $1\,\mathrm{dB}$ 감소하는 주파수를 구한 것은 아니에요.

주의할 점

  • 10% 감소는 $|H|/|H(0)|=0.9$예요. 남은 크기를 $0.1$로 놓거나, 전력비 $0.9$를 전압이득 비 대신 쓰지 않아요.
  • $1/(R_DC_L)=10^9$의 단위는 $\mathrm{rad/s}$예요. $\mathrm{Hz}$로 바꿀 때는 $2\pi$로 나눠요.
  • 극점에서는 크기가 $1/\sqrt2$로 줄어 약 $-3\,\mathrm{dB}$가 돼요. 이번 목표는 10% 감소이므로 그보다 낮은 주파수예요.
  • 원문의 “약 $1\,\mathrm{dB}$”를 정확한 $1\,\mathrm{dB}$ 조건으로 바꾸지 않아요. $\sqrt{19}/9$를 유지한 채 마지막에만 반올림해요.

조건을 바꾸어 생각해요

  1. $R_D$와 $g_m$을 고정하고 $C_L$만 $2\,\mathrm{pF}$로 늘리면, 같은 10% 감소를 만드는 주파수는 어떻게 바뀔까요? 채널 길이 변조와 다른 커패시턴스는 계속 무시해요.

전압이득 크기의 남은 비를 $0.9$로 놓고 단일 극점 응답을 풀어요.

$$\omega=\frac{\sqrt{19}}9\,\omega_p$$

$\omega_p=10^9\,\mathrm{rad/s}$이고 목표 주파수는 그보다 낮아요.

$$f\approx77.08\,\mathrm{MHz}$$

이 결과는 채널 길이 변조와 다른 커패시턴스를 무시해요.

정확한 조건은 10% 감소이고 약 $1\,\mathrm{dB}$라는 설명과 구별해요.

P5. 전력과 대역폭으로 정하는 이득

P11.02 · 장말문제 11.2 · 원 문제 보기

주어진 조건

  • 목표 −3 dB 대역폭 $1\ \text{GHz}$, 부하 커패시턴스 $2\ \text{pF}$
  • 전력 소모 $2\ \text{mW}$
  • $V_{CC} = 2.5\ \text{V}$
  • 얼리 효과와 다른 커패시턴스는 무시

구할 것

  • 얻을 수 있는 최대 (저주파) 이득
원문 보기

In the circuit of Fig. 11.63, we wish to achieve a −3-dB bandwidth of $1\ \text{GHz}$ with a load capacitance of $2\ \text{pF}$. What is the maximum (low-frequency) gain that can be achieved with a power dissipation of $2\ \text{mW}$? Assume $V_{CC} = 2.5\ \text{V}$ and neglect the Early effect and other capacitances.

문제를 읽어요

이득을 높이려고 전류나 부하 저항을 무작정 키울 수 없는 설계 문제예요.

전류는 전력 한계에, $R_1$은 목표 대역폭에 묶이므로 두 허용 범위 안에서 저주파 이득을 가장 크게 해요.

원문에는 열전압 $V_T$가 없으므로 기호 답을 먼저 구하고, 수업의 $26\,\mathrm{mV}$ 관례를 적용한 수치를 따로 밝혀요.

이 개념과 공식을 떠올려요

그림은 이미터가 접지된 공통 이미터(common-emitter, CE) 단이에요.

소신호에서 전원은 AC 접지이므로 컬렉터 출력에는 $R_1$과 $C_L$이 병렬로 보여요.

얼리 효과와 다른 커패시턴스를 무시한 단일 출력 노드 모델이므로 −3 dB 주파수는 $1/(2\pi R_1C_L)$이에요.

$g_m=I_C/V_T$는 베이스–이미터 전압 변화를 컬렉터 전류로 바꾸는 비율이에요.

$G_m$은 출력을 단락해 읽은 단 전체의 비율이고, $R_{out}$은 입력을 0으로 둔 출력저항이에요.

이상적으로 입력 전압을 인가하는 이 회로에서 저주파 이득 크기는 $I_CR_1/V_T$에 비례하므로 전류와 저항을 각각 얼마나 키울 수 있는지 먼저 찾아요.

예를 들어 전류를 고정하고 $R_1$만 두 배로 하면 이득 크기는 두 배지만 대역폭은 절반이 돼요.

전력은 그림의 컬렉터 전원이 공급하는 $P=V_{CC}I_C$로 계산해요.

이 수업 모델은 별도 베이스 바이어스·입력 구동 회로의 전력을 포함하지 않아요.

−3 dB 대역폭과 이득–대역폭 트레이드오프를 설계 제약으로 읽는 문제예요.

종이에 쓸 첫 줄

요구 대역폭을 $f_b=1\,\mathrm{GHz}$, 전력 한계를 $P_{\max}=2\,\mathrm{mW}$로 두고 두 제약을 먼저 써요.

$$V_{CC}I_C\le P_{\max}$$ $$f_{3\mathrm{dB}}=\frac{1}{2\pi R_1C_L}\ge f_b$$

목표를 정확히 $1\,\mathrm{GHz}$로 맞추는 경우에는 두 번째 식의 경계를 쓰게 돼요.

이렇게 풀어요

허용 전류와 저항을 먼저 구해요
$$I_C\le\frac{P_{\max}}{V_{CC}}=\frac{2\,\mathrm{mW}}{2.5\,\mathrm{V}}=0.8\,\mathrm{mA}$$

모든 양이 양수이므로 대역폭 부등식을 저항의 상한으로 바꿀 수 있어요.

$$R_1\le\frac{1}{2\pi f_bC_L}$$ $$\begin{aligned}R_{1,\max}&=\frac{1}{2\pi(10^9\,\mathrm{Hz})(2\times10^{-12}\,\mathrm{F})}\\&=\frac{250}{\pi}\,\Omega\approx79.58\,\Omega\end{aligned}$$

저항을 이보다 크게 고르면 이득이 올라가더라도 $1\,\mathrm{GHz}$ 대역폭을 충족하지 못해요.

$I_C$와 $R_1$이 커질수록 이득 크기가 커지므로 두 상한을 모두 쓰는 값이 최대를 만들어요.

$$I_C=\frac{P_{\max}}{V_{CC}}$$ $$R_1=\frac{1}{2\pi f_bC_L}$$

능동 영역에서 동작하도록 바이어스한다는 소신호 모델 안에서 선택한 값이에요.

출력을 단락해 전류 변환 비율 구하기

오른쪽에서 회로 안으로 들어오는 단락 전류를 양으로 정해요.

이미터가 AC 접지이므로 $v_{be}=V_{in}$이고, 단락된 $R_1,C_L$에는 전압 변화가 없어요.

$$i_{out,sc}=g_mV_{in}$$ $$G_m=\frac{i_{out,sc}}{V_{in}}=g_m=\frac{I_C}{V_T}$$
입력을 0으로 둔 출력 부하

베이스와 이미터가 모두 AC 접지이면 $v_{be}=0$이에요.

얼리 효과를 무시하므로 트랜지스터가 만드는 유한한 컬렉터 출력저항은 없어요.

외부 부하까지 포함한 출력 임피던스는 $R_1$과 $1/(sC_L)$의 병렬이에요.

$$Z_{out}(s)=R_1\parallel\frac{1}{sC_L}$$

구하려는 저주파에서는 $C_L$이 개방처럼 보여요.

$$R_{out}\approx R_1$$
반전 부호와 최대 이득 크기

출력 단락을 풀면 양의 입력은 컬렉터 전류를 늘려 출력 전압을 낮춰요.

$$A_0\approx-G_mR_{out}\approx-\frac{I_CR_1}{V_T}$$

두 경계식을 먼저 대입하고 공통 인자를 정리해요.

$$\begin{aligned}|A_0|_{\max}&=\frac{P_{\max}}{V_{CC}V_T}\frac{1}{2\pi f_bC_L}\\&=\frac{P_{\max}}{2\pi V_{CC}V_Tf_bC_L}\end{aligned}$$

주어진 값만 대입하면 열전압을 남긴 기호 답이 돼요.

$$|A_0|_{\max}=\frac{0.2\,\mathrm{V}}{\pi V_T}$$

이제 원문의 조건이 아닌 수업·참고 풀이의 관례 $V_T=26\,\mathrm{mV}=0.026\,\mathrm{V}$를 적용해 수치로 비교해요.

$$|A_0|_{\max}=\frac{0.2}{0.026\pi}\approx2.45\;\mathrm{V/V}$$ $$A_0\approx-2.45\;\mathrm{V/V}$$

dB 값은 반올림 전 $0.2/(0.026\pi)$로 계산해요.

$$20\log_{10}|A_0|_{\max}\approx7.78\,\mathrm{dB}$$

완성 답과 검산

열전압을 남긴 최대 저주파 이득 크기예요.

$$|A_0|_{\max}=\frac{P_{\max}}{2\pi V_{CC}V_Tf_bC_L}=\frac{0.2\,\mathrm{V}}{\pi V_T}$$

수업·참고 풀이의 관례 $V_T=26\,\mathrm{mV}$를 쓰면 다음과 같아요.

$$|A_0|_{\max}\approx2.45\;\mathrm{V/V}$$ $$A_0\approx-2.45\;\mathrm{V/V}$$

선택한 전류는 $0.8\,\mathrm{mA}$, 저항은 $(250/\pi)\,\Omega$이며 CE 능동 영역의 소신호 모델 결과예요.

원래의 전력 제약에 대입해요.

$$V_{CC}I_C=(2.5\,\mathrm{V})(0.8\,\mathrm{mA})=2\,\mathrm{mW}$$

대역폭은 반올림한 저항 대신 정확한 $250/\pi$를 넣어 확인해요.

$$f_{3\mathrm{dB}}=\frac{1}{2\pi(250/\pi\,\Omega)(2\times10^{-12}\,\mathrm{F})}=10^9\,\mathrm{Hz}$$

저항의 전압 강하는 전류와 저항의 곱이에요.

$$I_CR_1=(0.8\,\mathrm{mA})\frac{1}{4\pi}\,\mathrm{k}\Omega=\frac{0.2}{\pi}\,\mathrm{V}\approx63.66\,\mathrm{mV}$$

따라서 컬렉터의 DC 전압은 다음과 같아요.

$$V_C=V_{CC}-I_CR_1=2.5\,\mathrm{V}-\frac{0.2}{\pi}\,\mathrm{V}\approx2.44\,\mathrm{V}$$

실제 NPN 능동 영역에서는 베이스–이미터를 순방향으로 바이어스하고 $V_{CB}=V_C-V_B\ge0$을 만족해야 해요.

원문에는 베이스의 DC 바이어스가 없으므로 임의의 $V_B$를 넣어 동작 영역의 수치 여유를 단정하지 않아요.

저주파 이득의 단위도 $I_CR_1/V_T$가 $\mathrm{V}/\mathrm{V}=1$이므로 맞아요.

주의할 점

  • $1\,\mathrm{GHz}$는 Hz 단위 주파수예요. $R_1=1/(2\pi f_bC_L)$의 $2\pi$를 빼면 대역폭 조건이 틀려요.
  • 전력은 $Q_1$만의 $V_{CE}I_C$가 아니라 이 풀이에서 정한 컬렉터 전원 공급 전력 $V_{CC}I_C$로 계산해요.
  • $V_T=26\,\mathrm{mV}$는 원문에 주어진 값이 아니에요. 다른 열전압이면 최대 이득도 바뀌어요.
  • 최대 이득은 크기를 말해요. 실제 CE 전압이득에는 반전의 음수가 붙어요.
  • 반올림한 $79.58\,\Omega$를 다음 계산에 계속 넣지 말고 $250/\pi\,\Omega$를 유지해요.

조건을 바꾸어 생각해요

  1. 전력 한계 $2\,\mathrm{mW}$, $V_{CC}$, $C_L$, $V_T$와 같은 능동 영역 모델을 유지하고 목표 대역폭만 $2\,\mathrm{GHz}$로 높이면, 최대 허용 $I_C$, 최대 허용 $R_1$, 최대 이득 크기는 각각 어떻게 바뀔까요?

전력과 대역폭이 정한 전류·저항 상한을 함께 써서 이득 크기를 최대화해요.

전력은 컬렉터 전원의 $V_{CC}I_C$로 계산해요.

  • 전류 한계$$I_C\le\frac{P_{\max}}{V_{CC}}$$
  • 저항 한계$$R_1\le\frac{1}{2\pi f_bC_L}$$
  • 최대 크기$$\begin{aligned}|A_0|_{\max}&=\frac{P_{\max}}{V_{CC}V_T}\\&\quad\cdot\frac{1}{2\pi f_bC_L}\end{aligned}$$

$V_T=26\,\mathrm{mV}$는 수업 관례이며 이때 크기는 약 $2.45$예요.

반전 이득은 $A_0\approx-2.45$예요.

P6. 네 가지 부하의 대역폭

P11.03 · 장말문제 11.3 · 원 문제 보기

주어진 조건

  • $V_A = \infty$이지만 $\lambda > 0$으로 가정 (인쇄된 대로)
  • (a)(b)는 바이폴라에 $V_A = \infty$, (c)(d)는 MOS에 $\lambda > 0$을 적용한다고 봄
  • 다른 커패시턴스는 무시 ($C_L$만 고려)

구할 것

  • 네 회로 각각의 −3 dB 대역폭
원문 보기

Determine the −3 dB bandwidth of the circuits shown in Fig. 11.64. Assume $V_A = \infty$ but $\lambda > 0$. Neglect other capacitances.

문제를 읽어요

네 회로 모두 출력의 $C_L$이 충전되고 방전되는 속도를 구하는 문제예요. 출력에 붙은 트랜지스터가 어떤 저항으로 보이는지만 회로마다 달라요.

(a)·(b)는 $V_A=\infty$인 바이폴라 회로라 Early 효과의 출력저항을 무한대로 둬요. (c)·(d)는 $\lambda\gt0$인 MOS 회로라 두 소자의 유한 $r_O$를 남겨요.

입력은 원 그림의 $v_{in}$이고, 출력은 $C_L$이 달린 노드예요. 다른 커패시턴스를 무시하므로 출력의 한 극점이 $-3\,\mathrm{dB}$ 대역폭을 정해요.

이 개념과 공식을 떠올려요

“다른 커패시턴스를 무시”한다는 단서에서 단일 출력 극점(single output pole)을 떠올려요. $R_{out}$은 독립 입력을 0으로 두고 $C_L$을 떼어 낸 출력에서 AC 접지로 보이는 저항이에요.

같은 $C_L$에서 $R_{out}$이 절반이면 RC 시간도 절반이므로 대역폭은 2배예요. 예를 들어 서로 같은 두 저항 $R$이 출력과 접지 사이에 병렬이면 $R/2$로 읽으면 돼요.

이 문제에서는 소자의 알려진 저항 블록을 합성하면 충분해요. $g_{m2}$는 부하 소자의 트랜스컨덕턴스(transconductance), $r_{\pi2}=\beta/g_{m2}$는 $Q_2$의 베이스–이미터 소신호 저항이고, $\beta$는 $Q_2$의 전류 이득이에요.

MOS의 $r_{O1}$·$r_{O2}$는 각 소자의 채널 길이 변조(channel-length modulation)에 따른 출력저항이에요. 입력 신호를 0으로 만들어도 이 저항들은 사라지지 않아요.

트랜지스터는 주어진 동작점에서 소신호 활성·포화 동작을 한다고 보고 풀어요. (b)는 큰 $\beta$의 알려진 저항 블록을 써요. MOS는 수업의 큰 $g_mr_O$ 근사를 사용하되, 서로 다른 두 소자의 저항을 같다고 두지는 않아요.

−3 dB 대역폭의 단일 극점 관계를 쓰면 전압이득 전체를 구할 필요가 없어요.

$$\omega_{3\mathrm{dB}}\approx\frac1{R_{out}C_L}$$ $$f_{3\mathrm{dB}}=\frac{\omega_{3\mathrm{dB}}}{2\pi}$$

첫 식의 $\approx$는 여기에 넣는 출력저항 블록이 근사값일 수 있기 때문이에요. $\omega$는 $\mathrm{rad/s}$, $f$는 $\mathrm{Hz}$예요.

종이에 쓸 첫 줄

$v_{in}=0$으로 두고 $V_{CC}$·$V_{DD}$·고정 바이어스 $V_b$를 AC 접지로 바꿔요. 저항을 읽을 때는 $C_L$을 개방하고, 출력의 위·아래 가지를 마지막에 병렬로 합쳐요.

$$\omega_{3\mathrm{dB}}\approx\frac1{R_{out}C_L}$$

(a)·(b)는 $Q_2$를 이미터에서 보고, (c)는 두 MOS의 드레인 저항을 보며, (d)는 다이오드 접속 $M_2$와 위쪽 $M_1$의 드레인 저항을 함께 봐요.

이렇게 풀어요

(a) 베이스와 컬렉터가 AC 접지인 $Q_2$

입력을 0으로 두면 $Q_1$의 베이스와 이미터가 모두 AC 접지예요. $V_A=\infty$이므로 출력에서 그 컬렉터를 보면 저항은 무한대이고, 출력저항은 위쪽 $Q_2$가 정해요.

$Q_2$는 베이스와 컬렉터가 서로 묶여 AC 접지예요. 반대쪽인 이미터에서 보는 알려진 블록을 바로 써요.

$$R_{out,a}\approx\frac1{g_{m2}}\parallel r_{\pi2}$$ $$\omega_{3\mathrm{dB},a}\approx\frac{g_{m2}+1/r_{\pi2}}{C_L}$$

두 병렬 경로는 저항보다 컨덕턴스(conductance)를 더하면 간단해요. $r_{\pi2}$ 가지를 남긴 표기이며, 큰 $\beta$에서는 $1/r_{\pi2}=g_{m2}/\beta$의 기여가 작아져 $g_{m2}/C_L$에 가까워져요.

(b) 베이스 경로에 $R_B$가 있는 $Q_2$

아래쪽 $Q_1$은 (a)와 같이 출력에 유한 저항을 더하지 않아요. 달라진 것은 $Q_2$ 베이스에서 AC 접지까지의 경로에 $R_B$가 있다는 점이에요.

큰 $\beta$에서 베이스 경로 저항은 이미터 쪽에 약 $R_B/\beta$로 나타나요. 소자 자체의 $1/g_{m2}$와 직렬로 더해요.

$$R_{out,b}\approx\frac1{g_{m2}}+\frac{R_B}{\beta}$$ $$\omega_{3\mathrm{dB},b}\approx\frac1{\left(1/g_{m2}+R_B/\beta\right)C_L}$$

$R_B$가 베이스 전류 경로에 있으므로 출력 쪽에서 그대로 $R_B$로 보이는 것은 아니에요. 여기서는 $\beta\gg1$의 근사식이며, $R_B/\beta$ 항이 커져도 기본 블록의 $1/g_{m2}$는 식에 남겨요.

(c) 전류원 부하를 단 MOS 회로

$M_1$의 입력 게이트와 소스가 AC 접지이므로 입력에 의한 제어 전압은 0이에요. 위쪽 $M_2$도 게이트의 $V_b$와 소스의 $V_{DD}$가 모두 AC 접지예요. 그래도 $\lambda\gt0$이므로 각 드레인–소스의 $r_O$는 남아요.

두 소자의 소스가 각각 AC 접지이므로, 두 출력저항은 같은 출력–접지 두 노드에 걸려요.

$$R_{out,c}\approx r_{O1}\parallel r_{O2}$$ $$\omega_{3\mathrm{dB},c}\approx\frac1{(r_{O1}\parallel r_{O2})C_L}$$

이 부하는 이상적 전류원이 아니에요. $M_2$가 바이어스되어 전류를 공급하는 동작과, 소신호에서 유한 출력저항이 남는 동작을 함께 생각해야 해요.

(d) 다이오드 접속 NMOS를 부하로 단 PMOS 회로

이번에는 입력 소자가 위쪽 PMOS $M_1$이에요. 입력을 0으로 놓으면 게이트와 소스는 AC 접지지만, $\lambda\gt0$이므로 출력과 접지 사이의 $r_{O1}$은 남아요.

아래쪽 $M_2$는 게이트–드레인 결선을 확인하고, 소스가 접지인 다이오드 접속 저항 블록으로 바꿔요.

$$R_{d2}\approx\frac1{g_{m2}}\parallel r_{O2}$$

출력에 붙은 위쪽 $r_{O1}$을 마지막에 병렬로 합쳐요.

$$R_{out,d}\approx r_{O1}\parallel R_{d2}$$ $$\omega_{3\mathrm{dB},d}\approx\frac{g_{m2}+1/r_{O1}+1/r_{O2}}{C_L}$$

수업의 $g_{m2}r_{O2}\gg1$에서는 $R_{d2}\approx1/g_{m2}$로 줄일 수 있어요. 그래도 다른 소자 $M_1$의 $r_{O1}$을 없애려면 별도로 $g_{m2}r_{O1}\gg1$인지 확인해야 해요.

따라서 그 추가 확인 없이 대역폭을 $g_{m2}/C_L$만으로 쓰지 않아요.

완성 답과 검산

각 회로의 대역폭은 다음과 같아요.

BJT는 $V_A=\infty$, MOS는 $\lambda\gt0$인 출력저항을 써요.

회로와 조건각주파수 대역폭
(a) 베이스 경로 유지$$\omega_{3\mathrm{dB},a}\approx\frac{g_{m2}+1/r_{\pi2}}{C_L}$$
(b) $\beta\gg1$$$\omega_{3\mathrm{dB},b}\approx\frac1{\left(1/g_{m2}+R_B/\beta\right)C_L}$$
(c) 두 $r_O$ 병렬$$\omega_{3\mathrm{dB},c}\approx\frac1{(r_{O1}\parallel r_{O2})C_L}$$
(d) $r_{O1}$ 포함$$\omega_{3\mathrm{dB},d}\approx\frac{g_{m2}+1/r_{O1}+1/r_{O2}}{C_L}$$

네 식은 각주파수예요; $\mathrm{Hz}$ 대역폭은 각각 $2\pi$로 나눠요.

$$f_{3\mathrm{dB}}=\frac{\omega_{3\mathrm{dB}}}{2\pi}$$

단위 검산. 저항과 커패시턴스의 곱은 $\Omega\cdot\mathrm F=\mathrm s$예요. 따라서 $1/(R_{out}C_L)$의 차원은 $\mathrm{s^{-1}}$이고, 양의 코너 각주파수로 읽어요.

베이스 저항 0 검산. (b)에서 $R_B\to0$이면 $R_{out,b}\approx1/g_{m2}$예요. (a)도 큰 $\beta$에서 $r_{\pi2}=\beta/g_{m2}\gg1/g_{m2}$이므로 같은 저항과 대역폭으로 이어져요.

병렬 특수값 검산. 연결을 확인하기 위해 (c)의 두 출력저항을 같은 $R$이라고 놓으면 다음과 같아요.

$$\omega_{3\mathrm{dB},c}\approx\frac1{(R/2)C_L}=\frac2{RC_L}$$

병렬 연결이 저항을 절반으로 만들어 대역폭을 2배로 한다는 예상과 맞아요.

주의할 점

  • $V_A=\infty$는 (a)·(b)의 BJT Early 효과를 없애는 조건이에요. 이를 (c)·(d)의 MOS에도 적용해 $r_O$를 없애면 원문의 $\lambda\gt0$ 조건과 어긋나요.
  • (b)의 $R_B$는 베이스 경로에 있어요. 출력저항에 $R_B$를 그대로 더하거나, $1/g_{m2}$를 삭제한 $R_B/\beta$만 쓰지 않아요.
  • (c)의 $M_2$는 게이트가 고정 바이어스된 소자이고, (d)의 $M_2$는 게이트–드레인이 연결된 소자예요. 둘을 같은 $1/g_{m2}$ 부하로 처리하지 않아요.
  • (d)에서 $g_{m2}r_{O2}\gg1$이라는 사실만으로 서로 다른 소자의 $g_{m2}r_{O1}\gg1$까지 보장되지는 않아요.
  • (b)의 큰 $\beta$ 근사와 남겨 둔 유한 저항 가지를 구별해요. 근사 출력저항으로 얻은 결과를 모든 소신호 모델의 정확식이라고 부르지 않아요.

조건을 바꾸어 생각해요

  1. (b)에서 $g_{m2}$·$\beta$·$C_L$을 고정하고 $R_B$만 2배로 바꾸면 대역폭은 항상 정확히 절반일까요? 변화 전후 비를 $1/g_{m2}+R_B/\beta$로 비교해 보세요.
  2. (d)에서 $g_{m2}$·$r_{O2}$·$C_L$을 고정하고 $r_{O1}$만 절반으로 줄이면 각주파수 대역폭은 얼마나 증가할까요?

입력을 0으로 두고 출력의 저항 블록을 합친 뒤 $C_L$과의 곱으로 대역폭을 찾아요.

(a)·(b)는 $V_A=\infty$, (c)·(d)는 $\lambda\gt0$이고 $C_L$만 고려해요.

$$\omega_{3\mathrm{dB}}\approx\frac1{R_{out}C_L}$$ $$f_{3\mathrm{dB}}=\frac{\omega_{3\mathrm{dB}}}{2\pi}$$

(a)는 $1/g_{m2}\parallel r_{\pi2}$예요.

(b)는 큰 $\beta$에서 $1/g_{m2}+R_B/\beta$예요.

(c)는 $r_{O1}\parallel r_{O2}$예요.

(d)는 $r_{O1}\parallel(1/g_{m2})\parallel r_{O2}$예요.

(d)의 $r_{O1}$은 별도 조건 없이 없애지 않아요.

P7. 극점 두 개와 영점 한 개

P11.06 · 장말문제 11.6 · 원 문제 보기

주어진 조건

  • 증폭기의 극점 두 개: $100\ \text{MHz}$, $10\ \text{GHz}$
  • 영점 한 개: $1\ \text{GHz}$

구할 것

  • $|V_{out}/V_{in}|$의 보데 선도
원문 보기

An amplifier exhibits two poles at $100\ \text{MHz}$ and $10\ \text{GHz}$ and a zero at $1\ \text{GHz}$. Construct the Bode plot of $|V_{out}/V_{in}|$.

문제를 읽어요

낮은 주파수에서는 평평하게 가다가, 주어진 극점과 영점을 지날 때마다 선의 기울기를 바꾸면 돼요. 극점은 내려가는 기울기를 더하고, 영점은 올라가는 기울기를 더해요.

저주파 이득의 수치는 주어지지 않았어요. 그래서 선도의 모양과 상대 높이를 먼저 그리고, 전체 세로 위치는 미지의 저주파 이득으로 남겨요.

이 개념과 공식을 떠올려요

극점·영점의 주파수를 바로 주었으므로 회로의 $G_m$이나 출력저항을 구할 필요 없이 보데(Bode) 크기 근사를 써요. 가로축은 주파수 $f$의 로그 축이고, 세로축은 전압이득 크기의 dB 값이에요.

단일 극점 하나를 지나면 기존 기울기에 $-20\,\mathrm{dB/dec}$, 단일 영점 하나를 지나면 $+20\,\mathrm{dB/dec}$를 더해요. dec는 주파수가 10배 되는 구간이에요.

예를 들어 첫 극점 뒤 기울기가 $-20\,\mathrm{dB/dec}$라면, 다음 영점 뒤에는 $-20+20=0\,\mathrm{dB/dec}$로 평평해져요. 그동안 내려온 높이는 그대로 유지해요.

저주파 이득을 $A_0$라고 두고, 그 dB 높이를 $B_0$로 정의해요.

$$B_0=20\log_{10}|A_0|$$

그림은 그 높이를 뺀 상대 이득 $D(f)$로 그릴 거예요. $D=0\,\mathrm{dB}$는 실제 이득이 1이라는 뜻이 아니에요.

$$D(f)=20\log_{10}\frac{|H(j2\pi f)|}{|A_0|}$$

$f$와 주어진 코너 주파수는 모두 같은 주파수 단위로 비교해요. $100\,\mathrm{MHz}=0.1\,\mathrm{GHz}$이므로 $1\,\mathrm{GHz}$까지 정확히 한 decade예요.

종이에 쓸 첫 줄

주파수를 낮은 순서로 놓으면 첫 극점 $100\,\mathrm{MHz}$ → 영점 $1\,\mathrm{GHz}$ → 둘째 극점 $10\,\mathrm{GHz}$예요.

저주파에서는 상대 높이 $D\approx0\,\mathrm{dB}$에서 평평하게 시작해요.

$$m_0=0\,\mathrm{dB/dec}$$

이렇게 풀어요

코너를 지날 때 이득값이 갑자기 바뀌는 것이 아니라, 그 뒤 구간의 기울기가 바뀌어요.

주파수 구간기울기를 바꾸는 이유구간 기울기
$f\lt100\,\mathrm{MHz}$아직 코너를 지나지 않음$$m_0=0\,\mathrm{dB/dec}$$
$100\,\mathrm{MHz}\lt f\lt1\,\mathrm{GHz}$첫 극점: 기존 값에서 20을 뺌$$m_1=0-20=-20\,\mathrm{dB/dec}$$
$1\,\mathrm{GHz}\lt f\lt10\,\mathrm{GHz}$영점: 기존 값에 20을 더함$$m_2=-20+20=0\,\mathrm{dB/dec}$$
$f\gt10\,\mathrm{GHz}$둘째 극점: 기존 값에서 20을 뺌$$m_3=0-20=-20\,\mathrm{dB/dec}$$

첫 극점과 영점 사이는 $100\,\mathrm{MHz}$에서 $1\,\mathrm{GHz}$까지 주파수가 10배예요. $-20\,\mathrm{dB/dec}$로 한 decade를 가므로 상대 높이가 $0$에서 $-20\,\mathrm{dB}$로 내려가요.

$$D_{asym}(1\,\mathrm{GHz})=-20\log_{10}\frac{1\,\mathrm{GHz}}{0.1\,\mathrm{GHz}}=-20\,\mathrm{dB}$$

그다음 한 decade는 기울기가 0이라 $-20\,\mathrm{dB}$를 유지해요. $10\,\mathrm{GHz}$를 지나면 그 높이에서 다시 내려가요.

절대 dB 높이는 그림의 $0$을 $B_0$로, $-20$을 $B_0-20\,\mathrm{dB}$로 읽어요. $A_0$의 수치가 없으므로 절대 높이는 하나로 정할 수 없어요.

코너를 포함한 직선 근사식을 쓰면 그림의 각 선분을 확인할 수 있어요.

$$D_{asym}(f)=\begin{cases} 0\,\mathrm{dB},& f\le100\,\mathrm{MHz}\\ -20\log_{10}\dfrac{f}{100\,\mathrm{MHz}}\,\mathrm{dB},&100\,\mathrm{MHz}\le f\le1\,\mathrm{GHz}\\ -20\,\mathrm{dB},&1\,\mathrm{GHz}\le f\le10\,\mathrm{GHz}\\ \left[-20-20\log_{10}\dfrac{f}{10\,\mathrm{GHz}}\right]\mathrm{dB},&f\ge10\,\mathrm{GHz} \end{cases}$$

경계에서 이웃한 두 식의 높이가 같으므로 선은 끊기지 않아요. 이 그래프는 직선 근사이며, 정확한 응답은 코너 부근에서 부드럽게 휘어요.

완성 답과 검산

$B_0=20\log_{10}|A_0|$를 기준 높이로 하는 보데 크기 근사예요.

  • $100\,\mathrm{MHz}$ 전에는 높이 $B_0$에서 평평해요.
  • $100\,\mathrm{MHz}$부터 $1\,\mathrm{GHz}$까지 $-20\,\mathrm{dB/dec}$로 내려가요.
  • $1\,\mathrm{GHz}$부터 $10\,\mathrm{GHz}$까지 높이 $B_0-20\,\mathrm{dB}$에서 평평해요.
  • $10\,\mathrm{GHz}$ 뒤에는 그 높이에서 다시 $-20\,\mathrm{dB/dec}$로 내려가요.

전체 높이는 미지의 $B_0$만큼 달라질 수 있어요.

한 decade를 더 가서 검산해요. $10\,\mathrm{GHz}$부터 $100\,\mathrm{GHz}$까지도 주파수가 10배이므로 20 dB 더 내려가야 해요.

$$D_{asym}(100\,\mathrm{GHz})=-20-20=-40\,\mathrm{dB}$$

고주파 기울기도 맞아요. 극점 두 개가 $-40\,\mathrm{dB/dec}$를 더하고 영점 하나가 $+20\,\mathrm{dB/dec}$를 더하므로 합은 $-20\,\mathrm{dB/dec}$예요.

정확한 크기 모델과 비교할 때도 위상 부호를 고를 필요는 없어요. 코너를 $f_{p1}=100\,\mathrm{MHz}$, $f_z=1\,\mathrm{GHz}$, $f_{p2}=10\,\mathrm{GHz}$로 두면 정규화한 크기는 다음과 같아요.

$$\frac{|H(j2\pi f)|}{|A_0|}=\frac{\sqrt{1+(f/f_z)^2}}{\sqrt{1+(f/f_{p1})^2}\sqrt{1+(f/f_{p2})^2}}$$

$100\,\mathrm{GHz}$에서 이 크기를 dB로 바꾸면 약 $-40.04\,\mathrm{dB}$예요. 직선 근사의 $-40\,\mathrm{dB}$와 가깝고, 코너 바로 근처에서는 두 값의 차이가 더 커져요.

주의할 점

  • 첫 극점에서 이득이 갑자기 20 dB 떨어지는 것이 아니에요. 기울기가 바뀐 뒤 주파수가 10배 올라가는 동안 20 dB 내려가요.
  • $1\,\mathrm{GHz}$의 영점은 내려온 높이를 0으로 되돌리지 않아요. 기울기만 0으로 만들어 상대 높이 $-20\,\mathrm{dB}$를 유지해요.
  • 그림의 상대 높이 $0\,\mathrm{dB}$를 절대 이득 $0\,\mathrm{dB}$로 읽지 않아요. 저주파 이득은 주어지지 않았어요.
  • 가로축은 $f$예요. $100\,\mathrm{MHz}$를 그대로 $100\,\mathrm{Mrad/s}$로 쓰지 않아요.
  • 영점이 좌반평면인지 우반평면인지에 따라 위상은 달라질 수 있지만, 이 문제의 크기 선도만으로 그 위치를 정하지 않아요.

조건을 바꾸어 생각해요

  1. 기존 극점·영점과 저주파 이득은 그대로 두고 $100\,\mathrm{GHz}$에 1차 극점을 하나 더 넣으면, 그 주파수 뒤의 보데 직선 기울기는 얼마가 될까요?

코너를 지날 때마다 기울기를 더하면 $0\to-20\to0\to-20\,\mathrm{dB/dec}$가 돼요.

코너 순서는 $100\,\mathrm{MHz}$ 극점, $1\,\mathrm{GHz}$ 영점, $10\,\mathrm{GHz}$ 극점이에요.

$1$–$10\,\mathrm{GHz}$의 상대 높이는 $-20\,\mathrm{dB}$예요.

실제 dB 높이에는 미지의 $20\log_{10}|A_0|$를 더해요.

기울기 변화는 순간적인 이득 감소와 달라요.

P8. 같은 CS 단 두 개의 보데 선도

P11.09 · 장말문제 11.9 · 원 문제 보기

주어진 조건

  • 채널길이 변조와 다른 커패시턴스는 무시
  • $V_{out}/V_{in} = (V_X/V_{in})(V_{out}/V_X)$임을 이용

구할 것

  • $|V_{out}/V_{in}|$의 보데 선도
원문 보기

Figure 11.65 illustrates a cascade of two identical CS stages. Neglecting channel-length modulation and other capacitances, construct the Bode plot of $|V_{out}/V_{in}|$. Note that $V_{out}/V_{in} = (V_X/V_{in})(V_{out}/V_X)$.

문제를 읽어요

똑같은 CS 단 두 개가 이어져 있으므로, 한 단에서 신호가 얼마나 줄어드는지 구해 두 번 곱하는 문제예요.

첫째 출력은 $V_X$이고 동시에 둘째 입력이며, 최종 출력은 $V_{out}$이에요.

구할 것은 전체 이득 크기의 보데 선도이므로 저주파 높이·코너 위치·구간별 기울기를 밝혀요.

이 개념과 공식을 떠올려요

단서는 두 단이 동일하고, 채널 길이 변조와 다른 커패시턴스를 무시한다는 조건이에요.

이 모델에서 $M_2$ 게이트는 전류를 받지 않으므로 $X$에 추가 부하를 주지 않아요.

따라서 첫째 단의 $R_D,C_L$을 둘째 단 때문에 바꾸지 않고 각 단의 전달 함수를 곱할 수 있어요.

$g_m$은 두 동일 MOS의 트랜스컨덕턴스이고, 단 전체의 출력 단락 전류 비율은 $G_m$으로 구별해요.

한 단의 출력에서는 $R_D$와 $1/(sC_L)$이 AC 접지로 병렬이에요.

보데(Bode) 근사에서는 각 실수 극점의 코너를 지날 때마다 기울기에 $-20\,\mathrm{dB/dec}$를 더해요.

이 회로는 같은 코너에서 두 극점을 한꺼번에 지나므로 $0\to-20-20=-40\,\mathrm{dB/dec}$가 돼요.

예를 들어 코너보다 충분히 높은 구간에서 주파수가 열 배가 되면 전체 이득 크기는 약 $1/100$이 돼요.

보데 근사: 극점마다 기울기 −20 dB/dec의 기울기 합성을 같은 주파수에서 두 번 적용해요.

종이에 쓸 첫 줄

원문이 알려 준 중간 노드 $X$로 전체 경로를 나누는 식을 먼저 써요.

$$\frac{V_{out}}{V_{in}}=\frac{V_X}{V_{in}}\frac{V_{out}}{V_X}$$

두 단은 같고 둘째 게이트가 첫째 출력을 부하로 당기지 않는 모델이므로, 첫째 단을 한 번 풀어 두 비율에 적용해요.

이렇게 풀어요

대표로 첫째 단의 출력 단락을 읽어요

출력 $X$를 단락하고 오른쪽에서 회로 안으로 들어오는 전류를 양으로 정해요.

소스가 AC 접지라 $v_{gs1}=V_{in}$이고 $R_D,C_L$ 양단 전압은 0이에요.

$$i_{out,sc}=g_mV_{in}$$ $$G_m=\frac{i_{out,sc}}{V_{in}}=g_m$$
입력을 0으로 둔 부하를 합쳐요

$V_{in}=0$이면 $M_1$의 게이트와 소스가 AC 접지라 제어 전류가 0이에요.

채널 길이 변조를 무시하므로 유한 $r_O$는 없고, 이상적인 $M_2$ 게이트도 $X$에서 전류를 받지 않아요.

저주파에서는 $C_L$을 개방으로 보아 출력저항부터 읽어요.

$$R_{out}\approx R_D$$

주파수 응답에는 같은 노드의 외부 커패시터 부하를 포함해요.

$$\begin{aligned}Z_{out}(s)&=R_D\parallel\frac{1}{sC_L}\\&=\frac{R_D}{1+sR_DC_L}\end{aligned}$$
단락을 풀고 한 단의 반전 이득을 구해요

양의 게이트 입력은 출력에서 끌어내리는 전류를 늘리므로 반전 부호가 붙어요.

$$\begin{aligned}H_1(s)&=\frac{V_X}{V_{in}}=-G_mZ_{out}(s)\\&=-\frac{g_mR_D}{1+sR_DC_L}\end{aligned}$$

둘째 단은 입력이 $V_X$, 출력이 $V_{out}$으로 바뀔 뿐 같은 $g_m,R_D,C_L$을 가져요.

$$H_2(s)=\frac{V_{out}}{V_X}=-\frac{g_mR_D}{1+sR_DC_L}$$

음수 두 개가 곱해져 전체 저주파 이득은 양수가 돼요.

$$H(s)=H_1(s)H_2(s)=\frac{(g_mR_D)^2}{(1+sR_DC_L)^2}$$

분모에 같은 인자가 두 번 있으므로 같은 위치에 두 극점이 겹쳐요.

$$\omega_p=\frac{1}{R_DC_L}$$

$s=j\omega$에서 한 인자의 크기는 $\sqrt{1+(\omega/\omega_p)^2}$예요.

그 크기를 두 번 곱하면 제곱근이 사라져요.

$$|H(j\omega)|=\frac{(g_mR_D)^2}{1+(\omega/\omega_p)^2}$$
dB 높이와 기울기로 그려요

실제 dB 이득을 $D(\omega)$, 저주파 높이를 $D_0$로 정의해요.

$$D_0=20\log_{10}\!\left[(g_mR_D)^2\right]=40\log_{10}(g_mR_D)$$ $$\omega_p=\frac{1}{R_DC_L}$$

로그에서 곱은 합, 나눗셈은 차가 돼요.

$$D(\omega)=D_0-20\log_{10}\!\left[1+(\omega/\omega_p)^2\right]$$

코너 아래에서는 대괄호를 1로, 코너 위에서는 $(\omega/\omega_p)^2$로 근사해요.

$$D(\omega)\approx\begin{cases}D_0,&\omega\le\omega_p\\D_0-40\log_{10}(\omega/\omega_p),&\omega\ge\omega_p\end{cases}$$

직선 근사는 $D_0$에서 시작해 $\omega_p$ 이후 $-40\,\mathrm{dB/dec}$로 내려가요.

코너에서 이득이 갑자기 40 dB 내려가는 것이 아니라 그 이후 기울기가 바뀌어요.

완성 답과 검산

전체 보데 직선 근사의 저주파 높이와 코너예요.

$$D_0=40\log_{10}(g_mR_D)$$ $$\omega_p=\frac{1}{R_DC_L}$$

$\omega_p$ 아래의 기울기는 $0\,\mathrm{dB/dec}$이고, 위의 기울기는 $-40\,\mathrm{dB/dec}$예요.

동일한 두 CS 단이며 둘째 입력이 첫째 출력을 부하로 당기지 않는 주어진 모델의 결과예요.

저주파 극한은 반전 두 번의 부호와 크기를 확인해 줘요.

$$H(0)=(g_mR_D)^2\gt0$$

정확한 크기 식에 $\omega=\omega_p$를 넣으면 저주파 진폭의 절반이에요.

$$|H(j\omega_p)|=\frac{(g_mR_D)^2}{2}$$ $$20\log_{10}\frac12\approx-6.02\,\mathrm{dB}$$

따라서 두 극점의 공통 코너를 전체 회로의 −3 dB 주파수라고 부르면 틀려요.

코너보다 충분히 높으면 크기 식은 다음처럼 돼요.

$$|H(j\omega)|\approx(g_mR_D)^2\left(\frac{\omega_p}{\omega}\right)^2$$

이 구간에서 주파수를 열 배로 하면 크기는 약 $1/100$이므로 기울기가 맞아요.

$$20\log_{10}\frac1{100}=-40\,\mathrm{dB}$$

$g_mR_D$는 무차원이고 $R_DC_L$은 초 단위이므로 이득과 코너의 단위도 맞아요.

주의할 점

  • 첫째 출력 $X$는 둘째 게이트에 연결돼요. 다른 커패시턴스를 무시한 이 모델에서 그 게이트는 추가 입력 부하가 아니에요.
  • 두 전압이득을 더하지 않아요. 전달 함수는 곱하고, dB로 바꾼 높이를 더해요.
  • CS 두 단을 지났으므로 저주파 전체 부호는 양수예요.
  • 같은 코너에 극점이 두 개라서 기울기 변화는 $-20-20=-40\,\mathrm{dB/dec}$예요.
  • 직선 근사의 꺾이는 점과 정확한 응답의 감쇠값을 구별해요. 정확한 공통 코너 감쇠는 약 $-6.02\,\mathrm{dB}$예요.

조건을 바꾸어 생각해요

  1. 같은 $g_m,R_D,C_L$을 가진 CS 단을 하나 더 이어 세 단으로 만들어요. 각 다음 단의 입력이 앞단에 부하를 주지 않고 다른 커패시턴스도 없다면, 공통 코너 위의 보데 기울기와 전체 저주파 이득의 부호는 어떻게 바뀔까요?

부하를 주지 않는 동일한 CS 두 단의 전달 함수를 곱해요.

반전 두 번으로 전체 저주파 이득은 양수예요.

  • 저주파 높이$$D_0=40\log_{10}(g_mR_D)$$
  • 겹친 코너$$\omega_p=\frac{1}{R_DC_L}$$

기울기는 코너에서 $0\to-40\,\mathrm{dB/dec}$로 바뀌어요.

정확한 코너 감쇠는 약 $-6.02\,\mathrm{dB}$예요.

P9. CS 단의 입력과 출력 극점

E11.08 · 예제 11.8 · 원 문제 보기

주어진 조건

  • $\lambda = 0$
  • 소자 값은 주어지지 않음 (답은 기호로)

구할 것

  • 회로의 극점
원문 보기

그림 11.11에 나타낸 회로의 극점을 결정하라. $\lambda = 0$으로 가정한다.

문제를 읽어요

입력과 출력에 접지 커패시터가 하나씩 있는 CS 회로예요. 각 커패시터가 어떤 저항을 통해 충전되고 방전되는지 찾아 두 극점을 구해요.

$v_{in}$은 $R_S$ 앞의 신호이고, 실제 게이트 전압은 $R_S$ 뒤의 $v_X$예요. 두 전압을 같은 노드로 놓지 않는 것이 출발점이에요.

이 개념과 공식을 떠올려요

$\lambda=0$이라는 단서에서 $M_1$의 드레인 출력저항은 무한대로 봐요. 그림에 표시된 $C_{in}$과 $C_L$은 서로 다른 신호 노드에서 각각 접지로 연결돼 있어요.

이 단순 소신호 모델은 게이트 전도 전류와 몸체효과를 무시하고, 입력과 출력을 잇는 부유 커패시터도 두지 않아요. 소스는 AC 접지이고, 게이트 전압은 출력 전류에 영향을 주지만 출력 전압이 게이트 쪽으로 되돌아가지는 않아요.

이 조건에서는 입력 RC가 있는 CS 단의 두 극점처럼 노드별 접지 RC 인자가 따로 나타나요. 저항 $R$과 커패시턴스 $C$의 곱은 시간상수(time constant)이고, 그 역수가 양의 코너 각주파수예요.

$$\tau=RC$$ $$\omega_p=\frac1{RC}$$

예를 들어 같은 저항에서 커패시턴스만 2배가 되면 시간상수는 2배이고 코너 각주파수는 절반이에요. 모든 회로의 노드 수를 세어 극점을 정하는 일반 법칙으로 확대하지 않아요.

종이에 쓸 첫 줄

독립 입력 전압을 0으로 두어 단락하고, $V_{DD}$는 AC 접지로 봐요. 저항 경로를 읽을 때는 커패시터 자체를 개방해서 생각해요.

$$v_{in}=0$$

게이트를 바로 접지로 옮기는 것이 아니에요. $v_{in}$을 단락해도 게이트 노드와 접지 사이에는 $R_S$가 남아요.

이렇게 풀어요

입력 노드 $v_X$

MOS 게이트로 전도 전류가 흐르지 않으므로 게이트 쪽에 추가 병렬 저항은 없어요. 입력원을 단락한 뒤 X에서 접지로 보면 $R_S$가 저항 경로이고, 같은 X–접지 두 노드에 $C_{in}$이 연결돼요.

$$R_{eq,in}=R_S$$ $$\tau_{in}=R_SC_{in}$$

입력의 RC 인자에서 양의 코너 각주파수를 구해요.

$$\omega_{p,in}=\frac1{R_SC_{in}}$$
출력 노드 $v_{out}$

저항을 읽는 단계에서 $C_{in}$도 개방하면 입력 0 조건에 의해 게이트와 소스의 제어 전압이 0이에요. $\lambda=0$이라 트랜지스터의 드레인 저항도 무한대예요.

따라서 출력의 저항 경로는 위쪽 $R_D$이고, 출력의 커패시턴스는 $C_L$이에요.

$$R_{eq,out}=R_D$$ $$\tau_{out}=R_DC_L$$

출력의 RC 인자에서 양의 코너 각주파수를 구해요.

$$\omega_{p,out}=\frac1{R_DC_L}$$

두 식은 접지 커패시터와 한 방향 전달이라는 선택 모델 안에서의 극점 코너예요. 소자값이 없으므로 입력과 출력 중 어느 코너가 더 낮은지는 정할 수 없어요.

완성 답과 검산

양의 극점 코너 각주파수는 다음과 같아요.

$$\omega_{p,in}=\frac1{R_SC_{in}}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

$\lambda=0$이고, 게이트 전도 전류·몸체효과를 무시한 이 접지 커패시터 모델의 결과예요.

$s$ 평면의 극점 위치를 쓰면 음의 실수예요.

$$s_{p,in}=-\frac1{R_SC_{in}}$$ $$s_{p,out}=-\frac1{R_DC_L}$$

두 RC 인자를 확인해요. 출력에서 입력으로 돌아가는 결합이 없어서 입력의 자연응답 인자는 출력 쪽 동작으로 바뀌지 않아요. 따라서 이 모델의 극점을 만드는 두 인자는 다음처럼 곱해져요.

$$D(s)=(1+sR_SC_{in})(1+sR_DC_L)$$

$D(s)=0$을 풀면 완성 답의 두 음의 근이 나와요. 두 RC 시간이 같으면 같은 위치에 겹친 극점이 생기며 차수는 2로 남아요.

단위도 확인해요. $\Omega\cdot\mathrm F=\mathrm s$이므로 두 $RC$ 곱의 역수는 $\mathrm{s^{-1}}$ 차원을 가져요. $\omega_p$의 단위는 $\mathrm{rad/s}$이고, $\mathrm{Hz}$의 코너 주파수가 필요하면 $2\pi$로 나눠요.

주의할 점

  • 입력원을 0으로 놓는 것은 $R_S$ 앞의 $v_{in}$을 단락하는 것이에요. $v_X$를 입력원과 같은 노드로 취급해 $R_S$를 없애지 않아요.
  • 게이트를 보는 입력 저항과 소스를 보는 입력 저항은 달라요. 이 CS의 게이트 노드에 $1/g_m$을 병렬로 넣지 않아요.
  • $C_{in}$과 $C_L$은 같은 노드에 붙어 있지 않으므로 합쳐서 하나의 커패시턴스로 만들지 않아요.
  • 입력 코너가 항상 낮은 것도, 두 코너가 반드시 서로 다른 것도 아니에요. 크기 비교에는 실제 소자값이 필요해요.
  • 양의 코너 $\omega_p$와 음의 $s$ 평면 근을 구별해요. 부유 커패시터나 역방향 결합이 있는 다른 회로에 이 두 RC 식을 그대로 적용하지 않아요.

조건을 바꾸어 생각해요

  1. $R_S$·$R_D$·$C_L$을 그대로 두고 $C_{in}$만 2배로 늘리면, 입력과 출력의 코너 각주파수는 각각 어떻게 바뀔까요? 같은 $\lambda=0$ 모델을 사용해요.

입력은 $R_SC_{in}$, 출력은 $R_DC_L$의 접지 RC 인자로 극점을 찾아요.

$\lambda=0$이고 게이트 전도 전류·몸체효과와 입력–출력 부유 커패시터를 무시한 모델이에요.

$$\omega_{p,in}=\frac1{R_SC_{in}}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

양의 코너 각주파수와 음의 $s$ 평면 근을 구별해요.

어느 코너가 낮은지는 소자값으로 판단해요.

P10. 같은 두 극점의 3 dB 주파수

X11.08 · 연습문제 11.8 · 원 문제 보기

주어진 조건

  • 예제 11.8의 회로: Fig 11.11 CS 단 ($R_S$, $C_{in}$, $M_1$, $R_D$, $C_L$), $\lambda = 0$
  • $\omega_{p1} = \omega_{p2}$
  • 즉 $R_S C_{in} = R_D C_L$

구할 것

  • 전압 이득이 3 dB만큼 떨어지는 주파수
원문 보기

$\omega_{p1} = \omega_{p2}$라면, 어느 주파수에서 전압 이득이 3 dB만큼 떨어지는가?

문제를 읽어요

입력 쪽과 출력 쪽의 두 극점이 같은 주파수에 있을 때, 전체 이득이 얼마나 일찍 줄어드는지 찾는 문제예요.

구할 것은 공통 극점 주파수 자체가 아니라 전체 이득 크기가 저주파 값의 $1/\sqrt2$가 되는 주파수예요.

이 개념과 공식을 떠올려요

단서는 $\omega_{p1}=\omega_{p2}$라는 조건이에요.

예제 11.8의 두 극점 크기 응답에서 같은 인자 두 개를 묶으면 되므로 회로를 다시 전개할 필요가 없어요.

양의 공통 코너 각주파수를 $\omega_p$로 정해요.

저주파 전압이득을 $A_0$라고 쓰고 크기 응답을 $|A_0|$로 나누면, 저주파에서 1인 정규화 응답(normalized response)이 돼요.

전압 이득에서 교과서의 −3 dB 기준은 진폭이 $1/\sqrt2$가 되는 것이에요.

예를 들어 $\omega=\omega_p$에서는 각 극점이 $1/\sqrt2$배를 만들므로, 두 인자를 곱한 전체 진폭은 $1/2$이에요.

따라서 전체 −3 dB 지점은 $\omega_p$에 도착하기 전에 나타나요.

예제의 $\lambda=0$인 입력·출력 두 RC 모델을 그대로 사용하며 다른 커패시턴스는 추가하지 않아요.

입력 RC가 있는 CS 단의 두 극점에서 얻은 크기 식을 출발점으로 써요.

종이에 쓸 첫 줄

예제의 크기 식을 저주파 값으로 나눈 뒤 두 극점을 같게 놓아요.

$$\frac{|H(j\omega)|}{|A_0|}=\frac{1}{\sqrt{\left[1+(\omega/\omega_{p1})^2\right]\left[1+(\omega/\omega_{p2})^2\right]}}$$ $$\omega_{p1}=\omega_{p2}=\omega_p$$

이렇게 풀어요

같은 두 인자를 먼저 합쳐요

정규화 크기를 $M(\omega)=|H(j\omega)|/|A_0|$로 간단히 적어요.

같은 양을 두 번 곱한 제곱근이며 $1+(\omega/\omega_p)^2$는 양수예요.

$$\begin{aligned}M(\omega)&=\frac{1}{\sqrt{\left[1+(\omega/\omega_p)^2\right]^2}}\\&=\frac{1}{1+(\omega/\omega_p)^2}\end{aligned}$$
전체 응답에 −3 dB 조건을 걸어요
$$\frac{1}{1+(\omega_{3\mathrm{dB}}/\omega_p)^2}=\frac{1}{\sqrt2}$$

양변의 역수를 취하고 1을 빼요.

$$1+(\omega_{3\mathrm{dB}}/\omega_p)^2=\sqrt2$$ $$\left(\frac{\omega_{3\mathrm{dB}}}{\omega_p}\right)^2=\sqrt2-1$$

찾는 각주파수는 양수이므로 양의 제곱근을 골라요.

$$\omega_{3\mathrm{dB}}=\sqrt{\sqrt2-1}\,\omega_p\approx0.64\,\omega_p$$

계산에는 $0.64$가 아니라 정확한 $\sqrt{\sqrt2-1}$을 유지해요.

공통 극점의 회로값 표현은 예제에서 이미 구한 값이에요.

$$\omega_p=\frac{1}{R_SC_{in}}=\frac{1}{R_DC_L}$$

완성 답과 검산

같은 두 극점의 전체 −3 dB 각주파수예요.

$$\omega_{3\mathrm{dB}}=\sqrt{\sqrt2-1}\,\omega_p\approx0.64\,\omega_p$$ $$\omega_p=\frac{1}{R_SC_{in}}=\frac{1}{R_DC_L}$$

예제 11.8의 $\lambda=0$인 두 RC 모델과 $R_SC_{in}=R_DC_L$ 조건을 사용해요.

정확한 근호 값을 원래 정규화 크기 식에 다시 넣어요.

$$M(\omega_{3\mathrm{dB}})=\frac{1}{1+(\sqrt2-1)}=\frac{1}{\sqrt2}$$ $$20\log_{10}\frac{1}{\sqrt2}\approx-3.01\,\mathrm{dB}$$

공통 코너 $\omega_p$에 대입하면 진폭은 절반이므로 같은 지점이 아니에요.

$$M(\omega_p)=\frac{1}{1+1}=\frac12$$ $$20\log_{10}\frac12\approx-6.02\,\mathrm{dB}$$

$0\lt\sqrt{\sqrt2-1}\lt1$이므로 전체 대역폭이 공통 코너보다 낮다는 예상과 맞아요.

배율은 무차원이므로 $\omega_{3\mathrm{dB}}$와 $\omega_p$는 둘 다 rad/s 단위예요.

Hz로 비교하더라도 두 주파수를 똑같이 $2\pi$로 나누므로 $f_{3\mathrm{dB}}/f_p$의 배율은 같아요.

주의할 점

  • 극점 하나일 때의 $\omega_{3\mathrm{dB}}=\omega_p$를 두 극점에 그대로 쓰지 않아요.
  • 같은 인자 두 개의 크기를 곱했으므로 분모는 $1+(\omega/\omega_p)^2$예요. 바깥 제곱근을 한 번 더 남기지 않아요.
  • −3 dB는 진폭 절반이 아니에요. 이 회로에서 진폭 절반은 공통 코너의 약 −6.02 dB예요.
  • $\omega_p$는 양의 코너 각주파수예요. 전달 함수의 음의 극점 위치와 혼동하지 않아요.

조건을 바꾸어 생각해요

  1. 처음에는 두 극점이 같아요. $R_S,R_D,C_L,g_m$을 고정하고 $C_{in}$만 절반으로 줄이면 더 이상 두 극점이 같지 않아요. 원래의 공통 주파수로 $x=\omega/\omega_p$를 정의해 새로운 −3 dB 조건을 써 보고, 전체 대역폭이 원래보다 커지는지 판단해 보세요.

같은 두 극점의 감쇠가 곱해지므로 전체 −3 dB 지점은 공통 코너보다 낮아요.

예제의 $\lambda=0$인 두 RC 모델과 동일 극점 조건을 사용해요.

  • 정규화 크기$$M(\omega)=\frac{1}{1+(\omega/\omega_p)^2}$$
  • 전체 3 dB 경계$$\begin{aligned}\omega_{3\mathrm{dB}}&=\sqrt{\sqrt2-1}\,\omega_p\\&\approx0.64\,\omega_p\end{aligned}$$

$\omega_p$에서의 전체 감쇠는 약 −6.02 dB예요.

  • 소자 값은 주어지지 않음 (답은 기호로)

원문 보기

그림 11.12에 나타낸 회로의 극점들을 계산하라. $\lambda = 0$으로 가정한다.

문제를 읽어요

이번 CG(common gate) 회로는 입력이 게이트가 아니라 소스로 들어가요. 게이트는 고정 바이어스 $V_b$에 연결되고, 출력은 드레인이에요.

$v_{in}$은 $R_S$ 앞의 독립 입력이고, $v_X$는 그 저항 뒤의 실제 소스 전압이에요. 소스와 출력에 접지 커패시터가 하나씩 있으므로 각 노드의 저항 경로를 찾아요.

이 개념과 공식을 떠올려요

게이트가 AC 접지이고 소스에서 신호를 받는다는 단서에서, 소스 쪽 입력저항(source input resistance)이라는 알려진 블록을 떠올려요. $\lambda=0$이고 몸체효과를 무시하면 그 값은 $1/g_m$이에요.

$g_m$은 $M_1$의 트랜스컨덕턴스예요. 이 $1/g_m$은 소자 내부의 소신호 저항을 나타내며, 외부에 붙인 소스 축퇴 저항이 아니에요.

$$g_m\left(\frac1{g_m}\right)=1$$

따라서 내부 $1/g_m$에 외부 축퇴 저항의 큰 곱 근사를 적용해 항을 없애지 않아요. $R_S$와 $1/g_m$의 상대 크기는 실제 값에 따라 달라요.

예를 들어 $R_S=1/g_m$이면 같은 저항 두 개의 병렬이라 등가 저항이 $1/(2g_m)$이 돼요. 같은 $C_{in}$에서 저항이 절반이 되면 코너 각주파수는 2배예요.

CG 단의 입력 극점처럼 그림의 두 커패시터는 각각 접지에 연결되고, 게이트 전도 전류는 무시해요. $\lambda=0$에서는 드레인 전압이 소스 전류를 바꾸지 않으므로 출력의 움직임이 입력 저항에 되돌아오지 않아요.

종이에 쓸 첫 줄

독립 입력원을 0으로 놓아 $R_S$의 왼쪽을 접지로 연결해요. 고정 바이어스 $V_b$와 전원 $V_{DD}$도 AC 접지로 봐요.

$$v_{in}=0$$

저항 경로를 읽을 때 커패시터 자체는 개방해서 생각해요. 소스 노드 X에는 $R_S$로 가는 경로와 $M_1$의 소스 쪽을 보는 경로가 함께 남아요.

이렇게 풀어요

입력 노드 $v_X$

먼저 게이트가 AC 접지이고 몸체효과를 무시하는 $\lambda=0$ 모델에서, 소스를 바라보는 알려진 저항 블록을 써요.

$$R_{in,S}=\frac1{g_m}$$

입력을 단락한 뒤 $R_S$와 이 소스 쪽 저항은 모두 X에서 AC 접지로 보이므로 병렬이에요.

$$R_{eq,in}=R_S\parallel\frac1{g_m}$$

같은 X–접지 두 노드에 $C_{in}$이 연결되므로 입력 코너가 정해져요.

$$\omega_{p,in}=\frac1{(R_S\parallel1/g_m)C_{in}}=\frac{1+g_mR_S}{R_SC_{in}}$$

$R_D$와 $C_L$은 이 소스 쪽 저항에 들어가지 않아요. $\lambda=0$에서는 드레인 전압 변화가 소스 전류로 되돌아오지 않기 때문이에요.

출력 노드 $v_{out}$

출력의 저항을 읽는 단계에서는 커패시터를 개방하고 독립 입력을 0으로 두어요. 소스는 입력의 접지 경로를 통해 0이 되고 게이트도 AC 접지라 제어 전압이 0이에요. $\lambda=0$에서 소자의 드레인 저항은 무한대이므로 출력의 저항 경로는 $R_D$예요.

$$R_{eq,out}=R_D$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

이 두 식은 소스 쪽 저항이 드레인 전압에 의존하지 않는 선택 모델에서의 극점이에요. 모든 접지 커패시터 회로가 노드별로 분리된다는 뜻은 아니에요.

완성 답과 검산

양의 코너 각주파수는 다음과 같아요.

$$\omega_{p,in}=\frac1{(R_S\parallel1/g_m)C_{in}}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

$\lambda=0$·게이트 AC 접지·몸체효과와 게이트 전도 전류 무시 조건이에요.

$s$ 평면의 극점은 각 양의 코너에 음의 부호를 붙인 위치예요.

$$s_{p,in}=-\frac1{(R_S\parallel1/g_m)C_{in}}$$ $$s_{p,out}=-\frac1{R_DC_L}$$

동일한 병렬 저항으로 검산해요. $R_S=1/g_m$을 넣으면 다음과 같아요.

$$R_{eq,in}=\frac1{g_m}\parallel\frac1{g_m}=\frac1{2g_m}$$ $$\omega_{p,in}=\frac{2g_m}{C_{in}}$$

두 경로가 병렬이라 한 경로만 있을 때보다 저항이 절반이고, 같은 커패시턴스의 코너는 2배라는 예상과 맞아요.

단위와 순서를 확인해요. 두 등가 저항에 각각 커패시턴스를 곱하면 단위는 $\Omega\cdot\mathrm F=\mathrm s$예요. 역수인 코너 각주파수는 $\mathrm{rad/s}$이고, 입력과 출력 중 어느 코너가 더 낮은지는 소자값으로 정해요.

주의할 점

  • 독립 입력 $v_{in}$을 0으로 두는 것과 실제 소스 전압 $v_X$를 바로 0으로 놓는 것은 달라요. $R_S$가 남은 연결을 먼저 읽어요.
  • 게이트가 AC 접지라는 이유로 소스 쪽 $1/g_m$ 경로를 없애지 않아요. 이번에는 게이트가 아니라 소스를 바라봐요.
  • $1/g_m$은 내부 소신호 저항이에요. 외부 축퇴 저항의 $g_mR_e\gg1$ 조건을 이 값에 적용하지 않아요.
  • $1+g_mR_S$의 1을 조건 없이 지우지 않아요. $R_S=1/g_m$인 경우에는 그 두 항이 같은 크기예요.
  • 입력 코너가 CS의 같은 $R_S$·$C_{in}$보다 높아져도, 출력 코너보다 반드시 높거나 낮다고 정할 수는 없어요.

조건을 바꾸어 생각해요

  1. $g_m$·$C_{in}$·$R_D$·$C_L$을 고정하고 $R_S=1/g_m$인 상태에서 $R_S\gg1/g_m$인 상태로 바꾸면, 입력 코너는 처음의 약 몇 배로 가까워질까요? 같은 $\lambda=0$ 모델을 사용해요.

CG 소스 노드의 $R_S\parallel1/g_m$과 입력 커패시턴스가 입력 극점을 정해요.

$\lambda=0$·게이트 AC 접지·몸체효과와 게이트 전도 전류 무시 조건이에요.

$$\omega_{p,in}=\frac1{(R_S\parallel1/g_m)C_{in}}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

내부 $1/g_m$에 외부 축퇴 저항의 큰 곱 근사를 적용하지 않아요.

양의 코너와 음의 $s$ 평면 근을 구별해요.

P12. 극점을 열 배 벌리는 저항

X11.09 · 연습문제 11.9 · 원 문제 보기

주어진 조건

  • 예제 11.9의 회로: Fig 11.12 CG 단 ($R_S$, $C_{in}$, $M_1$, $V_b$, $R_D$, $C_L$), $\lambda = 0$
  • 출력 극점 주파수가 입력 극점 주파수의 10배

구할 것

  • $R_D$의 값을 어떻게 선택해야 하는가? (답은 기호로)
원문 보기

출력 극점 주파수가 입력 극점 주파수의 10배라면 $R_D$의 값을 어떻게 선택해야 하는가?

문제를 읽어요

입력 극점은 그대로 두고 출력 극점만 그보다 열 배 높은 곳으로 보내도록 $R_D$를 고르는 문제예요.

출력 극점은 $R_DC_L$의 역수이므로, 다른 값이 같을 때 더 높은 출력 극점을 원하면 $R_D$를 작게 해야 해요.

이 개념과 공식을 떠올려요

단서는 출력 극점 주파수가 입력 극점 주파수의 10배라는 비교 조건이에요.

예제 11.9의 CG(common-gate) 단에서 입력은 $M_1$의 소스이고 게이트의 고정 바이어스 $V_b$는 AC 접지예요.

독립 입력 전압을 0으로 두면 소스 입력 노드에서 $R_S$가 접지로 보여요.

$\lambda=0$이고 몸체효과를 무시한 모델에서는 게이트가 AC 접지인 MOS의 소스 쪽 저항이 알려진 블록 $1/g_m$이에요.

따라서 입력 커패시터 $C_{in}$이 보는 저항은 $R_S$만이 아니라 $R_S\parallel(1/g_m)$이에요.

반면 드레인 출력에서는 $R_D$와 $C_L$이 극점을 정하므로, 두 커패시터를 서로 바꾸지 않아요.

예를 들어 $C_{in}=C_L$이라면 출력 저항을 입력의 유효 저항의 $1/10$로 만들 때 출력 코너가 열 배 높아져요.

일반적인 서로 다른 커패시턴스에서는 그 비율까지 포함해야 해요.

CG 단의 입력 극점에서 얻은 두 극점 식을 그대로 사용해요.

종이에 쓸 첫 줄

구할 저항부터 추측하지 말고 원문의 주파수 비교를 먼저 식으로 옮겨요.

$$\omega_{p,out}=10\,\omega_{p,in}$$

여기서 $\omega_{p,in},\omega_{p,out}$은 각각 입력·출력의 양의 코너 각주파수예요.

이렇게 풀어요

입력의 알려진 저항 블록을 묶어요

입력 노드의 병렬 저항을 $R_i$로 정의해요.

$$R_i=R_S\parallel\frac1{g_m}$$

예제에서 구한 입력 극점은 이 저항과 $C_{in}$으로 정해져요.

$$\omega_{p,in}=\frac1{R_iC_{in}}$$

출력 극점에는 별도의 $R_D$와 $C_L$을 써요.

$$\omega_{p,out}=\frac1{R_DC_L}$$
비교 조건에 대입하고 저항을 역산해요
$$\frac1{R_DC_L}=\frac{10}{R_iC_{in}}$$

저항과 커패시턴스가 양수이므로 양변에 $R_DC_LR_iC_{in}$을 곱해요.

$$R_iC_{in}=10R_DC_L$$

양변을 $10C_L$로 나누어 $R_D$만 남겨요.

$$R_D=\frac{R_iC_{in}}{10C_L}$$ $$R_D=\frac{C_{in}}{10C_L}\left(R_S\parallel\frac1{g_m}\right)$$

$1/10$은 출력 주파수를 열 배 높이라는 요구에서 나오고, $C_{in}/C_L$은 서로 다른 두 노드의 커패시턴스를 보정해요.

완성 답과 검산

출력 극점이 정확히 입력 극점의 10배가 되도록 고르는 값이에요.

$$R_D=\frac{C_{in}}{10C_L}\left(R_S\parallel\frac1{g_m}\right)$$

예제의 $\lambda=0$·몸체효과 무시·게이트 AC 접지 조건을 사용해요.

구한 저항을 출력 극점 식에 그대로 넣어 비교 조건을 확인해요.

$$\begin{aligned}\omega_{p,out}&=\frac1{\left(R_iC_{in}/(10C_L)\right)C_L}\\&=\frac{10}{R_iC_{in}}\\&=10\,\omega_{p,in}\end{aligned}$$

$C_{in}/C_L$의 단위는 $\mathrm{F}/\mathrm{F}=1$이라 저항에 곱해도 답의 단위는 $\Omega$예요.

$C_{in}=C_L$인 특수값에서는 예측한 단순 비율로 돌아와요.

$$R_D=\frac1{10}\left(R_S\parallel\frac1{g_m}\right)$$

선택한 값보다 $R_D$를 더 작게 만들면 출력의 시간상수는 줄고 출력 극점은 10배보다 더 높아져요.

만약 요구를 “적어도 10배”로 바꾼 경우에만 다음 부등식 범위를 답으로 쓸 수 있어요.

$$R_D\le\frac{C_{in}}{10C_L}\left(R_S\parallel\frac1{g_m}\right)$$

주의할 점

  • CG 입력에서는 $1/g_m$ 경로를 빠뜨리지 않아요. 입력 유효 저항은 $R_S$ 하나가 아니에요.
  • 출력 극점을 높이려면 $R_D$를 키우는 것이 아니라 줄여야 해요.
  • $C_{in}$은 입력 극점에, $C_L$은 출력 극점에 들어가므로 최종 비는 $C_{in}/C_L$이에요.
  • 원문의 “10배”는 등식이에요. “10배 이상”을 위한 저항 범위와 구별해요.
  • 두 주파수의 비는 Hz로 구해도 같으므로 이 비교식에 $2\pi$를 한쪽에만 추가하지 않아요.

조건을 바꾸어 생각해요

  1. $R_S,g_m,C_{in},C_L$을 고정하고 출력 극점 목표를 입력의 20배로 높이면, 고를 $R_D$는 원래 값의 몇 배일까요?
  2. $R_S,g_m,C_{in}$을 고정하고 $C_L$만 두 배가 되었어요. 출력 극점을 여전히 입력의 10배로 유지하려면 $R_D$를 어떻게 바꿔야 할까요?

두 극점의 비를 먼저 정하고 출력 시간상수에서 $R_D$를 역산해요.

$\lambda=0$·몸체효과 무시·게이트 AC 접지인 CG 모델이에요.

  • 원문의 비교 조건$$\omega_{p,out}=10\,\omega_{p,in}$$
  • 입력 저항 블록$$R_i=R_S\parallel\frac1{g_m}$$
  • 정확히 열 배인 선택$$R_D=\frac{C_{in}}{10C_L}R_i$$

$R_D$를 더 작게 고르면 출력 극점은 10배보다 높아져요.

P13. CG 소스에 붙은 기생 저항

주어진 조건

  • 제조 오류로 기생 저항 $R_p$가 $M_1$의 소스와 직렬로 생김 (그림 라벨은 $R_P$, 그림에 $M_1$ 라벨은 인쇄되지 않음)
  • $\lambda = 0$, 다른 커패시턴스는 무시

구할 것

  • 회로의 입력 극점과 출력 극점
원문 보기

Due to a manufacturing error, a parasitic resistance $R_p$ has appeared in series with the source of $M_1$ in Fig. 11.67. Assuming $\lambda = 0$ and neglecting other capacitances, determine the input and output poles of the circuit.

문제를 읽어요

CG 입력 경로에 생긴 기생 저항 때문에, 입력 커패시터가 붙은 노드와 MOS의 실제 소스가 서로 다른 노드가 됐어요. 입력 극점에서 이 차이를 반영하고, 출력 극점도 따로 확인해요.

문제의 $M_1$은 게이트가 $V_b$에 고정된 MOS예요. 기생 저항은 그림의 표기 $R_P$로 쓰고, $R_S$·$R_P$·$C_{in}$의 접속점을 해석용 X, 실제 소스를 해석용 S라고 부를게요.

이 개념과 공식을 떠올려요

$\lambda=0$이고 다른 커패시턴스를 무시하므로, 그림의 $C_{in}$과 $C_L$에 해당하는 두 RC 인자를 찾아요. 게이트는 AC 접지이고 몸체효과와 게이트 전도 전류는 무시하는 모델이에요.

CG 소스 쪽의 알려진 입력저항은 $1/g_m$이에요. 여기서 $g_m$은 문제의 MOS 트랜스컨덕턴스예요. X에서 그 소스 쪽을 보려면 먼저 $R_P$를 지나야 하므로 두 저항은 직렬이에요.

예를 들어 $R_P=1/g_m$이면 소자 쪽 가지의 직렬 합은 $2/g_m$이에요. 그다음에야 X에서 접지로 가는 다른 경로인 $R_S$와 병렬로 합쳐요.

$R_P$는 CG 신호 입력 경로에 직렬로 생긴 저항이에요. 일반적인 접지 소스 축퇴 저항으로 바꿔 놓거나 $g_mR_P\gg1$을 강제하지 않고, 내부 저항 $1/g_m$을 포함한 $R_P+1/g_m$을 유지해요.

$\lambda=0$에서는 드레인 전압 변화가 소스 전류에 영향을 주지 않아요. 그래서 입력 쪽 저항 블록은 출력의 $R_D$·$C_L$에 의존하지 않아요.

S에는 별도의 커패시턴스를 두지 않으므로, 해석용 노드 이름을 추가했다고 RC 극점이 하나 더 생기지는 않아요.

종이에 쓸 첫 줄

독립 입력을 0으로 두어 $R_S$의 왼쪽을 단락하고, 고정 바이어스와 전원은 AC 접지로 봐요.

$$v_{in}=0$$

저항을 읽을 때 커패시터를 개방해서 생각해도 $R_P$의 위치는 그대로예요. $C_{in}$이 보는 노드는 S가 아니라 X예요.

이렇게 풀어요

입력 커패시터 노드 X

먼 곳의 소자 블록부터 읽어요. 게이트 AC 접지·$\lambda=0$·몸체효과 무시 조건에서, 실제 소스 S에서 MOS 안쪽을 보면 $1/g_m$이에요.

$$R_{in,S}=\frac1{g_m}$$

X에서 S를 거쳐 들어가는 가지에는 $R_P$가 직렬로 더해져요.

$$R_{branch}=R_P+\frac1{g_m}$$

입력원을 단락하면 $R_S$도 X에서 AC 접지로 보여요. 두 경로를 마지막에 병렬로 합쳐요.

$$R_{eq,in}=R_S\parallel\left(R_P+\frac1{g_m}\right)$$

X–접지의 커패시턴스는 $C_{in}$이므로 입력 코너예요.

$$\omega_{p,in}=\frac1{\left[R_S\parallel\left(R_P+1/g_m\right)\right]C_{in}}$$
드레인 출력 노드

출력의 저항 경로를 읽을 때도 독립 입력을 0으로 두고 커패시터를 개방해요. 소스는 입력의 접지 경로를 통해 0이 되고 게이트도 AC 접지라 제어 전압이 0이에요.

$\lambda=0$이므로 MOS의 드레인 저항은 무한대예요. 소스 쪽에 $R_P$가 있어도 드레인 전압의 영향이 되돌아가지 않아서 출력의 저항 경로는 $R_D$예요.

$$R_{eq,out}=R_D$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

이 결론은 주어진 한 방향 소신호 모델의 결과예요. 소스 전류가 드레인 전압에 의존하는 다른 모델에 그대로 옮기지 않아요.

완성 답과 검산

양의 입력·출력 코너 각주파수예요.

$$\omega_{p,in}=\frac1{\left[R_S\parallel\left(R_P+1/g_m\right)\right]C_{in}}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

$\lambda=0$·게이트 AC 접지·몸체효과와 게이트 전도 전류 무시 조건이고, 다른 커패시턴스는 고려하지 않아요.

$s$ 평면의 극점은 이 양의 코너에 각각 음의 부호를 붙인 위치예요.

기생 저항이 없어지는 경우를 확인해요. $R_P\to0$을 넣으면 기본 CG 입력 극점으로 돌아가요.

$$\omega_{p,in}\longrightarrow\frac1{(R_S\parallel1/g_m)C_{in}}$$

저항 증가 방향을 확인해요. $g_m$과 다른 소신호 값을 고정하면 입력 코너를 다음처럼 컨덕턴스의 합으로 쓸 수 있어요.

$$\omega_{p,in}=\frac1{C_{in}}\left(\frac1{R_S}+\frac1{R_P+1/g_m}\right)$$

$R_P$가 커지면 두 번째 항이 작아지므로 입력 코너는 낮아져요. 출력 코너 식에는 $R_P$가 없어서 같은 $R_D$·$C_L$이면 그대로예요.

단위를 확인해요. $R_P$와 $1/g_m$은 모두 저항이라 직렬 합의 단위는 $\Omega$예요. 병렬 합도 $\Omega$이고, $C_{in}$을 곱한 뒤 역수를 취하면 $\mathrm{s^{-1}}$ 차원의 코너 각주파수이며 단위는 $\mathrm{rad/s}$예요.

주의할 점

  • $R_P$는 X와 실제 소스 S 사이에 있어요. $C_{in}$을 S에 옮겨 그리면 다른 회로를 푸는 셈이에요.
  • $R_P$와 $1/g_m$은 직렬이고, 그 합이 $R_S$와 병렬이에요. 세 저항을 모두 직렬이나 모두 병렬로 묶지 않아요.
  • 소스 입력 경로의 기생 저항이라는 위치를 유지해요. $g_mR_P\gg1$을 조건 없이 넣어 내부 $1/g_m$을 지우지 않아요.
  • 입력원을 0으로 놓아도 실제로 단락하는 위치는 $R_S$ 앞이에요. X나 S를 바로 접지로 옮기지 않아요.
  • $R_P$를 바꾸었을 때 입력 코너가 낮아진다는 비교는 $g_m$과 나머지 소신호 값을 고정한 조건이에요.

조건을 바꾸어 생각해요

  1. $g_m$·$C_{in}$·$R_D$·$C_L$을 고정하고 $R_S\gg2/g_m$라고 해요. $R_P=0$에서 $R_P=1/g_m$으로 바꾸면 입력 코너는 처음의 약 몇 배가 되고, 출력 코너는 어떻게 될까요?

입력 커패시터 노드에서는 $R_P+1/g_m$을 먼저 만들고 $R_S$와 병렬로 합쳐요.

$\lambda=0$·게이트 AC 접지·몸체효과와 게이트 전도 전류 무시 조건이며 $C_{in}$과 $C_L$만 남겨요.

$$\begin{aligned}\omega_{p,in}&=\\&\frac1{\left[R_S\parallel\left(R_P+1/g_m\right)\right]C_{in}}\end{aligned}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

$R_P$는 입력 커패시터 노드와 MOS 소스 사이에 있어요.

$g_m$을 고정하면 $R_P$ 증가는 입력 코너를 낮추고 출력 코너는 바꾸지 않아요.
