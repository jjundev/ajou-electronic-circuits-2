# 장말문제 10.48 — 문제 10.46의 G_m이 2배만큼 떨어지는(절반이 되는) 입력 차

## 원문
Using the result obtained in Problem 10.46, calculate the value of $V_{in1} - V_{in2}$ at which the transconductance drops by a factor of 2.

## 조건
- 문제 10.46에서 얻은 결과(MOS 차동쌍의 $G_m$을 $V_{in1} - V_{in2}$의 함수로 나타낸 식)를 이용

## 구할 것
- 트랜스컨덕턴스가 2배만큼 떨어지는(절반이 되는) $V_{in1} - V_{in2}$
  - 기준은 $G_m$의 최댓값($V_{in1} = V_{in2}$일 때) (원문에 없음)

## 상속·참조
- 문제 10.46 (P10.46): 식 (10.147)로부터 MOS 차동쌍의 소신호 트랜스컨덕턴스 $G_m = \partial(I_{D1} - I_{D2})/\partial(V_{in1} - V_{in2})$ (10.221)을 구하고, $V_{in1} - V_{in2}$의 함수로 그려 최댓값을 구함
- 식 (10.147) (교재 532쪽):
  $$I_{D1} - I_{D2} = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{in1} - V_{in2})\sqrt{\frac{4I_{SS}}{\mu_n C_{ox}\dfrac{W}{L}} - (V_{in1} - V_{in2})^2} \qquad (10.147)$$
- 유도 가정 (교재 530쪽): 채널 길이 변조 무시($\lambda = 0$), 제곱 법칙 $I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$, 두 트랜지스터 동일. KVL $V_{in1} - V_{GS1} = V_{in2} - V_{GS2}$ (10.133), KCL $I_{D1} + I_{D2} = I_{SS}$ (10.134)
- 식 (10.131)–(10.147)의 회로: 본문 Fig 10.31 (교재 530쪽, PDF 18, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-31.png, "대신호 분석을 위한 MOS 차동쌍"). 연결: `R_D: VDD – Vout1`, `R_D: VDD – Vout2`, `M1: D = Vout1, G = Vin1, S = 공통 소스 노드`, `M2: D = Vout2, G = Vin2, S = 공통 소스 노드`, `I_SS: 공통 소스 노드 → 접지` (공통 소스 노드 라벨 없음)

## 회로 — 없음 (식에서 출발하는 문제, 문제 그림 없음)

## 풀이
### $G_m$의 비
- 문제 10.46의 결과: $K = \mu_n C_{ox} W/L$, $A = 4I_{SS}/K$, $\Delta V = V_{in1} - V_{in2}$로 $G_m = \dfrac{K}{2}\,\dfrac{A - 2\Delta V^2}{\sqrt{A - \Delta V^2}}$, 최댓값 $G_m(0) = \dfrac{K}{2}\sqrt{A}$
- $y = \Delta V^2/A$로 두면 $\dfrac{G_m}{G_m(0)} = \dfrac{1 - 2y}{\sqrt{1 - y}}$
### 절반 조건
- $\dfrac{1 - 2y}{\sqrt{1 - y}} = \dfrac{1}{2}$을 제곱하면 $4(1 - 2y)^2 = 1 - y$, 곧 $16y^2 - 15y + 3 = 0$
- $y = (15 \pm \sqrt{33})/32 = 0.289$ 또는 $0.648$. 제곱 전 식의 좌변이 양수여야 하므로($1 - 2y > 0$) $y = 0.289$
### $\Delta V$
- $\Delta V^2 = yA = 1.16\,I_{SS}/K$, $|\Delta V| = 1.08\sqrt{I_{SS}/K}$
- 평형 과구동 $(V_{GS} - V_{TH})_{equil} = \sqrt{I_{SS}/K}$의 $1.08$배이고, 한 소자가 꺼지는 $\sqrt{2I_{SS}/K}$의 $0.761$배
### 답
- $|V_{in1} - V_{in2}| = \sqrt{\dfrac{15 - \sqrt{33}}{8}\,\dfrac{I_{SS}}{\mu_n C_{ox} W/L}} \approx 1.08\sqrt{\dfrac{I_{SS}}{\mu_n C_{ox} W/L}} = 1.08\,(V_{GS} - V_{TH})_{equil}$
