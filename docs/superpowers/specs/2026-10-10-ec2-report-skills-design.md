# 전자회로2 보고서 스킬 3종 설계

> 2026-10-10 grill-yourself 세션 3회(설계과제1 보고서 양식 → 논회실 방식 이식 → 스킬 기획)의 확정본.

## 의도

설계과제 보고서를 논리회로실험(`../논회실`)과 같은 방식으로 제출한다.

1. 표지는 따로 만든다 (HTML → PDF, 한글 IEEE 윤리강령 포함 A4 1장).
2. 본문 md 를 노션에 텍스트만 올리고, 그림은 사용자가 노션에서 직접 끼운다.
3. 사용자가 노션에서 PDF 로 내보낸다.
4. 표지와 무손실 병합해 BB 제출본을 만든다.

설계과제2 이후에도 코드 수정 없이 쓴다.

## 구성 (Option A)

- 공용 패키지 `scripts/ec2_report/` — config · check · notion · html2pdf · cover · merge · sync
- 스킬 3개 (`.claude/skills/`, `.agents/skills/` 에 심링크)
  - `ec2-write-design-report` — 선배 양식 + 감점 체크리스트로 본문 md 작성
  - `ec2-sync-notion` — 검사 → 새 페이지 업로드 → baseline → 왕복 검사, 그림 빈자리 검사
  - `ec2-merge-report` — 표지 생성 + 병합 + 검증 (표지 단독 생성도 여기서)
- 단일 메타데이터 소스 `.claude/과목정보.md`

## 보고서 양식 (`from_the_past/설계+과제+1.pdf` 분석)

- 제목 "설계 과제 N: <회로>", 문제 조건과 그림 1 그대로.
- 소문항마다 문제 문장을 굵게 그대로 → 그 아래 "▶" 로 시작하는 풀이.
- 1): 이득식 유도, $I_D$ 식을 W 로 푼 식, MOSFET 별 W 계산식(숫자 대입) 표, 요약 표(|V_DS|·|V_GS|·W·W/L·Vb), saturation 부등식.
- 2): LTspice 회로도(.op 라벨, 학번·이름 텍스트) → (b) 표·부등식 → (c) 파형 → (d) 오차 % 와 번호 매긴 원인.
- 감점 이력(`from_the_past/감점요인.png`): 1-(a) Gm 미유도 −5, 주파수 응답 크기·위상 plot 누락 −5.
