## 적용 규칙

각 규칙의 적용 여부는 문항별로 판단한다. 적용할 이유가 없으면 이유를 적고

### UNIT-01: 공학 단위와 환산

- **관찰:** MOS 계산에 V·mA·kΩ·mS 조합을 반복한다. 100 μA/V²를 0.1 mA/V²로,
  500 Ω를 0.5 kΩ로 바꾸고 인자 아래에도 단위를 적는다.
- **근거:** H0909 p1·2·3·6·8. BJT의 다른 단위 사용은 H0911 p6, H0916 p6.
- **확신도:** 높음. MOS에서 반복 관찰했으나 항상 mS를 쓰는 것은 아니다.
- **생성 규칙:** 첫 사용에서 환산을 보이고 mA×kΩ=V, mS×kΩ=1,
  mS×kΩ²=kΩ를 유지한다. 식의 각 인자와 최종 답에 필요한 단위를 표시한다.
- **예외:** BJT의 $g_m=1/26\ \mathrm{S}$도 허용한다. 다른 규모에는 적절한 단위를
  쓰며 정성 문항에 수치를 억지로 넣지 않는다.
- **검토 기준:** 환산 계수와 차원이 맞는가? S·kΩ를 섞은 곱에서 $10^3$을 빠뜨리지 않았는가?

### CALC-01: 중간값과 역산

- **관찰:** 소자별 $r_o$, $g_m$, $r_\pi$를 먼저 구해 조립한다. 목표 $R_{out}$에서
  $g_m$, 이어 $W/L$을 역산하고 같은 소자는 등식으로 묶는다.
- **근거:** H0909 p2·3·6, H0911 p6·10.
- **확신도:** 높음.
- **생성 규칙:** 목표 식 → 필요한 중간값 → 대입 → 최종 답 순서로 연결한다.
  한 식에 모든 소자식을 무리하게 대입하지 않는다.
- **예외:** 원문의 서로 다른 소자·전류를 편의상 같다고 두지 않는다. 정성 문항에는
  불필요한 수치 계산 대신 필요한 관계를 쓴다.
- **검토 기준:** 각 중간값의 소자 번호·조건이 분명하고 역산 결과를 목표 식에 대입해 확인했는가?

### CALC-02: 분수와 반올림

- **관찰:** $5/4$, $25/16$ 같은 간단한 분수는 유지하고 제곱근은 1.79·3.33·0.42처럼
  표시한다. 고정 유효숫자 규칙은 확인되지 않았다.
- **근거:** H0909 p2·3·6·8.
- **확신도:** 높음. 특정 소수 자릿수 선호까지 확정하지 않는다.
- **생성 규칙:** 내부 계산의 정밀도를 유지하고 표시만 반올림한다. 간단한 분수는
  다음 계산에 활용한다. 반올림 뒤 값이 달라지면 등호 대신 근사 표시로 드러낸다.
- **예외:** 원문이 요구한 유효숫자·정밀도가 있으면 그것을 우선한다.
- **검토 기준:** 표시된 중간값을 무단 재사용해 최종 값이 변하지 않았는가?
  동치 변형과 수치 근사를 구별했는가?

### CIRCUIT-01: 역할과 바라보는 방향

- **관찰:** 입력 소자·출력 노드·위아래로 바라보는 저항·전류 경로를 회로에 표시한다.
  $R_{out}=R_{on}\parallel R_{op}$로 합치거나 입력 아래를 $R_s^*$로 묶는다.
- **근거:** H0916 p4·8, HGM p1.
- **확신도:** 높음.
- **생성 규칙:** 원문 소자 번호를 유지하고 역할로 설명한다. 저항을 보는 화살표와
  전류 방향을 구별한다. $R_s^*$를 쓰기 전에 어느 회로 부분을 묶는지 정의한다.
- **예외:** 회로마다 입력 위치와 관찰 단자가 다르다. 위쪽 소자가 항상 같은 역할이라고 가정하지 않는다.
- **검토 기준:** 화살표가 뜻하는 측정 단자·방향·회로 범위가 명확한가?
  병렬로 묶은 두 저항이 실제로 같은 두 소신호 노드에 연결되는가?

### CIRCUIT-02: 필요한 만큼의 등가회로

- **관찰:** MOS 기호와 저항으로 간략화하기도 하고 제어 전류원·노드 전압까지 펼치기도 한다.
- **근거:** 간략화는 H0909 p4/H0916 p1(같은 문항), 상세 소신호 전개는 H0911 p8/H0916 p3.
- **확신도:** 높음. 표현의 선택이 관찰되며 소신호 회로를 싫어한다는 해석은 근거가 없다.
- **생성 규칙:** 알려진 블록과 연결 관계로 충분하면 간략 회로부터 보여준다.
  KCL/KVL·제어 전압 유도가 필요하면 기존 필수 소신호 SVG 규칙에 따라
  제어 전류원·필요한 저항·노드·극성을 명시한다.
- **예외:** 핵심 유도를 숨기려고 회로를 과도하게 줄이지 않는다. 단순 블록 재사용을
  모든 문제에 대한 소신호 회로 생략 허가로 해석하지 않는다.
- **검토 기준:** 독자가 핵심 식을 회로에서 확인할 수 있는가? 필요한 모델 요소가 빠지지 않았는가?

### GAIN-01: Gm과 Rout 분리

- **관찰:** $G_m$과 $R_{out}$을 따로 구해 $A_v=-G_mR_{out}$으로 연결한다.
  입력의 전류 생성과 출력저항 증대 역할을 구분한다.
- **근거:** H0911 p10, H0916 p3·4·5·6, HGM p1.
- **확신도:** 매우 높음.
- **생성 규칙:** 전류 방향을 정의하고 $G_m$의 출력 단락 조건과 $R_{out}$의
  입력 영점 조건을 구분한다. 해당 정의에서 이득의 부호를 확인한다.
- **예외:** 상단 소자의 $G_m$ 영향이 항상 0이라는 일반 법칙으로 확대하지 않는다.
  다른 전달 특성·주파수 범위에서는 해당 모델과 부호 정의를 다시 확인한다.
- **검토 기준:** 두 측정 조건을 섞지 않았는가? $G_m$과 $g_m$을 구별하고
  $-G_mR_{out}$의 조건·차원·부호를 검산했는가?

### DEGEN-01: 제어 전압과 저항 합 형태

- **관찰:** $g_{m2}(v_{in}-i_{out}r_{o1})=i_{out}$를 쓰고
  $g_m/(1+g_mR)$를 $1/(1/g_m+R)$로 바꿔 지배항을 본다.
- **근거:** H0916 p3, HGM p1의 같은 형태.
- **확신도:** 높음. 관찰된 축퇴 모델에 한정한다.
- **생성 규칙:** 입력 전압 → 소스/이미터 전압 상승 → 남는 제어 전압 → 전류
  관계를 연결한다. 저항 합 형태로 바꿔 어떤 항이 큰지 설명한다.
- **예외:** 위 제어 전압 식은 모든 BJT의 정확식이 아니다. 베이스 전류와 해당
  $r_o$ 경로 등을 무시했다면 큰 β·큰 $g_mr_o$ 등 필요한 조건을 밝힌다.
- **검토 기준:** $i_{out}$과 소스/이미터 전류를 같게 둔 근거가 있는가?
  생략한 β·$r_o$ 항이 결론에 미치는 영향을 확인했는가?

### SCALE-01: 고정 인자와 비율

- **관찰:** $W\to NW$에서 $R_{out}$의 $\sqrt N$배 변화, $g_{m1}g_{m2}$의
  $N$배 변화, $W$·$I_D$ 동시 두 배 효과를 추론한다. 변화 전후 $R_{out}$의
  비에서 공통 인자를 소거하기도 한다.
- **근거:** H0909 p7, H0916 p5, H0911 p9, H0909 p5의 비율 계산.
- **확신도:** 높음.
- **생성 규칙:** 고정 인자 → 변하는 인자 → 각 배율 → 최종 배율을 보인다.
  일반적인 의존성 논증을 수치 재계산만으로 대체하지 않는다.
- **예외:** $I_D$·$L$·λ의 고정 여부와 사용한 소자 모델을 확인한다.
  폭만 바뀌는 경우와 전류도 바뀌는 경우를 혼동하지 않는다.
- **검토 기준:** 모든 고정 조건을 적었는가? 제곱근·곱·병렬에서 배율을 올바르게 합성했는가?

### BIAS-01: 노드 전압과 경계 부등식

- **관찰:** $V_{ov}$와 포화 경계를 구한다. $V_1=V_{DD}-I_DR_D$를 먼저 계산한 뒤
  $V_{GD}\le V_{TH}$로 $V_{b1}$ 상한을 구한다.
- **근거:** H0909 p1·8.
- **확신도:** 높음. 관찰 범위는 해당 MOS 바이어스 문제다.
- **생성 규칙:** 먼저 구할 수 있는 노드 전압을 계산하고 원 회로의 단자 전압으로
  경계 조건을 쓴다. 부등식에서 허용 범위와 경계값을 구분한다.
- **예외:** 상한·하한·최댓값·최솟값을 등식 하나로 뭉개지 않는다.
  NMOS 부등식을 PMOS에 그대로 적용하지 않는다.
- **검토 기준:** $V_{GD}$ 등 단자 차의 순서·극성·부등호가 맞는가?
  다른 소자의 동작 조건도 만족하며 경계가 실제 허용 범위에 들어가는가?

### EXPLAIN-01: 짧은 판단과 식 연결

- **관찰:** “L은 일정”, “Base 전류는 무시”, “전류 통로” 같은 판단 한 줄이 식을 연결한다.
- **근거:** 설계의 필기 종합 관찰 기록(개별 문구의 쪽수는 미확인).
  사용자가 확정한 선택은 핵심 풀이를 먼저, 필요한 상세 개념·유도를 이어서 제공하는 것이다.
- **확신도:** 순서는 사용자 확정. 짧은 판단과 식의 연결은 관찰 근거가 있으나
  모든 상황에서 짧은 설명만 원한다는 뜻은 아니다.
- **생성 규칙:** 판단 한 문장 → 대응 식 → 변형/대입 → 결과로 핵심을 보여준다.
  뒤의 상세 설명에서 신규 개념의 동기·성립 조건·필요한 유도를 충실히 설명한다.
- **예외:** 순수 개념 토픽에 숫자나 억지 풀이를 강요하지 않는다.
  짧게 쓰기 위해 핵심 논증·원문의 요구를 생략하지 않는다.
- **검토 기준:** 핵심 풀이와 상세 설명이 단위·조건·부호·최종 답에서 일치하는가?

## 근거를 이용한 적용 예시

다음은 표기와 전개 방식의 모범 예시다. 해당 문제의 전체 해설을 대체하지 않는다.
소자 번호·입력 위치는 각 workbook 원문 MD와 대조했으며 원본은 변경하지 않았다.
기본 모델은 저주파 소신호 모델이다. 포화/활성 동작과 각 근사 조건을 별도로 확인한다.

#### 1. E9.05 — 목표 출력저항에서 W/L 역산

Fig 9.8의 상단은 $M_1$, 하단은 $M_2$다. 두 소자가 같고
$I_D=0.5\ \mathrm{mA}$, $\lambda=0.1\ \mathrm{V}^{-1}$이면
$r_{o1}=r_{o2}=1/(\lambda I_D)=20\ \mathrm{k}\Omega$다.
먼저 $100\ \mu\mathrm{A/V^2}=0.1\ \mathrm{mA/V^2}$로 환산한다.

주항 모델 $R_{out}\approx g_{m1}r_{o1}r_{o2}$로 목표 $500\ \mathrm{k}\Omega$를 맞추면

$$g_{m1}=\frac{500\ \mathrm{k}\Omega}{(20\ \mathrm{k}\Omega)^2}
=\frac54\ \mathrm{mS},\qquad
\frac WL=\frac{(5/4)^2}{2\times0.1\times0.5}
=\frac{25/16}{2\times0.1\times0.5}=15.625.$$

**주항 근사 설계 답은 두 소자 모두 $W/L=15.625\approx15.6$**이다.
$g_mr_o=25$이며 정확한 저주파 모델의
$R_{out}=(1+g_{m1}r_{o2})r_{o1}+r_{o2}$에 넣으면 $540\ \mathrm{k}\Omega$다.
따라서 이 값이 정확식에서도 목표 500 kΩ를 만족한다고 말하지 않는다.

#### 2. E9.06 — 같은 두 노드의 병렬 인식

Fig 9.11의 $R_P$는 상단 **$M_1$의 드레인–소스** 사이이므로
$r'_{o1}=r_{o1}\parallel R_P$다. 하단 $M_2$는 해당 바이어스의 소신호 모델에서
$r_{o2}$로 보인다. 이 연결을 MOS 기호와 저항의 간략 회로로 먼저 보여준다.

$$R_{out}=(1+g_{m1}r_{o2})r'_{o1}+r_{o2}
\approx g_{m1}(r_{o1}\parallel R_P)r_{o2}.$$

마지막 근사는 $g_{m1}r'_{o1}r_{o2}\gg r'_{o1},r_{o2}$일 때만 쓴다.
$R_P\to\infty$이면 원래 캐스코드 식으로 돌아가는지 확인한다.
인쇄 힌트가 있었던 관찰이므로 이 병렬 인식을 독자적인 발명으로 설명하지 않는다.

#### 3. E9.01 — BJT 단위와 병렬 중간값

Fig 9.2(a)는 상단 $Q_1$, 하단 $Q_2$다. $I_C=1\ \mathrm{mA}$,
$V_T=26\ \mathrm{mV}$, $\beta=100$, $V_A=5\ \mathrm{V}$이면

$$g_m=\frac1{26}\ \mathrm{S}=\frac{1000}{26}\ \mathrm{mS},\quad
r_\pi=\frac\beta{g_m}=2.6\ \mathrm{k}\Omega,\quad r_o=5\ \mathrm{k}\Omega.$$

$$r_{o2}\parallel r_{\pi1}=\frac{5\times2.6}{5+2.6}\ \mathrm{k}\Omega
=1.710526\ldots\ \mathrm{k}\Omega.$$

큰 주항 모델에서
$$R_{out}\approx\frac{1000}{26}\ \mathrm{mS}\times5\ \mathrm{k}\Omega
\times\frac{5\times2.6}{5+2.6}\ \mathrm{k}\Omega
=328.947368\ldots\ \mathrm{k}\Omega.$$

**$R_{out}\approx328.947\ \mathrm{k}\Omega$**는 주항의 계산값이다.
$g_{m1}(r_{o2}\parallel r_{\pi1})=65.789\ldots\gg1$임을 확인하며,
유한한 β와 $r_o$의 모든 항을 포함한 정확식이라고 부르지 않는다.
$1/26$을 그대로 mS 값으로 대입하면 빠지는 $10^3$을 명시했다.

#### 4. P9.23 — 입력 위치 변경과 축퇴

Fig 9.56은 상단 **$Q_2$의 베이스에 입력**을 넣는다. 하단 $Q_1$은 베이스와
이미터가 AC 접지여서 $r_{o1}$로 보인다. 큰 축퇴 저항 때문에 이미터 전압이 입력을
따라가므로 제어 전압이 작아진다는 판단을 먼저 적는다.

출력 단락 시 **큰 β로 베이스 전류를 무시하고, $Q_2$의 $r_{o2}$ 경로의 전류를
무시한 단순 모델**에서는
$$v_e\approx i_{out}r_{o1},\quad
i_{out}\approx g_{m2}(v_{in}-i_{out}r_{o1}),\quad
G_m\approx\frac{g_{m2}}{1+g_{m2}r_{o1}}
=\frac1{1/g_{m2}+r_{o1}}\approx\frac1{r_{o1}}.$$

마지막 단계는 $g_{m2}r_{o1}\gg1$을 쓴다. 같은 큰 β·큰 $g_mr_o$의 주항 모델로
입력 영점에서 $R_{out}\approx g_{m2}r_{o2}r_{o1}$을 구하면
**$A_v=-G_mR_{out}\approx-g_{m2}r_{o2}$**다. 이는 추가로 큰 β를 가정한 예시다.
원문의 $g_mr_o\gg1$만으로 큰 β까지 보장되지는 않으므로, 유한 β가 중요한 실제
풀이에서는 $r_{\pi2}$와 $r_{o2}$를 포함한 소신호 회로에서 $G_m$과 $R_{out}$을
각각 다시 구한다. 단순 제어 전압 식을 모든 조건의 정확식으로 재사용하지 않는다.

#### 5. E9.11 — 위아래 저항과 Gm의 역할

Fig 9.20(b)는 아래 $M_1,M_2$, 위 $M_3,M_4$다. 입력 영점에서 출력 아래와 위를
따로 바라보고, 각 캐스코드의 곱 항이 나머지 저항 항보다 큰 조건에서

$$R_{on}\approx g_{m2}r_{o2}r_{o1},\quad
R_{op}\approx g_{m3}r_{o3}r_{o4},\quad R_{out}=R_{on}\parallel R_{op}.$$

별도로 출력 단락에서 $G_m\approx g_{m1}$의 조건
$(1/g_{m2}\ll r_{o1})$을 확인한 뒤 **$A_v\approx-g_{m1}(R_{on}\parallel R_{op})$**로 연결한다.
출력 단락·고정 바이어스의 저주파 소신호 모델에서 PMOS 부하 가지를 구동하는
소신호가 없어 $G_m$ 측정에 기여하지 않는 상황과, 출력에 시험 전압을 걸어
$R_{out}$을 구할 때 그 가지가 $R_{op}$로 기여하는 상황을 구별한다.
이를 “PMOS가 DC에서 꺼졌다”라고 설명하지 않는다.

#### 6. P9.30 — W 배율에서 이득 배율

Fig 9.20(a)의 $M_1,M_2$ 폭을 각각 $N$배로 늘린다. **$I_D,L,\lambda$와
이동도·산화막 파라미터는 고정**하고 같은 포화 영역의 장채널 모델을 사용한다.

$$g_m\propto\sqrt{(W/L)I_D}\ \Rightarrow\ g_{m1},g_{m2}\to\sqrt N\text{배},
\qquad r_o=\frac1{\lambda I_D}\ \Rightarrow\ \text{그대로}.$$

$$A_v\approx-g_{m1}g_{m2}r_{o1}r_{o2}
\ \Rightarrow\ \frac{A'_v}{A_v}\approx\sqrt N\sqrt N=N.$$

**이득의 크기는 약 $N$배**, 반전 부호는 유지된다. 출력저항 주항만은
$\sqrt N$배이고, 여기에 입력 $g_{m1}$의 $\sqrt N$배가 더해진다.
새 바이어스에서도 포화·주항 근사가 유효한지 확인하며, 이 저주파 결과를
커패시턴스가 바뀌는 주파수 응답 전체로 확장하지 않는다.

## 미확인 범위와 적용 감사

이 관찰로 주파수 응답·차동 회로·모든 트랜지스터 회로의 풀이 선호를 확정하지 않는다.
실제 사고의 시간 순서, 고정 유효숫자·고정 색, 빈칸이나 계산 생략의 원인도 미확인이다.
상세 설명이 필요 없거나 소신호 회로를 싫어한다는 해석은 하지 않는다.

작성자와 내용 리뷰어는 이 파일을 읽고 문항별 모든 규칙의 적용 위치·내용 또는
비적용 이유를 기록한다. 실제 검토 없이 `pass`를 채우지 않는다. 필수 명세가 없거나
검토가 실패하면 기존 풀이로 조용히 대체하지 않는다. 명세는 원본 바이트의 SHA-256으로
고정하며 한 바이트라도 바뀌면 이전 개인화 검토를 새 발행에 재사용하지 않는다.
과거 발행물은 계속 열 수 있으나 구버전 검토가 새 발행을 승인하지는 않는다.
형식 검사는 수학 검산·원문 대조·내용 검토·화면 검토를 대체하지 않는다.
