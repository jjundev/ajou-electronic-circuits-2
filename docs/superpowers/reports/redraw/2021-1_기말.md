# 2021-1 기말 다시 그린 그림 검토 (절차 C)

범위: `63db526..e20a1f2`, `figures/redrawn/fig-Q{1..6}.py`, `.png`. `draw_exam.py --compare`는 종료 코드 0이고 ERROR·WARN 줄이 없었다.

확인한 것:
- **연결:** 넷리스트를 줄마다 따라가 모든 단자가 적힌 노드에 닿는 것을 확인했다(Q1–Q6, Q5(eq) 포함).
- **접속점:** 점 개수가 md와 같다. Q1 2, Q2 1, Q3 3, Q4 2, Q5 본 회로 8(n1, Vout 위, Vout 아래, n2, n3, X, n4, Y), Q5(eq) 3, Q6 4. 교차는 없다.
- **방향:** 좌우 반전(Q3·Q4의 M1), pnp와 pmos의 화살표 방향, I_in(위)과 I_out(아래) 화살표, 연산증폭기의 ± 위치(Q5는 −가 위, Q6은 +가 위)가 표시 bullet과 같다.
- **라벨 간격:** 잉크 기준으로 다시 쟀고, 작성자 보고서와 같은 값이 나왔다. 단자 라벨이 아닌 라벨의 최솟값은 0.202u(Q1 R_S)다. 0.2u보다 작은 것은 V_b2, V_b1, V_b, V_Y뿐이고, 모두 자기 단자 점이나 원과의 간격이므로 예외에 해당한다.
- **.py 규칙:** add 뒤에 `.label()`을 부른 곳이 없다. FET와 BJT에 `.scale()`을 쓰지 않았다. `FONT_SIZE`, `LW`, `INCHES_PER_UNIT`도 바꾸지 않았다.
