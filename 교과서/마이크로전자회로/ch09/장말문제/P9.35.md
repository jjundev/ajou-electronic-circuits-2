# 장말문제 9.35 — 저항 분배기로 바이어스한 BJT 전류원의 V_CC 감도

## 원문
From Eq. (9.83), determine the sensitivity of $I_1$ to $V_{CC}$, defined as $\partial I_1 / \partial V_{CC}$. Explain intuitively why this sensitivity is proportional to the transconductance of $Q_1$.

## 조건
- 식 (9.83)에서 출발 (저항 분배기로 베이스를 바이어스한 바이폴라 전류원)
- 감도는 $\partial I_1 / \partial V_{CC}$로 정의

## 구할 것
- $I_1$의 $V_{CC}$에 대한 감도 $\partial I_1 / \partial V_{CC}$
- 이 감도가 $Q_1$의 트랜스컨덕턴스에 비례하는 이유를 직관적으로 설명

## 상속·참조
- 본문 Fig 9.22(a) (교재 468쪽, 크롭 안 함): 저항 분배기 바이어스 바이폴라 전류원
  - `R1: VCC — P`, `R2: P — 0`
  - `Q1: C = I_1이 들어가는 단자, B = P, E = 0`
- 식 (9.83) (9.2.1절, 베이스 전류 무시): $\dfrac{R_2}{R_1 + R_2} V_{CC} = V_T \ln \dfrac{I_1}{I_S}$
