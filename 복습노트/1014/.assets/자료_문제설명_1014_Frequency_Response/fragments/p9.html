문제를 읽어요

입력과 출력에 접지 커패시터가 하나씩 있는 CS 회로예요. 각 커패시터가 어떤 저항을 통해 충전되고 방전되는지 찾아 두 극점을 구해요.

$v_{in}$은 $R_S$ 앞의 신호이고, 실제 게이트 전압은 $R_S$ 뒤의 $v_X$예요. 두 전압을 같은 노드로 놓지 않는 것이 출발점이에요.

이 개념과 공식을 떠올려요

$\lambda=0$이라는 단서에서 $M_1$의 드레인 출력저항은 무한대로 봐요. 그림에 표시된 $C_{in}$과 $C_L$은 서로 다른 신호 노드에서 각각 접지로 연결돼 있어요.

이 단순 소신호 모델은 게이트 전도 전류와 몸체효과를 무시하고, 입력과 출력을 잇는 부유 커패시터도 두지 않아요. 소스는 AC 접지이고, 게이트 전압은 출력 전류에 영향을 주지만 출력 전압이 게이트 쪽으로 되돌아가지는 않아요.

이 조건에서는 입력 RC가 있는 CS 단의 두 극점처럼 노드별 접지 RC 인자가 따로 나타나요. 저항 $R$과 커패시턴스 $C$의 곱은 시간상수(time constant)이고, 그 역수가 양의 코너 각주파수예요.

$$\tau=RC$$ $$\omega_p=\frac1{RC}$$

예를 들어 같은 저항에서 커패시턴스만 2배가 되면 시간상수는 2배이고 코너 각주파수는 절반이에요. 모든 회로의 노드 수를 세어 극점을 정하는 일반 법칙으로 확대하지 않아요.

종이에 쓸 첫 줄

독립 입력 전압을 0으로 두어 단락하고, $V_{DD}$는 AC 접지로 봐요. 저항 경로를 읽을 때는 커패시터 자체를 개방해서 생각해요.

$$v_{in}=0$$

게이트를 바로 접지로 옮기는 것이 아니에요. $v_{in}$을 단락해도 게이트 노드와 접지 사이에는 $R_S$가 남아요.

이렇게 풀어요

입력 노드 $v_X$

MOS 게이트로 전도 전류가 흐르지 않으므로 게이트 쪽에 추가 병렬 저항은 없어요. 입력원을 단락한 뒤 X에서 접지로 보면 $R_S$가 저항 경로이고, 같은 X–접지 두 노드에 $C_{in}$이 연결돼요.

$$R_{eq,in}=R_S$$ $$\tau_{in}=R_SC_{in}$$

입력의 RC 인자에서 양의 코너 각주파수를 구해요.

$$\omega_{p,in}=\frac1{R_SC_{in}}$$
출력 노드 $v_{out}$

저항을 읽는 단계에서 $C_{in}$도 개방하면 입력 0 조건에 의해 게이트와 소스의 제어 전압이 0이에요. $\lambda=0$이라 트랜지스터의 드레인 저항도 무한대예요.

따라서 출력의 저항 경로는 위쪽 $R_D$이고, 출력의 커패시턴스는 $C_L$이에요.

$$R_{eq,out}=R_D$$ $$\tau_{out}=R_DC_L$$

출력의 RC 인자에서 양의 코너 각주파수를 구해요.

$$\omega_{p,out}=\frac1{R_DC_L}$$

두 식은 접지 커패시터와 한 방향 전달이라는 선택 모델 안에서의 극점 코너예요. 소자값이 없으므로 입력과 출력 중 어느 코너가 더 낮은지는 정할 수 없어요.

완성 답과 검산

양의 극점 코너 각주파수는 다음과 같아요.

$$\omega_{p,in}=\frac1{R_SC_{in}}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

$\lambda=0$이고, 게이트 전도 전류·몸체효과를 무시한 이 접지 커패시터 모델의 결과예요.

$s$ 평면의 극점 위치를 쓰면 음의 실수예요.

$$s_{p,in}=-\frac1{R_SC_{in}}$$ $$s_{p,out}=-\frac1{R_DC_L}$$

두 RC 인자를 확인해요. 출력에서 입력으로 돌아가는 결합이 없어서 입력의 자연응답 인자는 출력 쪽 동작으로 바뀌지 않아요. 따라서 이 모델의 극점을 만드는 두 인자는 다음처럼 곱해져요.

$$D(s)=(1+sR_SC_{in})(1+sR_DC_L)$$

$D(s)=0$을 풀면 완성 답의 두 음의 근이 나와요. 두 RC 시간이 같으면 같은 위치에 겹친 극점이 생기며 차수는 2로 남아요.

단위도 확인해요. $\Omega\cdot\mathrm F=\mathrm s$이므로 두 $RC$ 곱의 역수는 $\mathrm{s^{-1}}$ 차원을 가져요. $\omega_p$의 단위는 $\mathrm{rad/s}$이고, $\mathrm{Hz}$의 코너 주파수가 필요하면 $2\pi$로 나눠요.

주의할 점

  • 입력원을 0으로 놓는 것은 $R_S$ 앞의 $v_{in}$을 단락하는 것이에요. $v_X$를 입력원과 같은 노드로 취급해 $R_S$를 없애지 않아요.
  • 게이트를 보는 입력 저항과 소스를 보는 입력 저항은 달라요. 이 CS의 게이트 노드에 $1/g_m$을 병렬로 넣지 않아요.
  • $C_{in}$과 $C_L$은 같은 노드에 붙어 있지 않으므로 합쳐서 하나의 커패시턴스로 만들지 않아요.
  • 입력 코너가 항상 낮은 것도, 두 코너가 반드시 서로 다른 것도 아니에요. 크기 비교에는 실제 소자값이 필요해요.
  • 양의 코너 $\omega_p$와 음의 $s$ 평면 근을 구별해요. 부유 커패시터나 역방향 결합이 있는 다른 회로에 이 두 RC 식을 그대로 적용하지 않아요.

조건을 바꾸어 생각해요

  1. $R_S$·$R_D$·$C_L$을 그대로 두고 $C_{in}$만 2배로 늘리면, 입력과 출력의 코너 각주파수는 각각 어떻게 바뀔까요? 같은 $\lambda=0$ 모델을 사용해요.

입력은 $R_SC_{in}$, 출력은 $R_DC_L$의 접지 RC 인자로 극점을 찾아요.

$\lambda=0$이고 게이트 전도 전류·몸체효과와 입력–출력 부유 커패시터를 무시한 모델이에요.

$$\omega_{p,in}=\frac1{R_SC_{in}}$$ $$\omega_{p,out}=\frac1{R_DC_L}$$

양의 코너 각주파수와 음의 $s$ 평면 근을 구별해요.

어느 코너가 낮은지는 소자값으로 판단해요.
