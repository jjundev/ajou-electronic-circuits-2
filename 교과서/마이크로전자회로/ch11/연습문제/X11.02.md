# 연습문제 11.2 — 감기에 걸렸을 때 목소리의 변화

## 원문
감기에 걸렸을 때 목소리에 어떤 변화가 생기는지 설명해 보라.

## 조건
- 감기에 걸린 상황
- 예제 11.2처럼 목소리가 전파되는 통로의 주파수 응답 관점에서 생각함 (원문에 없음, 원문은 질문만 적음)

## 구할 것
- 감기에 걸렸을 때 목소리에 어떤 변화가 생기는지 설명

## 상속·참조
- 예제 11.2 (E11.02): 음성이 전파되는 통로(공기 중, 두개골)마다 주파수 응답이 달라 같은 목소리가 다르게 들림

## 회로 — 없음 (그림 없는 글 문제)

## 풀이
### 목소리가 지나는 통로
- 목소리는 성대에서 나와 목, 입, 코안(비강)을 거쳐 밖으로 나온다
- 이 통로 전체가 하나의 시스템이고, 통로의 모양이 주파수별로 얼마나 통과·울림시키는지(주파수 응답)를 정한다
### 감기가 바꾸는 것
- 감기에 걸리면 코가 막히고 성대와 목 안쪽이 붓는다 → 통로의 모양이 바뀌어 주파수 응답이 달라진다
- 코안을 울려 나오던 성분(비음)이 제대로 나오지 못하고, 붓고 무거워진 성대는 더 낮고 거칠게 떨린다
### 답
- 코와 목이 막히고 부어 목소리가 지나는 통로의 주파수 응답이 바뀐다. 그래서 같은 사람의 목소리라도 주파수 성분의 비율이 달라져 코 막힌 듯 먹먹하게 들린다. 성대가 부어 더 낮고 거칠게 떨리는 것도 한몫한다.
