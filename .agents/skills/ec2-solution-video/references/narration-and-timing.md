# 음성과 작성 타이밍

기본 설정은 assets/defaults.json이다. Aoede/한국어/24kHz mono PCM, 1920×1080/30fps이며 모델과 공급자를 자동 대체하지 않는다. 환경 GOOGLE_API_KEY 또는 GEMINI_API_KEY를 사용한다. --env-file은 메모리로만 읽고 config/로그에 키를 넣지 않는다. budget_usd=null은 상한 없음이며 명시 상한을 주면 price 요율과 기존 예산 규칙을 따른다. 모든 문항은 batch/usage.json 하나를 쓴다.

문제를 확인하는 발화로 시작한다. 판단 이유(reason), 원문을 쓰는 동안의 설명(write), 계산 확인(check), 답 확인(summary)을 원자료에 연결한다. PDF에 없는 새 계산이나 풀이를 만들지 않는다. 한 발화가 길면 PageMap 단계도 작은 연속 단위로 나눈다. 실패한 문항만 재개하고 성공 WAV는 내용/설정 해시로 재사용한다.

각 write는 max(실제 WAV 길이, 글자 수 × ceil(30/7) 프레임)+0.75초를 확보한다. 보수적 프레임 반올림으로 7글자/초를 넘지 않는다. 공백은 이벤트 시간만 쓰고 그림은 나타나지 않는다. shape는 같은 단계의 anchor glyph와 함께 공개한다. 전체 타이밍은 800샘플=1프레임이며 실제 PCM은 자르거나 늘이지 않고 남는 구간을 무음으로 채운다. 마지막은 최소 1초 전체 답안 확인이다. 단어별 실제 음성 정렬을 주장하지 않는다.

개발 테스트는 fake transport와 로컬 PCM만 사용한다. 실제 Aoede 품질/발음/의미는 최종 파일을 청취하여 별도 현재 audio-review로 확인한다. fake PCM의 기술 검사로 실제 음성 의미 검토를 통과 처리하지 않는다.
