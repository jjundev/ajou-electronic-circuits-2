# 연습문제 9.15 — 150 μA 밴드갭 기준 전류로 다시 설계 (예제 9.15 변형)

## 조건
- 예제 9.15와 같은 설계 문제: 기준 전류 하나로 두 전류 $50\ \mu\text{A}$와 $500\ \mu\text{A}$를 만드는 전류 거울
- 바뀐 점: 기준 전류가 $150\ \mu\text{A}$의 밴드갭 기준 전류 (예제는 $200\ \mu\text{A}$)

## 구할 것
- $I_{REF} = 150\ \mu\text{A}$로 $50\ \mu\text{A}$와 $500\ \mu\text{A}$를 만드는 전류 거울 회로 설계

## 상속·참조
- 예제 9.15 (E9.15): $I_{REF} = 200\ \mu\text{A}$에서 같은 두 전류를 만드는 설계
  - 풀이: 기준 쪽($Q_{REF}$)을 각각 $50\ \mu\text{A}$를 흘리는 단위 트랜지스터 4개(총 $4A_E$)로 만들고, $Q_1 = A_E$ → $50\ \mu\text{A}$, $Q_2 = 10A_E$(단위 트랜지스터 10개) → $500\ \mu\text{A}$
  - 풀이가 쓴 가정: 단위 트랜지스터 하나(면적 $A_E$)가 $50\ \mu\text{A}$를 흘리고, 전류는 이미터 면적 배수에 비례 (원문에 없음, 그림의 면적 라벨에서 읽은 것)
  - 결과 회로 Fig 9.30: 기준 트랜지스터들은 다이오드 연결되어 공통 베이스 노드 X를 만들고, $Q_1$, $Q_2$의 베이스가 X에, 이미터가 접지에 연결됨

## 회로 — 없음 (설계 문제, 그림은 예제 9.15 풀이에만 있음)
