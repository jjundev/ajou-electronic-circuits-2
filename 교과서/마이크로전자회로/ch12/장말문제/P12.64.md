# 장말문제 12.64 — 예제 12.38을 같은 단 네 개로 반복하고 비교

## 원문
Repeat Example 12-38 for four identical stages and compare the results.

## 조건
- 예제 12.38을 같은 단 네 개로 되풀이 (원문 표기 "Example 12-38")
- 예제 12.38: 그림 12.69(a)의 3단 증폭기에 $K = 1$인 부귀환을 걸려고 한다. 다른 커패시턴스를 무시하고 단이 모두 같다고 가정할 때 회로의 주파수 응답을 그리고 안정성 조건을 결정하라. $\lambda = 0$이라고 가정하라 (원문에 없음)
- 참고 회로 (본문 Fig 12.69(a)): 같은 공통 소스단($M_1$, $M_2$, $M_3$)이 직렬로 이어지고, 각 단은 $V_{DD}$에 달린 드레인 저항 $R_D$와 드레인–접지 커패시터 $C_1$을 가짐. $V_{in}$은 $M_1$ 게이트, 마지막 단 드레인이 $V_{out}$. 이 문제는 이 단을 네 개로 늘린 회로 (원문에 없음)
- 예제 12.38에서 이어받는 가정: $K = 1$, 다른 커패시턴스 무시, 단이 모두 같음, $\lambda = 0$, 각 단 이득의 음의 부호는 생략 (원문에 없음)
- 예제 12.38의 결과: $H(s) = \dfrac{(g_m R_D)^3}{(1 + s/\omega_p)^3}$, $\omega_p = (R_D C_1)^{-1}$, $\omega_{PX} = \sqrt{3}\,\omega_p$, 안정 조건 $g_m R_D < 2$ (본문 식 12.188, 12.190, 12.192, 원문에 없음)

## 구할 것
- 네 단 증폭기의 주파수 응답과 안정성 조건 (원문에 없음, 원문은 "Repeat Example 12-38"만 적음)
- 그 결과를 예제 12.38(세 단)의 결과와 비교

## 상속·참조
- 예제 12.38 (E12.38, 교재 707–709쪽): "그림 12.69(a)의 3단 증폭기에 $K = 1$인 부귀환을 걸려고 한다. 다른 커패시턴스를 무시하고 단이 모두 같다고 가정할 때 회로의 주파수 응답을 그리고 안정성 조건을 결정하라. $\lambda = 0$이라고 가정하라."
  - 그림 12.69(a) (이 파일의 그림 목록에는 넣지 않음, 크롭은 fig12-69-a.png): `RD (세 개): VDD — 각 단 드레인`, `M1: D = n1, G = Vin, S = 0`, `C1: n1 — 0`, `M2: D = n2, G = n1, S = 0`, `C1: n2 — 0`, `M3: D = Vout, G = n2, S = 0`, `C1: Vout — 0`
  - 풀이: 저주파 이득 $(g_m R_D)^3$, 겹친 세 극점 $(R_D C_1)^{-1}$. $|H|$는 $\omega_p = (R_D C_1)^{-1}$에서 60 dB/dec로 떨어지기 시작하고, 위상은 이 주파수의 1/10에서 변하기 시작해 $\omega_p$에서 $-135°$, $10\omega_p$에서 $-270°$에 접근
  - 안정하려면 $|KH| (= |H|)$가 위상 교차 주파수에서 1 이하로 떨어져야 함 (그림 12.69(c), 점 P에서 $|H_P| < 1$)
  - $H(s) = \dfrac{(g_m R_D)^3}{\left(1 + \dfrac{s}{\omega_p}\right)^3}$ (12.188), $\angle H(j\omega) = -3\tan^{-1}\dfrac{\omega}{\omega_p}$ (12.189), $\tan^{-1}(\omega/\omega_p) = 60°$에서 위상 교차, $\omega_{PX} = \sqrt{3}\,\omega_p$ (12.190)
  - $\dfrac{(g_m R_D)^3}{\left[\sqrt{1 + \left(\dfrac{\omega_{PX}}{\omega_p}\right)^2}\right]^3} < 1$ (12.191), 따라서 $g_m R_D < 2$ (12.192)

## 회로 — 없음 (네 단으로 늘린 회로는 그림 없음, 예제 12.38의 Fig 12.69(a)는 조건에 글로 적음)
