# 장말문제 12.9 — 1차 개루프·폐루프 시스템의 −1 dB 대역폭

## 원문
In some applications, we may define a “$-1$ dB bandwidth” as the frequency at which the gain falls by 10%. Determine the $-1$ dB bandwidth of the open-loop and closed-loop first-order systems described by Eqs. (12.19) and (12.22). Can we say the $-1$ dB bandwidth increases by $1 + KA_0$ as a result of feedback?

## 조건
- "$-1$ dB 대역폭": 이득이 10% 떨어지는 주파수로 정의
- 개루프 1차 시스템: 식 (12.19)
- 식 (12.19): $A_1(s) = \dfrac{A_0}{1 + \dfrac{s}{\omega_0}}$, $A_0$는 저주파 이득, $\omega_0$는 $-3$ dB 대역폭 (본문 식, 원문에 없음)
- 폐루프 1차 시스템: 식 (12.22)
- 식 (12.22): $\dfrac{Y}{X}(s) = \dfrac{\dfrac{A_0}{1 + KA_0}}{1 + \dfrac{s}{(1 + KA_0)\,\omega_0}}$ (본문 식, 원문에 없음)

## 구할 것
- 개루프 시스템의 $-1$ dB 대역폭
- 폐루프 시스템의 $-1$ dB 대역폭
- 귀환으로 $-1$ dB 대역폭이 $1 + KA_0$배 늘어난다고 말할 수 있는가?

## 상속·참조
- 식 (12.19) (12.2.2절, 교재 651쪽): 단일 극점 개루프 증폭기 $A_1(s) = \dfrac{A_0}{1 + s/\omega_0}$
- 식 (12.22) (교재 652쪽): 식 (12.2)의 $A_1$에 식 (12.19)를 대입한 폐루프 전달 함수 $\dfrac{Y}{X}(s) = \dfrac{A_0/(1 + KA_0)}{1 + \dfrac{s}{(1 + KA_0)\omega_0}}$. 폐루프 이득 $A_0/(1 + KA_0)$ (식 12.23), 폐루프 대역폭 $(1 + KA_0)\omega_0$ (식 12.24)
