# 연습문제 10.16 — 종횡비 200 이하일 때 얻을 수 있는 전압 이득 (예제 10.16 변형)

## 원문
종횡비가 200 이하로 유지되어야 한다면, 얼마의 전압 이득을 얻을 수 있는가?

## 조건
- 예제 10.16의 NMOS 차동쌍 설계에서 종횡비를 $W/L \le 200$으로 유지해야 함
- 나머지 조건과 설계 값은 예제 10.16과 같음: $I_{SS} = 1.11\ \text{mA}$, $R_D = 360\ \Omega$, $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $\lambda = 0$, $V_{DD} = 1.8\ \text{V}$ (원문에 없음)

## 구할 것
- 얻을 수 있는 전압 이득

## 상속·참조
- 예제 10.16 (E10.16): 전력 $2\ \text{mW}$, $V_{DD} = 1.8\ \text{V}$ → $I_{SS} = 1.11\ \text{mA}$ (식 10.123). 출력 CM 레벨 $\ge 1.6\ \text{V}$ → $R_D = 360\ \Omega$ (식 10.125). 이득 $|A_v| = g_m R_D$, $g_m = \sqrt{2\mu_n C_{ox}\tfrac{W}{L}\tfrac{I_{SS}}{2}}$ (식 10.126)

## 회로 — 없음 (그림 없는 글 문제)

## 풀이
### 트랜스컨덕턴스
- 설계 값 $I_{SS} = 1.11\ \text{mA}$, $R_D = 360\ \Omega$은 그대로 두고 $W/L$만 최대 200으로 둔다
- 각 트랜지스터의 $g_m = \sqrt{2\mu_n C_{ox}\dfrac{W}{L}\dfrac{I_{SS}}{2}} = \sqrt{2 \times 100\ \mu\text{A/V}^2 \times 200 \times 0.556\ \text{mA}} = 4.71\ \text{mS}$
### 전압 이득
- $|A_v| = g_m R_D = 4.71\ \text{mS} \times 360\ \Omega = 1.70$
- $g_m \propto \sqrt{W/L}$이고 $R_D$는 출력 CM 레벨 때문에 늘릴 수 없어, 이득은 약 1.7이 한계다
### 답
- 얻을 수 있는 전압 이득 $|A_v| \approx 1.70$
