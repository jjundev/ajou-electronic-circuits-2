# 예제 9.17 — 전압 이득 100, 전력 2 mW인 pnp 거울 부하 CE 단 설계

## 조건
- 회로: Fig 9.34(c) — pnp 전류 거울($Q_{REF}$, $Q_2$)을 부하로 쓰는 npn CE 단($Q_1$)
- 목표: 전압 이득 $100$, 전력 소모 $2\ \text{mW}$
- $V_{A,npn} = 5\ \text{V}$, $V_{A,pnp} = 4\ \text{V}$
- $I_{REF} = 100\ \mu\text{A}$, $V_{CC} = 2.5\ \text{V}$

## 구할 것
- 위 조건을 만족하는 Fig 9.34(c) 회로 설계

## 상속·참조
- 본문 (교재 477–478쪽): 전류원 부하로 쓰는 pnp 트랜지스터 $Q_2$의 바이어스 전류를 정하려고, Fig 9.24(c)의 npn 전류 거울과 비슷하게 Fig 9.34(c)의 pnp 전류 거울을 구성. $Q_{REF}$와 $Q_2$가 같고 베이스 전류를 무시하면 $Q_2$는 $I_{REF}$와 같은 전류를 흘림 (면적이 다르면 면적 비만큼)
- CE 단 소신호 이득: $A_v = -g_{m1} (r_{O1} \parallel r_{O2})$, $g_m = I_C/V_T$, $r_O = V_A/I_C$

## 회로 — Fig 9.34(c)
```spice
QREF  X     X    VCC  pnp
IREF  X     0
Q2    vout  X    VCC  pnp
Q1    vout  vin  0    npn
```
- 단자: VCC = 전원, 그림에는 값 없음 (가로 레일) / vin = 소신호 입력 (개방 원) / vout = 출력 (개방 원)
- 표시: 노드 라벨 VCC (레일 오른쪽 끝), X (베이스 공통선 아래, X 접속점 오른쪽), v_in (입력 원 왼쪽), v_out (출력 원 오른쪽) / 소자 라벨 Q_REF (Q_REF 왼쪽, 베이스 높이), Q2 (Q2 오른쪽), I_REF (전류원 왼쪽), Q1 (Q1 오른쪽, 이미터 옆) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 맨 위 굵은 가로 레일 VCC가 Q_REF 이미터 선보다 조금 왼쪽에서 Q2 이미터 선보다 조금 오른쪽까지 뻗음, 두 이미터 선이 매달림 / 왼쪽 Q_REF: pnp 좌우 반전(베이스 막대 오른쪽, 이미터는 막대 위쪽에서 왼쪽 위로 나가 수직으로 레일, 화살표 막대 쪽으로 들어감, 컬렉터는 막대 아래쪽에서 왼쪽 아래로 나가 수직으로 내려감) / 오른쪽 Q2: pnp 보통 방향(베이스 왼쪽, 이미터 오른쪽 위로 레일, 컬렉터 오른쪽 아래) / 베이스 공통선: 베이스 높이 가로선이 Q_REF 베이스에서 X 접속점을 지나 Q2 베이스까지 한 직선 / 다이오드 연결: Q_REF 컬렉터 아래 접속점에서 가로선이 오른쪽으로 가다 위로 꺾여 X 접속점 / 왼쪽 세로줄: 컬렉터 접속점 아래로 I_REF 전류원(화살표 아래), 그 아래 접지 / 오른쪽 세로줄: Q2 컬렉터 → vout 접속점 → Q1 컬렉터, Q1 이미터 아래 접지 (I_REF 접지와 같은 높이), 접속점에서 가로선이 오른쪽 v_out 원 / Q1 npn 보통 방향, v_in 원 → 가로선 → 베이스 (v_in 원은 Q_REF 세로줄과 Q2 세로줄 사이) / 접속점 (세 갈래 이상, 3곳): ① X = 왼쪽 Q_REF 베이스 + 오른쪽 Q2 베이스로 가는 선 + 아래 다이오드 연결 선 (점) ② Q_REF 컬렉터 = 위 Q_REF 컬렉터 + 아래 I_REF + 오른쪽 다이오드 연결 선 (점) ③ vout = 위 Q2 컬렉터 + 아래 Q1 컬렉터 + 오른쪽 v_out 선 (점) / 교차: 없음

## 답 (검증용)
- $2\ \text{mW} / 2.5\ \text{V} = 800\ \mu\text{A}$ 중 $100\ \mu\text{A}$는 $I_{REF}$와 $Q_{REF}$ 가지, $Q_1$과 $Q_2$는 $700\ \mu\text{A}$ → $Q_2$의 이미터 면적 = $Q_{REF}$의 7배 (원문 예시: "$Q_{REF}$는 단위 소자 1개, $Q_1$ 단위 소자 7개를 결합" — 문맥상 $Q_2$ 쪽 7개로 보임) (원문에 없음)
- $A_v = -g_{m1}(r_{O1} \parallel r_{O2}) = -\dfrac{1}{V_T} \cdot \dfrac{V_{A,npn} V_{A,pnp}}{V_{A,npn} + V_{A,pnp}} = -85.5$ (식 9.118–9.120) → 이득은 바이어스 전류와 무관하게 얼리 전압과 $V_T$로 정해지므로 이 얼리 전압으로는 100 불가능
