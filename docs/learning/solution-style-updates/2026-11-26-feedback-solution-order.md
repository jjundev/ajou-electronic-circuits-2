## 기존 자료 탐색 및 적용

0909~1125의 문제설명 HTML 19개와 184문항을 탐색했다. 감지·반송, 복제, 테브난, 다단 전달비를 단서로 찾아 실제 회로와 원문 요구를 대조했다.

| 해설 | 적용 단계 |
|---|---|
| 1118 P1 | 큰 $R_F$ 근사를 유지하면서 (b)의 목표 곱을 각 이득 앞에 두고, (c)에서 입력 전류원을 개방한 귀환 가지와 $i_F$ 기준을 식 앞에 표시했다. |
| 1120 P5 | 두 CS 단의 출력 부하와 목표 전압이득 곱을 앞으로 옮기고, 반송 전압을 구할 때의 개방 조건을 명시했다. |
| 1120 P7–P9 | 개루프 저항, 테브난 전압과 목표 곱, 부호가 있는 각 항, 귀환율 시험 순서를 적용했다. P8은 PMOS 공통 소스, P9는 소스 팔로워의 정궤환과 원문 소문항 순서를 따랐다. P7에는 귀환 시험 가지를 그렸다. |
| 1120 P10·P11 | P10은 단일 CE에서 두 포트 저항을 재사용한다. P11은 유한 $r_o$와 분배망의 두 종단, $i_F$의 방향을 포함한다. |
| 1125 P3·P5 | P3은 레이저 두 단자의 직렬 출력저항과 $T_0$를 유지한다. P5는 출력 전압을 감지할 때의 접지 기준 병렬 부하와 $I_F$의 방향을 연결했다. |

1111·1113의 블록 루프/극성 문항, 1120의 실제 출력 단락 $G_m$ 경로, 1125 P4의 지정 노턴 변환은 각 문항 요구에 맞게 읽었다. 1014 P8의 두 CS 전달함수는 이미 목표 곱으로 시작한다. 0923 P2는 동일 전원에서 두 출력으로 갈라지는 병렬 경로이므로 두 전달비의 차를 취한다.
