# 장말문제 10.55 — 두 캐스코드 노드 사이에 기생 저항 R_P가 생긴 바이폴라 캐스코드 차동쌍(Fig 10.80)의 전압 이득

## 원문
Due to a manufacturing error, a parasitic resistance, $R_P$, has appeared in the circuit of Fig. 10.80. Calculate the voltage gain.

## 조건
- 회로: Fig 10.80 — 바이폴라 캐스코드 차동쌍
- 제조 오류로 기생 저항 $R_P$가 회로에 생김 ($Q_3$ 이미터–$Q_1$ 컬렉터 노드와 $Q_4$ 이미터–$Q_2$ 컬렉터 노드 사이)

## 구할 것
- 전압 이득

## 회로 — Fig 10.80
```spice
I1   VCC   out1                ; 전류원, 라벨·값 없음
I2   VCC   out2                ; 전류원, 라벨·값 없음
Q3   out1  Vb    n1    npn
Q4   out2  Vb    n2    npn     ; 베이스는 Q3 베이스 높이의 가로선에서 옴
RP   n1    n2    {R_P}
Q1   n1    Vin1  n3    npn
Q2   n2    Vin2  n3    npn     ; 좌우 반전 (베이스 오른쪽)
IEE  n3    0     {I_EE}
* Vb 점 단자 → Q3 베이스. 같은 높이의 가로선이 Q3 기호(컬렉터·이미터 선 사이)를 가로질러 Q4 베이스까지 이어짐 → Q3·Q4 베이스 공통(Vb)
* n1 = Q3 이미터–Q1 컬렉터, n2 = Q4 이미터–Q2 컬렉터, n3 = 공통 이미터(테일) 노드 (라벨 없음)
* out1, out2 = 두 출력 점에서 안쪽으로 이어진 개방 원. 두 원 사이에 "V_out" 라벨 하나 (차동 출력)
```
- 단자: VCC = 전원, 값 미지정 (가로 레일) / Vb = 바이어스, 값 미지정 (점 단자) / Vin1, Vin2 = 입력 (개방 원) / out1, out2 = 차동 출력 V_out (개방 원 두 개, 각 원 옆 라벨 없음)
- 표시: 노드 라벨 V_CC (레일 오른쪽 끝), V_b (점 단자 왼쪽), V_out (두 출력 원 사이), V_in1 (왼쪽 입력 원 왼쪽), V_in2 (오른쪽 입력 원 오른쪽) / 소자 라벨 Q3 (Q3 왼쪽 위), Q4 (Q4 왼쪽 위), R_P (가로 저항 위), Q1 (Q1 오른쪽), Q2 (Q2 왼쪽), I_EE (전류원 오른쪽), 위 전류원 둘 I1, I2 (라벨 없음) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 맨 위 굵은 가로 레일 V_CC / 왼쪽 세로줄 위→아래 전류원(화살표 아래), 출력 점, Q3, n1 점, Q1 / 오른쪽 세로줄 위→아래 전류원(화살표 아래), 출력 점, Q4, n2 점, Q2 / 각 출력 점에서 짧은 가로선이 안쪽으로 개방 원 (사이에 V_out 라벨) / Q3, Q4 npn 둘 다 보통 방향(베이스 왼쪽) / V_b 점 단자 → Q3 베이스, 같은 높이 가로선이 Q3 기호를 가로질러 Q4 베이스 / n1 점과 n2 점 사이 가로 저항 R_P / Q1 npn 보통 방향(베이스 왼쪽), Q2 npn 좌우 반전(베이스 오른쪽) / V_in1 원 → Q1 베이스, V_in2 원 → Q2 베이스 / 두 이미터는 꼬리 가로선 가운데 n3 점, n3에서 아래로 I_EE(화살표 아래), 그 아래 접지 / 접속점 (세 갈래 이상, 5곳): ① 왼쪽 출력 점 = 위 전류원 + 아래 Q3 컬렉터 + 오른쪽 출력선 (점) ② 오른쪽 출력 점 = 위 전류원 + 아래 Q4 컬렉터 + 왼쪽 출력선 (점) ③ n1 = 위 Q3 이미터 + 아래 Q1 컬렉터 + 오른쪽 R_P (점) ④ n2 = 위 Q4 이미터 + 아래 Q2 컬렉터 + 왼쪽 R_P (점) ⑤ n3 = 왼쪽 Q1 이미터 선 + 오른쪽 Q2 이미터 선 + 아래 I_EE (점) / 교차: 없음 (베이스 가로선은 Q3 기호를 지나지만 도선과 교차하지 않음)
