# 장말문제 11.26 — C_μ와 C_GD를 무시하지 않은 f_T 유도

## 원문
In arriving at Eq. (11.52) for the $f_T$ of transistors, we neglected $C_\mu$ and $C_{GD}$. Repeat the derivation without this approximation.

## 조건
- 식 (11.52)의 트랜지스터 $f_T$를 유도할 때 $C_\mu$와 $C_{GD}$를 무시했음

## 구할 것
- 이 근사 없이($C_\mu$, $C_{GD}$를 포함해) 유도를 다시 함

## 상속·참조
- 11.2.3절 (교재 595–596쪽) $f_T$ 정의: 소자의 소신호 전류 이득이 1로 떨어지는 주파수. 본문 Fig 11.29 (교재 595쪽, 크롭 안 함)의 개념적 구성: 베이스(게이트)에 전류원 $I_{in}$(아래 끝 접지, 화살표 위)으로 사인파 전류를 주입하고, 컬렉터(드레인)는 ac GND에 연결해 그 선에 흐르는 $I_{out}$(ac GND → 컬렉터 방향)을 측정. 베이스–접지 전압 $V_{in}$, 입력 쪽에서 들여다본 $C_{in}$, 이미터(소스) 접지. 왼쪽이 바이폴라 $Q_1$(본문은 "그림 11.29(a)"로 부름), 오른쪽이 MOS $M_1$로 같은 구성 (그림에 패널 글자는 인쇄되지 않음)
- 유도 과정 ($C_\mu$, $C_{GD}$ 무시): $Z_{in} = \dfrac{1}{C_\pi s} \parallel r_\pi$ (식 11.46), $I_{out} = g_m I_{in} Z_{in}$이므로 $\dfrac{I_{out}}{I_{in}} = \dfrac{g_m r_\pi}{r_\pi C_\pi s + 1} = \dfrac{\beta}{r_\pi C_\pi s + 1}$ (식 11.47, 11.48). 트랜싯 주파수 $\omega_T (= 2\pi f_T)$에서 전류 이득의 크기가 1로 떨어지므로 $r_\pi^2 C_\pi^2 \omega_T^2 = \beta^2 - 1 \approx \beta^2$ (식 11.49, 11.50), 즉 $\omega_T \approx \dfrac{g_m}{C_\pi}$ (식 11.51)
- 식 (11.52): $2\pi f_T \approx \dfrac{g_m}{C_\pi}$ 또는 $\dfrac{g_m}{C_{GS}}$. 컬렉터–기판, 드레인–벌크 커패시턴스는 출력이 교류 접지이므로 $f_T$에 영향을 주지 않음

## 회로 — 없음 (식 유도 문제, 그림 없음)

## 힌트
### $C_\mu$의 컬렉터 쪽 끝은 AC 접지
- $f_T$를 잴 때 컬렉터(드레인)를 AC 접지에 묶으므로, $C_\mu$($C_{GD}$)는 밀러 배수 없이 베이스에서 접지로 가는 커패시터가 되어 $C_\pi$($C_{GS}$)와 병렬이다
- 출력 전류에서는 $C_\mu$를 거쳐 입력 쪽에서 오는 전류가 $g_m v_\pi$에서 빠지므로 이 항도 함께 적는다. 버리려면 $C_\mu \ll C_\pi$라는 근사가 따로 필요하다

## 풀이
### 측정 회로에서 $C_\mu$의 자리
- $f_T$는 베이스에 전류 $I_{in}$을 넣고 컬렉터를 AC 접지에 묶어 컬렉터 전류 $I_{out}$을 잴 때 $|I_{out}/I_{in}| = 1$이 되는 주파수다
- 컬렉터가 AC 접지이므로 $C_\mu$는 밀러 배수 없이 베이스–접지 커패시터가 되어 $C_\pi$와 병렬이다
- 베이스 전압 $V_\pi = I_{in}\left[r_\pi \parallel \dfrac{1}{(C_\pi + C_\mu)s}\right] = \dfrac{I_{in}r_\pi}{1 + r_\pi(C_\pi + C_\mu)s}$
### 출력 전류
- 컬렉터 노드에서 종속 전원 $g_m V_\pi$ 가운데 $C_\mu$를 거쳐 베이스에서 오는 $C_\mu s V_\pi$만큼은 AC 접지에서 오지 않는다
- $\dfrac{I_{out}}{I_{in}} = \dfrac{(g_m - C_\mu s)\,r_\pi}{1 + r_\pi(C_\pi + C_\mu)s}$
### 크기가 1인 주파수
- $\omega_T = 2\pi f_T$에서 $|I_{out}/I_{in}|^2 = 1$: $r_\pi^2(g_m^2 + \omega_T^2 C_\mu^2) = 1 + \omega_T^2 r_\pi^2(C_\pi + C_\mu)^2$
- $\omega_T^2 r_\pi^2[(C_\pi + C_\mu)^2 - C_\mu^2] = \beta^2 - 1$ ($\beta = g_m r_\pi$) → $\omega_T^2 = \dfrac{\beta^2 - 1}{r_\pi^2 C_\pi(C_\pi + 2C_\mu)}$
- $\beta^2 \gg 1$이면 $\omega_T \approx \dfrac{g_m}{\sqrt{C_\pi(C_\pi + 2C_\mu)}}$. $C_\mu \ll C_\pi$이면 $\approx g_m/(C_\pi + C_\mu)$
### MOSFET
- $r_\pi \to \infty$, $C_\pi \to C_{GS}$, $C_\mu \to C_{GD}$: $g_m^2 + \omega_T^2 C_{GD}^2 = \omega_T^2(C_{GS} + C_{GD})^2$ → $\omega_T = \dfrac{g_m}{\sqrt{C_{GS}(C_{GS} + 2C_{GD})}}$ (근사 없음)
### 답
- 바이폴라: $2\pi f_T = \sqrt{\dfrac{\beta^2 - 1}{r_\pi^2 C_\pi(C_\pi + 2C_\mu)}} \approx \dfrac{g_m}{\sqrt{C_\pi(C_\pi + 2C_\mu)}}$
- MOSFET: $2\pi f_T = \dfrac{g_m}{\sqrt{C_{GS}(C_{GS} + 2C_{GD})}}$. $C_\mu$, $C_{GD}$가 작으면 둘 다 $g_m/(C_\pi + C_\mu)$, $g_m/(C_{GS} + C_{GD})$로 줄어든다.
