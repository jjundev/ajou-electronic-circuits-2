# RC 두 단 로딩과 극점 분리

- 저장 파일명: `인터렉티브_02_RC_두_단_로딩과_극점_분리`
- 아키타입: `approx` · 점수 6 (값→극점·크기 +2, 로딩 포함/제외 비교로 "두 극점이 정확히 겹친다" 오개념 해소 +2, 두 단의 곱 근사 vs 정확식 붕괴 조건 +2)

## 기존 위젯과의 관계
- 관련 절 `s0-selectivity-order`에는 위젯이 없음(그림 fig-s0-order-bode, fig-circuit-s0-rc-two-pole 정적). 이웃 위젯 없음 → 처리 해당 없음.

## 모드·조작
- 모드: `cascade` (강의노트 s7 오른쪽 RC 두 단)
- params: k = 2단 임피던스 배율 0.1–100(log), R2=kR1, C2=C1/k (R2C2=R1C1 유지, 단독 극점은 늘 겹침) / 측정점 ωR1C1 0.01–100(log). 기준 R1=1 kΩ, C1=1 nF (ω0=10⁶ rad/s)
- elems: `buf` 이상적 버퍼 ×1 (기본 제외 = 수업 회로). (교과서 보충)
- presets: 수업 가정 k=1 / 버퍼로 분리 / 가벼운 2단 k=10 / 무거운 2단 k=0.1
- steps 5개: 수업 가정 → 실제 분리(0.38·2.62, 1/3) → k=10에서 약 5% → 버퍼 → ωRC=100에서 −40 dB/dec 일치
- plotData: 실선 회로 계산(MNA), 점선 1/((1+jx)²) 두 1차 단의 곱, errPct = (근사−실제)/실제, threshold 10%

## 예측
- 버퍼 없이 R1=R2, C1=C2, ω=1/(R1C1)에서 실제 |H|는 근사 1/2와 비교해? 답: 작아요(1/3). 검증 after k=1, x=1, buf 제외, 타일 exact·approx.

## 오개념 (3개)
- 같은 RC 두 단이면 극점이 정확히 겹친다 / 로딩 때문에 2차가 아니게 된다 / RC만으로 복소 극점을 만들 수 있다

## 모델·근거
- N(s) = (1+sR1C1)(1+sR2C2) + sR1C2, 정규화 N = 1 + (2+1/k)(sτ) + (sτ)², τ=R1C1. k=1에서 p = (3∓√5)/2 = 0.382, 2.618. 판별식 > 0.
- 근거: 정리노트 s0-selectivity-order "두 RC 단의 극점은 어디에 있나요"(로딩 유도), STT 1127 506–510행(수업은 R1=R2, C1=C2이면 같은 위치 극점 두 개라고 설명, "이게 좀 이상한 게"). 버퍼로 단을 분리하는 것은 수업에서 다루지 않아 (교과서 보충) 표시.
- 이상적 버퍼는 MNA에서 gm=10⁶ S VCCS + Rb=1 µΩ (전압 이득 1, 출력 저항 1 µΩ)로 근사.
