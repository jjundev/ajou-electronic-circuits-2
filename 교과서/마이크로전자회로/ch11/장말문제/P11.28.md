# 장말문제 11.28 — C_GS ≈ (2/3)WLC_ox로 MOSFET f_T 식(11.183) 증명

## 원문
It can be shown that $C_{GS} \approx (2/3) W L C_{ox}$ for a MOSFET operating in saturation. Using Eq. (11.52), prove that

$$2\pi f_T = \frac{3}{2}\frac{\mu_n}{L^2}(V_{GS} - V_{TH}). \qquad (11.183)$$

Note that $f_T$ increases with the overdrive voltage.

## 조건
- 포화 영역에서 동작하는 MOSFET은 $C_{GS} \approx (2/3) W L C_{ox}$임을 보일 수 있음
- $f_T$가 과구동 전압에 따라 증가함에 유의 (원문의 메모)

## 구할 것
- 식 (11.52)를 이용해 다음을 증명:
$$2\pi f_T = \frac{3}{2}\frac{\mu_n}{L^2}(V_{GS} - V_{TH}) \quad (11.183)$$

## 상속·참조
- 식 (11.52) (교재 596쪽): $2\pi f_T \approx \dfrac{g_m}{C_\pi}$ 또는 $\dfrac{g_m}{C_{GS}}$ — 소신호 전류 이득이 1로 떨어지는 주파수(트랜싯 주파수)

## 회로 — 없음 (식 증명 문제, 그림 없음)

## 풀이
### 포화 영역의 $g_m$
- $g_m = \mu_n C_{ox}\dfrac{W}{L}(V_{GS} - V_{TH})$ (제곱 법칙 $I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$을 $V_{GS}$로 미분)
### 식 (11.52)에 대입
- $2\pi f_T \approx \dfrac{g_m}{C_{GS}} = \dfrac{\mu_n C_{ox}(W/L)(V_{GS} - V_{TH})}{(2/3)WLC_{ox}}$
- $C_{ox}$와 $W$가 약분되고 $L$이 두 번 남는다: $2\pi f_T = \dfrac{3}{2}\dfrac{\mu_n}{L^2}(V_{GS} - V_{TH})$
### 답
- $2\pi f_T = \dfrac{g_m}{C_{GS}} = \dfrac{\mu_n C_{ox}(W/L)(V_{GS} - V_{TH})}{(2/3)WLC_{ox}} = \dfrac{3}{2}\dfrac{\mu_n}{L^2}(V_{GS} - V_{TH})$이므로 식 (11.183)이 성립한다. $W$와 $I_D$가 사라져 $L$이 정해지면 $f_T$는 과구동 전압에 비례한다.
