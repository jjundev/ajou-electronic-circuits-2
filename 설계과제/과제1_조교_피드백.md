# 설계과제 1 조교 피드백

## 1. 감점 항목

- [10점 감점] simulation part에서 DC simulation은 LTspice 화면을 그대로 캡처했으면서, TR과 AC simulation 결과는 시뮬레이터 화면이 아니라 별도로 다시 그린 그래프(python plot)로만 제시함. 이 그래프로는 실제 시뮬레이션 결과임을 증명할 수 없으므로 TR 파형, 출력 302.5 mV p-p, 이득 151.2 모두 완전히 인정할 수 없음 (증거 없음) 원칙적으로는 TR, AC 결과와 이를 근거로 한 이득 비교 전체를 인정하지 않고 해당 항목을 0점 처리하는 것이 맞으나, 이번에 한해 TR 파형과 이득 비교 항목에서 각 5점만 감점하였음. 다음 과제부터는 모든 simulation 결과를 LTspice 또는 PSpice 화면 그대로(cursor, .meas 결과 포함) 캡처하여 첨부하지 않으면 해당 결과를 인정하지 않음
