# Native 독립 리뷰와 수정

리뷰어: gpt-6-astra, 읽기 전용. Critical 0, Important 1, Minor 0.

## Important 지적
부호가 붙은 괄호 분모를 분수 보호 구간에 포함해야 한다.
재현: `출력 전류는 (I₀ + ΔI + I₁) / −(I₀ − ΔI + I₂)입니다.`
기존 결과는 `/ −(...)` 앞에서 분수를 나눴다. 분수와 붙은 서술어가 36자이므로 기본 34자 제한에서는 저작 오류를 반환해야 한다.

## 수정
단항 부호 흡수를 bare atom뿐 아니라 모든 괄호 그룹에도 적용한 뒤 분수를 결합한다. `−(...)`, `-(...)`, 부호 뒤 공백이 있는 두 경우 모두 오류를 반환하고, 짧은 분수는 설명 다음 줄에서 통째로 유지한다.
`test_signed_group_denominator_is_protected`: RED 4개 부호 변형 실패 → GREEN. 관련 38개 테스트 통과. 수정 후 전체 250개 테스트 중 248개 통과, 2개 선택 실행 제외. 현재 영상의 12개 기술·화면 검증을 다시 실행해 모두 통과했다. 음성 의미 청취만 unverified이며 complete=false를 유지한다. 추가 리뷰어는 사용하지 않는다.

## 독립 확인
리뷰어가 관련 25개 테스트(libass 포함), 66개 WAV/보존 파일 해시, 현재 보고서 지문과 대표 cue25 화면을 직접 확인했다. 기대 SRT 대조와 기존 화면 검사 연결을 확인했다. 실제 음성 미청취 및 complete=false 유지가 적절하다고 판단했다.

## 판단하지 않은 항목
실제 음성 청취, 전체 프레임의 교육적 정확성, 모든 역사적 기능의 독립 재인증, 전체 suite의 독립 재실행은 수행하지 않았다. 실행자는 그대로인 음성/원본 master/시각 입력 보존 증거와 전체 회귀·기술 검증으로 해당 범위를 구분한다. 기존 음성 의미 unverified를 유지한다.
