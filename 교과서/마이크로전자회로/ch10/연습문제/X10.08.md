# 연습문제 10.8 — 테일 전류의 90%를 조종하는 차동 입력 (예제 10.8 변형)

## 조건
- 예제 10.8의 바이폴라 차동쌍(본문 Fig 10.14)에서 트랜지스터 하나가 테일 전류의 90%를 조종함 (예제는 98%)

## 구할 것
- 테일 전류의 90%를 조종하는 데 필요한 차동 입력 $V_{in1} - V_{in2}$

## 상속·참조
- 예제 10.8 (E10.08): $Q_2$가 98%를 흘릴 때 $I_{C1} = 0.02 I_{EE} \approx I_{EE}\exp\dfrac{V_{in1} - V_{in2}}{V_T}$로 놓아 $V_{in1} - V_{in2} \approx -3.91 V_T$를 얻음 (가정: $\alpha = 1$, $V_A = \infty$. $I_{S1} = I_{S2}$는 식 (10.59)→(10.60)에서 말없이 쓰임, 원문에 없음)
- 본문 Fig 10.14 (교재 514쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-14.png): $V_{CC}$ 레일, 두 $R_C$, $Q_1$(베이스 $V_{in1}$), $Q_2$(베이스 $V_{in2}$), 공통 이미터 노드 $P$와 테일 전류원 $I_{EE}$. 연결: `RC(왼쪽): VCC – Vout1`, `RC(오른쪽): VCC – Vout2`, `Q1: C = Vout1, B = Vin1, E = P`, `Q2: C = Vout2, B = Vin2, E = P`, `I_EE: P → 접지`
- 식 (10.63), (10.65): $I_{C2} = \dfrac{I_{EE}}{1 + \exp\dfrac{V_{in1} - V_{in2}}{V_T}}$, $I_{C1} = \dfrac{I_{EE}\exp\dfrac{V_{in1} - V_{in2}}{V_T}}{1 + \exp\dfrac{V_{in1} - V_{in2}}{V_T}}$
