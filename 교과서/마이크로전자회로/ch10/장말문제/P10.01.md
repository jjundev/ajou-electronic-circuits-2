# 장말문제 10.1 — 정류기 전원 CE 단에서 V_CC → V_out 소신호 이득 (리플 영향)

## 조건
- 회로: Fig 10.1의 회로 (정류기로 전원을 공급받는 CE 단, 패널 (a)) (패널은 원문에 없음, 원문은 "Fig. 10.1"만 적음)
- 출력의 리플 영향을 계산하기 위해 $V_{CC}$를 소신호 "입력"으로 볼 수 있음
- $V_A < \infty$ (Early 효과 고려) (괄호 안은 원문에 없음)
- 소자 값은 주어지지 않음 (답은 기호로) (원문에 없음)

## 구할 것
- $V_{CC}$에서 $V_{out}$까지의 (소신호) 이득

## 회로 — Fig 10.1(a)
```spice
* n1(+), n2(-): "110 V 60 Hz" 교류 선로가 걸리는 입력 단자 (그림은 개방 원 두 개, 전원 기호 없음)
LP    n1    n2                         ; 변압기 1차 코일 (라벨·값 없음)
LS    n3    n4                         ; 변압기 2차 코일 (라벨·값 없음)
* LP와 LS는 자기 결합된 변압기 한 개 (그림은 코일 두 개를 나란히 그림). 결합은 SPICE K 문 대신 주석으로 적음 (원문에 없음)
* XBR 노드 순서: 위 꼭짓점, 아래 꼭짓점(교류 입력), 오른쪽 꼭짓점(+ 출력), 왼쪽 꼭짓점(- 출력)
XBR   n3    n4    VCC  0  box "정류 브리지"   ; 그림은 다이아몬드 안에 다이오드 기호 하나, 글자 없음. 상자 라벨은 원문에 없음
C1    VCC   0     {C_1}
XMIC  n5    0     box "마이크"               ; 그림은 D자 모양 마이크 기호, 글자 없음. 상자 라벨은 원문에 없음
CC    n5    n6                               ; 결합 커패시터 (라벨·값 없음)
RC    VCC   Vout  {R_C}
Q1    Vout  n6    0  npn
* 노드 0 = 그림 아래쪽 공통 귀환선. 그림에 접지 기호 없음 (기준 노드로 적은 것은 원문에 없음)
```
- 단자: n1, n2 = 교류 선로 입력 110 V 60 Hz, n1 쪽 +, n2 쪽 − (개방 원 두 개) / VCC = 정류기 출력이자 CE 단 전원, 값 미지정 (T 전원 기호, 정류기 쪽 도선이 T 막대 왼쪽 끝에 닿음) / n6 = Q1 베이스 노드, 바이어스 회로로 가는 "To Bias" 연결 (선 끝, 끝에 위쪽 화살촉) / Vout = 출력 (개방 원)
- 표시: 노드 라벨 VCC (T 막대 오른쪽), V_out (출력 원 오른쪽) / 소자 라벨 C1 (커패시터 오른쪽), R_C (저항 오른쪽), Q1 (Q1 오른쪽, 이미터 옆), 변압기 코일·정류 브리지·마이크·결합 커패시터 (라벨 없음) / 부호 + (위 입력 원 바로 아래), − (아래 입력 원 바로 위) / 화살표 "To Bias": n6 접속점에서 위로 뻗은 짧은 도선, 위 방향, 도선 위 (도선 끝에 화살촉, 글자는 화살표 왼쪽 위) / 수치·면적 라벨 "110 V", "60 Hz" (두 줄, 입력 원 두 개 왼쪽)
- 배치: 왼쪽→오른쪽 순서로 입력 원 두 개, 1차 코일(세로), 2차 코일(세로), 다이아몬드 정류 브리지, C1(세로), 마이크·결합 커패시터·Q1 / 위 입력 원 → 가로선 → 1차 코일 위 끝, 1차 코일 아래 끝 → 가로선 → 아래 입력 원 / 2차 코일 위 끝은 위로 올라가 오른쪽으로 꺾여 다이아몬드 위 꼭짓점, 2차 코일 아래 끝은 내려가 가로선으로 다이아몬드 아래 꼭짓점 / 다이아몬드 안 다이오드 기호는 가로 방향, 화살표가 오른쪽(오른쪽 꼭짓점 쪽)을 향함 / 오른쪽 꼭짓점 → 가로선 → C1 위 접속점, 여기서 세로선이 위로 올라가 맨 위 가로선이 되어 오른쪽 VCC T 막대까지 / 왼쪽 꼭짓점 → 왼쪽으로 조금 → 아래로 꺾여 맨 아래 공통 귀환선의 왼쪽 끝 / 공통 귀환선은 C1 아래 접속점, 마이크 아래 도선, Q1 이미터를 지나 Q1 이미터보다 조금 오른쪽까지 뻗음 / R_C는 VCC T 막대에서 세로로 내려와 Vout 접속점, 여기서 오른쪽으로 Vout 원, 아래로 Q1 컬렉터 / Q1 npn 보통 방향(베이스 왼쪽, 이미터 오른쪽 아래 → 공통 귀환선) / 마이크(D자, 평평한 쪽 왼쪽)는 오른쪽에 위·아래 두 짧은 가로 인출선(서로 떨어짐). 위 인출선 → 위로 → 오른쪽 결합 커패시터(가로 방향), 아래 인출선 → 아래로 → 공통 귀환선 / 결합 커패시터 오른쪽 → n6 접속점 → 오른쪽 Q1 베이스 / 접속점 (세 갈래 이상): ① C1 위 = 왼쪽 브리지 출력선 + 아래 C1 + 위 VCC 쪽 선 (점) ② C1 아래 = 왼쪽 귀환선 + 위 C1 + 오른쪽 귀환선 (점) ③ n6 = 왼쪽 결합 커패시터 + 오른쪽 Q1 베이스 + 위 To Bias 화살표 선 (점) ④ Vout = 위 R_C + 아래 Q1 컬렉터 + 오른쪽 Vout 선 (점) ⑤ 마이크 아래 도선이 귀환선에 닿는 곳, 왼쪽 + 오른쪽 + 위 (점 없음) ⑥ Q1 이미터가 귀환선에 닿는 곳, 왼쪽 귀환선 + 오른쪽 짧은 끝 + 위 이미터 (점 없음) / 교차: 다이아몬드 왼쪽 꼭짓점에서 내려오는 세로선이 2차 코일 아래 끝 → 다이아몬드 아래 꼭짓점 가로선과 점 없이 교차 (1곳)
