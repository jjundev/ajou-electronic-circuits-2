Vov = sqrt(I_SS)*sqrt(L)/(sqrt(C_ox)*sqrt(W)*sqrt(mu)) ; V_P = V_CM - V_TH - sqrt(I_SS)*sqrt(L)/(sqrt(C_ox)*sqrt(W)*sqrt(mu))
(a) W->2W : dV_P = sqrt(I_SS)*sqrt(L)*(2 - sqrt(2))/(2*sqrt(C_ox)*sqrt(W)*sqrt(mu)) = Vov*(1-1/sqrt2): 0
(b) Iss->2Iss: dV_P = sqrt(I_SS)*sqrt(L)*(1 - sqrt(2))/(sqrt(C_ox)*sqrt(W)*sqrt(mu)) = -(sqrt2-1)Vov: 0
(c) tox->2tox (Cox->Cox/2): dV_P = sqrt(I_SS)*sqrt(L)*(1 - sqrt(2))/(sqrt(C_ox)*sqrt(W)*sqrt(mu)) = -(sqrt2-1)Vov: 0
signs: a>0 rises, b<0 falls, c<0 falls (V_TH held fixed; a thicker oxide also raises |V_TH| which lowers V_P further)
