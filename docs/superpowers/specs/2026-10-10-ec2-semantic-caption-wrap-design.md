# 의미 단위 자막 줄바꿈 설계

## 의도와 범위
전자회로2 문제풀이 영상에서 설명과 수식을 자연스럽게 나눈다. 기존 wrap_caption의 길이 균형 기준을 보강하는 bounded 작업이다. ec2-solution-video만 수정한다.

## 확정 동작
- 짧은 자막은 한 줄로 유지한다. 최대 두 줄, 줄당 34자, 현재 글자 크기를 유지한다.
- 수식 전체가 한 줄에 들어가면 설명과 수식 사이에서 나눈다.
- 중첩 괄호 안, 식별자·첨자, 소수, 분수 내부는 나누지 않는다.
- 긴 수식은 괄호 밖 관계식·연산 경계에서만 나눈다. 연산자는 다음 항과 같은 줄에 둔다.
- 후보 우선순위는 설명/수식 경계, 일반 문장 공백, 수식 밖 연산 경계다. 같은 우선순위에서만 길이 균형을 비교한다.
- 안전한 두 줄을 만들 수 없으면 청크를 지정한 InputError를 반환한다. 자동 축약·글자 크기 축소·cue 분할은 하지 않는다.
- 원문 기호와 공백 연결 결과를 보존한다. 기존 문장/쉼표 cue 규칙은 유지한다.
- 실제 PCM 청크 시작/종료 시간, 음성, 회로 필기, 영상 길이를 유지한다.

## 대표 사례
입력: `저항으로 흐르는 전류는 (I₀ + ΔI) − (I₀ − ΔI)입니다.`
출력:
```
저항으로 흐르는 전류는
(I₀ + ΔI) − (I₀ − ΔI)입니다.
```

## 구현 경계
완전한 한국어 문법 해석기를 도입하지 않는다. 명확한 수식 구간과 보수적인 공백 규칙을 사용한다. 기존 wrap_caption / chunk_caption / write_srt 인터페이스를 유지한다. libass 실제 출력에서 명시 줄바꿈이 유지되는지 검증한다. 스킬과 참조 문서를 코드와 함께 수정한다.

## 재생성과 제한
현재 circuit-ink 실행을 보존하고 별도 실행 사본의 기존 master.mp4에 새 SRT를 입힌다. WAV 66개와 narration.wav, manifest, timeline, master, 회로 필기 파일의 SHA256 및 7220프레임을 비교한다. 유료 TTS 요청은 0이다. 캐시 지문을 무조건 갱신하지 않는다. 현재 증거에 맞춰 검증을 재실행한다. 실제 음성 의미 검토의 unverified 상태를 임의로 passed로 바꾸지 않는다. 게시, latest 변경, 커밋, 푸시는 별도 요청 전 하지 않는다.

## 승인 상태
grill-yourself에서 제시한 8개 추천 결정을 기준으로 계획을 작성했다. 사용자가 “좋아. Native로 진행해.”로 승인한 범위를 구현한다.
