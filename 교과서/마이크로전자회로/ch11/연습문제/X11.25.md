# 연습문제 11.25 — M2의 폭과 커패시턴스가 2배인 캐스코드 (예제 11.25 변형)

## 원문
$M_2$의 폭과 그러므로 모든 커패시턴스가 2배인 경우 위의 예제를 반복하라. $g_{m2} = (100\ \Omega)^{-1}$로 가정한다.

## 조건
- 예제 11.25의 캐스코드 (예제 11.18의 CS 단을 캐스코드로 바꾼 것, $C_{DB} = C_{SB}$)
- 변경: $M_2$의 폭과 그러므로 $M_2$의 모든 커패시턴스가 2배
- $g_{m2} = (100\ \Omega)^{-1}$
- $M_1$은 예제 11.18의 값 그대로라고 봄 (원문에 없음)

## 구할 것
- 예제 11.25 반복: 극점 예측, 주파수 응답 그리기, 예제 11.18과 결과 비교

## 상속·참조
- 예제 11.18 (E11.18)의 값: $R_S = 200\ \Omega$, $C_{GS} = 250\ \text{fF}$, $C_{GD} = 80\ \text{fF}$, $C_{DB} = 100\ \text{fF}$, $g_m = (150\ \Omega)^{-1}$, $\lambda = 0$, $R_L = 2\ \text{k}\Omega$ (Fig 11.31(a) CS 단의 $R_D$ 자리). 예제 11.18의 CS 단 결과: 저주파수 이득 $g_m R_L = 13.3$ ($22\ \text{dB}$), 밀러 근사 $|\omega_{p,in}| = 2\pi \times (571\ \text{MHz})$, $|\omega_{p,out}| = 2\pi \times (428\ \text{MHz})$, 정확한 전달 함수 $|\omega_{p1}| = 2\pi \times (264\ \text{MHz})$, $|\omega_{p2}| = 2\pi \times (4.53\ \text{GHz})$, −3 dB 대역폭 약 $250\ \text{MHz}$
- 예제 11.25 (E11.25): 두 트랜지스터 동일, $C_{DB} = C_{SB}$에서 $|\omega_{p,X}| = 2\pi \times (1.95\ \text{GHz})$, $|\omega_{p,Y}| = 2\pi \times (1.73\ \text{GHz})$, $|\omega_{p,out}| = 2\pi \times (442\ \text{MHz})$
- 본문 Fig 11.52 (교재 621쪽, 크롭 안 함) 밀러 근사 후 트랜지스터 커패시턴스를 포함한 MOS 캐스코드: $V_{DD}$–$R_L$–$V_{out}$, $M_2$ 드레인 $V_{out}$, 게이트 $V_b$ (점 단자), 소스 노드 $Y$ = $M_1$ 드레인, $M_1$ 소스 접지, $V_{in}$–$R_S$–게이트 노드 $X$. $V_{out}$–접지 $C_{GD2} + C_{DB2}$, $Y$–접지 $C_{GS2} + C_{GD1}(1 + g_{m2}/g_{m1}) + C_{DB1} + C_{SB2}$, $X$–접지 $C_{GS1} + C_{GD1}(1 + g_{m1}/g_{m2})$. $X$에서 $Y$까지의 이득은 $-g_{m1}/g_{m2}$
- MOS 캐스코드의 극점 (각 노드에 극점 하나): $|\omega_{p,X}| = \dfrac{1}{R_S\left[C_{GS1} + \left(1 + \dfrac{g_{m1}}{g_{m2}}\right)C_{GD1}\right]}$ (식 11.141), $|\omega_{p,Y}| = \dfrac{1}{\dfrac{1}{g_{m2}}\left[C_{DB1} + C_{GS2} + \left(1 + \dfrac{g_{m2}}{g_{m1}}\right)C_{GD1} + C_{SB2}\right]}$ (식 11.142), $|\omega_{p,out}| = \dfrac{1}{R_L(C_{DB2} + C_{GD2})}$ (식 11.143)

## 회로 — 없음 (문제 그림 없음, 예제 11.25의 캐스코드. 본문 Fig 11.52 참고)

## 풀이
### 바뀐 소자 값
- 회로 값은 예제 11.18의 $R_S = 200\ \Omega$, $R_L = 2\ \text{k}\Omega$를 쓴다. $M_1$: $C_{GS1} = 250$, $C_{GD1} = 80$, $C_{DB1} = 100\ \text{fF}$, $g_{m1} = (150\ \Omega)^{-1}$
- $M_2$는 모두 2배: $C_{GS2} = 500$, $C_{GD2} = 160$, $C_{DB2} = C_{SB2} = 200\ \text{fF}$, $g_{m2} = (100\ \Omega)^{-1}$
- $X$에서 $Y$까지 이득 $-g_{m1}/g_{m2} = -0.667$ ($Y$에서 본 저항 $1/g_{m2}$, $\lambda = 0$)
### $X$, $Y$ 노드 극점
- $|\omega_{p,X}| = \dfrac{1}{R_S[C_{GS1} + (1 + g_{m1}/g_{m2})C_{GD1}]} = \dfrac{1}{(200\ \Omega)(383\ \text{fF})} = 2\pi \times 2.08\ \text{GHz}$
- $C_Y = C_{DB1} + C_{GS2} + (1 + g_{m2}/g_{m1})C_{GD1} + C_{SB2} = 100 + 500 + 200 + 200 = 1000\ \text{fF}$
- $|\omega_{p,Y}| = g_{m2}/C_Y = 1/[(100\ \Omega)(1\ \text{pF})] = 2\pi \times 1.59\ \text{GHz}$
### 출력 노드 극점
- $|\omega_{p,out}| = \dfrac{1}{R_L(C_{DB2} + C_{GD2})} = \dfrac{1}{(2\ \text{k}\Omega)(360\ \text{fF})} = 2\pi \times 221\ \text{MHz}$
### 응답과 비교
- 저주파수 이득 $g_{m1}R_L = 13.3$ ($22.5\ \text{dB}$)은 그대로다. $221\ \text{MHz}$에서 꺾이고 $1.6$–$2.1\ \text{GHz}$ 위에서 더 가파르다 (세 극점으로 푼 $-3\ \text{dB}$는 약 $215\ \text{MHz}$)
- 출력 노드 커패시턴스가 2배라 대역폭은 예제 11.25($442\ \text{MHz}$)의 절반이고, 예제 11.18의 CS 단(정확한 주극점 $263\ \text{MHz}$)보다도 $221/263 = 0.84$배로 좁다
### 답
- $|\omega_{p,X}| = 2\pi \times 2.08\ \text{GHz}$, $|\omega_{p,Y}| = 2\pi \times 1.59\ \text{GHz}$, $|\omega_{p,out}| = 2\pi \times 221\ \text{MHz}$
- 응답은 $22.5\ \text{dB}$에서 평평하다가 출력 극점 $221\ \text{MHz}$에서 꺾인다
- 예제 11.18과 이득은 같지만, $M_2$를 키워 늘어난 출력 커패시턴스 때문에 대역폭은 약 $0.84$배로 오히려 좁아진다
