# 예제 10.8 — 트랜지스터 하나가 테일 전류의 98%를 조종할 때의 차동 입력

## 조건
- 바이폴라 차동쌍 (본문 Fig 10.14)
- 트랜지스터 하나가 테일 전류의 98%를 조종(흘림)함
- 소자 값은 주어지지 않음 (답은 $V_T$의 배수로) (원문에 없음)

## 구할 것
- 이때의 차동 입력 전압 $V_{in1} - V_{in2}$

## 상속·참조
- 본문 Fig 10.14 (교재 514쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-14.png): $V_{CC}$ 레일, 두 $R_C$, $Q_1$(베이스 $V_{in1}$), $Q_2$(베이스 $V_{in2}$), 공통 이미터 노드 $P$와 테일 전류원 $I_{EE}$. 출력 $V_{out1}$(왼쪽 컬렉터), $V_{out2}$(오른쪽 컬렉터), 두 출력 사이 $V_{out}$(+ 왼쪽, − 오른쪽). 연결: `RC(왼쪽): VCC – Vout1`, `RC(오른쪽): VCC – Vout2`, `Q1: C = Vout1, B = Vin1, E = P`, `Q2: C = Vout2, B = Vin2, E = P`, `I_EE: P → 접지`
- 본문 대신호 해석의 가정: $\alpha = 1$, $V_A = \infty$, $V_{BE} = V_T \ln(I_C/I_S)$. 식 (10.59)→(10.60)에서 $I_{S1} = I_{S2}$(두 트랜지스터 동일)로 둠 (본문에 명시되지 않음, 원문에 없음)
- 식 (10.61): $I_{C1} + I_{C2} = I_{EE}$
- 식 (10.63): $I_{C2} = \dfrac{I_{EE}}{1 + \exp\dfrac{V_{in1} - V_{in2}}{V_T}}$
- 식 (10.65): $I_{C1} = \dfrac{I_{EE}\exp\dfrac{V_{in1} - V_{in2}}{V_T}}{1 + \exp\dfrac{V_{in1} - V_{in2}}{V_T}}$

## 회로 — 없음 (그림 없는 글 문제, 본문 그림 10.14는 상속·참조에 적음)

## 답 (검증용)
- $Q_2$가 98%를 흘린다고 보면 $I_{C1} = 0.02 I_{EE} \approx I_{EE}\exp\dfrac{V_{in1} - V_{in2}}{V_T}$ (식 10.74–10.75) → $V_{in1} - V_{in2} \approx -3.91 V_T$ (식 10.76). 약 $4V_T$의 차동 입력이면 쌍의 한쪽이 거의 오프되며, 이 값은 $I_{EE}$와 $I_S$에 무관
