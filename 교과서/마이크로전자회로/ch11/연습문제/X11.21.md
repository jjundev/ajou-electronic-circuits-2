# 연습문제 11.21 — 소스 폴로어의 두 극점이 같은 실수가 되는 g_m (예제 11.21 이어서)

## 원문
2개의 극점이 실수이고 같아지도록 하는 $g_m$의 값은 얼마인가?

## 조건
- 예제 11.21의 소스 폴로어: 구동 저항 $R_S = 200\ \Omega$, 부하 커패시턴스 $C_L = 100\ \text{fF}$, 예제 11.18의 트랜지스터 파라미터
- 예제 11.18의 트랜지스터 파라미터 가운데 $g_m$ 외의 값: $C_{GS} = 250\ \text{fF}$, $C_{GD} = 80\ \text{fF}$, $C_{DB} = 100\ \text{fF}$, $\lambda = 0$ (원문에 없음)
- $C_{SB} = 100\ \text{fF}$ ($= C_{DB}$)로 봄 (예제 11.21 풀이의 $a$ 값에 맞는 값, 원문에 없음)
- $g_m$만 바꿈 (원문에 없음)

## 구할 것
- 2개의 극점이 실수이고 같아지도록 하는 $g_m$의 값

## 상속·참조
- 예제 11.18 (E11.18)의 트랜지스터 파라미터: $C_{GS} = 250\ \text{fF}$, $C_{GD} = 80\ \text{fF}$, $C_{DB} = 100\ \text{fF}$, $g_m = (150\ \Omega)^{-1}$, $\lambda = 0$ (예제 11.18의 $R_S = 200\ \Omega$, $R_L = 2\ \text{k}\Omega$는 CS 단의 회로 값)
- 본문 Fig 11.40(b) 소스 폴로어 (교재 611쪽, 크롭 안 함): $M_1$ 드레인은 $V_{DD}$, $R_S$는 $V_{in}$과 게이트 노드 $X$ 사이, $C_{GD}$는 $X$–$V_{DD}$(드레인), 회색 $C_{DB}$는 드레인–접지 (양 끝 교류 접지), $C_{GS}$는 $X$–소스 노드 $Y$, $Y$ = $V_{out}$, $Y$→접지 바이어스 전류원, $V_{out}$–접지 $C_{SB} + C_L$
- 이미터 폴로어 결과에서 $r_\pi \to \infty$로 둔 소스 폴로어 전달 함수 ($C_{SB}$와 $C_L$이 병렬): $\dfrac{V_{out}}{V_{in}} = \dfrac{1 + \dfrac{C_{GS}}{g_m}s}{as^2 + bs + 1}$ (식 11.112), $a = \dfrac{R_S}{g_m}[C_{GD}C_{GS} + C_{GD}(C_{SB} + C_L) + C_{GS}(C_{SB} + C_L)]$ (식 11.113), $b = R_S C_{GD} + \dfrac{C_{GS} + C_{SB} + C_L}{g_m}$ (식 11.114)
- 예제 11.21 (E11.21): $g_m = (150\ \Omega)^{-1}$에서 $a = 2.58 \times 10^{-21}\ \text{s}^{-2}$, $b = 5.8 \times 10^{-11}\ \text{s}$, 극점 $2\pi[-1.79\ \text{GHz} \pm j(2.57\ \text{GHz})]$ (복소수). 문제와 풀이 모두 $C_{SB}$ 값을 적지 않음

## 회로 — 없음 (문제 그림 없음, 예제 11.21의 소스 폴로어)

## 풀이
### 전달 함수의 분모
- $\dfrac{V_{out}}{V_{in}} = \dfrac{1 + (C_{GS}/g_m)s}{as^2 + bs + 1}$, $a = \dfrac{R_S}{g_m}K$, $b = R_S C_{GD} + \dfrac{C_3}{g_m}$
- $K = C_{GD}C_{GS} + (C_{GD} + C_{GS})(C_{SB} + C_L) = 20000 + (330)(200) = 86000\ \text{fF}^2$, $C_3 = C_{GS} + C_{SB} + C_L = 450\ \text{fF}$
### 같은 실수 극점의 조건
- 두 근이 실수이고 같으려면 판별식이 0: $b^2 = 4a$
- $x = 1/g_m$로 두면 $(R_S C_{GD} + C_3 x)^2 = 4R_S K x$, 즉 $C_3^2 x^2 + (2R_S C_{GD}C_3 - 4R_S K)x + (R_S C_{GD})^2 = 0$
### $g_m$ 풀기
- 근: $x = 264\ \Omega$ 또는 $x = 4.79\ \Omega$ → $g_m = (264\ \Omega)^{-1} = 3.79\ \text{mS}$ 또는 $g_m = (4.79\ \Omega)^{-1} = 209\ \text{mS}$
- 두 값 사이의 $g_m$(예제의 $(150\ \Omega)^{-1}$ 포함)에서는 극점이 복소수, 바깥에서는 서로 다른 실수다
- 큰 값은 같은 커패시턴스로 $g_m$을 약 31배 키워야 하므로 현실적인 답은 작은 값이다
### 겹친 극점의 위치
- $b^2 = 4a$이면 근은 $s = -b/(2a) = -2/b$
- $g_m = (264\ \Omega)^{-1}$: $b = 1.35 \times 10^{-10}\ \text{s}$ → $\omega_p = -2\pi \times 2.36\ \text{GHz}$ (중근)
### 답
- $g_m = (264\ \Omega)^{-1} \approx 3.79\ \text{mS}$ (이때 두 극점 모두 $-2\pi \times 2.36\ \text{GHz}$). 수식상 $g_m = (4.79\ \Omega)^{-1} \approx 209\ \text{mS}$도 조건을 만족하지만 비현실적이다.
