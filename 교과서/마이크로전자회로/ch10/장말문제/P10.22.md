# 장말문제 10.22 — 식 10.83으로 구하는 바이폴라 차동쌍의 소신호 전압 이득 (dc 성분 30 mV)

## 원문
With the aid of Eq. (10.83), we can compute the small-signal voltage gain of the bipolar differential pair:

$$A_v = \frac{\partial (V_{out1} - V_{out2})}{\partial (V_{in1} - V_{in2})}. \qquad (10.218)$$

Determine the gain and compute its value if $V_{in1} - V_{in2}$ contains a dc component of $30\ \text{mV}$.

## 조건
- 식 (10.83)으로 바이폴라 차동쌍의 소신호 전압 이득을 계산할 수 있음:
  $$A_v = \frac{\partial (V_{out1} - V_{out2})}{\partial (V_{in1} - V_{in2})} \qquad (10.218)$$
- 참고 회로 (본문 Fig 10.14): 두 부하 $R_C$가 $V_{CC}$에서 각 컬렉터 $V_{out1}$, $V_{out2}$로, $Q_1$ 베이스 $V_{in1}$, $Q_2$ 베이스 $V_{in2}$, 공통 이미터 노드에서 접지로 테일 전류원 $I_{EE}$ (원문에 없음)
- 식 (10.83): $\alpha = 1$, $V_A = \infty$일 때 $V_{out1} - V_{out2} = -R_C I_{EE} \tanh\dfrac{V_{in1} - V_{in2}}{2V_T}$ (본문 식, 원문에 없음)
- $V_{in1} - V_{in2}$에 $30\ \text{mV}$의 dc 성분이 들어 있는 경우

## 구할 것
- 이득 $A_v$
- $V_{in1} - V_{in2}$에 $30\ \text{mV}$ dc 성분이 있을 때 이득의 값

## 상속·참조
- 식 (10.83) (교재 516쪽, Fig 10.14의 대신호 해석, $\alpha = 1$, $V_A = \infty$):
  $$V_{out1} - V_{out2} = -R_C I_{EE} \tanh\frac{V_{in1} - V_{in2}}{2V_T}$$
- 식 (10.83)의 회로: 본문 Fig 10.14 (교재 514쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-14.png). 연결: `R_C: VCC – Vout1`, `R_C: VCC – Vout2`, `Q1: C = Vout1, B = Vin1, E = P`, `Q2: C = Vout2, B = Vin2, E = P`, `I_EE: P → 접지`

## 회로 — 없음 (식에서 출발하는 문제, 문제 그림 없음)

## 풀이
### 대신호 전달 특성
- 바이폴라 차동쌍($\alpha = 1$, $V_A = \infty$)의 출력: $V_{out1} - V_{out2} = -R_C I_{EE} \tanh\dfrac{V_{in1} - V_{in2}}{2V_T}$
### 이득 식
- 미분하면 $A_v = -\dfrac{R_C I_{EE}}{2V_T}\, \text{sech}^2\dfrac{V_{in1} - V_{in2}}{2V_T}$
- 평형에서는 $\text{sech}^2 0 = 1$이라 $A_v = -R_C I_{EE}/(2V_T) = -g_m R_C$ ($g_m$: 각 트랜지스터의 $I_{EE}/(2V_T)$)
### 30 mV dc 성분에서의 값
- $V_T = 26\ \text{mV}$로 두면 $\dfrac{30\ \text{mV}}{2V_T} = 0.577$, $\tanh 0.577 = 0.520$ → $\text{sech}^2 = 1 - 0.520^2 = 0.729$
- $A_v = -0.729\, \dfrac{R_C I_{EE}}{2V_T} = -(14.0\ \text{V}^{-1})\, R_C I_{EE}$. 평형 이득의 약 73 %다
### 답
- $A_v = -\dfrac{R_C I_{EE}}{2V_T}\, \text{sech}^2\dfrac{V_{in1} - V_{in2}}{2V_T}$
- $30\ \text{mV}$에서 $A_v \approx -0.729\, \dfrac{R_C I_{EE}}{2V_T} = -(14.0\ \text{V}^{-1})\, R_C I_{EE}$
