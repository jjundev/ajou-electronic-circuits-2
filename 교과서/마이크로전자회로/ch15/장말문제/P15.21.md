# 장말문제 15.21 — 지정된 저항 감도에서 Q와 저항비의 허용 범위

## 조건
- Fig 15.33에 대해 원문은 $S_{R_1}^Q=2$를 제시한다.
- $C_2=C_1$이다.

## 구할 것
- $\sqrt{R_2/R_1}$에 대한 $Q$의 그래프를 그린다.
- 허용되는 $Q$와 $\sqrt{R_2/R_1}$ 값의 범위를 결정한다.

## 상속·참조
- Fig 15.33은 단위 이득 회로이다. 제시된 양의 감도 2는 양의 유한한 소자값에서 이 회로 및 $C_2=C_1$ 조건과 양립하지 않는다. (원문에 없음)

## 회로 — Fig 15.33
```spice
VIN  Vin  0     {V_in}
R1   Vin  Y     {R_1}
R2   Y    X     {R_2}
C1   Y    Vout  {C_1}
C2   X    0     {C_2}
XA   X    Vout  Vout opamp
```
- 단자: Vout = 출력 (개방 원) / Vin = 접지 기준 입력 전압원의 전압
- 표시: 노드 라벨 Y, X, V_out / 소자 라벨 V_in, R_1, R_2, C_1, C_2, XA (라벨 없음) / 부호 입력 전압원은 위 +, 아래 −, 연산증폭기는 왼쪽 위 +, 아래 − / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 접지 전압원 위에서 가로 R_1, Y(점), R_2, X(점), 비반전 입력 순으로 이어진다. Y에서 위로 C_1을 거쳐 출력으로 돌아가고, X에서 아래로 C_2가 접지된다. 반전 입력은 아래쪽 선을 따라 출력 접속점(점)으로 바로 되돌아간다. 교차: 없음
