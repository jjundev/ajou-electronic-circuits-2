# 장말문제 11.29 — g_m = 2I_D/(V_GS − V_TH) 대입으로 얻은 식(11.184)과 식(11.183)의 모순 설명

## 원문
Having solved Problem 11.28 successfully, a student attempts a different substitution for $g_m$: $2I_D/(V_{GS} - V_{TH})$, arriving at

$$2\pi f_T = \frac{3}{2}\frac{2I_D}{WLC_{ox}}\frac{1}{V_{GS} - V_{TH}}. \qquad (11.184)$$

This result suggests that $f_T$ decreases as the overdrive voltage increases! Explain this apparent discrepancy between Eqs. (11.183) and (11.184).

## 조건
- 문제 11.28을 푼 학생이 $g_m$에 다른 식 $2I_D/(V_{GS} - V_{TH})$를 대입해 다음을 얻음:
$$2\pi f_T = \frac{3}{2}\frac{2I_D}{WLC_{ox}}\frac{1}{V_{GS} - V_{TH}} \quad (11.184)$$
- 이 결과는 과구동 전압이 증가하면 $f_T$가 감소함을 뜻하는 것처럼 보임

## 구할 것
- 식 (11.183)과 (11.184) 사이의 이 겉보기 모순을 설명

## 상속·참조
- 문제 11.28 (P11.28): 포화 영역 MOSFET의 $C_{GS} \approx (2/3) W L C_{ox}$와 식 (11.52) $2\pi f_T \approx g_m / C_{GS}$를 이용해 $2\pi f_T = \dfrac{3}{2}\dfrac{\mu_n}{L^2}(V_{GS} - V_{TH})$ (식 11.183)를 증명. 이 식에서 $f_T$는 과구동 전압에 따라 증가

## 회로 — 없음 (개념 설명 문제, 그림 없음)

## 풀이
### 세 변수는 서로 묶여 있다
- 제곱 법칙 $I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$ 때문에 $L$이 정해지면 $I_D$, $W$, $V_{GS} - V_{TH}$ 가운데 둘만 마음대로 고를 수 있다
- 식 (11.184)를 "$V_{GS} - V_{TH}$가 늘면 $f_T$가 준다"로 읽으려면 $I_D$와 $W$를 둘 다 고정한 채 $V_{GS} - V_{TH}$만 바꿔야 하는데, 이는 불가능하다
### 두 식은 같은 식이다
- 식 (11.184)의 $I_D$에 제곱 법칙을 넣으면 $2\pi f_T = \dfrac{3}{2}\cdot\dfrac{\mu_n C_{ox}(W/L)(V_{GS} - V_{TH})^2}{WLC_{ox}(V_{GS} - V_{TH})} = \dfrac{3}{2}\dfrac{\mu_n}{L^2}(V_{GS} - V_{TH})$로 식 (11.183)이 된다
### $I_D$를 고정하면
- $I_D$를 고정하고 $V_{GS} - V_{TH}$를 키우면 $W \propto 1/(V_{GS} - V_{TH})^2$로 줄어야 한다. 식 (11.184)의 분모 $W$가 그보다 빨리 줄어 $f_T$는 $V_{GS} - V_{TH}$에 비례해 오른다
### 답
- 모순은 겉보기일 뿐이다. 식 (11.184)는 $I_D$와 $W$를 고정하고 $V_{GS} - V_{TH}$만 바꾸는 것처럼 보이지만, 제곱 법칙 때문에 셋은 독립이 아니다. $I_D$를 제곱 법칙으로 바꾸면 식 (11.183)과 같아지고, 어느 식으로 보든 $L$이 정해지면 $f_T$는 과구동 전압에 비례해 늘어난다.
