# 장말문제 10.46 — 식 10.147에서 MOS 차동쌍의 소신호 트랜스컨덕턴스 G_m을 구하고 그래프로 그림

## 원문
From Eq. (10.147), compute the small-signal transconductance of a MOS differential pair, defined as

$$G_m = \frac{\partial(I_{D1} - I_{D2})}{\partial(V_{in1} - V_{in2})}. \qquad (10.221)$$

Plot the result as a function of $V_{in1} - V_{in2}$ and determine its maximum value.

## 조건
- MOS 차동쌍의 대신호 식 (10.147)
- 소신호 트랜스컨덕턴스의 정의:
  $$G_m = \frac{\partial(I_{D1} - I_{D2})}{\partial(V_{in1} - V_{in2})} \qquad (10.221)$$

## 구할 것
- 식 (10.147)로부터 $G_m$ 계산
- $G_m$을 $V_{in1} - V_{in2}$의 함수로 그림
- $G_m$의 최댓값

## 상속·참조
- 식 (10.147) (교재 532쪽):
  $$I_{D1} - I_{D2} = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{in1} - V_{in2})\sqrt{\frac{4I_{SS}}{\mu_n C_{ox}\dfrac{W}{L}} - (V_{in1} - V_{in2})^2} \qquad (10.147)$$
- 유도 가정 (교재 530쪽): 채널 길이 변조 무시($\lambda = 0$), 제곱 법칙 $I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$, 두 트랜지스터 동일. KVL $V_{in1} - V_{GS1} = V_{in2} - V_{GS2}$ (10.133), KCL $I_{D1} + I_{D2} = I_{SS}$ (10.134)
- 식 (10.131)–(10.147)의 회로: 본문 Fig 10.31 (교재 530쪽, PDF 18, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-31.png, "대신호 분석을 위한 MOS 차동쌍"). 연결: `R_D: VDD – Vout1`, `R_D: VDD – Vout2`, `M1: D = Vout1, G = Vin1, S = 공통 소스 노드`, `M2: D = Vout2, G = Vin2, S = 공통 소스 노드`, `I_SS: 공통 소스 노드 → 접지` (공통 소스 노드 라벨 없음)

## 회로 — 없음 (식에서 출발하는 문제, 문제 그림 없음)

## 풀이
### 미분
- $K = \mu_n C_{ox} W/L$, $\Delta V = V_{in1} - V_{in2}$, $A = 4I_{SS}/K$로 두면 $I_{D1} - I_{D2} = \frac{1}{2}K\Delta V\sqrt{A - \Delta V^2}$
- 곱의 미분: $G_m = \dfrac{K}{2}\left[\sqrt{A - \Delta V^2} - \dfrac{\Delta V^2}{\sqrt{A - \Delta V^2}}\right] = \dfrac{K}{2}\,\dfrac{A - 2\Delta V^2}{\sqrt{A - \Delta V^2}}$
### 모양
- $\Delta V^2$만의 함수라 $\Delta V = 0$에 대해 좌우 대칭이고, $|\Delta V|$가 커지면 분자는 줄고 분모 근호도 줄지만 분자가 더 빨리 줄어 단조 감소한다
- $\Delta V^2 = A/2$, 곧 $|\Delta V| = \sqrt{2I_{SS}/K}$에서 0이 된다. 여기서 한 소자가 꺼지므로 그 바깥에서는 $G_m = 0$ (식은 쓸 수 없음)
- 그래프: $\Delta V = 0$에서 꼭대기인 종 모양 곡선이 $\pm\sqrt{2I_{SS}/K}$에서 0에 닿고 바깥은 0
### 최댓값
- $\Delta V = 0$: $G_{m,max} = \dfrac{K}{2}\sqrt{A} = \dfrac{K}{2} \cdot 2\sqrt{I_{SS}/K} = \sqrt{K I_{SS}}$
- 각 소자의 $g_m = \sqrt{2K(I_{SS}/2)} = \sqrt{K I_{SS}}$와 같다
### 답
- $G_m = \dfrac{\mu_n C_{ox}\frac{W}{L}}{2}\,\dfrac{4I_{SS}/(\mu_n C_{ox}\frac{W}{L}) - 2(V_{in1} - V_{in2})^2}{\sqrt{4I_{SS}/(\mu_n C_{ox}\frac{W}{L}) - (V_{in1} - V_{in2})^2}}$
- 그래프는 $V_{in1} = V_{in2}$에서 꼭대기인 좌우 대칭 종 모양으로, $|V_{in1} - V_{in2}| = \sqrt{2I_{SS}/(\mu_n C_{ox} W/L)}$에서 0이 되고 그 바깥은 0
- 최댓값 $G_{m,max} = \sqrt{\mu_n C_{ox}(W/L) I_{SS}}$ (평형에서 각 소자의 $g_m$)
