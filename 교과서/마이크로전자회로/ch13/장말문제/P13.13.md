# 장말문제 13.13 — PMOS 전류원 부하 3단 링 발진기의 발진 주파수와 시작 조건

## 원문
Derive the oscillation frequency and startup condition for the ring oscillator of Fig. 13.9(a). Consider only the $C_{GS}$ of the NMOS transistors and assume all transistors are in saturation.

## 조건
- 회로: Fig 13.9(a)의 3단 링 발진기 (PMOS 전류원 부하 CS 단 세 개)
- 커패시턴스는 NMOS 트랜지스터의 $C_{GS}$만 고려
- 모든 트랜지스터는 포화 영역
- 참고 해석 (본문 13.2절): Fig 13.8에서 각 단 전달 함수 $-\dfrac{g_m R_D}{1 + R_D C_D s}$로 $\omega_1 = \sqrt{3}/(R_D C_D)$, $g_m R_D = 2$를 얻었고, 부하를 PMOS 전류원으로 바꾸면 $R_D$를 $r_{Op} \parallel r_{On}$으로 바꾼 것과 같음 (원문에 없음)

## 구할 것
- 발진 주파수
- 발진 시작 조건

## 상속·참조
- 본문 13.2절 3단 링 발진기 해석 (교재 736–737쪽, Fig 13.8, $C_{GD}$ 무시)
  - 각 단의 전달 함수 ($\lambda = 0$): $-\dfrac{g_m R_D}{1 + R_D C_D s}$. 세 단이 같아 각 극점이 $60^\circ$씩 위상을 이동시켜야 함
  - 식 (13.2): $-\tan^{-1}(R_D C_D \omega_1) = -60^\circ$
  - 식 (13.3): $\omega_1 = \dfrac{\sqrt{3}}{R_D C_D}$
  - 식 (13.4): $\left(\dfrac{g_m R_D}{\sqrt{1 + R_D^2 C_D^2 \omega_1^2}}\right)^3 = 1$
  - 식 (13.5)–(13.6): $g_m R_D = \sqrt{1 + R_D^2 C_D^2 \omega_1^2} = 2$. 발진 시작에는 각 단의 저주파 이득이 2를 넘어야 함
- 본문 설명 (교재 737–738쪽): Fig 13.8의 부하 저항을 Fig 13.9(a)처럼 PMOS 전류원으로 바꾸면 $R_D$를 $r_{Op} \parallel r_{On}$으로 바꾼 것과 같고 앞의 유도가 그대로 성립함. Fig 13.9(b)처럼 PMOS 게이트도 그 단의 입력에 이으면 두 트랜지스터가 포화 영역일 때 각 단은 이득 $-(g_{mp} + g_{mn})(r_{Op} \parallel r_{On})$의 CMOS 인버터가 됨

## 회로 — Fig 13.9(a)
```spice
M4  X  Vb  VDD  pmos
M5  Y  Vb  VDD  pmos
M6  Z  Vb  VDD  pmos
M1  X  Z   0    nmos    ; 게이트 = 귀환선 (Z, V_out)
M2  Y  X   0    nmos
M3  Z  Y   0    nmos
```
- 단자: VDD = 전원, 값 미지정 (가로 레일) / Vb = PMOS 게이트 바이어스, 값 미지정 (점 단자) / Z = 출력 V_out (개방 원, Z 노드에서 오른쪽으로 이어진 선 끝) / X, Y, Z는 드레인 접속점 옆 라벨만 (원 없음)
- 표시: 노드 라벨 V_DD (레일 오른쪽 끝), V_b (점 단자 왼쪽), X, Y, Z (각 드레인 접속점 왼쪽 위), V_out (개방 원 오른쪽) / 소자 라벨 M_4, M_5, M_6 (각 PMOS 아래 왼쪽), M_1, M_2, M_3 (각 NMOS 오른쪽, 소스 옆) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 맨 위 VDD 가로 레일 / 세 단이 왼쪽→오른쪽 같은 모양: 위→아래 PMOS (M4/M5/M6, 게이트 왼쪽, 소스가 위로 레일), 드레인 접속점 (X/Y/Z), NMOS (M1/M2/M3, 게이트 왼쪽, 소스 아래 접지) / V_b 점 단자에서 가로선이 PMOS 게이트 높이로 오른쪽으로 가며 M4, M5 기호(게이트 판과 채널 막대)를 관통해 지나고 M6 게이트 판에서 끝남 (관통한 곳에 점 없음, 소스·드레인 리드와는 만나지 않음) / X 접속점에서 가로선이 오른쪽으로 가서 아래로 꺾이고 M2 게이트 높이에서 오른쪽으로 꺾여 M2 게이트, Y도 같은 모양으로 M3 게이트 / Z 접속점에서 가로선이 오른쪽 접속점을 지나 V_out 개방 원, 그 접속점에서 귀환선이 아래로 내려가 회로 아래를 왼쪽으로 가로지르고 M1 왼쪽에서 위로 꺾여 M1 게이트 높이에서 오른쪽으로 M1 게이트 / 접속점 (세 갈래 이상, 4곳): X, Y, Z = 위 PMOS 드레인 + 아래 NMOS 드레인 + 오른쪽 가로선 (점), Z 오른쪽 = 왼쪽 Z + 오른쪽 V_out + 아래 귀환선 (점) / 교차: 없음
