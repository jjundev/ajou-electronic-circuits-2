# 전자회로2 중간고사 실전 대비 모의고사 (v1)

아주대학교 전자공학과 권익진 교수님 전자회로2 2013~2023년 기출 경향과 2026-2학기 강의 범위(10월 16일 수업 기준)를 완벽히 반영한 실전 모의고사 패키지입니다.

---

## 1. 시험 안내 및 응시 규칙

| 항목 | 세부 규격 |
| :--- | :--- |
| **시험 시간** | **75분** (실제 시험 동일) |
| **문항 구성** | 총 5문항 (문항당 20점, **총 100점 만점**) |
| **시험 방식** | **Closed-book** (별도 공식지 미제공) |
| **준비물** | 일반 필기도구, 공학용 계산기 지참 가능 |
| **답안 작성 원칙** | 단순 수치 나열 시 감점 처리되며, KCL/KVL 노드 방정식 유도 및 소신호 파라미터($g_m, r_o, R_{out}, G_m$) 계산 과정을 반드시 명시해야 함 |

## 2. 시험 범위

- **9장 (Cascode Amplifiers & Current Mirrors)**:
  - MOS 및 BJT 전류 거울 바이어스 회로
  - 소스 축퇴(Degeneration) 저항을 갖는 전류 거울 복사비 설계
  - 캐스코드 증폭기, Folded Cascode 회로 해석 ($R_{out}, G_m, A_v$)
- **10장 (Differential Amplifiers)**:
  - MOS 및 BJT 차동 증폭기의 대신호/소신호 해석
  - 가상 접지(Virtual Ground)를 활용한 차동 반회로(Half-circuit) 모델링
  - 능동 전류 거울 부하를 갖는 차동 증폭기
  - 비대칭(부하 불일치 $\Delta R_D$)과 공통 모드 특성 ($A_d, A_{CM}, A_{CM-DM}, \text{CMRR}$)
- **11장 전반부 (Frequency Response)**:
  - 고주파 소신호 모델 ($C_{gs}, C_{gd}, C_{db}$ 및 $C_\pi, C_\mu$)
  - 밀러 정리(Miller's Theorem) 및 반전 증폭기에서의 밀러 효과
  - 입력 등가 커패시턴스 증폭에 따른 대역폭(Bandwidth) 제한 원리
