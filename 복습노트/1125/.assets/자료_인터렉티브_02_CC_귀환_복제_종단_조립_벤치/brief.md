## 기존 `.widget` 관계 및 처리 계획
- 관련 절 `s2-cc-break`에는 위젯이 없다. 이웃 절 `s2-cc-io`에 `widget-ccio`($R_F, R_M$ 로그 슬라이더로 $R_{in,open}$·$R_{out,open}$ 오차율 막대 표시)가 있다.
- 본 실험은 C-C 귀환 회로도 위의 입력·출력 복제 포트(`in_term`, `out_term`)와 $K$ 측정 포트(`sense_port`, `ret_port`)를 직접 개방/접지/시험원으로 조립하고 오조립 결과를 MNA로 즉시 진단한다.
- 예측 질문은 출력 쪽 복제의 반송 포트를 잘못 개방했을 때 출력 복제 저항 변화를 묻는 것이므로 `widget-ccio`가 예측 답을 노출하지 않으며, `widget-ccio`는 기준 임피던스($1/g_{m1}$ vs $r_{O2}$) 대비 비율 감각을 익히는 본문 위젯으로 쓰임이 남는다.
- **처리:** `widget-ccio` **유지**.

## 모드·조작·대표 설정·인과 단계
- **모드 1 (`open_break` — 개루프 복제 종단 조립):**
  - 포트 2개:
    - `in_term` (입력 쪽 복제 감지 포트): `open`(정답: 개방 → $R_F+R_M$), `gnd`(오조립 `badOption`: 접지 → $R_M$ 단락, $R_F$만 남음).
    - `out_term` (출력 쪽 복제 반송 포트): `gnd`(정답: 접지 → $R_F \parallel R_M$), `open`(오조립 `badOption`: 개방 → $R_F$ 부유, $R_M$만 남음).
  - 파라미터: `rf` ($1$–$50\text{ k}\Omega$, 기본 $10$), `rm` ($0.1$–$10\text{ k}\Omega$, 기본 $1$). 고정: $g_{m1}=2\text{ mS}, R_D=10\text{ k}\Omega, g_{m2}=5\text{ mS}, r_{O2}=50\text{ k}\Omega, R_L=1\text{ k}\Omega$.
  - MNA 계산: 개루프 $R_{in,open}$, $R_{out,open}$, $A_{I,open}$을 포트 종단에 따라 MNA로 직접 계산해 오조립 시 수치 왜곡을 즉시 표시.
- **모드 2 (`k_measure` — 귀환 계수 $K$ 포트 종단 조립):**
  - 포트 2개:
    - `sense_port` (감지 포트 $P$): `isrc`(정답: 출력 전류원 $I_{out}=1\text{ mA}$ 인가), `gnd`(오조립 `badOption`: 접지 단락 → $V_P=0$, 전류원 무효/측정 불가).
    - `ret_port` (반송 포트): `gnd`(정답: 접지 단락해 $I_F$ 측정 → $K = -R_M/(R_F+R_M)$), `open`(오조립 `badOption`: 개방 → $I_F = 0$, $K = 0$ 오측정).
  - 파라미터: `rf` ($1$–$50\text{ k}\Omega$, 기본 $10$), `rm` ($0.1$–$10\text{ k}\Omega$, 기본 $1$).
- **대표 설정(`presets`):**
  - `open_break`: `정답 조립 (개방 / 접지)`, `오조립: 둘 다 개방`, `오조립: 둘 다 접지`
  - `k_measure`: `정답 조립 (I_out 인가 / 반송 접지)`, `오조립: 반송 포트 개방`, `오조립: 감지 포트 접지`

## 예측 질문 및 오개념
- **예측 질문 (`predict`, `mode: 'open_break'`):**
  - 질문: "C-C 귀환에서 출력 쪽 복제의 반송 포트를 접지 대신 잘못 **개방**하면, 출력 쪽 복제 저항은 정답($R_F \parallel R_M$)보다 어떻게 바뀔까요?"
  - 보기: `larger`("$R_M$만 남아 더 커진다"), `smaller`("0에 가까워져 더 작아진다"), `same`("변하지 않는다") — 정답: `larger`.
  - `check`: `before: { params: { rf: 10, rm: 1 }, ports: { in_term: 'open', out_term: 'gnd' } }`, `after: { ports: { in_term: 'open', out_term: 'open' } }`, `tiles: ['출력 복제 저항', '개루프 전류 이득']`.
- **모드별 오개념 (`mistakes`, 각 3개):**
  - `open_break`: (1) C-V 습관대로 두 복제를 모두 개방하는 오류, (2) 입력 쪽 복제를 접지해 $R_M$을 단락시켜 버리는 오류, (3) 출력 쪽 $r_{O2}$와 $R_F \parallel R_M$을 병렬로 계산하는 오류(실제는 두 AC 접지가 이어져 직렬).
  - `k_measure`: (1) 전류 반송 포트를 전압 반송처럼 개방하고 $I_F$를 재려는 오류($I_F=0$), (2) $I_F$의 양의 방향을 $P$에서 나가는 쪽으로 잘못 잡아 $K>0$로 쓰는 오류(입력에서 빠지는 방향이 양), (3) $K$가 음수이면 무조건 양의 귀환이라고 오해.
