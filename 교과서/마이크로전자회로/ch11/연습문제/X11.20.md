# 연습문제 11.20 — 150 fF 부하 커패시턴스를 구동하는 CG 증폭기 (예제 11.20 변형)

## 원문
공통 게이트(CG) 증폭기가 $150\ \text{fF}$의 부하 커패시턴스를 구동할 경우에 위의 예제를 반복하라.

## 조건
- 예제 11.20의 공통 게이트(CG) 증폭기 (예제 11.18의 CS 단을 $R_S$가 소스에 연결된 CG로 바꾼 것)
- CG 증폭기가 $150\ \text{fF}$의 부하 커패시턴스를 구동
- 예제 11.18의 값: $R_S = 200\ \Omega$, $C_{GS} = 250\ \text{fF}$, $C_{GD} = 80\ \text{fF}$, $C_{DB} = 100\ \text{fF}$, $g_m = (150\ \Omega)^{-1}$, $\lambda = 0$, $R_L = 2\ \text{k}\Omega$ (원문에 없음)
- $C_{SB} = C_{DB}$로 봄 (예제 11.20 풀이의 가정, 원문에 없음)
- 부하 커패시턴스는 출력 노드와 접지 사이에 더해지는 것으로 봄 (원문에 없음)

## 구할 것
- 예제 11.20 반복: 회로의 주파수 응답 그리기

## 상속·참조
- 예제 11.18 (E11.18)의 값: $R_S = 200\ \Omega$, $C_{GS} = 250\ \text{fF}$, $C_{GD} = 80\ \text{fF}$, $C_{DB} = 100\ \text{fF}$, $g_m = (150\ \Omega)^{-1}$, $\lambda = 0$, $R_L = 2\ \text{k}\Omega$ (Fig 11.31(a) CS 단의 $R_D$ 자리). 예제 11.18의 CS 단 저주파수 이득 $g_m R_L = 13.3$ ($22\ \text{dB}$)
- 예제 11.20 (E11.20): $C_{SB} = C_{DB}$로 두고 식 (11.99)–(11.100)으로 $|\omega_{p,in}| = 2\pi \times (5.31\ \text{GHz})$, $|\omega_{p,out}| = 2\pi \times (442\ \text{MHz})$, 저주파수 이득 $R_D/(R_S + 1/g_m) = 5.7$ ($15\ \text{dB}$), −3 dB 대역폭 약 $450\ \text{MHz}$
- 본문 Fig 11.37 (교재 608쪽, 크롭 안 함): 트랜지스터 커패시턴스를 포함한 (a) CB 단과 (b) CG 단. $r_O = \infty$. (b) CG 단: $V_{DD}$–$R_D$–$V_{out}$ = 드레인 노드 $Y$, $M_1$ 게이트는 $V_b$ (점 단자), 소스 노드 $X$, $R_S$는 $V_{in}$과 $X$ 사이. $C_{DB}$는 $Y$–접지, $C_{GD}$는 $Y$–$V_b$, $C_{GS}$는 $V_b$–$X$, $C_{SB}$는 $X$–접지. $V_b$가 교류 접지이므로 입력과 출력 사이에 커패시턴스가 없고 밀러 효과가 없음
- CB/CG 단의 극점: $|\omega_{p,X}| = \dfrac{1}{\left(R_S \parallel \dfrac{1}{g_m}\right)C_X}$ (식 11.99), $C_X = C_\pi$ 또는 $C_{GS} + C_{SB}$ / $|\omega_{p,Y}| = \dfrac{1}{R_L C_Y}$ (식 11.100), $C_Y = C_\mu + C_{CS}$ 또는 $C_{GD} + C_{DB}$
- 부하 커패시턴스는 출력 노드 $Y$와 접지 사이에 더해지는 것으로 봄 ($C_Y$에 더해짐) (원문에 없음)

## 회로 — 없음 (문제 그림 없음, 예제 11.20의 CG 증폭기에 부하 커패시턴스를 더한 회로)
