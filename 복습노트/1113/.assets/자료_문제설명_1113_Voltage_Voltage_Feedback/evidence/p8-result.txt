(a) M2 NMOS SF: gate=Vout, src=n1, drain=VDD
  qualitative: Vin up -> n1 up -> M1 CS: Vout down -> M2 follower: n1(src) follows gate down -> opposes -> NEGATIVE
  return ratio on M2: T = R_S*g_m2*r_o2*(g_m1*r_o1 + 1)/(R_S + r_o2)
     r_o->oo : T = oo
     sign(T) over all positive params = 1  -> NEGATIVE feedback
  return ratio on M1: T = R_S*g_m1*g_m2*r_o1*r_o2/(R_S*g_m2*r_o2 + R_S + r_o2)

     r_o->oo : T = -oo
     sign(T) over all positive params = -1  -> POSITIVE feedback
