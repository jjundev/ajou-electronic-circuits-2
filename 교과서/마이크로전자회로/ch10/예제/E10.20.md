# 예제 10.20 — 전력 3 mW, ΔV_in,max = 500 mV인 NMOS 차동쌍 설계

## 원문
한계 전력 소모가 $3\ \text{mW}$이고 $\Delta V_{in,max} = 500\ \text{mV}$인 NMOS 차동쌍을 설계하라. $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $V_{DD} = 1.8\ \text{V}$로 가정한다.

## 조건
- NMOS 차동쌍, 한계 전력 소모 $3\ \text{mW}$
- $\Delta V_{in,max} = 500\ \text{mV}$
- $\Delta V_{in,max}$: 한쪽 트랜지스터가 전도의 끝에 놓이는(다른 쪽이 $I_{SS}$를 모두 흘리는) 차동 입력. 식 (10.150): $\Delta V_{in,max} = \sqrt{\dfrac{2I_{SS}}{\mu_n C_{ox} W/L}}$ (본문 정의, 원문에 없음)
- 전력 소모는 $V_{DD} I_{SS}$ (원문에 없음)
- $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $V_{DD} = 1.8\ \text{V}$

## 구할 것
- 위 조건을 만족하는 NMOS 차동쌍 설계
- 정할 값: 테일 전류 $I_{SS}$, 트랜지스터 종횡비 $W/L$ (원문에 없음, 원문은 "설계하라"만 적음)

## 상속·참조
- 식 (10.150): 한쪽 트랜지스터가 전도의 끝에 놓이는 차동 입력 $\Delta V_{in,max} = \sqrt{\dfrac{2I_{SS}}{\mu_n C_{ox}\frac{W}{L}}}$ (좌변 $\Delta V_{in,max}$는 원문 533쪽 본문 표기, 식 (10.150)에는 없음)
- 전력 소모 = $V_{DD} I_{SS}$ (원문에 없음, 풀이가 암시)

## 회로 — 없음 (설계 문제, 문제 그림 없음)

## 답 (검증용)
- 테일 전류는 $3\ \text{mW}/1.8\ \text{V} = 1.67\ \text{mA}$를 넘으면 안 됨. 식 (10.150)에서 $\dfrac{W}{L} = \dfrac{2I_{SS}}{\mu_n C_{ox}\Delta V_{in,max}^2}$ (식 10.152) $= 133.6$ (식 10.153). 부하 저항 값은 요구되는 전압 이득으로 정해짐

## 풀이
### 테일 전류
- 전력 $= V_{DD} I_{SS}$이므로 $I_{SS} \le 3\ \text{mW}/1.8\ \text{V} = 1.67\ \text{mA}$
- 전력 한계를 다 쓰도록 $I_{SS} = 1.67\ \text{mA}$로 잡는다 (같은 $\Delta V_{in,max}$에서 전류가 클수록 $g_m$이 크다)
### 종횡비
- $\Delta V_{in,max} = \sqrt{\dfrac{2I_{SS}}{\mu_n C_{ox} W/L}}$ → $\dfrac{W}{L} = \dfrac{2I_{SS}}{\mu_n C_{ox}\Delta V_{in,max}^2}$
- $\dfrac{W}{L} = \dfrac{2(1.67\ \text{mA})}{(100\ \mu\text{A/V}^2)(0.5\ \text{V})^2} = 133$
### 부하 저항
- 조건에 이득 사양이 없으므로 $R_D$는 요구되는 전압 이득 $g_m R_D$로 정한다
### 답
- $I_{SS} = 1.67\ \text{mA}$, $W/L \approx 133$ ($R_D$는 요구 이득으로 정함)
