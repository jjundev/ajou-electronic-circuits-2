# 예제 10.28 — 그림 10.48 회로의 CMRR

## 원문
그림 10.48 회로의 CMRR을 계산하라.

## 조건
- 회로: Fig 10.48 (예제 10.27과 같은 회로, 새 그림 없음)
- 예제 10.27의 가정($Q_1$, $Q_2$의 $V_A = \infty$) 유지 (원문에 없음)
- 소자 값은 주어지지 않음 (답은 기호로) (원문에 없음)

## 구할 것
- 회로의 CMRR

## 상속·참조
- 식 (10.195): 공통 모드 제거비 $\text{CMRR} = \dfrac{A_{DM}}{A_{CM-DM}}$ (본문 547쪽: $A_{DM}$은 차동 이득)
- 예제 10.27 (E10.27): $A_{CM-DM} = \dfrac{\Delta R_C}{\dfrac{1}{g_{m1}} + 2\{[1 + g_{m3}(R_1 \| r_{\pi 3})] r_{O3} + R_1 \| r_{\pi 3}\}}$ (식 10.194)

## 답 (검증용)
- 작은 미스매치(예: 1%)에서 $\Delta R_C \ll R_C$이고 차동 이득은 $g_{m1} R_C$ → $\text{CMRR} = \dfrac{g_{m1} R_C}{\Delta R_C}\left\{\dfrac{1}{g_{m1}} + 2[1 + g_{m3}(R_1 \| r_{\pi 3})] r_{O3} + 2(R_1 \| r_{\pi 3})\right\}$ (식 10.196)

## 풀이
### CMRR의 정의
- $\text{CMRR} = \dfrac{A_{DM}}{A_{CM-DM}}$ ($A_{DM}$: 차동 이득)
### 차동 이득
- 차동 입력에서 $P$는 가상 접지라 각 쪽은 CE 단이다
- 미스매치가 작아($\Delta R_C \ll R_C$, 예: 1%) 부하를 $R_C$로 보면 $A_{DM} = g_{m1} R_C$
### 공통 모드에서 차동으로의 이득
- 예제 10.27에서 $A_{CM-DM} = \dfrac{\Delta R_C}{1/g_{m1} + 2R_{out3}}$, $R_{out3} = [1 + g_{m3}(R_1 \parallel r_{\pi 3})]\, r_{O3}$ (테일 $Q_3$의 출력 저항)
### CMRR
- $\text{CMRR} = \dfrac{g_{m1} R_C}{\Delta R_C}\left(\dfrac{1}{g_{m1}} + 2R_{out3}\right)$
- 테일의 출력 저항을 키우거나 미스매치 $\Delta R_C/R_C$를 줄이면 CMRR이 커진다
### 답
- $\text{CMRR} = \dfrac{g_{m1} R_C}{\Delta R_C}\left\{\dfrac{1}{g_{m1}} + 2[1 + g_{m3}(R_1 \parallel r_{\pi 3})]\, r_{O3}\right\}$
