# 연습문제 12.35 — ω_p1 = ω_p2인 3극점 시스템의 크기·위상 응답 (예제 12.35 변형)

## 원문
$\omega_{p1} = \omega_{p2}$일 때 3개의 극점을 갖는 시스템에 대한 위의 해석을 반복하라.

## 조건
- 예제 12.35 (c): 3개의 극점 $\omega_{p1}$, $\omega_{p2}$, $\omega_{p3}$을 갖는 증폭기의 크기와 위상 응답
- 바뀐 점: $\omega_{p1} = \omega_{p2}$ (겹친 극점), $\omega_{p3}$은 그보다 높은 주파수 (원문에 없음)
- 영점은 없고 극점은 좌반면에 있다고 봄 (원문에 없음)
- 보데의 규칙 (본문 12.8.1절): 크기의 기울기는 주파수가 극점을 지날 때마다 20 dB/dec씩 감소. 위상은 극점 주파수의 1/10부터 감소하기 시작해 극점 주파수에서 −45°, 10배에서 거의 −90°만큼 바뀜 (본문 규칙, 원문에 없음)

## 구할 것
- $\omega_{p1} = \omega_{p2}$인 3극점 시스템의 크기 응답 $20\log|H|$와 위상 응답 $\angle H$ (예제처럼 위상이 $-180^\circ$가 되는 주파수 $\omega_1$에 대한 관찰 포함) (괄호 안은 원문에 없음)

## 상속·참조
- 예제 12.35 (E12.35): 극점이 1개, 2개, 3개인 시스템의 위상 시프트는 각각 점근적으로 $-90^\circ$, $-180^\circ$, $-270^\circ$. 3극점 시스템은 유한한 주파수 $\omega_1$에서 $-180^\circ$의 위상 시프트를 가져 입력 정현파의 부호를 바꿈. 예제 그림(Fig 12.64(c))은 세 극점이 떨어져 있어 크기가 $\omega_{p1}$, $\omega_{p2}$, $\omega_{p3}$에서 차례로 꺾이고 위상이 $-90^\circ$, $-180^\circ$ 근처에서 계단을 이룸 (그림 12.64는 예제의 풀이 그림, 이 파일에는 넣지 않음)

## 회로 — 없음 (그림 없는 글 문제, 예제 12.35의 그림 12.64는 풀이 그림)
