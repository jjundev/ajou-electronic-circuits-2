# 장말문제 10.42 — 예제 10.16을 공급 전압 2 V로 다시 설계, V_DD와 W/L의 트레이드오프

## 원문
Repeat Example 10-16 for a supply voltage of $2\ \text{V}$. Formulate the trade-off between $V_{DD}$ and $W/L$ for a given output common-mode level.

## 조건
- 예제 10.16을 공급 전압 $V_{DD} = 2\ \text{V}$로 되풀이 (원문 표기 "Example 10-16")
- 나머지 조건은 예제 10.16과 같음 (아래 상속·참조) (원문에 없음, 원문은 "Repeat Example 10-16"만 적음)

## 구할 것
- $V_{DD} = 2\ \text{V}$에서 예제 10.16의 설계 ($I_{SS}$, $R_D$, $W/L$) (괄호 안은 원문에 없음)
- 주어진 출력 공통 모드 레벨에서 $V_{DD}$와 $W/L$ 사이의 트레이드오프를 식으로 정리

## 상속·참조
- 예제 10.16 (E10.16): 전압 이득 $5$, 한계 전력 소모 $2\ \text{mW}$인 NMOS 차동쌍 설계. 다음 단이 적어도 $1.6\ \text{V}$의 입력 공통 모드 레벨을 요구(즉 차동쌍 출력 CM 레벨 $\ge 1.6\ \text{V}$) (괄호 안은 원문에 없음). $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $\lambda = 0$, $V_{DD} = 1.8\ \text{V}$
- 예제 10.16 풀이 과정 ($V_{DD} = 1.8\ \text{V}$):
  - 전력 한계와 공급 전압에서 $I_{SS} = 1.11\ \text{mA}$ (10.123) (전력 $= V_{DD} I_{SS}$) (괄호 안은 원문에 없음)
  - 출력 CM 레벨 $V_{CM,out} = V_{DD} - R_D\dfrac{I_{SS}}{2}$ (10.124) $= 1.6\ \text{V}$ → 각 저항 전압 강하 $\le 200\ \text{mV}$ → $R_D = 360\ \Omega$ (10.125)
  - $g_m R_D = 5$ (이득 식 $A_v = -g_m R_D$, 10.122), $g_m = \sqrt{2\mu_n C_{ox}\dfrac{W}{L}\dfrac{I_{SS}}{2}}$ (10.126) → $W/L = 1738$ (10.127)

## 회로 — 없음 (설계 문제, 문제 그림 없음)

## 풀이
### 테일 전류와 부하 저항
- 예제 10.16의 조건(이득 5, 전력 2 mW, 출력 CM $\ge 1.6\ \text{V}$, $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $\lambda = 0$)을 그대로 쓴다
- $I_{SS} = 2\ \text{mW}/2\ \text{V} = 1.00\ \text{mA}$, 각 트랜지스터 $I_D = 0.500\ \text{mA}$
- $R_D$ 강하 $\le 2\ \text{V} - 1.6\ \text{V} = 0.4\ \text{V}$ → $R_D = 0.4\ \text{V}/0.5\ \text{mA} = 800\ \Omega$ (필요한 $g_m$을 줄이려고 최댓값)
### 종횡비
- $g_m = 5/R_D = 5/800\ \Omega = 6.25\ \text{mS}$
- $\dfrac{W}{L} = \dfrac{g_m^2}{2\mu_n C_{ox} I_D} = \dfrac{(6.25\ \text{mS})^2}{2(100\ \mu\text{A/V}^2)(0.5\ \text{mA})} = 391$
### $V_{DD}$와 $W/L$의 트레이드오프
- 전력 $P$, 이득 $A_v$, 출력 CM 레벨 $V_{CM,out}$로 두면 $I_{SS} = P/V_{DD}$, $R_D = \dfrac{2(V_{DD} - V_{CM,out})}{I_{SS}}$
- $\dfrac{W}{L} = \dfrac{(A_v/R_D)^2}{\mu_n C_{ox} I_{SS}} = \dfrac{A_v^2 P}{4\mu_n C_{ox} V_{DD} (V_{DD} - V_{CM,out})^2}$
- $V_{DD}$를 1.8 V에서 2 V로 올리면 $W/L$이 $1.74 \times 10^3$에서 391로 준다. 공급 전압을 올리면 $R_D$에 쓸 전압이 늘어 작은 소자로 되고, 낮추면 $W/L$이 급격히 커진다
### 답
- $I_{SS} = 1.00\ \text{mA}$, $R_D = 800\ \Omega$, $W/L \approx 391$
- $\dfrac{W}{L} = \dfrac{A_v^2 P}{4\mu_n C_{ox} V_{DD} (V_{DD} - V_{CM,out})^2}$로, $V_{DD}$가 $V_{CM,out}$에 가까울수록 $W/L$이 커진다
