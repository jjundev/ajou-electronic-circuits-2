# 장말문제 11.44 — 게이트를 함께 묶고 R_S로 구동하는 NMOS·PMOS 단(Fig 11.86)의 전달 함수 (밀러 이론 없이)

## 원문
Compute the transfer function of the circuit shown in Fig. 11.86 without using Miller's theorem. Assume $\lambda > 0$.

## 조건
- 회로: Fig 11.86 — $V_{in}$이 $R_S$를 거쳐 $M_1$(NMOS)과 $M_2$(PMOS)의 게이트에 함께 들어가고, 두 드레인이 함께 $V_{out}$
- $\lambda > 0$으로 가정

## 구할 것
- 밀러 이론을 쓰지 않고 회로의 전달 함수 $V_{out}/V_{in}$ 계산

## 회로 — Fig 11.86
```spice
RS  Vin   n1    {R_S}
M2  Vout  n1    VDD   pmos
M1  Vout  n1    0     nmos
```
- 단자: VDD = 전원, 값 미지정 (T 전원 기호) / Vin = 입력 (개방 원) / Vout = 출력 (개방 원)
- 표시: 노드 라벨 V_DD (T 기호 오른쪽), V_in (입력 원 왼쪽), V_out (출력 원 오른쪽) / 소자 라벨 R_S (저항 위), M2 (M2 오른쪽), M1 (M1 오른쪽, 소스 옆) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 가운데 세로줄 위→아래 V_DD T 기호, M2, 출력 접속점, M1, 접지 / M2 PMOS(게이트 왼쪽, 소스 위 → V_DD, 소스 화살표 게이트 쪽), M1 NMOS 보통 방향(게이트 왼쪽, 소스 아래·화살표 바깥 → 접지) / V_in 원 → 가로 R_S → 게이트 접속점 / 게이트 접속점에서 세로선이 위로 M2 게이트 높이까지 올라가 오른쪽으로 꺾여 M2 게이트, 아래로 M1 게이트 높이까지 내려가 오른쪽으로 꺾여 M1 게이트 / 출력 접속점 → 가로선 → V_out 원 / 접속점 (세 갈래 이상, 2곳): ① 게이트 = 왼쪽 R_S + 위 M2 게이트로 가는 선 + 아래 M1 게이트로 가는 선 (점) ② 출력 = 위 M2 드레인 + 아래 M1 드레인 + 오른쪽 V_out 선 (점) / 교차: 없음
