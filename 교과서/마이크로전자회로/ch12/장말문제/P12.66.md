# 장말문제 12.66 — 문제 12.65를 K = 0.5로 반복 (단일 극점 회로의 위상 마진)

## 원문
Repeat Problem 12.65 for $K = 0.5$.

## 조건
- 문제 12.65를 귀환율 $K = 0.5$로 되풀이
- 문제 12.65에서 이어받는 조건: 극점이 하나인 회로의 개루프 전달 함수 $H(s) = \dfrac{A_0}{1 + s/\omega_0}$ (식 12.202), 이 회로를 쓴 귀환 회로망 (원문에 없음)
- 식 (12.195): $\text{Phase Margin} = \angle H(\omega_{GX}) + 180^\circ$ ($\omega_{GX}$: 루프 이득 $|KH|$가 1이 되는 이득 교차 주파수) (본문 식, 원문에 없음)

## 구할 것
- $K = 0.5$일 때 귀환 회로망의 위상 마진 (원문에 없음, 원문은 "Repeat Problem 12.65"만 적음)

## 상속·참조
- 문제 12.65: 극점이 하나인 회로의 개루프 전달 함수가 $H(s) = \dfrac{A_0}{1 + \dfrac{s}{\omega_0}}$ (12.202)일 때, 이 회로를 쓴 $K = 1$ 귀환 회로망의 위상 마진을 구함
- 식 (12.195) (교재 711쪽, 12.8.4 위상 마진): $\text{Phase Margin} = \angle H(\omega_{GX}) + 180^\circ$. $K$에는 위상 편이가 없으므로 $\angle KH = \angle H$로 둠
