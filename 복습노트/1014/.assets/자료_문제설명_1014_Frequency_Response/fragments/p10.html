문제를 읽어요

입력 쪽과 출력 쪽의 두 극점이 같은 주파수에 있을 때, 전체 이득이 얼마나 일찍 줄어드는지 찾는 문제예요.

구할 것은 공통 극점 주파수 자체가 아니라 전체 이득 크기가 저주파 값의 $1/\sqrt2$가 되는 주파수예요.

이 개념과 공식을 떠올려요

단서는 $\omega_{p1}=\omega_{p2}$라는 조건이에요.

예제 11.8의 두 극점 크기 응답에서 같은 인자 두 개를 묶으면 되므로 회로를 다시 전개할 필요가 없어요.

양의 공통 코너 각주파수를 $\omega_p$로 정해요.

저주파 전압이득을 $A_0$라고 쓰고 크기 응답을 $|A_0|$로 나누면, 저주파에서 1인 정규화 응답(normalized response)이 돼요.

전압 이득에서 교과서의 −3 dB 기준은 진폭이 $1/\sqrt2$가 되는 것이에요.

예를 들어 $\omega=\omega_p$에서는 각 극점이 $1/\sqrt2$배를 만들므로, 두 인자를 곱한 전체 진폭은 $1/2$이에요.

따라서 전체 −3 dB 지점은 $\omega_p$에 도착하기 전에 나타나요.

예제의 $\lambda=0$인 입력·출력 두 RC 모델을 그대로 사용하며 다른 커패시턴스는 추가하지 않아요.

입력 RC가 있는 CS 단의 두 극점에서 얻은 크기 식을 출발점으로 써요.

종이에 쓸 첫 줄

예제의 크기 식을 저주파 값으로 나눈 뒤 두 극점을 같게 놓아요.

$$\frac{|H(j\omega)|}{|A_0|}=\frac{1}{\sqrt{\left[1+(\omega/\omega_{p1})^2\right]\left[1+(\omega/\omega_{p2})^2\right]}}$$ $$\omega_{p1}=\omega_{p2}=\omega_p$$

이렇게 풀어요

같은 두 인자를 먼저 합쳐요

정규화 크기를 $M(\omega)=|H(j\omega)|/|A_0|$로 간단히 적어요.

같은 양을 두 번 곱한 제곱근이며 $1+(\omega/\omega_p)^2$는 양수예요.

$$\begin{aligned}M(\omega)&=\frac{1}{\sqrt{\left[1+(\omega/\omega_p)^2\right]^2}}\\&=\frac{1}{1+(\omega/\omega_p)^2}\end{aligned}$$
전체 응답에 −3 dB 조건을 걸어요
$$\frac{1}{1+(\omega_{3\mathrm{dB}}/\omega_p)^2}=\frac{1}{\sqrt2}$$

양변의 역수를 취하고 1을 빼요.

$$1+(\omega_{3\mathrm{dB}}/\omega_p)^2=\sqrt2$$ $$\left(\frac{\omega_{3\mathrm{dB}}}{\omega_p}\right)^2=\sqrt2-1$$

찾는 각주파수는 양수이므로 양의 제곱근을 골라요.

$$\omega_{3\mathrm{dB}}=\sqrt{\sqrt2-1}\,\omega_p\approx0.64\,\omega_p$$

계산에는 $0.64$가 아니라 정확한 $\sqrt{\sqrt2-1}$을 유지해요.

공통 극점의 회로값 표현은 예제에서 이미 구한 값이에요.

$$\omega_p=\frac{1}{R_SC_{in}}=\frac{1}{R_DC_L}$$

완성 답과 검산

같은 두 극점의 전체 −3 dB 각주파수예요.

$$\omega_{3\mathrm{dB}}=\sqrt{\sqrt2-1}\,\omega_p\approx0.64\,\omega_p$$ $$\omega_p=\frac{1}{R_SC_{in}}=\frac{1}{R_DC_L}$$

예제 11.8의 $\lambda=0$인 두 RC 모델과 $R_SC_{in}=R_DC_L$ 조건을 사용해요.

정확한 근호 값을 원래 정규화 크기 식에 다시 넣어요.

$$M(\omega_{3\mathrm{dB}})=\frac{1}{1+(\sqrt2-1)}=\frac{1}{\sqrt2}$$ $$20\log_{10}\frac{1}{\sqrt2}\approx-3.01\,\mathrm{dB}$$

공통 코너 $\omega_p$에 대입하면 진폭은 절반이므로 같은 지점이 아니에요.

$$M(\omega_p)=\frac{1}{1+1}=\frac12$$ $$20\log_{10}\frac12\approx-6.02\,\mathrm{dB}$$

$0\lt\sqrt{\sqrt2-1}\lt1$이므로 전체 대역폭이 공통 코너보다 낮다는 예상과 맞아요.

배율은 무차원이므로 $\omega_{3\mathrm{dB}}$와 $\omega_p$는 둘 다 rad/s 단위예요.

Hz로 비교하더라도 두 주파수를 똑같이 $2\pi$로 나누므로 $f_{3\mathrm{dB}}/f_p$의 배율은 같아요.

주의할 점

  • 극점 하나일 때의 $\omega_{3\mathrm{dB}}=\omega_p$를 두 극점에 그대로 쓰지 않아요.
  • 같은 인자 두 개의 크기를 곱했으므로 분모는 $1+(\omega/\omega_p)^2$예요. 바깥 제곱근을 한 번 더 남기지 않아요.
  • −3 dB는 진폭 절반이 아니에요. 이 회로에서 진폭 절반은 공통 코너의 약 −6.02 dB예요.
  • $\omega_p$는 양의 코너 각주파수예요. 전달 함수의 음의 극점 위치와 혼동하지 않아요.

조건을 바꾸어 생각해요

  1. 처음에는 두 극점이 같아요. $R_S,R_D,C_L,g_m$을 고정하고 $C_{in}$만 절반으로 줄이면 더 이상 두 극점이 같지 않아요. 원래의 공통 주파수로 $x=\omega/\omega_p$를 정의해 새로운 −3 dB 조건을 써 보고, 전체 대역폭이 원래보다 커지는지 판단해 보세요.

같은 두 극점의 감쇠가 곱해지므로 전체 −3 dB 지점은 공통 코너보다 낮아요.

예제의 $\lambda=0$인 두 RC 모델과 동일 극점 조건을 사용해요.

  • 정규화 크기$$M(\omega)=\frac{1}{1+(\omega/\omega_p)^2}$$
  • 전체 3 dB 경계$$\begin{aligned}\omega_{3\mathrm{dB}}&=\sqrt{\sqrt2-1}\,\omega_p\\&\approx0.64\,\omega_p\end{aligned}$$

$\omega_p$에서의 전체 감쇠는 약 −6.02 dB예요.
