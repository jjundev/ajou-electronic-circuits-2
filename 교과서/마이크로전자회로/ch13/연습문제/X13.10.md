# 연습문제 13.10 — R_S를 무시하지 않을 때의 ω_2/ω_1

## 원문
$R_S$를 무시할 수 없다고 가정할 경우, $\omega_2/\omega_1$에 대한 식을 유도하라.

## 조건
- 예제 13.10과 같은 크리스털 모델 (본문 Fig 13.30(c)): 두 단자 사이에 $C_2$가 있고, 그와 병렬로 $R_S$, $C_1$, $L_1$이 직렬로 이어진 가지가 있음 (원문에 없음)
- 바뀐 점: $R_S$를 무시할 수 없음
- 직렬 공진 주파수 $\omega_1 = \dfrac{1}{\sqrt{L_1 C_1}}$ (본문 정의, 원문에 없음)
- $\omega_2$는 $Z_{cr}$의 병렬 공진 주파수, $R_S$를 무시하면 식 (13.48) $\omega_2 = \dfrac{1}{\sqrt{L_1 \dfrac{C_1 C_2}{C_1 + C_2}}}$ (본문 식, 원문에 없음)
- 식 (13.46): $Z_{cr}(j\omega) = Z_S(j\omega) \parallel \dfrac{1}{jC_2\omega}$, $Z_S = R_S + \dfrac{1}{jC_1\omega} + jL_1\omega$ (본문 식, 원문에 없음)

## 구할 것
- $R_S$를 무시하지 않을 때 $\omega_2/\omega_1$에 대한 식 유도

## 상속·참조
- 예제 13.10 (E13.10): $R_S$를 무시하면 $\dfrac{\omega_2}{\omega_1} = \sqrt{\dfrac{C_1 + C_2}{C_2}}$ (식 13.52), $C_2 \gg C_1$이면 $\approx 1 + \dfrac{C_1}{2C_2}$ (식 13.53)
- 본문 Fig 13.30(c) (교재 757쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig13-30-c.png): 완벽한 모델. `C2: 단자1 — 단자2`, `RS: 단자1 — n1`, `C1: n1 — n2`, `L1: n2 — 단자2`, 단자 쪽 임피던스 $Z_{cr}$
- 본문 Fig 13.30(b), 13.6.1절: $Z_S$ = $R_S$, $C_1$, $L_1$ 직렬, $\omega_1$에서 $jL_1\omega + 1/(jC_1\omega) = 0$이 되어 $Z_S = R_S$
- 식 (13.46)–(13.47): $R_S$를 무시하면 $Z_{cr} \approx \dfrac{1 - L_1 C_1 \omega^2}{j\omega(C_1 + C_2 - L_1 C_1 C_2 \omega^2)}$

## 회로 — 없음 (본문 크리스털 모델의 식을 쓰는 문제, 연습문제에 그림 없음)
