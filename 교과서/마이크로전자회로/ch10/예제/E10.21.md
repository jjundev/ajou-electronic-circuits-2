# 예제 10.21 — 식 (10.156)에서 차동 전압 이득 유도

## 원문
식 (10.156)이 차동 전압 이득 또한 산출할 수 있음을 증명하라.

## 조건
- MOS 차동쌍의 작은 차동 입력 근사식 (10.156)
- 식 (10.156): $|V_{in1} - V_{in2}|^2 \ll \dfrac{4I_{SS}}{\mu_n C_{ox} W/L}$이면 $I_{D1} - I_{D2} \approx \sqrt{\mu_n C_{ox}\tfrac{W}{L} I_{SS}}\,(V_{in1} - V_{in2})$ (본문 식, 원문에 없음)
- 식 (10.132): 부하 $R_D$ 두 개, 테일 $I_{SS}$인 쌍에서 $V_{out1} - V_{out2} = -R_D(I_{D1} - I_{D2})$ (본문 식, 원문에 없음)
- 평형에서 각 트랜지스터 $I_D = I_{SS}/2$, $g_m = \sqrt{2\mu_n C_{ox}\tfrac{W}{L} I_D}$ (원문에 없음)
- 소자 값은 주어지지 않음 (답은 기호로) (원문에 없음)

## 구할 것
- 식 (10.156)으로부터 차동 전압 이득도 구할 수 있음을 증명

## 상속·참조
- 식 (10.156): $|V_{in1} - V_{in2}|^2 \ll \dfrac{4I_{SS}}{\mu_n C_{ox}\frac{W}{L}}$ (식 10.154)이면 $I_{D1} - I_{D2} \approx \sqrt{\mu_n C_{ox}\tfrac{W}{L} I_{SS}}\,(V_{in1} - V_{in2})$
- 식 (10.132): $V_{out1} - V_{out2} = -R_D(I_{D1} - I_{D2})$ (본문 Fig 10.31의 쌍: 부하 $R_D$ 두 개, 테일 $I_{SS}$)
- 평형에서 각 트랜지스터 $I_D = I_{SS}/2$, $g_m = \sqrt{2\mu_n C_{ox}\tfrac{W}{L} I_D}$

## 회로 — 없음 (그림 없는 증명 문제)

## 답 (검증용)
- $V_{out1} - V_{out2} = -R_D(I_{D1} - I_{D2})$이고 $g_m = \sqrt{\mu_n C_{ox}(W/L) I_{SS}}$ (각 트랜지스터 전류가 $I_{SS}/2$이므로) (원문에 없음, 원문은 "왜 그럴까?"라고만 적음)라서, 식 (10.156)에서 $V_{out1} - V_{out2} = -R_D\sqrt{\mu_n C_{ox}\tfrac{W}{L} I_{SS}}\,(V_{in1} - V_{in2})$ (식 10.166) $= -g_m R_D (V_{in1} - V_{in2})$ (식 10.167). 소신호 동작은 식 (10.147)의 입출력 특성을 평형점 주변의 직선(식 10.156)으로 근사한 것

## 풀이
### 차동 출력과 드레인 전류 차
- 부하 저항 $R_D$ 두 개와 테일 $I_{SS}$를 가진 쌍에서 $V_{out1} = V_{DD} - R_D I_{D1}$, $V_{out2} = V_{DD} - R_D I_{D2}$
- 빼면 $V_{out1} - V_{out2} = -R_D (I_{D1} - I_{D2})$
### 식 (10.156) 대입
- 작은 차동 입력에서 $I_{D1} - I_{D2} \approx \sqrt{\mu_n C_{ox}\tfrac{W}{L} I_{SS}}\,(V_{in1} - V_{in2})$
- $V_{out1} - V_{out2} = -R_D \sqrt{\mu_n C_{ox}\tfrac{W}{L} I_{SS}}\,(V_{in1} - V_{in2})$
### 계수는 $g_m$
- 평형에서 각 트랜지스터는 $I_D = I_{SS}/2$를 흘리므로 $g_m = \sqrt{2\mu_n C_{ox}\tfrac{W}{L}\cdot\tfrac{I_{SS}}{2}} = \sqrt{\mu_n C_{ox}\tfrac{W}{L} I_{SS}}$
- 따라서 $\dfrac{V_{out1} - V_{out2}}{V_{in1} - V_{in2}} = -g_m R_D$로, 소신호 해석의 차동 이득과 같다
- 식 (10.156)은 큰 신호 특성을 평형점 둘레의 직선으로 근사한 것이라 그 기울기가 곧 소신호 이득이다
### 답
- $V_{out1} - V_{out2} = -R_D(I_{D1} - I_{D2})$에 식 (10.156)을 넣으면 계수 $\sqrt{\mu_n C_{ox}(W/L) I_{SS}}$가 평형점의 $g_m$과 같아 차동 이득 $-g_m R_D$가 나온다.
