# 연습문제 10.6 — 전력 한계 0.5 mW로 다시 설계하고 비교 (예제 10.6 변형)

## 원문
$0.5\ \text{mW}$의 한계 전력 소모를 갖는 회로로 다시 설계하고 결과를 비교하라.

## 조건
- 예제 10.6에서 전력 소모 한계만 $0.5\ \text{mW}$로 바꿈
- 나머지(공급 전압 $2\ \text{V}$, 이득 $10$)는 예제와 같음 (원문에 없음)

## 구할 것
- $0.5\ \text{mW}$ 한계로 회로를 다시 설계 — 정할 값: $I_{EE}$, $R_C$ (원문에 없음, 원문은 "다시 설계하라"만 적음)
- 예제 10.6의 결과와 비교

## 상속·참조
- 예제 10.6 (E10.06): $V_{CC} = 2\ \text{V}$, $1\ \text{mW}$ → $I_{EE} = 0.5\ \text{mA}$, 각 트랜지스터 $0.25\ \text{mA}$, $g_m = 0.25\ \text{mA}/26\ \text{mV} = (104\ \Omega)^{-1}$, $R_C = |A_v|/g_m = 1040\ \Omega$
- 식 (10.45): $A_v = -g_m R_C$, $g_m = I_C/V_T$ ($I_C = I_{EE}/2$, $V_T = 26\ \text{mV}$), 전력 = $V_{CC} I_{EE}$

## 회로 — 없음 (설계 문제, 문제 그림 없음)

## 풀이
### 테일 전류
- 전력 $= V_{CC} I_{EE}$이므로 $I_{EE} = 0.5\ \text{mW}/2\ \text{V} = 0.250\ \text{mA}$
- 각 트랜지스터 전류 $I_C = I_{EE}/2 = 0.125\ \text{mA}$
### 트랜스컨덕턴스
- 각 트랜지스터의 $g_m = I_C/V_T = 0.125\ \text{mA}/26\ \text{mV} = 4.81\ \text{mS} = (208\ \Omega)^{-1}$ ($V_T = 26\ \text{mV}$)
### 컬렉터 저항
- 차동 이득 $|A_v| = g_m R_C = 10$이므로 $R_C = 10/g_m = 2.08\ \text{k}\Omega$
### 예제 10.6과 비교
- 전력을 절반으로 줄이면 $I_{EE}$와 $g_m$이 절반($0.5 \to 0.25\ \text{mA}$)이 되어, 같은 이득을 얻으려면 $R_C$가 2배($1040\ \Omega \to 2080\ \Omega$)가 된다
- $R_C$에 걸리는 dc 전압 $R_C I_C = 0.26\ \text{V}$는 두 설계에서 같다
### 답
- $I_{EE} = 0.250\ \text{mA}$, $R_C = 2.08\ \text{k}\Omega$
- 예제 10.6과 비교하면 테일 전류는 절반, $R_C$는 2배이고 $R_C$의 dc 전압 강하($0.26\ \text{V}$)는 같다
