# 장말문제 12.65 — 단일 극점 회로로 만든 K = 1 귀환 회로망의 위상 마진

## 원문
Consider a one-pole circuit whose open-loop transfer function is given by

$$H(s) = \frac{A_0}{1 + \dfrac{s}{\omega_0}}. \qquad (12.202)$$

Determine the phase margin of a feedback network using this circuit with $K = 1$.

## 조건
- 극점이 하나인 회로의 개루프 전달 함수: $H(s) = \dfrac{A_0}{1 + s/\omega_0}$ (식 12.202)
- 이 회로를 써서 귀환율 $K = 1$인 귀환 회로망을 만듦
- 식 (12.195): $\text{Phase Margin} = \angle H(\omega_{GX}) + 180^\circ$ ($\omega_{GX}$: 루프 이득 $|KH|$가 1이 되는 이득 교차 주파수) (본문 식, 원문에 없음)

## 구할 것
- 귀환 회로망의 위상 마진

## 상속·참조
- 식 (12.195) (교재 711쪽, 12.8.4 위상 마진): $\text{Phase Margin} = \angle H(\omega_{GX}) + 180^\circ$. $K$에는 위상 편이가 없으므로 $\angle KH = \angle H$로 둠
