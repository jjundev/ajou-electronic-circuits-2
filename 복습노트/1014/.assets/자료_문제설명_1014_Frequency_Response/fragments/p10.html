문제를 내 말로 읽어요

그림 11.67은 그림 11.12의 CG 단에서 $M_1$ 소스와 직렬로 기생 저항이 생긴 회로예요. 문제 문장의 $R_p$는 그림 라벨 $R_P$와 같은 소자이고, 그림에 $M_1$ 라벨은 인쇄되어 있지 않아요. $V_{in}$이 $R_S$를 지나 $C_{in}$이 붙은 접점에 오고, 그 접점과 실제 소스 사이에 $R_P$가 있어요. $\lambda=0$, 다른 커패시턴스는 무시하고 입력·출력 극점을 기호로 구해요.

이 문제를 봤을 때 떠올릴 개념과 공식

“소스와 직렬인 기생 저항”은 CG 소스 입력 저항 $1/g_m$에 $R_P$가 직렬로 더해진다는 단서예요. $\lambda=0$이면 드레인에서 소스 쪽으로의 소신호 되먹임이 없고 몸체 효과도 무시해요. 입력원을 0으로 놓으면 $C_{in}$ 노드에서 AC 접지로 가는 길은 $R_S$와 $R_P+1/g_m$ 두 갈래이고, 둘은 병렬이에요. 출력 노드는 $\lambda=0$이라 여전히 $R_D$만 봐요.

종이에 쓰는 실제 첫 줄

$V_{DD}$와 $V_b$를 AC 접지로 보내고 $M_1$을 종속 전류원으로 바꿔요. $C_{in}$이 붙은 접점 전압을 $v_x$, 실제 소스를 $v_s$라 두면 $v_{gs}=-v_s$라서 $v_s$에서 드레인 쪽으로 $g_mv_s$가 흘러 나가요. $R_P$를 $v_x\to v_s$ 방향으로 흐르는 전류 $(v_x-v_s)/R_P$는 $v_s$ 노드에서 이 $g_mv_s$와 같아야 해요. $v_x$에서 나가는 전류는 $R_S$ 가지 $(v_x-v_{in})/R_S$, $C_{in}$ 가지 $sC_{in}v_x$, $R_P$ 가지 $(v_x-v_s)/R_P$예요.

$$v_s\text{ 노드: }\ \frac{v_x-v_s}{R_P}=g_mv_s$$

왜 이렇게 푸는지 함께 따라가요

첫 식을 $v_s$로 풀면 $v_x=(1+g_mR_P)v_s$, 곧 $v_s=v_x/(1+g_mR_P)$예요. 그래서 $R_P$ 가지 전류는 $g_mv_s=\dfrac{g_m v_x}{1+g_mR_P}=\dfrac{v_x}{R_P+1/g_m}$이에요. 이것을 $v_x$ 노드 KCL에 넣으면 $$\frac{v_x-v_{in}}{R_S}+sC_{in}v_x+\frac{v_x}{R_P+1/g_m}=0.$$ $v_x$의 계수는 $\dfrac1{R_S}+\dfrac1{R_P+1/g_m}+sC_{in}$이므로 $$\omega_{p,in}=\frac1{[R_S\parallel(R_P+1/g_m)]C_{in}}.$$ $v_{out}$ 노드는 $(1/R_D+sC_L)v_{out}-g_mv_s=0$이고 $\lambda=0$이라 소스 쪽 저항 변화가 드레인 출력 저항에 전달되지 않아 $\omega_{p,out}=1/(R_DC_L)$이에요. 실제 $s$ 극점은 둘 다 음수예요.

완성 답과 검산

입력은 $1/\{[R_S\parallel(R_P+1/g_m)]C_{in}\}$, 출력은 $1/(R_DC_L)$예요. $R_P\to0$이면 예제 11.9 CG 입력 식 $1/[(R_S\parallel1/g_m)C_{in}]$로 돌아와요. $R_P\to\infty$이면 입력 저항은 $R_S$로 가서 입력 극점은 $1/(R_SC_{in})$예요. $R_P$가 커질수록 병렬 합 저항이 증가하므로 입력 극점이 내려가요. $g_mR_P$는 무차원이라 $R_P+1/g_m$도 저항 단위가 맞아요.

여기서 조심해요

$R_P$를 $R_S$와 먼저 직렬로 합치지 않아요. $C_{in}$이 $R_S$와 $R_P$ 사이 접점 $v_x$에 붙어 있어 두 갈래를 분리해야 해요. $R_P$를 $1/g_m$과 병렬로 두는 것도 틀려요. 같은 전류가 $R_P$와 트랜지스터를 차례로 지나므로 직렬이에요. 출력 극점도 무조건 내려간다고 추정하지 않아요.

설명을 닫고 규칙을 적용해 봐요

  1. $C_{in}$이 보는 저항에서 $R_P$는 $1/g_m$과 직렬인가요, 병렬인가요? $R_S$와는요? 각각 같은 전류가 지나는지, 같은 두 노드 사이인지로 판단해 보세요.
  2. $R_S=1\,\mathrm{k\Omega}$, $1/g_m=100\,\Omega$, $C_{in}=1\,\mathrm{pF}$일 때 $R_P=100\,\Omega$이 생기면 입력 극점은 $R_P=0$일 때보다 몇 배가 되나요? 출력 극점은요?

입력 극점은 $1/\{[R_S\parallel(R_P+1/g_m)]C_{in}\}$, 출력은 $1/(R_DC_L)$예요. $R_P$가 커지면 입력 극점만 내려가요.

$C_{in}$은 $R_S$와 $R_P$ 사이 노드에 있어요. $\lambda=0$·몸체 효과와 다른 커패시턴스 무시에서 $R_P$와 $1/g_m$은 직렬, 그 합과 $R_S$는 병렬이에요.

핵심 개념·답

입력 $R_S\parallel(R_P+1/g_m)$, 출력 $R_D$

$R_P\to0$으로 원래 CG 회로 복원

첫 줄

$v_s$ 노드: $(v_x-v_s)/R_P=g_mv_s$

$v_x$ 노드 KCL에 $v_x/(R_P+1/g_m)$ 대입

검산

$R_P\to0$에서 예제 11.9 입력 극점, $R_P\to\infty$에서 $1/(R_SC_{in})$이에요.
