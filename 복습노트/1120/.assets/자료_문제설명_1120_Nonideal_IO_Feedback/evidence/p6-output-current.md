# P6 · E12.27 독립 검산

이상 꼬리전류원, 정합 차동쌍과 1:1 미러, 통상의 일차 소신호 근사를 사용한다. RΣ = R1+R2, K = R2/RΣ, RL = rOP ∥ rON ∥ RΣ. 오차 입력 vd = vin−K vout.

출력을 소신호 단락하면 vout = 0, M2 게이트도 0, vd = vin이다. vin > 0일 때 꼬리 전류가 일정하여 M1의 아래쪽 전류가 gmN vin/2만큼 늘고 M2의 아래쪽 전류는 같은 양만큼 준다. M3를 통해 늘어난 전류를 M4가 복사하므로 위에서 출력으로 공급하는 M4 전류가 gmN vin/2만큼 늘어난다. 따라서 출력에서 외부 단락으로 나가는 증분은 (+gmN vin/2)−(−gmN vin/2)=+gmN vin. 외부에서 증폭기로 들어가는 방향을 양으로 한 단락 전류는 −gmN vin이고 그 기준 Gm,sc = −gmN이다. RΣ 전류 증분은 단락 시 0이다.

출력을 열면 증폭기가 공급하는 전류 gmN vd가 RL에 전압을 만든다. 부하를 유지한 개루프 전압 이득 A0 = +gmN RL. vout = A0(vin−K vout)이므로 폐루프 이득 Acl = A0/(1+K A0). 게이트 전류가 0이므로 개·폐루프 Rin = ∞. 개루프 Rout = RL. vin = 0에서 출력에 vx를 인가하면 증폭기에 들어가는 시험전류 ix = vx/RL + gmN K vx이므로 폐루프 Rout = RL/(1+K A0). 미러의 유한 전달 오차 및 gm·ro의 역수 차수 효과는 일차 근사에서 생략했다.
