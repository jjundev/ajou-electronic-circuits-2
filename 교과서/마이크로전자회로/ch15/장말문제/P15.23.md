# 장말문제 15.23 — 고역통과 SK 필터의 소자별 Q 감도

## 조건
- 문제 15.22의 고역통과 SK 회로와 그 결과를 사용한다.
- 문제 15.22의 회로에서 $\omega_n=1/\sqrt{R_1R_2C_1C_2}$, $Q=\sqrt{R_1C_1C_2/R_2}/(C_1+C_2)$이다. (원문에 없음)

## 구할 것
- 각 회로 소자에 대한 $Q$의 감도를 계산한다.

## 상속·참조
- 문제 15.22에서는 직렬 커패시터 두 개, 접지 저항 및 되먹임 저항이 있는 Fig 15.61의 전달 함수와 $Q,\omega_n$을 구했다. 이번에는 기준 소자값에서 다른 소자값을 고정하고 $S_{x}^{Q}=(x/Q)(\partial Q/\partial x)$를 계산한다.

## 회로 — Fig 15.61
```spice
VIN Vin 0 {V_in}
C1 Vin n1 {C_1}
C2 n1 n2 {C_2}
R1 n2 0 {R_1}
R2 n1 Vout {R_2}
XA n2 Vout Vout opamp
```
- 단자: Vout = 출력 (개방 원) / Vin = 접지 기준 입력 전압원의 전압
- 표시: 노드 라벨 V_out / 소자 라벨 V_in, C_1, C_2, R_1, R_2, XA (라벨 없음) / 부호 입력 전압원은 위 +, 아래 −, 연산증폭기는 왼쪽 위 +, 아래 − / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 접지 전압원 위에서 가로 C_1, C_2를 차례로 지나 비반전 입력에 닿는다. 두 커패시터 중간 분기(점)에서 위로 R_2를 거쳐 출력 분기(점)에 귀환한다. C_2 오른쪽의 비반전 입력 분기(점) 아래에는 R_1과 접지가 있다. 반전 입력은 아래로 돌아 출력에 직접 연결한다. 교차: 없음
