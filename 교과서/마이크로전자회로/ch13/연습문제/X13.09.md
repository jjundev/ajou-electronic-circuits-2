# 연습문제 13.9 — 루프 이득 1이 되는 R_F/R_4

## 원문
발진 주파수에서 루프 이득이 1이 되도록 하려면 $R_F/R_4$는 어떤 값을 가져야 하는가?

## 조건
- 회로: Fig 13.25 (예제 13.9에서 설계한 연산 증폭기 위상 시프트 발진기, (a) $R_3$가 있는 회로, (b) $R_3$를 없앤 회로)
- 예제 13.9의 설계 조건: $C_1 = C_2 = C_3 = C$, (a)에서는 $R_3 \parallel R_4 = R_2 = R_1 = R$, (b)에서는 $R_3 \to \infty$, $R_4 = R$ (원문에 없음)
- 연산 증폭기는 이상적이라고 봄 (원문에 없음)
- 식 (13.35): 발진 주파수 $\omega_1 = \dfrac{1}{\sqrt{6}RC}$ (본문 식, 원문에 없음)
- 식 (13.36): 스타트업 조건은 식 (13.32)의 $\omega_1$에서의 크기에 증폭기 전압 이득 $A$를 곱한 값이 1, $\dfrac{(\sqrt{6})^{-3}A}{5/\sqrt{6} - (\sqrt{6})^{-3}} = 1$ (본문 식, 원문에 없음)

## 구할 것
- 발진 주파수에서 루프 이득이 1이 되는 $R_F/R_4$

## 상속·참조
- 예제 13.9 (E13.09): 연산 증폭기로 반전 증폭기를 구성. $R_4$가 노드 Z와 가상 접지 사이에 있어 $R_3$와 병렬로 보이므로 $R_3 \parallel R_4 = R_2 = R_1 = R$로 선택. $R_3$를 무한대, $R_4 = R$로 두면 Fig 13.25(b)
- 식 (13.32): $C_1 = C_2 = C_3 = C$, $R_1 = R_2 = R_3 = R$일 때 RC 회로망 전달 함수 $\dfrac{V_{out}}{V_{in}} = \dfrac{(RCs)^3}{(RCs)^3 + 6(RCs)^2 + 5RCs + 1}$
- 식 (13.35)–(13.37): $\omega_1 = 1/(\sqrt{6}RC)$, 스타트업에 필요한 증폭기 이득 $A = 29$

## 회로 — Fig 13.25(a)
```spice
C1  Vout  X     {C_1}
R1  X     0     {R_1}
C2  X     Y     {C_2}
R2  Y     0     {R_2}
C3  Y     Z     {C_3}
R3  Z     0     {R_3}
R4  Z     n1    {R_4}
RF  n1    Vout  {R_F}
XA  0     n1    Vout  opamp
```
- 단자: Vout = 출력 (개방 원)
- 표시: 노드 라벨 X, Y, Z (각 노드 위), V_out (출력 원 오른쪽) / 소자 라벨 C_1, C_2, C_3 (각 커패시터 위), R_1, R_2, R_3 (각 저항 오른쪽), R_4 (저항 위), R_F (저항 위), "−A_0" (점선 상자 왼쪽 위 바깥) / 부호 연산 증폭기 입력 − (위), + (아래) / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 가로 신호선 왼쪽→오른쪽 C_1, X, C_2, Y, C_3, Z, R_4, 연산 증폭기 − 입력 / X, Y, Z에서 각각 R_1, R_2, R_3가 아래로 내려가 접지 / 점선 사각 상자("−A_0")가 R_4, R_F, 연산 증폭기를 둘러쌈 (R_3·Z는 상자 왼쪽 밖) / R_F는 − 입력 접속점에서 위로 올라가 오른쪽으로 가로질러 출력 접속점으로 내려옴 / + 입력은 짧은 가로선 끝에서 아래로 접지 / 출력선 오른쪽으로 상자 밖 접속점을 지나 V_out 원에서 끝남 / 그 접속점에서 귀환선이 위로 올라가 그림 맨 위를 왼쪽으로 가로질러 왼쪽 끝에서 내려와 C_1 왼쪽에 이어짐 / 접속점 (세 갈래 이상, 6곳): ① X = C_1 + C_2 + 아래 R_1 (점) ② Y = C_2 + C_3 + 아래 R_2 (점) ③ Z = C_3 + 오른쪽 R_4 선 + 아래 R_3 (점) ④ − 입력 = 왼쪽 R_4 + 오른쪽 − 입력 + 위 R_F (점) ⑤ 연산 증폭기 출력 = 왼쪽 출력 + 위 R_F + 오른쪽 출력선 (점, 상자 안) ⑥ 상자 밖 = 왼쪽 출력선 + 위 귀환선 + 오른쪽 V_out 원 (점) / 교차: 없음
