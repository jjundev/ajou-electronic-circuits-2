# 연습문제 10.17 — V_TH = 0.2 V일 때 예제 10.17 결과의 유지 여부

## 원문
$V_{TH} = 0.2\ \text{V}$라면 위의 결과가 유지되는가?

## 조건
- 예제 10.17에서 $V_{TH} = 0.2\ \text{V}$ (예제는 $0.4\ \text{V}$)

## 구할 것
- 위의 결과(입력 CM 레벨을 $V_{DD}$에 둘 수 있다는 결과)가 유지되는지 (괄호 안 풀이는 원문에 없음)

## 상속·참조
- 예제 10.17 (E10.17): 예제 10.16 설계($V_{DD} = 1.8\ \text{V}$, $I_{SS} = 1.11\ \text{mA}$, $R_D = 360\ \Omega$, $V_{CM,out} = V_{DD} - R_D I_{SS}/2 = 1.6\ \text{V}$)에서 $M_1$, $M_2$ 포화 조건 $V_{CM,in} < V_{DD} - R_D \dfrac{I_{SS}}{2} + V_{TH} = V_{CM,out} + V_{TH}$ (식 10.128–10.129) → $V_{TH} = 0.4\ \text{V}$이면 $V_{CM,in} < 2\ \text{V}$ (식 10.130)이라 입력 CM 레벨이 $V_{DD}$에 있어도 됨

## 회로 — 없음 (그림 없는 글 문제, 예제의 그림 10.29는 풀이에만 있음)

## 풀이
### 출력 CM 레벨
- 예제 10.16 설계에서 $V_{CM,out} = V_{DD} - R_D \dfrac{I_{SS}}{2} = 1.8\ \text{V} - 360\ \Omega \times 0.556\ \text{mA} = 1.60\ \text{V}$
### 입력 CM 레벨의 상한
- $M_1$, $M_2$가 포화에 있으려면 게이트가 드레인보다 $V_{TH}$ 이상 높으면 안 된다: $V_{CM,in} < V_{CM,out} + V_{TH}$
- $V_{CM,in} < 1.6\ \text{V} + 0.2\ \text{V} = 1.80\ \text{V}$
### 판단
- 입력 CM 레벨을 $V_{DD} = 1.8\ \text{V}$에 두면 상한과 정확히 같아, $M_1$, $M_2$는 포화 경계($V_{GD} = V_{TH}$)에 놓인다
- 여유가 0이므로 신호가 조금만 들어와도 트라이오드로 들어간다
### 답
- 유지되지 않는다(경계). $V_{CM,in} < 1.80\ \text{V}$이므로 입력 CM을 $V_{DD}$에 두면 $M_1$, $M_2$가 포화 경계에 걸려 여유가 없다
