# 장말문제 15.54 — 감도가 1 이하인 30 MHz SK 저역통과 필터

## 조건
- 저역통과 SK 필터의 $-3\ \mathrm{dB}$ 대역폭은 $30\ \mathrm{MHz}$이고 저주파 이득은 2이다.
- 감도는 1 이하여야 한다.

## 구할 것
- 요구 대역폭·이득·감도를 만족하는 필터를 설계한다 (정할 값 예: RC 소자값과 귀환 저항비). (괄호 안은 원문에 없음)

## 상속·참조
- Fig 15.34는 저주파 이득을 정할 수 있는 본문의 SK 회로이다. 문제 문장은 감도를 적용할 파라미터나 소자 목록을 따로 지정하지 않는다. (원문에 없음)

## 회로 — Fig 15.34
```spice
VIN  Vin  0     {V_in}
R1   Vin  Y     {R_1}
R2   Y    X     {R_2}
C1   Y    Vout  {C_1}
C2   X    0     {C_2}
R3   Vout n1    {R_3}
R4   n1   0     {R_4}
XA   X    n1    Vout  opamp
```
- 단자: Vout = 출력 (개방 원) / Vin = 접지 기준 전압원 전압
- 표시: 노드 라벨 Y, X, V_out / 소자 라벨 V_in, R_1, R_2, R_3, R_4, C_1, C_2, XA (라벨 없음) / 부호 입력 전압원 위 +, 아래 −, 연산증폭기 왼쪽 위 +, 아래 − / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 전압원 위에서 가로 R_1, Y, R_2, X, 비반전 입력이 차례로 이어진다. Y(점)에서 위로 올라간 가지에 피드백 C_1이 있고, X(점)에서는 아래로 C_2를 거쳐 접지된다. 출력의 접속점(점)에 위쪽 C_1 선과 아래쪽 R_3 선이 닿는다. 아래쪽 반전 입력의 분기(점)는 오른쪽의 가로 R_3과 아래쪽 접지 R_4를 잇는다. 교차: 없음
