# 장말문제 15.27 — 저항 감도 소거와 저주파 이득 2의 동시 설계

## 조건
- Fig 15.36(b)의 KHN 저역통과 출력에 대해 목표 저주파 이득은 $\alpha=2$이다.
- $R_3$와 $R_6$에 대한 $Q$ 감도가 0이어야 한다.

## 구할 것
- 두 요구를 동시에 충족할 수 없는 이유를 설명한다.

## 상속·참조
- 본문 식 (15.102)의 $\alpha=[R_5/(R_4+R_5)](1+R_6/R_3)$는 고역통과 전달 함수의 분자 계수이고, 저역통과 출력 $Y$의 DC 이득은 $\alpha R_3/R_6$이다. 감도 소거 조건 $R_3=R_6$에서는 두 값이 일치한다. (기호 대응은 원문에 없음)

## 회로 — Fig 15.36(b)
```spice
R4 Vin n1 {R_4}
R5 X n1 {R_5}
R3 Y n2 {R_3}
R6 Vout n2 {R_6}
XA n1 n2 Vout opamp
R1 Vout n3 {R_1}
C1 X n3 {C_1}
XB 0 n3 X opamp
R2 X n4 {R_2}
C2 Y n4 {C_2}
XC 0 n4 Y opamp
```
- 단자: Vin = 입력 (개방 원) / Vout = 출력 (개방 원)
- 표시: 노드 라벨 V_in, V_out, X, Y / 소자 라벨 R_1–R_6, C_1, C_2, XA, XB, XC (증폭기 라벨 없음) / 부호 세 연산증폭기의 왼쪽 위 −, 아래 + / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 합산 증폭기의 비반전 입력 분기(점)에는 입력의 R_4와 아래쪽으로 X에서 돌아오는 R_5가 연결된다. 반전 입력 쪽(점)에는 옆 R_6 및 맨 위 Y에서 돌아오는 R_3이 닿는다. R_6 오른쪽 V_out 원의 분기(점)와 그 아래 합산기 출력 분기(점)를 세로선이 잇는다. 가운데와 오른쪽 적분기는 비반전 입력이 접지이며, 각 반전 입력의 분기(점)에는 가로 R_1·R_2와 위쪽 되먹임 C_1·C_2가 연결된다. X 출력 분기(점)에는 C_1, R_2, R_5 선이 닿고 Y 위쪽 분기(점)는 C_2와 R_3으로 이어진다. 교차: 없음
