# 장말문제 9.43 — 기준 전류 180 μA로 예제 9.15 다시 설계

## 원문
Repeat Example 9-15 if the reference current is equal to $180\ \mu\text{A}$.

## 조건
- 예제 9.15를 기준 전류 $I_{REF} = 180\ \mu\text{A}$로 바꿔 다시 풂

## 구할 것
- $180\ \mu\text{A}$ 기준 전류로 $50\ \mu\text{A}$와 $500\ \mu\text{A}$를 만드는 전류 거울 설계

## 상속·참조
- 예제 9.15 (교재 474쪽): 기준 전류 $I_{REF} = 200\ \mu\text{A}$ 하나로 두 전류 $50\ \mu\text{A}$와 $500\ \mu\text{A}$를 만드는 (바이폴라) 전류 거울 설계
  - 예제 풀이: 기준 쪽을 단위 트랜지스터 4개(총 $4A_E$), $Q_1 = A_E$ → $50\ \mu\text{A}$, $Q_2 = 10A_E$ → $500\ \mu\text{A}$
  - 베이스 전류는 무시 (예제 풀이에는 없고, 474쪽 예제 바로 뒤 본문 "베이스 전류의 효과"에서 지금까지 무시했다고 밝힘)
- 만들 전류 $50\ \mu\text{A}$, $500\ \mu\text{A}$는 예제 그대로 (원문에 없음)

## 회로 — 없음 (설계 문제, 문제 그림 없음)

## 풀이
### 전류비와 면적비
- 예제 9.15처럼 베이스 전류를 무시하면 같은 $V_{BE}$를 받는 트랜지스터의 컬렉터 전류는 이미터 면적에 비례한다
- $180$, $50$, $500\ \mu\text{A}$의 최대공약수는 $10\ \mu\text{A}$이므로 $10\ \mu\text{A}$를 흘리는 단위 트랜지스터(면적 $A_E$)로 짠다
### 트랜지스터 크기
- 다이오드 연결 기준 트랜지스터 $Q_{REF}$: $180/10 = 18$개 병렬, $18 A_E$
- $50\ \mu\text{A}$ 출력 $Q_1$: $5 A_E$ → $(5/18) \times 180\ \mu\text{A} = 50.0\ \mu\text{A}$
- $500\ \mu\text{A}$ 출력 $Q_2$: $50 A_E$ → $(50/18) \times 180\ \mu\text{A} = 500\ \mu\text{A}$
### 연결
- 예제와 같이 $I_{REF}$를 $Q_{REF}$에 넣어 다이오드 연결하고 $Q_1$, $Q_2$의 베이스를 그 노드에, 이미터를 접지에 붙인다. 예제의 $4 A_E : A_E : 10 A_E$ 대신 $18 A_E : 5 A_E : 50 A_E$가 된다
### 답
- $Q_{REF} = 18 A_E$(다이오드 연결), $Q_1 = 5 A_E$($50\ \mu\text{A}$), $Q_2 = 50 A_E$($500\ \mu\text{A}$)로 베이스를 공통으로 묶은 전류 거울.
