# 기출 선별 JSON 설계

사용자가 2026-10-21 승인한 설계와 문항 전체 채택 결정을 기록한다.

- MD는 수정 원본이다. `from_the_past/json/index.json`과 `problems/<id>.json`은 재생성한다.
- index는 주제·필요 개념·소문항 요약·의존성으로 후보를 좁히고 상세 JSON은 원문·조건·회로·힌트·풀이·출처를 보존한다.
- 전체 MD 문자열과 순서 있는 절 배열을 보존한다. 그림은 저장소 상대 경로로 기록한다.
- 기존 YAML에서 추출한 사실과 MD frontmatter의 `selection`에 기록한 해석 메타데이터를 구분한다. 해석에는 근거 절, 검토 상태, 해석 당시 내용 해시를 둔다. 미분류·오래된 분류는 숨기지 않는다.
- PDF에는 문항 전체만 채택한다. 소문항 하나라도 범위 밖이면 제외한다. 자작·수치 변형·소문항 절취는 하지 않는다.
- 풀이 없는 문항도 카탈로그에는 포함하나 복습문제 후보에서는 제외한다.
- 사용 이력은 실행마다 계산한다. 동일 range의 이전 선택은 USED에서 제외한다.
- 후보 JSON은 기존 TSV와 병행 지원한다. 선택 후에는 기존 manifest ID → problems.txt → workbook PDF / problem-explain MD 로딩 경로를 유지한다.
- 실행의 선택 근거·카탈로그 해시는 RUN/selection.json에 남긴다. 실제 수업 범위 일치는 AI가 전체 내용과 그림을 확인한다.
- 카탈로그 해시에는 MD·exam.yaml·그림 설정·실제 그림을 포함한다. 오래된 저장 JSON을 자동 신뢰하지 않는다.
- 복습팩 실행 중 저장소에 쓰지 않는다. 최신 카탈로그가 필요하면 RUN 아래 생성한다.
- 해설의 원문 대조·독립 검산·내용/브라우저 검토는 그대로 수행한다. JSON 분류는 검산 근거가 아니다.
- Python 3.10+, 기존 PyYAML과 표준 라이브러리만 사용한다. 커밋·푸시는 이번 요청에 포함하지 않는다.
