# 장말문제 10.90 — MOS 텔레스코픽 캐스코드(Fig 10.43(a)) 설계: 전압 이득 600, 4 mW, 필요한 λ_p

## 원문
Design the telescopic cascode of Fig. 10.43(a) for a voltage gain of 600 and a power budget of $4\ \text{mW}$. Assume an (equilibrium) overdrive of $100\ \text{mV}$ for the NMOS devices and $150\ \text{mV}$ for the PMOS devices. If $V_{DD} = 1.8\ \text{V}$, $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $\mu_p C_{ox} = 50\ \mu\text{A/V}^2$, and $\lambda_n = 0.1\ \text{V}^{-1}$, determine the required value of $\lambda_p$. Assume $M_1$-$M_4$ are identical and so are $M_5$-$M_8$.

## 조건
- 설계 대상: 본문 Fig 10.43(a)의 MOS 텔레스코픽 캐스코드
- 전압 이득 $600$
- 전력 예산 $4\ \text{mW}$
- (평형) 과구동: NMOS 소자 $100\ \text{mV}$, PMOS 소자 $150\ \text{mV}$
- $V_{DD} = 1.8\ \text{V}$, $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $\mu_p C_{ox} = 50\ \mu\text{A/V}^2$, $\lambda_n = 0.1\ \text{V}^{-1}$
- $M_1$–$M_4$는 서로 동일, $M_5$–$M_8$도 서로 동일

## 구할 것
- 회로 설계 (정할 값 예: $I_{SS}$, 각 $W/L$) (원문에 없음, 원문은 "설계하라"만 적음)
- 필요한 $\lambda_p$ 값

## 상속·참조
- 본문 (교재 541쪽): 완전한 CMOS 텔레스코픽 캐스코드 증폭기 Fig 10.43(a)는 부하 전류원으로 PMOS 캐스코드($M_5$–$M_8$)를 가짐. 절반 회로 Fig 10.43(b)($v_{in1}$ → $M_1$ 게이트, $M_1$ 드레인 → $M_3$ 소스, $M_3$ 드레인 = $v_{out1}$ = $M_5$ 드레인, $M_5$ 소스 → $M_7$ 드레인, $M_1$ 소스·$M_3$·$M_5$·$M_7$ 게이트·$M_7$ 소스는 교류 접지)로 해석. 식 (9.72)로부터
  $$A_v \approx -g_{m1}[(g_{m3}r_{O3}r_{O1}) \| (g_{m5}r_{O5}r_{O7})] \qquad (10.176)$$

## 회로 — Fig 10.43(a)
```spice
M7   n1    Vb3   VDD   pmos
M8   n2    Vb3   VDD   pmos    ; 게이트는 M7 게이트 높이의 가로선에서 옴
M5   out1  Vb2   n1    pmos
M6   out2  Vb2   n2    pmos    ; 게이트는 M5 게이트 높이의 가로선에서 옴
M3   out1  Vb1   n3    nmos
M4   out2  Vb1   n4    nmos    ; 게이트는 M3 게이트 높이의 가로선에서 옴
M1   n3    Vin1  n5    nmos
M2   n4    Vin2  n5    nmos    ; 좌우 반전 (게이트 오른쪽)
ISS  n5    0     {I_SS}
* Vb3, Vb2, Vb1 점 단자 → 각각 M7, M5, M3 게이트. 같은 높이의 가로선이 왼쪽 트랜지스터 기호(채널 막대 오른쪽)에서 시작해 오른쪽 M8, M6, M4 게이트까지 이어짐 → 게이트 공통으로 읽음
* n1 = M7 드레인–M5 소스, n2 = M8 드레인–M6 소스, n3 = M3 소스–M1 드레인, n4 = M4 소스–M2 드레인, n5 = 공통 소스(테일) 노드 (라벨 없음)
* out1, out2 = 두 출력 점에서 안쪽으로 이어진 개방 원. 두 원 사이에 "V_out" 라벨 하나 (차동 출력)
```
- 단자: VDD = 전원, 값 미지정 (가로 레일) / Vb1, Vb2, Vb3 = 바이어스, 값 미지정 (점 단자) / Vin1, Vin2 = 입력 (개방 원) / out1, out2 = 차동 출력 V_out (개방 원 두 개, 각 원 옆 라벨 없음)
- 표시: 노드 라벨 V_DD (레일 오른쪽 끝), V_b3, V_b2, V_b1 (각 점 단자 왼쪽), V_out (두 출력 원 사이), V_in1 (왼쪽 입력 원 왼쪽), V_in2 (오른쪽 입력 원 오른쪽) / 소자 라벨 M7 (M7 왼쪽 위), M8 (M8 왼쪽 위), M5 (M5 아래), M6 (M6 아래), M3 (M3 왼쪽 위), M4 (M4 오른쪽), M1 (M1 오른쪽), M2 (M2 왼쪽), I_SS (전류원 오른쪽) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 맨 위 굵은 가로 레일 V_DD / 왼쪽 세로줄 위→아래 M7, M5, 출력 점, M3, M1 / 오른쪽 세로줄 위→아래 M8, M6, 출력 점, M4, M2 / M7, M8, M5, M6 pmos 모두 보통 방향(게이트 왼쪽, 소스 위·화살표 안쪽) / M3, M4, M1 nmos 보통 방향(게이트 왼쪽), M2 nmos 좌우 반전(게이트 오른쪽) / 트랜지스터끼리는 세로선으로 바로 이어짐 (점 없음) / 각 출력 점에서 짧은 가로선이 안쪽으로 개방 원 (사이에 V_out 라벨) / V_in1 원 → M1 게이트, V_in2 원 → M2 게이트 / 두 소스는 꼬리 가로선 가운데 n5 점, n5에서 아래로 I_SS(화살표 아래), 그 아래 접지 / 접속점 (세 갈래 이상, 3곳): ① 왼쪽 출력 점 = 위 M5 드레인 + 아래 M3 드레인 + 오른쪽 출력선 (점) ② 오른쪽 출력 점 = 위 M6 드레인 + 아래 M4 드레인 + 왼쪽 출력선 (점) ③ n5 = 왼쪽 M1 소스 선 + 오른쪽 M2 소스 선 + 아래 I_SS (점) / 교차: 없음 (세 게이트 가로선은 왼쪽 트랜지스터 기호를 지나지만 도선과 교차하지 않음)

## 풀이
### 전류와 소신호 값
- $I_{SS} = P/V_{DD} = 4\ \text{mW}/1.8\ \text{V} = 2.22\ \text{mA}$, 모든 소자 $I_D = 1.11\ \text{mA}$
- $g_{mn} = 2I_D/0.1\ \text{V} = 22.2\ \text{mS}$, $g_{mp} = 2I_D/0.15\ \text{V} = 14.8\ \text{mS}$, $r_{On} = 1/(\lambda_n I_D) = 9.00\ \text{k}\Omega$
### $W/L$
- $(W/L)_{1\text{–}4} = \dfrac{2I_D}{\mu_n C_{ox}(0.1\ \text{V})^2} = 2.22 \times 10^3$, $(W/L)_{5\text{–}8} = \dfrac{2I_D}{\mu_p C_{ox}(0.15\ \text{V})^2} = 1.98 \times 10^3$
### 이득 식과 아래 저항
- 테일 가상 접지, 바이어스 교류 접지로 절반 회로는 $M_1$–$M_3$ 캐스코드와 $M_5$–$M_7$ 캐스코드 부하다. 축퇴 저항이 $r_O$라 1을 빼면 $|A_v| \approx g_{mn}[(g_{mn} r_{On}^2) \parallel (g_{mp} r_{Op}^2)]$
- 아래로 본 저항 $g_{mn} r_{On}^2 = 22.2\ \text{mS} \times (9.00\ \text{k}\Omega)^2 = 1.80\ \text{M}\Omega$
### $\lambda_p$
- 두 저항의 병렬 $= 600/g_{mn} = 27.0\ \text{k}\Omega$ → 위로 본 저항 $g_{mp} r_{Op}^2 = 27.4\ \text{k}\Omega$
- $r_{Op} = \sqrt{27.4\ \text{k}\Omega/14.8\ \text{mS}} = 1.36\ \text{k}\Omega$ → $\lambda_p = 1/(r_{Op} I_D) = 0.662\ \text{V}^{-1}$
- 정확식(절반 회로 노드 해석)으로는 $\lambda_p = 0.694\ \text{V}^{-1}$ ($g_{mp} r_{Op} = 20.2$로 크지 않아 약 5% 차이)
### 답
- $I_{SS} = 2.22\ \text{mA}$, $(W/L)_{1\text{–}4} = 2.22 \times 10^3$, $(W/L)_{5\text{–}8} = 1.98 \times 10^3$
- $\lambda_p \approx 0.662\ \text{V}^{-1}$
