# 연습문제 12.13 — $M_2$를 CG 단으로 바꿨을 때의 귀환 극성

## 원문
$M_2$가 CG 단으로 바뀌었을 때, 다시 말하면 소스가 노드 $A$에 연결되고 게이트가 바이어스 전압에 연결되었을 때 위의 예제를 다시 풀어라.

## 조건
- 예제 12.13과 같은 회로: Fig 12.29 (두 단 증폭기 $M_1$–$R_{D1}$, $M_2$–$R_{D2}$, 출력 $v_{out}$에서 $R_{F1}$–$R_{F2}$ 분배기, 가운데 노드 $X$가 $M_1$ 소스)
- 바뀐 점: $M_2$가 CG 단 — 소스가 노드 $A$에, 게이트가 바이어스 전압에 연결
- $M_2$의 드레인은 그대로 $R_{D2}$와 출력 $v_{out}$에 연결 (원문에 없음)
- 소자 값은 주어지지 않음 (답은 정성적 판정) (원문에 없음)

## 구할 것
- 귀환의 극성

## 상속·참조
- 예제 12.13 (E12.13): 원래 회로($M_2$가 CS 단)에서 $V_{in}$이 증가하면 $I_{D1}$이 증가하려 하고, $V_A$는 떨어지고 $V_{out}$은 올라가며 $V_X$도 올라감. $V_X$의 증가는 $I_{D1}$을 감소시켜 $V_{in}$이 만든 효과를 방해 → 부귀환
- 본문 12.5절: 입력 신호가 증가한다고 가정하고 순방향 증폭기와 귀환 회로망을 통하는 변화를 따라가, 반송된 양이 원래의 효과를 방해하는지 개선하는지 결정

## 회로 — Fig 12.29
```spice
* 그림은 바뀌기 전 회로 (문제 조건으로 M2의 소스는 A, 게이트는 바이어스 전압에 연결됨)
RD1  VDD   A     {R_D1}
RD2  VDD   vout  {R_D2}
M1   A     vin   X     nmos
M2   vout  A     0     nmos
RF1  vout  X     {R_F1}
RF2  X     0     {R_F2}
```
- 단자: VDD = 전원, 값 미지정 (가로 레일) / vin = 입력 (개방 원) / vout = 출력 (개방 원)
- 표시: 노드 라벨 V_DD (레일 오른쪽 끝), A (접속점 왼쪽), v_in (입력 원 왼쪽), v_out (출력 원 오른쪽), X (접속점 오른쪽) / 소자 라벨 R_D1, R_D2 (각 저항 오른쪽), M1 (오른쪽), M2 (오른쪽), R_F1, R_F2 (각 저항 오른쪽) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 맨 위 V_DD 가로 레일에 R_D1(왼쪽), R_D2(오른쪽)가 매달림 / 왼쪽 세로줄 R_D1 – A 접속점 – M1(보통 NMOS, 게이트 왼쪽 ← v_in 원) / A 접속점에서 가로선이 오른쪽 M2 게이트 / 가운데 세로줄 R_D2 – M2 드레인 접속점 – M2(보통 NMOS, 게이트 왼쪽) – 접지 / M2 드레인 접속점에서 가로선이 오른쪽으로 가서 vout 갈래 접속점, 다시 오른쪽 v_out 원 / 맨 오른쪽 세로줄 위→아래 vout 갈래, R_F1, X 접속점, R_F2, 접지 / M1 소스에서 세로선이 조금 내려가 오른쪽으로 꺾인 가로선이 M2 접지 아래를 지나 X 접속점에 닿음 / 접속점 (세 갈래 이상, 4곳): A (점), M2 드레인 (점), vout 갈래 (점), X (점) / 교차: 없음
