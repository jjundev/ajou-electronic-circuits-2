## 1. 4종 증폭기 종단 진리표 및 오조립 로딩 왜곡 (MNA 모델)

> 기준: 형태 표기는 **감지량-반송량** 순서(`V-V`, `V-C`, `C-V`, `C-C`). 이상적 임피던스는 **전압 입력 $\infty$, 전류 입력 $0$, 전압 출력 $0$, 전류 출력 $\infty$**이다.

| 모드 | 형태 | 감지 복제(출력 측) 남은 포트 (`sense-rem`) | 반송 복제(입력 측) 남은 포트 (`return-rem`) | 시험 귀환망 (MNA) | 정답 로딩 | 오조립 시 로딩 왜곡 |
|---|---|---|---|---|---|---|
| `vv` | V-V 전압 증폭기 ($A_0$) | **개방 (`open`)** — 원래 전압 입력 ($\infty$) | **단락/접지 (`short`)** — 원래 전압 출력 ($0$) | $R_1$–$R_2$ 분압기 ($3\ \text{k}\Omega, 1\ \text{k}\Omega$) | $R_{\text{load,out}} = R_1+R_2 = 4.00\ \text{k}\Omega$, $R_{\text{load,in}} = R_1\parallel R_2 = 0.75\ \text{k}\Omega$ | 감지 단락 → $R_1 = 3.00\ \text{k}\Omega$ ($-25.0\%$); 반송 개방 → $R_2 = 1.00\ \text{k}\Omega$ ($+33.3\%$) |
| `vc` | V-C 트랜스임피던스 ($R_0$) | **단락/접지 (`short`)** — 원래 전류 입력 ($0$) | **단락/접지 (`short`)** — 원래 전압 출력 ($0$) | 귀환 저항 $R_F$ ($10\ \text{k}\Omega$) | $R_{\text{load,out}} = R_F = 10.0\ \text{k}\Omega$, $R_{\text{load,in}} = R_F = 10.0\ \text{k}\Omega$ | 개방 시 전류 경로가 끊겨 $R_{\text{load}} = \infty$ (로딩 누락) |
| `cv` | C-V 트랜스컨덕턴스 ($G_m$) | **개방 (`open`)** — 원래 전압 입력 ($\infty$) | **개방 (`open`)** — 원래 전류 출력 ($\infty$) | 감지 저항 $R_M$ ($0.5\ \text{k}\Omega = 500\ \Omega$) *(교과서 보충: Razavi 예제 12.30)* | $R_{\text{load,out}} = R_M = 500\ \Omega$, $R_{\text{load,in}} = R_M = 500\ \Omega$ | 단락 시 $R_M$이 접지로 우회되어 $R_{\text{load}} = 0\ \Omega$ ($-100\%$) |
| `cc` | C-C 전류 증폭기 ($A_I$) | **단락/접지 (`short`)** — 원래 전류 입력 ($0$) | **개방 (`open`)** — 원래 전류 출력 ($\infty$) | $R_M$–$R_F$ 귀환망 ($1.5\ \text{k}\Omega, 3.0\ \text{k}\Omega$) *(교과서 보충: Razavi 예제 12.32)* | $R_{\text{load,out}} = R_M\parallel R_F = 1.00\ \text{k}\Omega$, $R_{\text{load,in}} = R_F+R_M = 4.50\ \text{k}\Omega$ | 감지 개방 → $R_M = 1.50\ \text{k}\Omega$ ($+50.0\%$); 반송 단락 → $R_F = 3.00\ \text{k}\Omega$ ($-33.3\%$) |

## 2. 모드·조작 범위·대표 설정·단계

- **모드 (`modes`, 4개):** `vv` (`V-V`), `vc` (`V-C`), `cv` (`C-V`), `cc` (`C-C`)
- **포트 (`ports`, 각 모드 2개):**
  - `return-rem`: 반송 복제 남은 포트 (`short` = 단락/접지, `open` = 개방)
  - `sense-rem`: 감지 복제 남은 포트 (`short` = 단락/접지, `open` = 개방)
  - 초기 상태(`def`)는 "자신이 달린 쪽(출력/입력)의 임피던스로 거꾸로 착각해 꽂은 흔한 오조립"으로 두어 진입 직후 오조립 진단과 교정 학습이 바로 시작되게 구성한다.
- **슬라이더 (`params`, 모드별 노출):**
  - `vv`: `vv_r1` ($1\text{–}10\ \text{k}\Omega$, 기본 $3$), `vv_r2` ($0.5\text{–}5\ \text{k}\Omega$, 기본 $1$), `vt` ($0.5\text{–}5\ \text{V}$, 기본 $1$)
  - `vc`: `vc_rf` ($1\text{–}50\ \text{k}\Omega$, 기본 $10$), `vt` ($0.5\text{–}5\ \text{V}$, 기본 $1$)
  - `cv`: `cv_rm` ($0.1\text{–}2.0\ \text{k}\Omega$, 기본 $0.5$), `it` ($0.5\text{–}5\ \text{mA}$, 기본 $1$)
  - `cc`: `cc_rm` ($0.5\text{–}5\ \text{k}\Omega$, 기본 $1.5$), `cc_rf` ($0.5\text{–}10\ \text{k}\Omega$, 기본 $3$), `it` ($0.5\text{–}5\ \text{mA}$, 기본 $1$)
- **대표 설정 (`presets`, 모드별 3개):**
  1. `정답 조립` (감지·반송 모두 이상적 임피던스 종단)
  2. `감지 복제만 오조립` (출력 측 로딩 왜곡)
  3. `반송 복제만 오조립` (입력 측 로딩 왜곡)
- **단계별 살펴보기 (`steps`):** 각 모드에 대해 (1) 원래 연결 포트 읽기 → (2) 감지 복제 정답 조립 → (3) 반송 복제 정답 조립 → (4) 오조립 시 로딩 왜곡 대조 순서 제공.

## 3. 예측 질문 (`predict`) 및 모드별 오개념 3개

- **예측 질문:** "V-V 귀환에서 출력 쪽에 다는 「감지 복제」의 남은 포트는 어떻게 종단할까요?"
  - 보기: `개방 (원래 전압 입력, Z_in = ∞)` [정답] / `단락/접지 (원래 전압 출력, Z_out = 0)`
- **오개념 (`mistakes`, 모드별 3개):**
  - `vv`: (1) 감지 복제를 출력(V) 기준으로 단락, (2) 반송 복제를 입력(V) 기준으로 개방, (3) 실제 포트 저항(BJT $r_\pi$, 출력 $R_D$ 등)과 이상적 임피던스(전압 $\infty/0$) 혼동 (참고: CG $1/g_m$은 V-C/C-C 전류 입력 사례)
  - `vc`: (1) V-V를 외워 감지 복제를 개방해 $R_F$ 출력 로딩 누락, (2) 반송 복제를 개방해 입력 로딩 누락, (3) V-C 폐루프 입·출력 저항 증감 방향 혼동
  - `cv`: (1) 남은 포트를 습관적으로 모두 접지해 $R_M$ 단락, (2) 직렬 감지 저항 $R_M$의 출력 로딩 무시, (3) 전류 출력 이상적 임피던스 $\infty$를 $0\ \Omega$으로 착각
  - `cc`: (1) 달린 쪽 기준(감지=전류출력 $\infty$ 개방, 반송=전류입력 $0$ 단락)으로 반대 조립, (2) C-C 출력 로딩을 $R_M \parallel R_F$ 대신 $R_M + R_F$ 직렬로 계산, (3) C-C 폐루프 입·출력 저항 $(1+KA_I)$ 방향 혼동
