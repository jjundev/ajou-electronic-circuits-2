# 교과서 문제 → 복원 가능한 MD 형식 (9장) — 설계

## Intent
`교과서/마이크로전자회로/9장.pdf`(스캔본, 텍스트 레이어 없음, 30쪽)에 있는 문제 110개를
**문제 1개당 md 1개**로 변환한다.

- 본문 예제 9.1–9.21 (21개)
- 예제 바로 뒤 연습문제 (21개, 예제마다 1개)
- 장말 PROBLEMS 9.1–9.68 (68개, Design Problems 9.54–9.68 포함)

md에는 조건, 구할 것, 회로도를 적는다. 목표는 **md만 보고 원본 문제를 그대로 복원**하는 것이다.
이번 라운드에서는 형식과 도구를 만들고 샘플 7개를 작성한다. 사용자 피드백으로 형식을 확정한 뒤
나머지 103개를 변환한다.

Classification: architectural. 레포에 기존 변환 흐름이 없다.

## 넷리스트 문법
| 소자 | 형식 |
|---|---|
| BJT | `Q<n> C B E npn\|pnp [area=k]` |
| MOSFET | `M<n> D G S nmos\|pmos [W/L=a/b]` |
| R/C/L | `R<n> n1 n2 [값\|{기호}]` |
| 전류원 | `I<n> from to [값]` (화살표 from→to) |
| 전압원·배터리 | `V<n> + - [값]` |
| 블랙박스 | `X<n> 노드… box "라벨"` |
| 연산증폭기 | `X<n> in+ in- out opamp` |

노드 이름: 그림 라벨 그대로(`X`, `P`, `Vout`, `Vb1`, `VCC`). 라벨 없는 내부 노드는 `n1…`,
라벨 없는 측정 단자는 `out`(여럿이면 `out1`, `out2`). 접지는 `0`.

## 풀이 그림
풀이 안의 그림(예: Fig 9.28, 9.30, 9.33, 9.38(b))은 `role: answer`로 표시하고 `## 답 (검증용)`에만 둔다.
단, 다른 문제가 그 그림을 문제 그림으로 쓰면(예: E9.16이 Fig 9.30을 씀) 그 문제에서는 `role: problem`이다.
