# 장말문제 15.44 — KHN 바이쿼드로 3차 버터워스 필터 설계

## 조건
- 예제 15.25의 설계를 KHN 바이쿼드로 반복한다.
- 예제 15.25의 목표는 $f_1=1\ \mathrm{MHz}$까지 평탄도 $0.45\ \mathrm{dB}$, $f_2=2\ \mathrm{MHz}$에서 감쇠 $9\ \mathrm{dB}$인 3차 버터워스 응답이다. $\omega_0\simeq2\pi(1.45\ \mathrm{MHz})$이다. (원문에 없음)

## 구할 것
- 주어진 구조를 사용하여 같은 버터워스 응답을 구현할 회로를 설계한다.

## 상속·참조
- 원문의 “Example 15-25”는 예제 15.25이다. 켤레 극점 두 개는 $\omega_n=\omega_0$, $Q=1$인 2차 단에, 실수 극점 $-\omega_0$는 1차 RC 단에 배정한다. 이번 문제에서는 2차 단으로 KHN 바이쿼드의 저역통과 출력을 사용한다.

## 회로 — Fig 15.36(b)
```spice
R4 Vin n1 {R_4}
R5 X n1 {R_5}
R3 Y n2 {R_3}
R6 Vout n2 {R_6}
XA n1 n2 Vout opamp
R1 Vout n3 {R_1}
C1 X n3 {C_1}
XB 0 n3 X opamp
R2 X n4 {R_2}
C2 Y n4 {C_2}
XC 0 n4 Y opamp
```
- 단자: Vin = 입력 (개방 원) / Vout = 출력 (개방 원)
- 표시: 노드 라벨 V_in, V_out, X, Y / 소자 라벨 R_1–R_6, C_1, C_2, XA, XB, XC (증폭기 라벨 없음) / 부호 세 연산증폭기의 왼쪽 위 −, 아래 + / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 합산 증폭기의 비반전 입력 분기(점)에는 입력의 R_4와 아래쪽으로 X에서 돌아오는 R_5가 연결된다. 반전 입력 쪽(점)에는 옆 R_6 및 맨 위 Y에서 돌아오는 R_3이 닿는다. R_6 오른쪽 V_out 원의 분기(점)와 그 아래 합산기 출력 분기(점)를 세로선이 잇는다. 가운데와 오른쪽 적분기는 비반전 입력이 접지이며, 각 반전 입력의 분기(점)에는 가로 R_1·R_2와 위쪽 되먹임 C_1·C_2가 연결된다. X 출력 분기(점)에는 C_1, R_2, R_5 선이 닿고 Y 위쪽 분기(점)는 C_2와 R_3으로 이어진다. 교차: 없음
