# 장말문제 11.5 — 겹친 두 극점의 보데 선도

## 원문
A circuit contains two coincident (i.e., equal) poles at $\omega_{p1}$. Construct the Bode plot of $|V_{out}/V_{in}|$.

## 조건
- 회로에 일치하는 (즉, 같은) 두 극점이 $\omega_{p1}$에 있음

## 구할 것
- $|V_{out}/V_{in}|$의 보데 선도

## 회로 — 없음 (보데 선도 문제, 그림 없음)

## 풀이
### 전달 함수
- 저주파 이득을 $A_0$라 하면 $\dfrac{V_{out}}{V_{in}} = \dfrac{A_0}{(1 + s/\omega_{p1})^2}$
- $\left|\dfrac{V_{out}}{V_{in}}\right| = \dfrac{|A_0|}{1 + \omega^2/\omega_{p1}^2}$
### 보데 근사
- $\omega < \omega_{p1}$: 기울기 0, 높이 $20\log|A_0|$
- $\omega_{p1}$에서 극점 두 개를 한꺼번에 지나므로 기울기가 $-20\ \text{dB/dec}$씩 두 번 줄어 $-40\ \text{dB/dec}$
### 근사의 오차
- $\omega = \omega_{p1}$에서 정확한 크기는 $|A_0|/2$, 곧 $6.02\ \text{dB}$ 낮다 (극점 하나일 때의 두 배)
- $\omega = 10\,\omega_{p1}$에서는 $-40.1\ \text{dB}$로 점근선 $-40\ \text{dB}$와 거의 같다
### 답
- $20\log|A_0|$에서 평평하다가 $\omega_{p1}$에서 꺾여 $-40\ \text{dB/dec}$로 떨어지는 직선. 꺾이는 점의 실제 크기는 점근선보다 $6.02\ \text{dB}$ 낮다.
