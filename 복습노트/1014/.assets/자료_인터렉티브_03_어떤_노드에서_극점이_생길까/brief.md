# 어떤 노드에서 극점이 생길까
명시 주제 하나. 선정 점수 7: 값 변화 2, 단계 해석 2, 노드 비교 2, 추가 학습 목표 1.
목표: 같은 도선의 두 점은 같은 노드임을 확인하고, 저항을 통한 커패시터 충방전이 유한 pole을 만드는 조건을 비교한다.
회로: Lec5 slide9 CS 단방향 소신호 모델. gm=5mS, RD=2kΩ 고정, ro=∞, 게이트 전류 0, Cgd/몸체 효과/클리핑 제외. CG가 아니므로 입력 Req는 RS이다.
식: H=-gm RD/[(1+s RS Cin)(1+s RD CL)]. 이상적 구동은 RS=0으로 첫 인자 제거. τ=RC, ωp=1/τ, fp=ωp/(2π). 실제 pole 위치는 s=-ωp.
모드: 노드와 보데. 점 선택은 X/X′/Y/전압원 A/AC 접지. 입력원 끄기는 Req 관찰용이며 보데 수치는 원래 전달함수이다.
조작: RS 100~10000Ω, Cin/CL 1e-14~1e-12 F, 주파수/낮은 pole .01~100. 기본/이상적 구동/겹침/입력 먼저 대표 설정.
단계: 동일 도선 → 입력 RC → 출력 RC → 이상적 구동 → 보데 기울기 → 겹친 pole.
오개념 3개: 점 추가가 pole 추가 / 커패시터 존재만으로 pole 확정 / 임의 결합 회로에도 노드별 RC가 정확.
근거: 정리노트 s1-bode, s2-cs-two-poles, s2-node-rule; STT/1014 Part05~06 약280~370행; 강의노트 Lec5 pp8~9의 식과 회로(실제9쪽 렌더 대조).
교과서 보충: 같은 도선과 이상적 전압원 직접 구동의 RS=0 극한. Razavi ch11 기본 RC 응답과 같은 모델에서 직접 도출. 화면에 보충 표시. 부유 커패시터/밀러는 다음 수업이라 제외.
기존 두 극점 자료와 차이: 노드의 동일성, 신호원 제거, 이상적 구동의 유한 pole 소실에 집중한다.
연결: 정리노트 s2-node-rule, s1-bode의 설명 뒤.
기존 ec2 공통 셸/테마/모바일 서랍을 따른다. 재생은 의미가 없어 사용하지 않는다.
