# 연습문제 9.16 — 기준 트랜지스터가 3A_E일 때 I_copy1 (예제 9.16 변형)

## 원문
4개의 트랜지스터 중 1개가 생략되었을 때, 다시 말하면 기준 트랜지스터가 $3A_E$의 면적을 가질 때 $I_{copy1}$을 계산하라.

## 조건
- 예제 9.16의 회로(Fig 9.30, Fig 9.33)에서 기준 쪽 트랜지스터 4개 중 1개를 뺌
  - 즉 기준 트랜지스터의 총 면적이 $3A_E$ (예제는 $4A_E$)
  - 나머지($I_{REF} = 0.2\ \text{mA}$, $Q_1 = A_E$, $Q_2 = 10A_E$)는 예제와 같음 (원문에 없음)
- 폴로어가 없는 회로(Fig 9.30)와 있는 회로(Fig 9.33) 중 어느 쪽인지 원문에 명시 없음. 예제처럼 두 경우 모두로 해석 (원문에 없음)

## 구할 것
- $I_{copy1}$

## 상속·참조
- 예제 9.16 (E9.16): 모든 트랜지스터의 $\beta$가 같고, $I_{copy1}$, $I_{copy2}$, $I_{C,REF}$(기준 트랜지스터 전체 전류)가 면적 비율을 유지한다고 보고 KCL을 씀
  - 폴로어 전, X에서: $I_{REF} = I_{C,REF} + \dfrac{I_{copy1}}{\beta} + \dfrac{I_{copy2}}{\beta} + \dfrac{I_{C,REF}}{\beta}$, $I_{C,REF} = 4 I_{copy1}$, $I_{copy2} = 10 I_{copy1}$ → $I_{copy1} = \dfrac{I_{REF}}{4 + 15/\beta}$ (식 9.109)
  - 폴로어 후(Fig 9.33): $Q_F$ 이미터 전류 $I_{C,F} = \dfrac{I_{C,REF} + I_{copy1} + I_{copy2}}{\beta}$, P에서 $I_{REF} = \dfrac{I_{C,F}}{\beta} + I_{C,REF}$ → $I_{copy1} = \dfrac{I_{REF}}{4 + 15/\beta^2}$ (식 9.116)

## 회로 — Fig 9.30
```spice
IREF  VCC   X  0.2mA
QR1   X     X  0  npn  area=1
QR2   X     X  0  npn  area=1
QR3   X     X  0  npn  area=1
QR4   X     X  0  npn  area=1
Q1    out1  X  0  npn  area=1
Q2    out2  X  0  npn  area=10
```
- 단자: VCC = 전원, 값 미지정 (T 전원 기호) / out1, out2 = Q1, Q2 컬렉터, 복사 전류 I_copy1, I_copy2가 들어가는 단자 (선 끝)
- 표시: 노드 라벨 VCC (T 기호 오른쪽), X (X 접속점 바로 위) / 소자 라벨 I_REF (전류원 왼쪽), Q1 (Q1 막대 위, 컬렉터 선 왼쪽), Q2 (Q2 막대 위, 컬렉터 선 왼쪽), QR1–QR4 (라벨 없음) / 부호 없음 / 화살표 "I_copy1": out1, 아래 방향(Q1 컬렉터로 들어감), 도선 위, 글자는 화살표 오른쪽; "I_copy2": out2, 아래 방향(Q2 컬렉터로 들어감), 도선 위, 글자는 화살표 오른쪽 / 수치·면적 라벨 "0.2 mA" (전류원 오른쪽), "4A_E" (기준 트랜지스터 4개의 접지 기호 아래에 가로로 걸친 중괄호 밑), "A_E" (Q1 오른쪽, 베이스 높이), "10A_E" (Q2 오른쪽, 베이스 높이)

- 표시: 노드 라벨 VCC (레일 오른쪽 끝), P (P 접속점 왼쪽), X (X 접속점 오른쪽 아래) / 소자 라벨 I_REF (전류원 왼쪽), Q_F (Q_F 오른쪽), Q1 (Q1 막대 위, 컬렉터 선 왼쪽), Q2 (Q2 막대 아래 왼쪽), QR1–QR4 (라벨 없음) / 부호 없음 / 화살표 "I_copy1": out1, 아래 방향(Q1 컬렉터로 들어감), 도선 위, 글자는 화살표 오른쪽; "I_copy2": out2, 아래 방향(Q2 컬렉터로 들어감), 도선 위, 글자는 화살표 오른쪽 / 수치·면적 라벨 "0.2 mA" (전류원 오른쪽), "4A_E" (기준 트랜지스터 4개의 접지 기호 아래 중괄호 밑), "A_E" (Q1 오른쪽), "10A_E" (Q2 오른쪽)

## 풀이
### 폴로어 전: X에서 KCL
- 면적 비대로 기준 쪽 전류 합 $I_{C,REF} = 3 I_{copy1}$, $I_{copy2} = 10 I_{copy1}$
- $I_{REF} = I_{C,REF} + (I_{C,REF} + I_{copy1} + I_{copy2})/\beta = 3 I_{copy1} + 14 I_{copy1}/\beta$
- $I_{copy1} = I_{REF}/(3 + 14/\beta)$ (상대 오차 약 $-14/(3\beta)$)
### 폴로어 후: 폴로어의 베이스 전류
- Fig 9.33: X의 베이스 전류 합은 $Q_F$가 $V_{CC}$에서 댄다, $I_{C,F} \approx 14 I_{copy1}/\beta$
- $I_{REF}$에서 새는 것은 $I_{B,F} = I_{C,F}/\beta = 14 I_{copy1}/\beta^2$뿐
### 폴로어 후: P에서 KCL
- $I_{REF} = I_{B,F} + I_{C,REF} = 14 I_{copy1}/\beta^2 + 3 I_{copy1}$
- $I_{copy1} = I_{REF}/(3 + 14/\beta^2)$ (상대 오차 약 $-14/(3\beta^2)$)
- $\beta \to \infty$이면 둘 다 $I_{REF}/3 = 0.2\ \text{mA}/3 = 66.7\ \mu\text{A}$
### 답
- 폴로어 없음: $I_{copy1} = 0.2\ \text{mA}/(3 + 14/\beta)$, 폴로어 있음: $I_{copy1} = 0.2\ \text{mA}/(3 + 14/\beta^2)$ (베이스 전류 무시 시 $66.7\ \mu\text{A}$)
