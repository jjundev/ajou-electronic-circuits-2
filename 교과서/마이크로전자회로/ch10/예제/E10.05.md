# 예제 10.5 — 테일 전류를 완전히 조종할 때 허용 최대 베이스 전압

## 조건
- 바이폴라 차동쌍, 테일 전류 $I_{EE} = 0.5\ \text{mA}$, 컬렉터 저항 $R_C = 1\ \text{k}\Omega$
- $V_{CC} = 2.5\ \text{V}$
- 차동 입력이 커서 테일 전류를 한쪽 트랜지스터로 완벽하게 조종함

## 구할 것
- 허용 가능한 최대 베이스 전압

## 상속·참조
- 본문 Fig 10.11(a) (교재 509쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-11.png): $V_{CC} = 2.5\ \text{V}$ 레일, 두 $R_C$, $Q_1$(베이스 $V_{in1}$), $Q_2$(베이스 $V_{in2}$), 공통 이미터 노드 $P$와 테일 전류원 $I_{EE}$. 연결: `RC(왼쪽): VCC – X`, `RC(오른쪽): VCC – Y`, `Q1: C = X, B = Vin1, E = P`, `Q2: C = Y, B = Vin2, E = P`, `I_EE: P → 접지`
- 식 (10.24), (10.26)–(10.27): 큰 양의 차동 입력에서 $I_{C1} = I_{EE}$, $I_{C2} = 0$, $V_X = V_{CC} - R_C I_{EE}$, $V_Y = V_{CC}$
- 포화를 피하려면 컬렉터 전압이 베이스 전압 아래로 떨어지면 안 됨

## 회로 — 없음 (그림 없는 글 문제, 본문 그림 10.11(a)는 상속·참조에 적음)

## 답 (검증용)
- 전류가 흐르는 트랜지스터의 컬렉터 전압이 $V_{CC} - R_C I_{EE} = 2\ \text{V}$까지 내려가므로, 포화를 피하려면 베이스 전압은 $2\ \text{V}$ 이하
