# 장말문제 9.42 — 130 μA 기준으로 50 μA와 230 μA를 만드는 npn 전류 거울 설계

## 원문
We wish to generate two currents equal to $50\ \mu\text{A}$ and $230\ \mu\text{A}$ from a reference of $130\ \mu\text{A}$. Design an npn current mirror for this purpose. Neglect the base currents.

## 조건
- 기준 전류 $130\ \mu\text{A}$
- 만들 전류 두 개: $50\ \mu\text{A}$, $230\ \mu\text{A}$
- npn 전류 거울로 설계
- 베이스 전류 무시

## 구할 것
- 위 두 전류를 만드는 npn 전류 거울 설계

## 회로 — 없음 (설계 문제, 문제 그림 없음)

## 풀이
### 전류비와 면적비
- 베이스 전류를 무시하면 같은 $V_{BE}$를 받는 트랜지스터의 컬렉터 전류는 이미터 면적에 비례한다: $I_{out}/I_{REF} = A_{E,out}/A_{E,REF}$
- 세 전류의 최대공약수는 $10\ \mu\text{A}$이므로 $10\ \mu\text{A}$를 흘리는 단위 트랜지스터(면적 $A_E$)로 짠다
### 트랜지스터 크기
- 다이오드 연결 기준 트랜지스터 $Q_{REF}$: $130/10 = 13$개 병렬, $13 A_E$
- 출력 $Q_1$: $50/10 = 5$개, $5 A_E$ → $I_1 = (5/13) \times 130\ \mu\text{A} = 50.0\ \mu\text{A}$
- 출력 $Q_2$: $230/10 = 23$개, $23 A_E$ → $I_2 = (23/13) \times 130\ \mu\text{A} = 230\ \mu\text{A}$
### 연결
- $I_{REF}$를 $Q_{REF}$ 컬렉터에 넣고 베이스와 컬렉터를 묶는다. $Q_1$, $Q_2$의 베이스를 이 노드에, 이미터를 모두 접지에 붙이고, 두 출력 전류는 $Q_1$, $Q_2$ 컬렉터로 흘러든다
### 답
- $Q_{REF} = 13 A_E$(다이오드 연결), $Q_1 = 5 A_E$, $Q_2 = 23 A_E$의 npn 거울(베이스 공통, 이미터 접지). $Q_1$에 $50\ \mu\text{A}$, $Q_2$에 $230\ \mu\text{A}$가 흐른다.
