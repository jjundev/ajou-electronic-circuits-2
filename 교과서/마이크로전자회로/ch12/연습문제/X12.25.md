# 연습문제 12.25 — RD를 이상적인 전류원으로 바꾼 귀환 CG 단 (예제 12.25 변형)

## 원문
$R_D$가 이상적인 전류원으로 대체되었을 때 위의 예제를 다시 풀어라.

## 조건
- 예제 12.25와 같은 회로: Fig 12.11 (예제 12.7의 회로), $R_1 + R_2$가 $R_D$에 비해 훨씬 크지 않다는 가정의 해석
- 바뀐 점: $R_D$를 이상적인 전류원으로 대체 ($V_{DD}$와 $V_{out}$ 사이, 소신호 저항 무한대) (괄호 안은 원문에 없음)
- 예제 12.7에서 이어받는 가정: $\lambda = 0$ (원문에 없음)
- 예제 12.25의 결과 ($R_D$일 때): 개루프 회로는 $M_1$ 게이트를 접지하고 출력에 $R_1 + R_2$를 단 회로, $A_O = g_{m1}[R_D \parallel (R_1 + R_2)]$, $R_{out,open} = R_D \parallel (R_1 + R_2)$, $K = R_2/(R_1 + R_2)$, $R_{in,open} = 1/g_{m1}$, 폐루프는 $A_{closed} = A_O/(1 + KA_O)$, $R_{in,closed} = R_{in,open}(1 + KA_O)$, $R_{out,closed} = R_{out,open}/(1 + KA_O)$ (원문에 없음)
- 소자 값은 주어지지 않음 (답은 $g_{m1}$, $R_1$, $R_2$의 식으로) (원문에 없음)

## 구할 것
- $R_D$를 이상적인 전류원으로 바꾼 회로의 해석: 개루프 회로, 개루프·폐루프 전압 이득, 폐루프 입력·출력 임피던스 (콜론 뒤는 원문에 없음)

## 상속·참조
- 예제 12.25 (E12.25): 예제 12.7 회로에서 $R_1 + R_2$가 $R_D$에 비해 훨씬 크지 않으면 $R_1 + R_2$가 $R_D$와 병렬로 나타나 개루프 이득을 줄임. 개루프 회로 (Fig 12.51): $M_1$ 게이트 접지, 드레인–$V_{out}$에 $R_D$와 $R_1$–$R_2$ 직렬이 접지까지. $A_O = g_{m1}[R_D \parallel (R_1 + R_2)]$ (식 12.115), $R_{out,open} = R_D \parallel (R_1 + R_2)$ (식 12.116), 다른 변수는 예제 12.7과 같음. 폐루프 식 (12.117)–(12.119): $A_{v,closed} = \dfrac{g_{m1}[R_D \parallel (R_1 + R_2)]}{1 + \dfrac{R_2}{R_1 + R_2}g_{m1}[R_D \parallel (R_1 + R_2)]}$, $R_{in,closed} = \dfrac{1}{g_{m1}}\left\{1 + \dfrac{R_2}{R_1 + R_2}g_{m1}[R_D \parallel (R_1 + R_2)]\right\}$, $R_{out,closed} = \dfrac{R_D \parallel (R_1 + R_2)}{1 + \dfrac{R_2}{R_1 + R_2}g_{m1}[R_D \parallel (R_1 + R_2)]}$
- 예제 12.7 (E12.07): $\lambda = 0$, 순방향 시스템은 $M_1$과 $R_D$의 CG 단, 귀환율 $K = R_2/(R_1 + R_2)$, $R_{in,open} = 1/g_m$

## 회로 — Fig 12.11
```spice
RD  VDD   Vout  {R_D}
M1  Vout  n1    Vin  nmos
R1  Vout  n1    {R_1}
R2  n1    0     {R_2}
```
- 단자: VDD = 전원, 값 미지정 (T 전원 기호) / Vin = 입력, M1 소스 (개방 원) / Vout = 출력 (개방 원)
- 표시: 노드 라벨 V_DD (T 기호 오른쪽), V_in (입력 원 왼쪽), V_out (출력 원 오른쪽) / 소자 라벨 R_D (저항 왼쪽), M1 (트랜지스터 왼쪽, 소스 화살표 바로 왼쪽 위), R1, R2 (각 저항 오른쪽) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 세로줄 위→아래 V_DD T 기호, R_D, 드레인 접속점, M1 / M1은 좌우 반전된 NMOS (게이트가 오른쪽, 드레인 위·소스 아래 인출선이 왼쪽, 소스 화살표는 채널에서 왼쪽 바깥을 향함) / 소스에서 세로선이 아래로 내려가 왼쪽으로 꺾여 V_in 원에서 끝남 / 드레인 접속점에서 가로선이 오른쪽으로 가 R1 위 접속점을 지나 V_out 원까지 / 오른쪽 세로줄 위→아래 R1 위 접속점, R1, 게이트 접속점(n1), R2, 접지 / M1 게이트에서 가로선이 오른쪽으로 곧장 n1 접속점 / 접속점 (세 갈래 이상, 3곳): 드레인 = 위 R_D + 아래 M1 드레인 + 오른쪽 가로선 (점), R1 위 = 왼쪽 가로선 + 아래 R1 + 오른쪽 V_out 선 (점), n1 = 위 R1 + 아래 R2 + 왼쪽 게이트 선 (점) / 교차: 없음
