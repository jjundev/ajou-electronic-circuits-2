# 연습문제 10.17 — V_TH = 0.2 V일 때 예제 10.17 결과의 유지 여부

## 원문
$V_{TH} = 0.2\ \text{V}$라면 위의 결과가 유지되는가?

## 조건
- 예제 10.17에서 $V_{TH} = 0.2\ \text{V}$ (예제는 $0.4\ \text{V}$)

## 구할 것
- 위의 결과(입력 CM 레벨을 $V_{DD}$에 둘 수 있다는 결과)가 유지되는지 (괄호 안 풀이는 원문에 없음)

## 상속·참조
- 예제 10.17 (E10.17): 예제 10.16 설계($V_{DD} = 1.8\ \text{V}$, $I_{SS} = 1.11\ \text{mA}$, $R_D = 360\ \Omega$, $V_{CM,out} = V_{DD} - R_D I_{SS}/2 = 1.6\ \text{V}$)에서 $M_1$, $M_2$ 포화 조건 $V_{CM,in} < V_{DD} - R_D \dfrac{I_{SS}}{2} + V_{TH} = V_{CM,out} + V_{TH}$ (식 10.128–10.129) → $V_{TH} = 0.4\ \text{V}$이면 $V_{CM,in} < 2\ \text{V}$ (식 10.130)이라 입력 CM 레벨이 $V_{DD}$에 있어도 됨
