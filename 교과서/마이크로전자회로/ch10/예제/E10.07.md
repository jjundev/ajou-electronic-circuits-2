# 예제 10.7 — 바이폴라 차동쌍과 CE 단의 전력 소모 비교

## 원문
바이폴라 차동쌍의 전력 소모를 공통 이미터(CE) 단의 전력 소모와 비교하라. 두 회로의 전압 이득, 컬렉터 저항, 공급 전압이 같다고 가정한다.

## 조건
- 바이폴라 차동쌍과 공통 이미터(CE) 단의 전력 소모를 비교
- 두 회로의 전압 이득, 컬렉터 저항, 공급 전압이 같다고 가정

## 구할 것
- 두 회로의 전력 소모 비교

## 상속·참조
- 식 (10.45): 차동쌍의 소신호 차동 이득 $A_v = -g_m R_C$ ($g_m$은 각 트랜지스터의 트랜스컨덕턴스, 각 트랜지스터 바이어스 전류 $I_{EE}/2$)
- CE 단 이득 $|A_v| = g_m R_C$, $g_m = I_C / V_T$

## 회로 — 없음 (그림 없는 글 문제)

## 답 (검증용)
- $|A_{V,diff}| = g_{m1,2} R_C$ (식 10.48), $|A_{V,CE}| = g_m R_C$ (식 10.49) → $g_{m1,2} = g_m$ → $\dfrac{I_{EE}}{2V_T} = \dfrac{I_C}{V_T}$ (식 10.51) → $I_{EE} = 2 I_C$ (식 10.52): 차동쌍이 2배의 전력을 소비 (차동 회로의 단점 중 하나)

## 풀이
### 두 회로의 이득
- 차동쌍: 각 트랜지스터 전류 $I_{EE}/2$, $|A_{v,diff}| = g_{m1,2} R_C$, $g_{m1,2} = \dfrac{I_{EE}/2}{V_T}$
- CE 단: 바이어스 전류 $I_C$, $|A_{v,CE}| = g_m R_C$, $g_m = \dfrac{I_C}{V_T}$
### 같은 이득·같은 $R_C$의 조건
- 이득과 $R_C$가 같으므로 $g_{m1,2} = g_m$ → $\dfrac{I_{EE}}{2V_T} = \dfrac{I_C}{V_T}$ → $I_{EE} = 2 I_C$
### 전력 소모 비교
- 공급 전압이 같으므로 전력은 전류에 비례: $\dfrac{P_{diff}}{P_{CE}} = \dfrac{V_{CC} I_{EE}}{V_{CC} I_C} = 2$
### 답
- 같은 이득을 얻으려면 차동쌍의 각 트랜지스터가 CE 단과 같은 전류를 흘려야 하므로 $I_{EE} = 2 I_C$이고, 차동쌍이 CE 단의 2배 전력을 소비한다. 이것이 차동 회로의 단점 중 하나다.
