# 교과서 문제 standalone화 — 설계

감사 결과: [2026-10-18-standalone-audit.md](../reports/2026-10-18-standalone-audit.md) (파일별 `수정` 칸이 이 설계의 파일 단위 명세)

## Intent
감사에서 고른 71개 문제 md(필수 42, 권장 29)를 고쳐, 학생이 **문제지에 보이는 부분**(`## 원문`, `## 조건`, `## 구할 것`, `role: problem` 그림)만 보고 풀 수 있게 한다. 대부분은 `## 상속·참조`에 이미 있는 식·값·정의·앞 문제 결과 중 필요한 최소한을 `## 조건`에 적으면 된다. 재발 방지로 FORMAT.md 규칙 한 줄과 check_md.py 오류 하나를 더한다.

완료: 71개 모두 문제지 부분에 참조 내용이 보임 / check_md·verify_chapter·workbook 테스트 통과 / ch09–11 PDF 재생성에 OVERFLOW 없음 / 같은 rubric 재감사 0건.

분류: bounded — 기존 md 형식 안의 내용 수정.

## Behavior when done
- "식 (9.12)와 비교" 위 조건에 `식 (9.12): $…$`가 보인다
- "문제 10.46의 결과를 이용"이면 그 결과식이 조건에 보인다
- $\Delta V_{in,max}$, $A_{CM-DM}$, CMRR, $G_m$ 같은 본문 정의 기호는 조건에 정의가 보인다
- 문제지 어디에도 "(아래 상속·참조)"가 없다 — check_md가 오류로 막는다
- `(원문에 없음)` 표시는 PDF에서 빠지므로 학생에게는 깔끔한 bullet로 보인다

## Not in this round
- `## 상속·참조`를 문제지에 렌더 — 예제 풀이 과정이 섞여 있어 풀이가 새고 쪽이 넘친다
- 본문 그림 새 크롭 — FORMAT.md "문제가 바로 그 회로를 쓸 때만 크롭". 글 설명으로 충분
- 기출(from_the_past) — 감사 범위 밖
- 힌트·풀이 손보기 — 조건 변경으로 힌트가 중복되면 따로
