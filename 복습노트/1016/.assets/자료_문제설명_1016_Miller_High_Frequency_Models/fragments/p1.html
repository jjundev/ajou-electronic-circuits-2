문제를 읽어요

차동 증폭기의 공통 모드 제거(CM rejection) 의미와 실제 회로에서 제한되는 이유 두 가지를 묻고, Miller 효과가 적용된 증폭기의 등가 입력 임피던스와 대역폭에 미치는 영향을 묻는 서술형 문제예요.

구할 것은 (1) CM rejection의 의미 및 제한 이유 2가지, (2) $C_F$에 의한 등가 입력 임피던스 $Z_{in}$ 식과 대역폭 변화 설명이에요.

이 개념과 공식을 떠올려요

(1)에서 “CM rejection”은 두 입력에 동시에 들어오는 동위상 잡음을 걸러내고 순수 차동 신호만 증폭하는 성질이에요. 이상적 테일 전류원은 $R_{SS}=\infty$이지만, 실제 회로에서는 유한한 $R_{SS}$와 양쪽 소자/부하 불일치 때문에 CM 신호가 출력에 나타나요.

(2)에서 입력과 출력 사이 부유 커패시턴스 $C_F$는 밀러 정리(Miller's theorem)에 의해 각 노드와 접지 사이의 임피던스로 변환돼요. 반전 전압 이득이 $A_V = -g_m R_D$이므로 입력 쪽 등가 임피던스는 $Z_{in} = \dfrac{Z_F}{1 - A_V} = \dfrac{1}{s(1 + g_m R_D)C_F}$예요.

신호원 저항 $R_S$와 입력 커패시턴스가 만드는 극점 주파수 $\omega_{p,in} = \dfrac{1}{R_S C_{in}}$이 대역폭을 결정해요.

종이에 쓸 첫 줄

차동쌍의 대칭성과 테일 전류원의 역할로 공통 모드 동작을 정리하고, Miller 정리를 적용해 부유 커패시터 $C_F$ 양단 전압을 입력 전압 $v_{in}$으로 나타내요.

이렇게 풀어요

CM rejection의 의미: 전원 잡음이나 외부 간섭처럼 두 입력 노드에 동일하게 유입되는 공통 모드 신호를 억제하고, 오직 원하는 차동 신호 $V_{in1} - V_{in2}$만을 증폭하는 특성이에요.

제한 이유 1 (테일 전류원의 유한한 출력 저항): 실제 테일 전류원의 출력 저항 $R_{SS}$가 유한하므로, 공통 모드 입력 전압이 변하면 테일 전류 자체가 변하여 단일 출력 공통 모드 전압이 변해요 ($A_{CM} \approx -\dfrac{R_D}{1/g_m + 2R_{SS}} \neq 0$).

제한 이유 2 (양쪽 소자 및 부하 저항의 불일치): 두 입력 트랜지스터의 $g_m$이나 드레인 부하 저항 $R_D$ 사이에 오차($\Delta g_m, \Delta R_D$)가 존재하면 대칭성이 깨져 공통 모드 입력 신호가 차동 출력 신호로 변환돼요 ($A_{CM-DM} \neq 0$).

입력에서 부유 커패시터 $C_F$로 흘러 들어가는 전류는 다음과 같아요.

$$I_{in} = \frac{v_{in} - v_{out}}{1/(sC_F)} = sC_F(1 + g_m R_D)v_{in}$$

따라서 입력에서 접지로 바라본 등가 입력 임피던스 $Z_{in}$은 다음과 같아요.

$$Z_{in} = \frac{v_{in}}{I_{in}} = \frac{1}{s(1 + g_m R_D)C_F}$$

이는 입력에서 접지 사이에 등가 커패시턴스 $C_{in} = (1 + g_m R_D)C_F$가 연결된 것과 같아요.

대역폭에 미치는 영향: 신호원 저항을 $R_S$라 할 때 증폭기 입력 노드에 형성되는 극점 주파수는 $\omega_{p,in} = \dfrac{1}{R_S C_{in}} = \dfrac{1}{R_S (1 + g_m R_D) C_F}$예요. 반전 이득 크기 $g_m R_D$에 의해 등가 입력 커패시턴스가 $(1 + g_m R_D)$배로 크게 증배(Miller effect)되어 입력 극점이 낮은 주파수로 내려가므로, 증폭기의 대역폭(bandwidth)이 크게 감소해요.

완성 답과 검산

(1) 의미: 두 입력에 공통으로 인가된 노이즈·신호를 제거하고 차동 입력 신호에만 반응하여 증폭하는 특성이에요.
제한 이유 2가지:
① 테일 전류원의 출력 저항 $R_{SS}$가 유한하여 공통 모드 전압에 따라 테일 전류가 변하기 때문이에요.
② 양쪽 트랜지스터($g_m$)와 부하 저항($R_D$)의 불일치로 인해 공통 모드 신호가 차동 출력 신호로 변환($A_{CM-DM}$)되기 때문이에요.

(2) 등가 입력 임피던스: $Z_{in} = \dfrac{1}{s(1 + g_m R_D)C_F}$ (등가 입력 커패시턴스 $C_{in} = (1 + g_m R_D)C_F$)
대역폭에 미치는 영향: Miller 효과에 의해 입력 등가 커패시턴스가 $(1 + g_m R_D)$배로 증가하여 입력 극점 주파수 $\omega_{p,in} = \dfrac{1}{R_S (1 + g_m R_D) C_F}$가 낮아지므로, 증폭기의 대역폭(bandwidth)이 감소해요.

주의할 점

밀러 정리에서 전압 이득이 반전 증폭기($A_V = -g_m R_D$)이므로 분모의 $1 - A_V$가 $1 - (-g_m R_D) = 1 + g_m R_D$로 부호가 플러스가 된다는 점에 주의해요.

대역폭 영향을 답할 때는 신호원 저항 $R_S$와 커진 $C_{in}$이 입력 극점 $\omega_{p,in}$을 낮추기 때문이라는 물리적 메커니즘을 함께 기술해야 해요.

조건을 바꾸어 생각해요

  1. 만약 증폭기의 전압 이득이 음의 반전 이득이 아니라 양의 비반전 이득 $A_V = +1$ (예: 이상적 소스 폴로어)이라면, 입력에서 바라본 등가 입력 임피던스와 커패시턴스는 어떻게 될까요?

차동쌍은 대칭성과 테일 저항으로 CM을 억제해요.

반전 증폭기의 $C_F$는 Miller 증배로 대역폭을 줄여요.
