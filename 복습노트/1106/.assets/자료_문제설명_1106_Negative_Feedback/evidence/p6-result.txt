Y/X = A1/(A1*R2/(R1 + R2) + 1)  = 1/(K + 1/A1)
limit A1->oo : (R1 + R2)/R2 = 1/K = 1+R1/R2
relative error 1 - (Y/X)/(1/K) = (R1 + R2)/(A1*R2 + R1 + R2) = 1/(1+K A1) -> 0
E = X - X_F = X/(A1*R2/(R1 + R2) + 1)  -> limit 0
Argument: E->0 so X_F ~= X (good replica). X_F = K*Y fixed by divider -> Y = X/K = (1+R1/R2) X.
Gain set only by resistor ratio, insensitive to A1 (desensitization).
