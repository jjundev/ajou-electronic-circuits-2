## 작성자가 애매하다고 한 곳 — 독립 판단
- P10.73: 동의. $\lambda = 0$에서 $I_{D4}/I_{D3} = (W/L)_4/(W/L)_3$이고 $g_m \propto \sqrt{(W/L)I_D}$라 $g_{m4}/g_{m3}$도 같은 비가 된다. $i_1$, $i_2$를 전류원의 아래 방향 소신호 성분으로 본 것은 `## 조건`의 메모와 맞고, 부호도 맞다.
- P10.74 (b): 동의. $\lambda = 0$이면 $M_4$와 $M_2$ 모두 전류가 $V_{DS}$와 무관해 KCL로 $V_Y$가 정해지지 않는다. 원문도 "Invoking symmetry"라고 한다. (c): 동의. $I_{SS}/2$가 그대로이므로 $|V_{GS3}|$도 그대로다.
- P10.78: 동의. $A_v = -G_mR_{out}$의 $G_m$은 출력 단락선에서 회로로 흘러드는 전류 기준이다(CS단: $G_m = g_m$, $A_v = -g_mR_{out}$). 그러면 $G_m = -g_{mN}$이고 $A_v = +g_{mN}(r_{ON}\parallel r_{OP})$로, 교재 (10.214)와 같다. 수치 절점 해석도 양의 이득을 준다.
- P10.80: 동의. 교재의 포화 기준은 $V_{BC} \le 0$이다. 최대 이득 $1.3\ \text{V}/V_T = 50$은 전류와 무관하다.
- P10.81: 동의. 전류가 줄 때 $\Delta = 0.111/g_m$가 는 경우가 최악이다(늘 때 120 Ω에서 1.62%). $\Delta/(D+\Delta) < 0.02$에서 $R_E > 111.9\ \Omega$, $R_E = 120\ \Omega$이면 1.91%이고 $R_C = 462.5\ \Omega$이다. 두 $I_{EE}$가 모두 $V_{CC}$에서 흐르므로 각 0.8 mA도 맞다.
- P10.82: 동의. 이득이 $V_{A,n}V_{A,p}/[V_T(V_{A,n}+V_{A,p})]$라 전류와 무관하므로 $V_{A,p} = 1.66\ \text{V}$로만 맞출 수 있다. $V_b$는 pnp $I_S$가 없어 전류 조건으로만 적을 수 있다.
