Q1. 트랜스컨덕턴스 형태의 두 복제 종단

전방 증폭기가 트랜스컨덕턴스 $G_m$형(전압 입력·전류 출력)이에요. 출력 전류를 감지해 입력에 전압을 돌려주는 C-V 귀환이에요.

로딩을 넣으려고 귀환망 사본을 출력 쪽(감지 복제)과 입력 쪽(반송 복제)에 하나씩 달아요. 두 사본의 남은 포트는 각각 어떻게 종단하나요?

  1. 감지 복제는 개방, 반송 복제는 단락(접지)해요.
  2. 두 사본 모두 단락(접지)해요.
  3. 감지 복제는 단락, 반송 복제는 개방해요.
  4. 두 사본 모두 개방해요.
힌트 보기

남은 포트가 원래 전방 증폭기의 어느 포트(전압 입력인지, 전류 출력인지)에 붙어 있었는지부터 떠올려요.

풀이 보기
  1. "V-V 귀환의 종단(개방·접지)을 형태와 상관없이 그대로 옮겨 썼어요." — 감지 복제는 맞지만, 반송 복제의 남은 포트는 원래 전류 출력에 붙어 있었어요. 이상적인 전류 출력 임피던스는 $\infty$라 개방해야 해요.
  2. "트랜스임피던스 형태의 종단을 트랜스컨덕턴스 형태와 뒤바꿔 기억했어요." — 두 포트 모두 단락하는 것은 전류 입력·전압 출력인 트랜스임피던스(V-C) 형태예요. 여기서는 입력이 전압, 출력이 전류라 이상 임피던스가 둘 다 $\infty$예요.
  3. "감지량이 전류라는 이유로 감지 복제를 단락했어요. 종단은 감지량 종류가 아니라 원래 붙어 있던 포트의 이상 임피던스로 정해요." — 감지 복제의 남은 포트는 원래 전압 입력에 붙어 있었어요. 이상적인 전압 입력 임피던스는 $\infty$라 개방해야 해요.
  4. 감지 복제의 남은 포트는 원래 전압 입력($Z_{in}=\infty$), 반송 복제의 남은 포트는 원래 전류 출력($Z_{out}=\infty$)에 붙어 있었어요. 둘 다 $\infty$라서 모두 개방해요.

정답: D

Q2. 실제 입력 임피던스와 종단값

트랜스임피던스 증폭기(전류 입력·전압 출력)의 첫 단이 공통 게이트(CG) 단이에요. 그래서 실제 입력 임피던스는 $0$이 아니라 $1/g_{m1}$이에요.

로딩을 넣으려고 출력 쪽에 감지 복제를 달아요. 감지 복제의 남은 포트는 수업에서 정한 규칙대로 어떻게 처리하나요?

  1. 실제 입력 임피던스를 따라 $1/g_{m1}$을 거쳐 접지해요.
  2. 단락(접지)해요. 이상적인 전류 입력 임피던스가 $0$이기 때문이에요.
  3. 개방해요. 증폭기 입력 포트의 이상적 임피던스는 $\infty$이기 때문이에요.
  4. $1/g_{m1}$이 $0$이 아니므로 감지 복제는 달지 않고 출력 쪽 로딩을 무시해요.
힌트 보기

종단에는 실제 소자 값과 이상적인 포트 임피던스 중 어느 쪽을 쓰는지 떠올려요.

풀이 보기
  1. "종단값을 실제 소자 임피던스로 읽었어요. 규칙은 그 포트가 가져야 할 이상적 임피던스를 써요." — 실제 임피던스를 다는 방법이 더 정확하긴 하지만 식이 복잡해져요. 수업 규칙은 실제값이 아니라 이상값으로 종단하는 근사예요.
  2. 남은 포트는 원래 전류 입력에 붙어 있었어요. 이상적인 전류 입력 임피던스 $0$을 따라 단락해요. 실제값 $1/g_{m1}$이 $0$이 아니어도 이상값을 쓰는 근사예요.
  3. "전압 입력과 전류 입력의 이상 임피던스를 구별하지 않았어요." — $\infty$는 전압 입력의 이상값이에요. 이 증폭기는 전류 입력이라 이상값이 $0$이에요.
  4. "종단 근사가 필요하다는 점을 복제 자체를 생략해도 된다는 뜻으로 오해했어요." — 입력 임피던스가 이상적이지 않다는 것은 복제를 생략할 이유가 아니에요. 감지 복제는 출력 쪽 로딩을 남기려고 다는 것이에요.

정답: B

Q3. 전류 증폭기 귀환의 K 측정

출력 전류를 감지해 입력에 전류를 돌려주는 C-C 귀환이에요(전방 증폭기는 전류 증폭기 $A_I$).

귀환망만 떼어 귀환율 $K$를 잴 때, 감지 포트에 거는 원·반송 포트 처리·$K$의 단위가 모두 맞는 것은?

  1. 전류원 $I_1$을 걸고 반송 포트를 단락해 $I_2$를 재요. $K=I_2/I_1$ [A/A]
  2. 전류원 $I_1$을 걸고 반송 포트를 개방해 $V_2$를 재요. $K=V_2/I_1$ [Ω]
  3. 전압원 $V_1$을 걸고 반송 포트를 단락해 $I_2$를 재요. $K=I_2/V_1$ [S]
  4. 전압원 $V_1$을 걸고 반송 포트를 개방해 $V_2$를 재요. $K=V_2/V_1$ [V/V]
힌트 보기

감지량이 무엇인지로 거는 원을, 반송량이 무엇인지로 반송 포트를 개방할지 단락할지를 정해요.

풀이 보기
  1. 감지량이 전류라 전류원 $I_1$을 걸어요. 반송량이 전류라 반송 포트를 단락하고 단락선 전류 $I_2$를 재요. 전류끼리의 비라서 단위는 A/A예요.
  2. "반송량이 전류일 때 단락해서 잰다는 짝을 놓쳤어요." — 이것은 전압을 돌려주는 C-V 귀환의 측정법이에요. 반송량이 전류인데 포트를 개방하면 흐르는 전류가 항상 $0$이라 잴 수 없어요.
  3. "감지량이 전류인데 전압원을 걸었어요. 거는 원의 종류는 감지량과 같아요." — 이것은 출력 전압을 감지하는 V-C 귀환의 측정법이에요. 이 회로는 출력 전류를 감지하므로 전류원을 걸어요.
  4. "$K$를 항상 전압 분배비로만 생각했어요. $K$는 형태에 따라 A/A, S, Ω 단위도 가져요." — 이것은 V-V 귀환의 측정법이에요. C-C 귀환의 $K$는 전류 이득이에요.

정답: A

Q4. 저항이 하나 더 달린 분배기의 귀환율

V-V 귀환(출력 전압 감지, 입력 쪽에 전압 반송)의 귀환망이 저항 세 개로 되어 있어요.

  • 출력 노드와 가운데 노드 $P$ 사이: $R_1=6\ \mathrm{k\Omega}$
  • $P$와 접지 사이: $R_2=2\ \mathrm{k\Omega}$
  • $P$와 반송 포트(게이트 쪽 단자) 사이: $R_3=10\ \mathrm{k\Omega}$

귀환망만 떼어 수업 규칙대로 $K$를 재요. 저주파 저항 회로이고, 전압은 접지 기준이에요.

$K$를 단위 없는 숫자로, 소수 둘째 자리까지 입력하세요.

힌트 보기

반송 포트를 개방하면 $R_3$에 전류가 흐르는지 먼저 봐요.

풀이 보기
  1. 감지량이 전압이라 출력 쪽 포트에 전압원 $V_1$을 걸고, 반송량이 전압이라 반송 포트를 개방해 접지 기준 전압 $V_2$를 재요. $K=V_2/V_1$이에요.
  2. 반송 포트가 열려 있으니 $R_3$에는 전류가 흐르지 않고 전압 강하도 없어요. 그래서 $V_2=V_P$이고, $R_3$는 분배비에 들어가지 않아요.
  3. $V_P$는 $R_1$–$R_2$ 분배로 정해져요: $K=\frac{V_2}{V_1}=\frac{R_2}{R_1+R_2}$
  4. 값을 넣으면 $K=\frac{2\ \mathrm{k\Omega}}{(6+2)\ \mathrm{k\Omega}}=0.25$예요. 전압끼리의 비라서 단위가 없어요(V/V).

정답: 0.25

Q5. 분배기가 달린 단의 역할 구분

NMOS $M_1$의 소스에 입력 전압 $V_{in}$을 걸어요. 드레인은 $R_D$를 거쳐 $V_{DD}$에 연결되고, 드레인 전압이 출력 $V_{out}$이에요. $V_{out}$과 접지 사이에 $R_1$(위)–$R_2$(아래) 직렬 분배기가 있고, 그 가운데 노드가 $M_1$의 게이트에 연결돼요.

$\lambda=0$, 저주파 소신호로 볼 때 이 회로의 입력·출력·귀환망을 바르게 구분한 것은?

  1. 입력은 게이트, 출력은 드레인인 공통 소스 단이고, 분배기는 게이트 바이어스용 저항이에요.
  2. 분배기는 출력 노드에 달린 부하일 뿐이고, 회로는 귀환이 없는 공통 게이트 단이에요.
  3. 입력은 소스, 출력은 드레인이에요. 분배기가 출력 전압을 감지해 게이트로 $V_F$를 돌려주고, $M_1$의 드레인 전류가 $g_{m1}(V_F-V_{in})$에 비례해 $M_1$이 뺄셈기 역할을 해요.
  4. 입력은 소스이고, 분배기가 출력에서 소스 쪽으로 전류를 돌려주는 V-C 귀환이에요.
힌트 보기

$V_{in}$이 실제로 어느 단자에 걸리는지, 게이트에는 무엇이 들어오는지 봐요.

풀이 보기
  1. "게이트를 입력 단자로 읽어 CS 단으로 착각했어요." — $V_{in}$은 소스에 걸려요. 게이트에는 분배기가 출력에서 나눠 돌려준 전압만 들어와요.
  2. "분배기를 부하로만 읽어 귀환을 놓쳤어요." — 분배기의 가운데 노드가 게이트로 이어져 출력 전압의 일부가 다시 $M_1$에 들어와요. 이것이 귀환 경로예요.
  3. 입력은 소스, 출력은 드레인이에요. 게이트 전류가 0이라 $V_F=\frac{R_2}{R_1+R_2}V_{out}$이 그대로 게이트에 들어가요. $v_{gs}=V_F-V_{in}$이라 $M_1$이 귀환량과 입력을 빼요. 출력 전압 감지·전압 반송인 V-V 귀환이에요.
  4. "귀환망이 연결된 단자를 소스로 잘못 읽어 반송량을 전류로 판단했어요." — 분배기 가운데 노드는 소스가 아니라 게이트에 붙어 있어요. 게이트로는 전류가 흐르지 않으니 돌려주는 양은 전압이에요.

정답: C

Q6. 게이트 쪽 복제와 입력저항

$M_1$ 소스로 입력을 받고, 출력(드레인)–$R_1$–게이트–$R_2$–접지 분배기로 귀환하는 CG 단이에요. $R_1+R_2$가 $R_D$보다 훨씬 크지 않아서 귀환망 사본을 달아 로딩을 포함한 개루프를 구해요. $\lambda=0$, 저주파 소신호예요.

게이트 쪽에 반송 복제(가운데 단자는 게이트, $R_1$ 위 끝은 접지)를 달아도 $R_{in,open}=1/g_{m1}$이 그대로인 이유로 맞는 것은?

  1. 반송 복제의 $R_1$ 위 끝을 개방하므로 복제로 전류가 흐를 길이 없기 때문이에요.
  2. $R_1+R_2\gg R_D$라고 가정했기 때문이에요.
  3. 반송 복제가 소스에 병렬로 붙어 $(1/g_{m1})\parallel(R_1\parallel R_2)$가 되지만, $R_1\parallel R_2$가 커서 무시하기 때문이에요.
  4. 반송 복제는 게이트에 달리고 게이트 전류가 0이라 $R_1\parallel R_2$에 신호 전압이 생기지 않아요. 게이트가 AC 0이므로 소스에서 본 저항은 $1/g_{m1}$ 그대로예요.
힌트 보기

반송 복제가 어느 단자에 붙는지, 그 단자로 신호 전류가 흐르는지 봐요.

풀이 보기
  1. "반송 복제의 종단을 개방으로 잘못 기억했어요." — V-V 귀환의 반송 복제는 원래 전압 출력($0$)에 붙어 있던 끝을 접지해요. 개방하지 않아요.
  2. "출력 쪽 로딩을 무시하는 조건을 입력저항에 대한 설명으로 끌어왔어요." — 이 문제는 그 가정이 없어요. 그 가정은 출력 쪽 감지 복제의 영향을 무시할 때 쓰는 조건이고, 입력저항이 그대로인 이유와는 상관없어요.
  3. "반송 복제가 붙는 단자를 입력 노드(소스)로 착각했어요." — 반송 복제의 가운데 단자는 소스가 아니라 게이트에 붙어요. 소스에 병렬로 들어가는 저항은 없어요.
  4. 게이트로 들어가는 전류가 없어서 반송 복제 $R_1\parallel R_2$에 전압 강하가 없고 게이트는 AC 접지와 같아요. 그래서 반송 복제는 입력저항을 바꾸지 않고, 감지 복제만 이득과 출력저항을 바꿔요.

정답: D

Q7. 분배기 로딩이 줄인 개루프 이득

$M_1$ 소스로 입력 $V_{in}$을 받고, 출력은 $R_D$가 달린 드레인이에요. 출력–$R_1$–게이트–$R_2$–접지 분배기가 귀환망이에요. $R_1+R_2=3R_D$이고, $\lambda=0$, 저주파 소신호예요. 이상적 귀환이라는 가정은 없어요.

로딩을 포함한 개루프 이득 $A_{v,open}$은 분배기를 무시한 이득 $g_{m1}R_D$의 몇 배인가요? 단위 없는 숫자로, 소수 둘째 자리까지 입력하세요.

힌트 보기

출력 쪽 감지 복제의 가운데 단자를 개방하면 출력 노드에 무엇이 접지까지 달리는지 봐요.

풀이 보기
  1. V-V 귀환이라 감지 복제의 가운데 단자는 원래 전압 입력($\infty$)이었으므로 개방해요. 출력 노드에 $R_1+R_2$가 접지까지 직렬로 달려요.
  2. 출력을 단락하고 출력 노드에서 드레인으로 들어가는 전류를 양으로 잡으면 $G_m=-g_{m1}$이에요. 게이트는 AC 0, 소스는 $v_{in}$이라 $v_{gs}=-v_{in}$이에요.
  3. $v_{in}=0$에서 출력은 $R_D$와 감지 복제를 함께 봐요: $R_{out,open}=R_D\parallel(R_1+R_2)$
  4. $A_{v,open}=-G_mR_{out,open}=g_{m1}[R_D\parallel(R_1+R_2)]$이므로 비는 $\frac{A_{v,open}}{g_{m1}R_D}=\frac{R_1+R_2}{R_D+R_1+R_2}$예요.
  5. $R_1+R_2=3R_D$를 넣으면 $\frac{3R_D}{4R_D}=0.75$예요. 감지 복제가 출력 부하를 줄여 이득이 25 % 작아져요.

Q8. 트랜스임피던스 회로의 개루프 저항

$M_1$은 게이트가 바이어스 전압(소신호 접지)에 묶이고, 소스가 입력 노드예요. 입력 전류 $I_{in}$이 이 노드로 들어오고, 소스의 바이어스 전류원은 이상적이에요. $M_1$ 드레인은 $R_{D1}$을 거쳐 $V_{DD}$에 연결되고 그 노드 $X$가 $M_2$ 게이트예요. $M_2$는 소스 접지, 드레인이 $R_{D2}$를 거쳐 $V_{DD}$에 연결된 출력 $V_{out}$이에요. $R_F$가 $V_{out}$과 입력 노드 사이에 있어요.

$\lambda=0$, 저주파 소신호이고 $R_F$의 크기에 대한 가정은 없어요. 로딩을 포함한 개루프의 입력·출력 저항으로 맞는 것은?

  1. $R_{in,open}=1/g_{m1}$, $R_{out,open}=R_{D2}\parallel R_F$
  2. $R_{in,open}=(1/g_{m1})\parallel R_F$, $R_{out,open}=R_{D2}\parallel R_F$
  3. $R_{in,open}=(1/g_{m1})\parallel R_F$, $R_{out,open}=R_{D2}$
  4. $R_{in,open}=1/g_{m1}$, $R_{out,open}=R_{D2}$
힌트 보기

전류 입력·전압 출력이라는 형태에서 두 $R_F$ 사본의 남은 포트가 각각 무엇으로 종단되는지 먼저 정해요.

풀이 보기
  1. "입력 쪽 사본을 개방해 입력 노드에서 $R_F$가 사라진다고 봤어요." — 반송 복제의 남은 포트는 원래 전압 출력($0$)에 붙어 있었으므로 접지해요. 그래서 입력 노드에도 접지된 $R_F$가 달려요.
  2. 감지 복제의 남은 포트는 원래 전류 입력($0$), 반송 복제의 남은 포트는 원래 전압 출력($0$)에 붙어 있었어요. 둘 다 단락이라 입력 노드와 출력 노드에 각각 접지된 $R_F$가 달려요. 입력 노드에서는 $1/g_{m1}$과, 출력 노드에서는 $R_{D2}$와 병렬이에요.
  3. "출력 전압을 감지한다는 이유로 V-V처럼 감지 복제를 개방했어요." — 출력 쪽 감지 복제의 남은 포트는 원래 전류 입력($0$)에 붙어 있었으므로 접지해요. 그래서 출력에도 $R_F$가 병렬로 보여요.
  4. "사본을 달고도 개루프 값이 바뀌지 않는다고 봤어요." — 이것은 $R_F$가 아주 커서 로딩을 무시한 이상적 개루프 값이에요. 가정이 없으면 두 사본의 로딩을 넣어야 해요.

Q9. 귀환 저항이 줄인 트랜스임피던스

$M_1$은 게이트가 소신호 접지인 CG 단으로, 소스(입력 노드)로 입력 전류 $I_{in}$을 받고 드레인 노드 $X$에 $R_{D1}$이 달려요. $M_2$는 게이트가 $X$, 소스가 접지, 드레인(출력 $V_{out}$)에 $R_{D2}$가 달린 CS 단이에요. $R_F$가 $V_{out}$과 입력 노드 사이에 있어요. $\lambda=0$, 저주파 소신호이고 $R_F$ 크기에 대한 가정은 없어요.

여기서 $R_F=9/g_{m1}$이고 $R_F=R_{D2}$예요.

로딩을 포함한 개루프 이득의 크기 $|R_0|$는 로딩을 무시한 값 $g_{m2}R_{D1}R_{D2}$의 몇 배인가요? 단위 없는 숫자로, 소수 둘째 자리까지 입력하세요.

힌트 보기

입력 노드에서 $I_{in}$이 $M_1$ 소스 쪽($1/g_{m1}$)과 접지된 $R_F$ 사본으로 어떻게 나뉘는지부터 봐요.

풀이 보기
  1. 두 사본을 모두 접지해 달면 입력 노드와 출력 노드에 각각 $R_F$가 접지로 달려요.
  2. 첫 단: $I_{in}$이 $1/g_{m1}$과 $R_F$로 나뉘고 $M_1$으로 간 몫만 $R_{D1}$에 흘러요: $\frac{V_X}{I_{in}}=\frac{R_FR_{D1}}{R_F+1/g_{m1}}$
  3. 둘째 단(CS): 출력을 단락하면 $G_{m2}=g_{m2}$, $V_X=0$에서 $R_{out,open}=R_{D2}\parallel R_F$, 그래서 $\frac{V_{out}}{V_X}=-G_{m2}R_{out,open}=-g_{m2}(R_{D2}\parallel R_F)$예요.
  4. 두 단을 곱해 이상값 $-g_{m2}R_{D1}R_{D2}$로 나누면 $\frac{|R_0|}{g_{m2}R_{D1}R_{D2}}=\frac{R_F}{R_F+1/g_{m1}}\cdot\frac{R_F}{R_F+R_{D2}}$예요.
  5. $R_F=9/g_{m1}$이면 첫 비는 $\frac{9}{9+1}=0.9$, $R_F=R_{D2}$이면 둘째 비는 $\frac{1}{2}=0.5$예요. 곱은 $0.9\times0.5=0.45$예요.

정답: 0.45

Q10. 귀환 저항이 충분히 큰가

$M_1$은 게이트가 소신호 접지인 CG 단으로, 소스(입력 노드)로 입력 전류 $I_{in}$을 받고 드레인 노드 $X$에 $R_{D1}$이 달려요. $M_2$는 게이트가 $X$, 소스가 접지, 드레인(출력 $V_{out}$)에 $R_{D2}$가 달린 CS 단이에요. $R_F$가 $V_{out}$과 입력 노드 사이에 있어요.

$1/g_{m1}=50\ \Omega$, $R_{D2}=10\ \mathrm{k\Omega}$, $R_F=20\ \mathrm{k\Omega}$이에요. 문제에는 $R_F$의 크기에 대한 가정이 따로 없어요. $\lambda=0$, 저주파 소신호예요.

개루프를 구할 때 가장 알맞은 판단은?

  1. $R_F$가 $1/g_{m1}$의 400배라 입력 쪽 영향은 작지만, $R_{D2}$의 2배뿐이라 $R_{out,open}$이 $R_{D2}$의 $2/3$로 줄어요. 로딩을 고려해야 해요.
  2. $R_F=20\ \mathrm{k\Omega}$는 큰 저항이므로 이상적 귀환으로 풀어요.
  3. $R_F$가 $1/g_{m1}$보다 400배 크므로 귀환망은 이상적이라고 봐도 돼요.
  4. $R_F$가 $R_{D2}$보다 크기만 하면 되므로 이상적 귀환으로 봐요.
힌트 보기

$R_F$를 절댓값이 아니라 입력 쪽 $1/g_{m1}$, 출력 쪽 $R_{D2}$와 각각 비교해요.

풀이 보기
  1. 기준은 상대 크기예요. 입력 쪽 비는 $\frac{20}{20+0.05}\approx1.00$이지만 출력 쪽 비는 $\frac{20}{20+10}=\frac{2}{3}$이에요. 가정도 없으니 로딩을 넣어요.
  2. "귀환 저항의 크기를 절댓값으로 판단했어요." — $20\ \mathrm{k\Omega}$이 큰지는 그 자리 저항과 비교해야 알 수 있어요. 출력 쪽 $R_{D2}=10\ \mathrm{k\Omega}$과 비교하면 2배뿐이에요.
  3. "입력 쪽 비교만 하고 출력 쪽 로딩을 확인하지 않았어요." — 입력 쪽 조건 $R_F\gg1/g_{m1}$만 맞아요. $R_F\gg R_{D2}$도 성립해야 이상적 귀환으로 볼 수 있어요.
  4. "'충분히 크다($\gg$)'를 '크다($>$)'로 약하게 읽었어요." — 필요한 조건은 '크다'가 아니라 '충분히 크다'예요. 2배면 출력 저항이 약 33 % 줄어요.

Q11. 분모가 1보다 작게 나왔을 때

$M_1$은 게이트가 소신호 접지인 CG 단으로, 소스(입력 노드)로 입력 전류 $I_{in}$을 받고 드레인 노드 $X$에 $R_{D1}$이 달려요. $M_2$는 게이트가 $X$, 소스가 접지, 드레인(출력 $V_{out}$)에 $R_{D2}$가 달린 CS 단이에요. $R_F$가 $V_{out}$과 입력 노드 사이에 있어요. 로딩을 포함한 개루프 이득은 $R_0\lt0$이에요. 한 학생이 반송 전류 $I_F$의 양의 방향을 $V_{out}$ 쪽에서 $R_F$를 지나 입력 노드로 들어오는 방향으로 잡아 $K=+1/R_F$를 얻었어요. 그러자 폐루프 이득의 분모가 $1-|R_0|/R_F$ 꼴로 1보다 작게 나왔어요.

맞는 진단은?

  1. 분모가 1보다 작으니 이 회로는 실제로 양귀환이에요.
  2. $K$가 음수면 양귀환이므로 $K=+1/R_F$가 맞고, 분모도 맞아요.
  3. $I_F$는 입력 노드에서 빠져 $R_F$로 들어가는 방향이 양이어야 해요. 그러면 $K=-1/R_F$, $KR_0=|R_0|/R_F\gt0$이라 분모 $1+|R_0|/R_F\gt1$인 음귀환이에요.
  4. 로딩을 빼먹어서 $R_0$의 부호가 바뀐 것이니, 로딩 포함 $R_0$를 다시 구하면 돼요.
힌트 보기

입력 노드의 KCL에서 전방 증폭기로 들어가는 전류를 $I_{in}-I_F$로 쓰려면 $I_F$가 어느 방향이어야 하는지 봐요.

풀이 보기
  1. "전류 방향을 잘못 잡아 생긴 부호 오류를 회로의 성질로 받아들였어요." — 신호를 따라가면 $I_{in}\uparrow\to V_X\uparrow\to V_{out}\downarrow\to$ 입력 노드에서 $R_F$로 빠지는 전류 $\uparrow$라서 입력 증가를 상쇄해요. 음귀환이에요.
  2. "$K$의 부호만으로 귀환의 종류를 판단했어요." — 음귀환 판단은 $K$ 하나의 부호가 아니라 루프 이득 $KR_0$의 부호로 해요. $R_0\lt0$이므로 $K\lt0$이어야 $KR_0\gt0$이에요.
  3. $I_e=I_{in}-I_F$가 성립하도록 $I_F$는 입력 노드에서 빠지는 방향을 양으로 잡아요. 이 방향으로 재면 실제 전류가 반대라 $K=-1/R_F$이고, $R_0\lt0$과 곱한 루프 이득은 양수예요. $1-KA$ 꼴은 부호 오류의 신호예요.
  4. "로딩 효과가 이득의 부호까지 바꾼다고 생각했어요." — 로딩은 $R_0$의 크기를 줄일 뿐 부호를 바꾸지 않아요. CG(비반전)와 CS(반전)의 곱이라 $R_0\lt0$은 그대로예요.

정답: C

Q13. 폐루프 출력저항 구하기

CG+CS 트랜스임피던스 귀환 회로를 다섯 단계로 풀어, 로딩을 포함한 개루프 값 $R_0=-36\ \mathrm{k\Omega}$, $R_{out,open}=1.5\ \mathrm{k\Omega}$을 얻었어요. 귀환망은 $V_{out}$과 입력 노드 사이의 $R_F=4\ \mathrm{k\Omega}$ 하나예요. 반송 전류의 양의 방향은 입력 노드에서 빠져 $R_F$로 들어가는 방향이에요. $\lambda=0$, 저주파 소신호예요.

힌트 보기

먼저 $K$를 구해 루프 이득 $KR_0$의 부호와 크기를 확인해요.

풀이 보기
  1. 4단계: 반송 포트를 단락하고 감지 포트에 $V_1$을 걸면 전류가 $R_F$를 지나 단락선으로 빠져나가 정한 방향과 반대예요. $K=-1/R_F=-1/(4\ \mathrm{k\Omega})=-0.25\ \mathrm{mS}$
  2. 루프 이득: $KR_0=(-0.25\ \mathrm{mS})\times(-36\ \mathrm{k\Omega})=9$ ($\mathrm{mS}\times\mathrm{k\Omega}=1$). 양수라 음귀환이고 $1+KR_0=10$이에요.
