# 장말문제 15.48 — 체비셰프 필터의 차수를 6으로 늘렸을 때의 최소 리플

## 조건
- 문제 15.47에서 필터 차수를 6으로 바꾼다.
- 문제 15.47과 같이 통과대역폭은 $2\ \mathrm{MHz}$이고 $5\ \mathrm{MHz}$에서 $25\ \mathrm{dB}$ 감쇠가 필요하다. (원문에 없음)

## 구할 것
- 6차 응답의 최소 리플을 구하고 문제 15.47의 차수 5 이하 결과와 비교한다.

## 상속·참조
- 문제 15.47은 같은 저지대역 사양에서 통과대역 리플을 최소화한다. 이번에는 차수를 6으로 정한다.
