# 수동·능동 1차 필터의 극점과 영점

- 저장 파일명: `인터렉티브_01_수동_능동_1차_필터의_극점과_영점`
- 아키타입: `probe` · 점수 7 (값→극점·영점·이득 +2, 가상 접지를 지나는 전류 인과 +2, 수동/능동 직접 비교로 오개념 해소 +2, 기존 위젯 확장 +1)

## 기존 위젯과의 관계
- 관련 위젯: `widget-s2-active` (반전 증폭기의 R1C1·R2C2·R2/R1 슬라이더 → 보데 근사 선도).
- 실험에서 새로 하는 일: 실제 회로도(수동 RC 분압기·반전 증폭기 두 모드)에서 개별 소자 R1·C1·R2·C2를 바꾸며, 수동에서는 극점에 네 소자가 얽히고 능동에서는 극점=귀환 가지·영점=입력 가지로 분리되는 것을 같은 조작으로 비교. 가상 접지 노드 전압(µV), 같은 전류가 Z1→Z2로 흐르는 인과 단계, 회로 계산 크기 응답과 측정점.
- 예측 답 노출: 위젯은 능동 회로만 다루고 수동 극점을 보여 주지 않으므로 예측(수동에서 C1↑ → 극점↓) 답을 먼저 보여 주지 않음 → **유지**.

## 모드·조작
- 모드: `passive`(수동 RC 분압기, 강의노트 s10 (a)), `active`(반전 증폭기, s11 (a))
- params: R1·R2 0.5–8 kΩ, C1·C2 0.5–8 nF (step 0.5), 측정 각주파수 ω 10⁴–10⁸ rad/s(log)
- presets: 수동 `정리노트 예시 R1=R2, C2=3C1`(1/2·1/4), `능동 예시와 같은 값`; 능동 `LPF 1k/1n/2k/2n`, `HPF 1k/4n/2k/0.5n`, `평탄 R2C2=R1C1`
- causalSteps: 수동 1 입력 → 2 Z1·Z2 같은 전류 → 3 분압 출력 / 능동 1 입력 → 2 Z1 전류(가상 접지) → 3 같은 전류가 Z2 → 4 출력 −iZ2
- steps 4개(수동 양 끝 이득 → 수동 C1이 극점 이동 → 능동 같은 조작 → 능동 이득>1)

## 예측
- 수동 RC 분압기에서 C1을 1→2 nF로 키우면 |p|는? 답: 작아져요(0.5→0.375×10⁶ rad/s). 검증: before R1=1k,C1=1n,R2=2k,C2=2n → after C1=2n, 타일 pole·zero.

## 오개념 (모드별 3개)
- 수동: 극점=1/(R2C2) / 이득>1 가능 / 직렬 가지를 R1+1/(sC1)로 읽기(수업 중 정정)
- 능동: 반전 단자가 실제 접지 / 입력 가지가 극점을 움직임 / 고주파 이득 C2/C1(수업 중 정정)

## 모델·근거
- 수동: H = R2(1+sR1C1)/((R1+R2)+sR1R2(C1+C2)), |p|=(R1+R2)/(R1R2(C1+C2)), |z|=1/(R1C1). 정리노트 s2-passive, STT 1127 L07 s10.
- 능동: H = −(R2/R1)(1+sR1C1)/(1+sR2C2). 정리노트 s2-active, STT “폴과 제로를 인디펜던트하게”. OP-amp는 이득 10⁶(gm=10⁶ S, Ro=1 Ω)의 이상적 근사로 MNA에 넣음. OP-amp 대역폭 한계는 모델에 없음(s2-compare에서 말로만 다룸).
- 수업 범위 안, 교과서 보충 없음.
