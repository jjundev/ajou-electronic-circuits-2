# 장말문제 11.6 — 극점 두 개와 영점 한 개의 보데 선도

## 원문
An amplifier exhibits two poles at $100\ \text{MHz}$ and $10\ \text{GHz}$ and a zero at $1\ \text{GHz}$. Construct the Bode plot of $|V_{out}/V_{in}|$.

## 조건
- 증폭기의 극점 두 개: $100\ \text{MHz}$, $10\ \text{GHz}$
- 영점 한 개: $1\ \text{GHz}$

## 구할 것
- $|V_{out}/V_{in}|$의 보데 선도

## 회로 — 없음 (보데 선도 문제, 그림 없음)

## 풀이
### 전달 함수
- 저주파 이득을 $A_0$라 하면 $|H| = |A_0|\dfrac{\sqrt{1 + (f/1\ \text{GHz})^2}}{\sqrt{1 + (f/100\ \text{MHz})^2}\sqrt{1 + (f/10\ \text{GHz})^2}}$
- 영점이 좌반면이든 우반면이든 크기는 같다
### 꺾이는 점마다 기울기
- $f < 100\ \text{MHz}$: 기울기 0, 높이 $20\log|A_0|$
- $100\ \text{MHz}$–$1\ \text{GHz}$: 극점 → $-20\ \text{dB/dec}$, 10배 구간이라 $20\ \text{dB}$ 내려간다
- $1$–$10\ \text{GHz}$: 영점이 기울기를 $+20\ \text{dB/dec}$ 되돌려 0, 높이 $20\log|A_0| - 20\ \text{dB}$
- $f > 10\ \text{GHz}$: 극점 → 다시 $-20\ \text{dB/dec}$
### 정확한 값과 비교
- $A_0$ 기준으로 $100\ \text{MHz}$에서 $-2.97\ \text{dB}$, $1\ \text{GHz}$에서 $-17.1\ \text{dB}$, $10\ \text{GHz}$에서 $-23.0\ \text{dB}$, $100\ \text{GHz}$에서 $-40.0\ \text{dB}$
### 답
- $20\log|A_0|$에서 평평하다가 $100\ \text{MHz}$부터 $-20\ \text{dB/dec}$로 $20\ \text{dB}$ 내려가고, $1\ \text{GHz}$에서 영점 때문에 다시 평평해져 $20\log|A_0| - 20\ \text{dB}$를 유지하다가, $10\ \text{GHz}$부터 다시 $-20\ \text{dB/dec}$로 떨어진다.
