# 회로 근거와 필기 음성을 연결하는 문제풀이 영상 설계

## 의도와 확정 범위
학생이 핵심 식을 보기 전에 관련 회로의 연결과 가정을 확인하고, 필기 중에는 쓰는 내용과 그 의미를 음성으로 듣는다. 자막은 발음 철자 대신 소자·수식 기호를 표시한다. 기존 Native 실행 선호를 유지한다. 이번 요청은 계획 작성이며 구현 승인은 별도 후속 메시지에서 받는다.

범위는 기존 ec2-solution-video 장면 저작·검증과 음성/자막 계약의 개선이다. 현재 샘플은 figure_intro/figure_return 두 회로 장면 이후 부하·출력 저항·이득을 필기하는 동안 회로 근거 장면이 없다. 음성과 자막은 같은 segment.text를 사용한다. 기존 reason/check 회로 포커스와 원본 SVG 주석을 재사용한다.

## 확정 동작
- 핵심 논리 단계마다 관련 회로를 reason 장면에서 먼저 짚고, write 장면에서 해당 결론을 쓴다. 연결 확인이 필요한 단계에는 check를 추가한다.
- 제목·단순 계산 줄에는 불필요한 회로 왕복을 넣지 않는다. 회로를 직접 참조하지 않는 단계도 근거와 제외 이유를 명시한다.
- 회로 장면은 어디를 보고 왜 판단하는지 설명한다. 필기 장면은 지금 쓰는 문장·식을 읽고 기호와 항의 의미를 설명한다.
- 필기 단위는 의미 있는 문장/짧은 식 단위로 나눈다. PageMap의 원본 glyph/shape를 중복·누락 없이 분할한다. 1개의 mapped step에 1개의 write segment 계약을 유지한다.
- 음성용 text와 자막용 caption_text를 별도로 저작한다. 음성의 ‘알 오 원’은 자막의 r_O1로 표시한다. r_O1, r_O3, g_m1, V_BE, R₁, Q₁, ∥ 등의 표기를 사용한다. 원문 기호의 대소문자와 첨자를 보존한다. SRT에서 미지원 LaTeX 문자열을 그대로 출력하지 않는다.
- 이전 데이터는 caption_text가 없으면 text로 자막을 생성한다. 새 guided 저작에서는 모든 segment에 caption_text가 필수다. 제공한 caption_text가 비어 있으면 오류이며 fallback하지 않는다.
- 핵심 식을 쓰기 전에 연결된 회로 근거 장면이 재생되어야 한다. 확인 장면은 필기 후에 재생한다. 현재 주석이 분명하도록 이전 주석의 hide_at을 저작한다.
- 영상 길이는 이해 우선으로 필요한 만큼 늘린다. 필기 기본 속도는 7.5 chars/sec, 30fps, 원본 왼쪽→오른쪽 순서와 줄 전체 구도, 12프레임 카메라 전환을 유지한다.
- 실제 PCM으로 필기 중 연속 무음을 검사한다. 60프레임(2초)을 초과하는 공백은 현재 입력 해시와 구간을 명시한 의도적 휴지 검토가 없으면 완료를 막는다. 70–85% 음성 밀도는 저작 가이드이며 의미 검토나 무음 검사 대신 자동 승인 근거가 되지 않는다.
- TTS의 자연 발화 시간을 변경하지 않는다. 음성/필기 차이가 크면 원문에 근거해 대본과 필기 단위를 조정한다. 자동 말 늘리기, 무한 재생성, 음성 늘이기/잘라내기를 하지 않는다.

## 저작 데이터
source/lesson.json을 선택적 추가한다. 존재하는 run은 guided 계약을 적용한다.
```json
{"schema_version":1,"steps":[{"step_id":"load_eq","mode":"circuit","reason_segment_ids":["load_reason"],"check_segment_ids":["load_check"],"region_ids":["load"],"annotation_ids":["load_mark"],"meaning_notes":"베이스/이미터 고정과 유한한 출력 저항을 짚는다","source_refs":["원본 근거"]}]}
```
steps는 PageMap 순서와 일치한다. circuit 모드는 reason/region/annotation이 각 1개 이상 필요하다. calculation 모드는 이 세 목록이 빈 목록이며 exemption_reason이 필수다. check는 선택이다. step에 속한 write의 text/caption_text는 지금 쓰는 내용과 연결되어야 하며 의미 검토가 확인한다. 기계적 단어 일치만으로 전자회로의 정당성을 승인하지 않는다.

## E10.13 승인용 샘플
1. 대칭 가지와 P/X를 짚기 → 가상 접지 결론 필기.
2. Q3/Q4 베이스·이미터 연결과 고정된 소신호 전압을 짚기 → 전류원 부하와 남는 r_O3 필기.
3. Q1 컬렉터와 R1의 반대쪽 끝 X를 짚기 → r_O1 ∥ r_O3 ∥ R₁ 필기.
4. Q1의 공통 이미터 동작과 앞서 구한 부하를 짚기 → 음의 부호와 g_m1을 포함한 이득 필기.
필기 음성 예: ‘출력 저항은 알 오 원, 알 오 쓰리, 알 원의 병렬입니다. 세 저항이 출력에서 같은 교류 접지로 연결되기 때문입니다.’ 자막 예: ‘출력 저항은 r_O1 ∥ r_O3 ∥ R₁입니다.’ 둘의 의미 일치는 사람이 검토한다.

## 실패·검증·범위 제한
잘못된 step/segment/region/annotation 연결, 근거 없는 circuit 단계, 순서 역전, 빈 자막은 유료 TTS 이전에 오류로 알린다. 실제 타임라인에서 회로 포커스와 해당 표시가 근거 장면에 나타나는지, 미래 풀이가 보이지 않는지, 필기 중 잘림이 없는지 검사한다. 의미 검토는 원문·회로 표시·음성·자막 네 요소를 함께 확인한다.
자막만 수정해도 후속 타임라인/렌더/검증은 갱신한다. 기존 TTS cache key는 음성 text 기반이므로 음성 원고가 같으면 WAV를 재사용하고 유료 호출은 0이어야 한다. 안전성을 위해 기존 stage 해시 전파는 유지한다.
원본 PDF/MD와 이전 샘플을 보존한다. fake PCM은 기술 검증용이며 실제 음성/교육 품질 통과로 취급하지 않는다. 기존 키만 환경 또는 사용자가 지정한 env 경로로 사용하며 비밀을 자동 검색/출력하지 않는다. 공개·latest 변경·커밋은 별도 명시적 승인 없이 수행하지 않는다.
항상 작은 회로 창을 표시하는 레이아웃, 자동 등가회로 생성, 단어별 강제 음성 정렬은 이번 범위에 포함하지 않는다.
