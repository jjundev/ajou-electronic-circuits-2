# 장말문제 10.85 — MOS 차동쌍(Fig 10.31) 설계: 평형 과구동 100 mV, 2 mW, 입력 공통 모드 1 V에서 트라이오드 경계가 되는 R_D와 전압 이득

## 원문
Design the MOS differential pair of Fig. 10.31 for an equilibrium overdrive voltage of $100\ \text{mV}$ and a power budget of $2\ \text{mW}$. Select the value of $R_D$ to place the transistor at the edge of triode region for an input common-mode level of $1\ \text{V}$. Assume $\lambda = 0$, $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $V_{TH,n} = 0.5\ \text{V}$, and $V_{DD} = 1.8\ \text{V}$. What is the voltage gain of the resulting design?

## 조건
- 설계 대상: 본문 Fig 10.31의 MOS 차동쌍
- 평형 과구동 전압 $100\ \text{mV}$
- 전력 예산 $2\ \text{mW}$
- 입력 공통 모드 레벨 $1\ \text{V}$에서 트랜지스터가 트라이오드 영역의 경계에 놓이도록 $R_D$ 값을 고름
- $\lambda = 0$, $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $V_{TH,n} = 0.5\ \text{V}$, $V_{DD} = 1.8\ \text{V}$

## 구할 것
- 회로 설계 (정할 값 예: $I_{SS}$, $W/L$) (원문에 없음, 원문은 "설계하라"만 적음)
- 트라이오드 경계 조건을 만족하는 $R_D$
- 설계 결과의 전압 이득

## 회로 — Fig 10.31
```spice

RD2  VDD    Vout2  {R_D}
M1   Vout1  Vin1   n1    nmos
M2   Vout2  Vin2   n1    nmos    ; 좌우 반전 (게이트 오른쪽)
ISS  n1     0      {I_SS}
* n1 = 공통 소스(테일) 노드 (라벨 없음)
* 각 드레인 점에서 바깥쪽으로 Vout1, Vout2 개방 원. 안쪽으로도 개방 원이 하나씩 있고 두 원 사이에 "V_out" 라벨 (+ 왼쪽, − 오른쪽, 차동 출력). 안쪽 원은 각각 Vout1, Vout2와 같은 노드
```
- 단자: VDD = 전원, 값 미지정 (가로 레일) / Vin1, Vin2 = 입력 (개방 원) / Vout1, Vout2 = 출력 (바깥쪽 개방 원) / 안쪽 개방 원 두 개 = 차동 출력 V_out = Vout1 − Vout2 (개방 원)
- 표시: 노드 라벨 V_DD (레일 오른쪽 끝), V_out1 (왼쪽 바깥 원 왼쪽), V_out2 (오른쪽 바깥 원 오른쪽), V_out (안쪽 두 원 사이), V_in1 (왼쪽 입력 원 왼쪽), V_in2 (오른쪽 입력 원 오른쪽) / 소자 라벨 R_D (왼쪽 저항 왼쪽), R_D (오른쪽 저항 오른쪽), M1 (M1 오른쪽), M2 (M2 왼쪽), I_SS (전류원 오른쪽) / 부호 + (왼쪽 안쪽 원 위), − (오른쪽 안쪽 원 위) / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 맨 위 굵은 가로 레일 V_DD / 왼쪽 세로줄 위→아래 R_D, 드레인 점, M1 / 오른쪽 세로줄 위→아래 R_D, 드레인 점, M2 / 왼쪽 드레인 점에서 가로선이 왼쪽으로 V_out1 원, 오른쪽으로 안쪽 원(+) / 오른쪽 드레인 점에서 가로선이 오른쪽으로 V_out2 원, 왼쪽으로 안쪽 원(−) / M1 nmos 보통 방향(게이트 왼쪽), M2 nmos 좌우 반전(게이트 오른쪽) / V_in1 원 → M1 게이트, V_in2 원 → M2 게이트 / 두 소스는 아래로 내려가 가로선으로 가운데 n1 점, n1에서 아래로 I_SS(화살표 아래), 그 아래 접지 / 접속점 (세 갈래 이상, 3곳): ① 왼쪽 드레인 점 = 위 R_D + 아래 M1 드레인 + 왼쪽 V_out1 선 + 오른쪽 안쪽 원 선 (점) ② 오른쪽 드레인 점 = 위 R_D + 아래 M2 드레인 + 오른쪽 V_out2 선 + 왼쪽 안쪽 원 선 (점) ③ n1 = 왼쪽 M1 소스 선 + 오른쪽 M2 소스 선 + 아래 I_SS (점) / 교차: 없음

## 풀이
### 전력과 과구동으로 $W/L$
- $I_{SS} = P/V_{DD} = 2\ \text{mW}/1.8\ \text{V} = 1.11\ \text{mA}$, 평형에서 $I_D = I_{SS}/2 = 0.556\ \text{mA}$
- $W/L = \dfrac{2I_D}{\mu_n C_{ox}(V_{GS} - V_{TH})^2} = \dfrac{2(0.556\ \text{mA})}{(100\ \mu\text{A/V}^2)(0.1\ \text{V})^2} = 1.11 \times 10^3$
### 트라이오드 경계로 $R_D$
- 경계 조건은 $V_D = V_G - V_{TH}$다. 두 입력이 공통 모드 $1\ \text{V}$인 평형에서 $V_D = 1\ \text{V} - 0.5\ \text{V} = 0.5\ \text{V}$
- $R_D = \dfrac{V_{DD} - V_D}{I_D} = \dfrac{1.8\ \text{V} - 0.5\ \text{V}}{0.556\ \text{mA}} = 2.34\ \text{k}\Omega$
### 전압 이득
- $g_m = 2I_D/(V_{GS} - V_{TH}) = 2(0.556\ \text{mA})/0.1\ \text{V} = 11.1\ \text{mS}$
- $|A_v| = g_m R_D = 11.1\ \text{mS} \times 2.34\ \text{k}\Omega = 26.0$
### 답
- $I_{SS} = 1.11\ \text{mA}$, $W/L = 1.11 \times 10^3$
- $R_D = 2.34\ \text{k}\Omega$
- $|A_v| = 26.0$
