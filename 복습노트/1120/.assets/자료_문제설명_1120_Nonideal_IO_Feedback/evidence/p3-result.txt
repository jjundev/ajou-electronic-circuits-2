A0 exact = (g_m + g_o)/(G_L + g_o) ; lambda=0 = g_m/G_L
Rin0 exact = (G_L + g_o)/(G_L*(g_m + g_o)) ; lambda=0 = 1/g_m
Rout0 exact = 1/(G_L + g_o) ; lambda=0 = 1/G_L
Acl exact = (g_m + g_o)/(G_L + K*g_m + g_o) ; lambda=0 = g_m/(G_L + K*g_m)
Rincl exact = (G_L + K*g_m + g_o)/(G_L*(g_m + g_o)) ; lambda=0 = (G_L + K*g_m)/(G_L*g_m)
Routcl exact = 1/(G_L + K*g_m + g_o) ; lambda=0 = 1/(G_L + K*g_m)
The ideal DC source is AC-open. G_L = 1/(R_1+R_2), K = R_2/(R_1+R_2).
At lambda=0 the closed denominator simplifies to 1+g_m*R_2.
