# 전자회로2 복습자료 zip

`복습노트/<MMDD>/`의 파일을 모아 `~/Downloads/`에 zip 하나로 만든다. 원본은 건드리지 않는다.

**인자**: `[범위] [notes]`
- 범위: `0918` / `0916-0930` / `0911,0923`. 생략하면 모든 날짜.
- `notes`: 정리노트 `.html`과 `figures_<MMDD>/` 폴더도 넣는다. html이 상대경로로 그림을 참조하므로 figures는 꼭 같이 넣어야 한다. `.md`는 넣지 않는다.

## 실행

프로젝트 루트에서 스크립트를 그대로 부른다. 직접 복사·압축하지 않는다.

```powershell
pwsh -File .claude/skills/ec2-review-zip/scripts/make-zip.ps1 -Range "0916-0930" -Notes
```

범위가 없으면 `-Range`를 빼고, `notes`가 없으면 `-Notes`를 뺀다.

| 결과 | zip 이름 |
|---|---|
| 문제·답안만 | `복습문제_<첫날>-<끝날>.zip` |
| `notes` 포함 | `복습자료_<첫날>-<끝날>.zip` |
| 날짜 하나 | `복습문제_0918.zip` |

같은 이름의 zip은 덮어쓴다.

## 보고

스크립트 출력 그대로 전한다: zip 경로·크기, 포함한 날짜, 건너뛴 날짜(넣을 파일이 없던 날짜, 예: 문제지가 없는 0902·0904). 종료 코드가 1이면 zip이 만들어지지 않은 것이니, 출력에 나온 실제 날짜 목록을 보여주고 범위를 다시 묻는다.
