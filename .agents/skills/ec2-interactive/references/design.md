# 전자회로 화면 규칙

기준은 example-frequency-response.dc.html이에요. 공통 셸은 템플릿을 따르고 주제별 슬롯·장면·문구를 채워요.

- 상단 바: 조작 토글·제목·1–3개 모드·테마·설명 토글. 640px 미만은 제목을 숨겨요.
- 왼쪽: 보기 옵션 → 값 조작·대표 설정 → 해석 단계. 오른쪽: 숫자 타일 → 현재 상태·범례 → 짧은 설명 → 꼭 기억해요 3개.
- 1024px 미만은 한 번에 하나의 패널 서랍을 열어요. 버튼은 44px 이상, 상태는 aria-pressed, 아이콘에는 aria-label을 써요.
- 평면 회로·파형·보데 선도가 기본이에요. cam yaw/pitch=0, autoSpin/rotatable=false. 시점 회전이 학습에 필요할 때만 입체 모드를 써요.
- 전기적 연결·종속원 화살표·AC 접지·입력/출력 노드·부호·단위·근사 가정을 정확히 표시해요. 물리적 배치가 전기적 연결로 오해되지 않게 해요.
- 같은 상태의 모델이 회로 라벨·곡선·현재 표식·숫자 패널을 계산해요. 극점과 전체 -3 dB 대역폭을 구별해요. Hz와 rad/s, |H|와 dB를 섞지 않아요.
- 색은 PAL 토큰만 써요. 정확식 실선과 근사 점선, 입력과 출력은 이름·선 모양도 함께 써요. 라이트·다크 대비를 확인해요.
- 선은 k:1, 화살표 k:4, 텍스트 k:3, 노드 k:0을 사용해요. fit에 여유를 두고 모바일 라벨 겹침·잘림을 실제 확인해요.
- 해요체로 한 문장에 한 가지를 써요. 수업 밖 해석은 (교과서 보충). 꼭 기억해요는 극점/대역폭처럼 실제 혼동을 풀어줘요.
- canvasLabel은 현재 화면을 설명해요. 마크업에 직접 hex 색을 넣지 않아요. 의미 없는 흔들림·깜박임을 넣지 않아요.
