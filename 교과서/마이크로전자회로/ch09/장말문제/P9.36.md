# 장말문제 9.36 — 저항 분배기로 바이어스한 MOS 전류원의 V_DD 감도

## 원문
Repeat Problem 9.35 for Eq. (9.85) (in terms of $V_{DD}$).

## 조건
- 문제 9.35를 식 (9.85)에 대해 다시 풂 ($V_{DD}$ 기준)

## 구할 것
- $I_1$의 $V_{DD}$에 대한 감도 $\partial I_1 / \partial V_{DD}$
- 이 감도가 $M_1$의 트랜스컨덕턴스에 비례하는 이유를 직관적으로 설명 (원문 "Repeat"로 문제 9.35에서 이어받음, $Q_1 \to M_1$ 치환은 원문에 없음)

## 상속·참조
- 문제 9.35: 식 (9.83)에서 $I_1$의 $V_{CC}$ 감도 $\partial I_1/\partial V_{CC}$를 구하고, 그 감도가 $Q_1$의 트랜스컨덕턴스에 비례하는 이유를 직관적으로 설명하는 문제
- 본문 Fig 9.22(b) (교재 468쪽, 크롭 안 함): 저항 분배기 바이어스 MOS 전류원
  - `R1: VDD — P`, `R2: P — 0`
  - `M1: D = I_1이 들어가는 단자, G = P, S = 0` (nmos)
- 식 (9.85): $I_1 = \dfrac{1}{2} \mu_n C_{ox} \dfrac{W}{L} \left( \dfrac{R_2}{R_1 + R_2} V_{DD} - V_{TH} \right)^2$

## 회로 — 없음 (식에서 출발하는 문제, 문제 그림 없음)

## 풀이
### 게이트 전압
- 분배비 $a = R_2/(R_1 + R_2)$로 쓰면 $M_1$의 $V_{GS} = a V_{DD}$이고, 식 (9.85)는 $I_1 = \frac{1}{2} \mu_n C_{ox} \frac{W}{L} (a V_{DD} - V_{TH})^2$
### 감도
- $\dfrac{\partial I_1}{\partial V_{DD}} = \mu_n C_{ox} \dfrac{W}{L} (a V_{DD} - V_{TH}) \cdot a = a\, g_{m1}$ ($M_1$의 $g_{m1} = \mu_n C_{ox} \frac{W}{L}(V_{GS} - V_{TH})$)
### 직관
- $V_{DD}$ 변화는 분배기를 거쳐 $a \Delta V_{DD}$만큼 $V_{GS}$를 바꾸고, $M_1$은 $V_{GS}$ 변화를 $g_{m1}$배의 드레인 전류 변화로 바꾼다
- 상대 감도는 $\frac{1}{I_1} \frac{\partial I_1}{\partial V_{DD}} = \frac{2a}{V_{GS} - V_{TH}}$로, $(V_{GS} - V_{TH})/2 > V_T$이면 바이폴라의 $a/V_T$보다 작다
### 답
- $\partial I_1/\partial V_{DD} = \dfrac{R_2}{R_1 + R_2}\, \mu_n C_{ox} \dfrac{W}{L} \left( \dfrac{R_2}{R_1 + R_2} V_{DD} - V_{TH} \right) = \dfrac{R_2}{R_1 + R_2}\, g_{m1}$
- $V_{DD}$ 변화가 분배기를 거쳐 $V_{GS}$ 변화로 들어가고, $M_1$은 $V_{GS}$ 변화를 $g_{m1}$배의 전류 변화로 바꾸기 때문이다.
