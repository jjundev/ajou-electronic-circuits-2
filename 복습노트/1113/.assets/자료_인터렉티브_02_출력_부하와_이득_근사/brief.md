# 출력 부하와 1/K 근사

- 파일명 `인터렉티브_02_출력_부하와_이득_근사.html`. 선정 5점(수치 변화 2, 부하 비교 2, 위젯 확장 1). 아키타입 `approx`.
- 1113 정리노트 §6, STT Part 11–13, L06 s33·s35, Razavi §12.6.1(669–672쪽, 식 12.58 및 예제 12.15·17)에 근거한다. (교과서 보충) 직렬 출력 저항에 외부 부하를 달아 1/K 근사 오차가 커지는 조건을 적용한다.
- 전압–전압 귀환 모드에서 무부하 개루프 이득 A₀=2–10,000, K=0.05–0.50, 100 Ω 부하를 조작한다. 대표 설정은 A₀=100에서 무부하와 부하 연결, 부하 연결 상태에서 A₀=10,000이다.
- A₀=100, K=0.1에서 부하를 달면 1/K 근사 오차가 어떻게 달라지는지 예측하고 전후 이득과 오차를 확인한다. 외부 부하 → 출력 분압 → 유효 루프 이득 저하 → 근사 오차 증가를 그래프로 확인한다.
- 오개념은 무부하 개루프 이득만 보는 것, 전압 감지 블록의 무부하 가정과 외부 부하를 혼동하는 것, 부하로 인한 오차 변화를 K 변화로 보는 것이다.
- 선형 저주파 전압 증폭기(입력 1 mV, 직렬 출력 저항 1 kΩ)와 이상적 단방향 감지·반송을 쓴다. 주파수 의존성·클리핑은 모형에 포함하지 않는다. 오차 분모는 비교 기준 1/K이고 10%를 학습용 기준으로 삼는다.
- 정리노트 `정리노트_1113_Voltage_Voltage_Feedback.html#s5-loop-gain-rule`에 연결한다. `widget-loopgain`은 세 폐루프 값을 한자리에서 비교하는 기능이 있고 부하 토글이나 부하에서의 근사 오차를 제시하지 않아 유지한다. `widget-polar`도 주제가 달라 유지한다.
