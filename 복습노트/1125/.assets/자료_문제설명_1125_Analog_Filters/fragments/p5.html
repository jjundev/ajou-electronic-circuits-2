루프를 끊는 위치

$R_F$는 출력 전압을 감지해 $N$으로 전류를 되돌리는 귀환망이에요. 교과서는 $R_M$을 순방향 증폭기에 넣어요. $R_M$ 없이는 $M_2$가 출력 전압을 만들 수 없기 때문이에요. 그래도 $R_M$까지 한 블록으로 묶어 복제하면 결과가 같아요. 입력 복제에서는 $R_M$의 양단이 모두 접지가 되어 사라지고, 출력 복제에서는 원래 $R_M$ 자리에 그대로 남기 때문이에요. 이렇게 묶으면 원 회로의 $R_F$와 $R_M$을 지우고 아래 두 복제로 바꾸면 돼요.

두 포트가 모두 원 회로에서 병렬이라, 복제본에서 쓰지 않는 포트는 둘 다 단락해요. 입력 복제는 감지 포트 $P$를, 출력 복제는 반송 포트 $N$을 접지에 붙여요.

  • 원래의 $R_M$을 출력 복제의 $R_F\parallel R_M$과 따로 더하지 않아요.
  • 입력 쪽 첫 인자에 출력 복제의 $R_F\parallel R_M$을 쓰지 않아요. 입력 복제에서 $N$에 걸린 저항은 $R_F$뿐이에요.
  • P3(E12.32)는 감지 포트가 레이저와 직렬이라 입력 복제에서 열어 $R_F+R_M$이 남아요. 여기는 병렬이라 단락해 $R_F$만 남아요.

개루프 저항과 이득

㉠ 입력 $N$에서는 $M_1$ 소스 쪽 저항과 입력 복제의 $R_F$가 병렬이에요. $r_{O1}\to\infty$로 두고 몸체 효과를 무시하면 $M_1$ 소스 쪽 저항은 $1/g_{m1}$이에요. ㉡ 출력 $P$에서는 $r_{O2}$와 출력 복제의 $R_M$, $R_F$가 병렬이에요.

$$R_{in,open}=\frac{1}{g_{m1}}\parallel R_F$$ $$R_{out,open}=r_{O2}\parallel R_M\parallel R_F$$

$g_{m1}R_Dg_{m2}R_F\gg1$에서 $R_F$의 직접 순방향 전달을 생략해요. $N$의 노턴 입력을 테브난 전압 $V_{\mathrm{Th}}=I_{in}R_F$와 직렬 $R_F$로 바꿔요. 이 $R_F$는 입력 복제에서 $N$에 걸린 저항이고, 첫 인자 $R_F$는 $V_{\mathrm{Th}}/I_{in}$이에요. 테브난 전압에서 $X$까지의 이득에는 $R_F$와 $1/g_{m1}$의 분압이 들어가요.

$$A_{\mathrm{open}}=\frac{V_{out}}{I_{in}}=R_F\frac{V_X}{V_{\mathrm{Th}}}\frac{V_{out}}{V_X}\ [\mathrm{V/A}]$$ $$\frac{V_X}{V_{\mathrm{Th}}}=\frac{R_D}{R_F+1/g_{m1}}$$

검산: 앞의 두 인자를 곱하면 $R_{in,open}$에 공통 게이트 이득 $g_{m1}R_D$를 곱한 값과 같아요.

$$R_F\frac{R_D}{R_F+1/g_{m1}}=\Bigl(\frac{1}{g_{m1}}\parallel R_F\Bigr)g_{m1}R_D$$

$M_2$는 공통 소스 단이고, 드레인 $P$에서 보이는 저항은 앞서 구한 $R_{out,open}$이에요.

$$\frac{V_{out}}{V_X}=-g_{m2}R_{out,open}$$ $$A_{\mathrm{open}}=\frac{R_FR_D}{R_F+1/g_{m1}}\bigl(-g_{m2}R_{out,open}\bigr)$$

㉢ 귀환망만 떼어 $N$을 접지하고 $P$에 $V_{out}$을 걸어요. 양의 $I_F$는 $N$에서 $P$로 향해요.

$$V_{out}=-R_FI_F$$ $$K=\frac{I_F}{V_{out}}=-\frac1{R_F}$$ $$KA_{\mathrm{open}}=\frac{g_{m2}R_DR_{out,open}}{R_F+1/g_{m1}}$$

폐루프 이득과 임피던스

병렬 입력·병렬 감지라 폐루프 이득과 두 포트 저항이 모두 $1+KA_{\mathrm{open}}$로 나뉘어요.

$$A_{\mathrm{closed}}=\frac{V_{out}}{I_{in}}\approx\frac{A_{\mathrm{open}}}{1+KA_{\mathrm{open}}}$$ $$R_{in,closed}\approx\frac{R_{in,open}}{1+KA_{\mathrm{open}}}$$ $$R_{out,closed}\approx\frac{R_{out,open}}{1+KA_{\mathrm{open}}}$$

교과서의 $r_{O2}\to\infty$ 모델에서는 출력 병렬 부하에 $R_M\parallel R_F$만 남아요. 두 회로의 차이는 아래와 같아요.
