# 연습문제 10.12 — R1 ≠ R2일 때 예제 10.12 반복 (예제 10.12 변형)

## 원문
만약 $R_1 \neq R_2$일 때, 위의 예제를 반복하라.

## 조건
- 예제 10.12의 회로(Fig 10.21(a)), $V_A < \infty$
- 바뀐 조건: $R_1 \neq R_2$
- 트랜지스터 쌍($Q_1$와 $Q_2$, $Q_3$와 $Q_4$)은 예제처럼 대칭 (원문에 없음)
- 소자 값은 주어지지 않음 (답은 기호로) (원문에 없음)

## 구할 것
- 차동 이득 (예제 10.12를 반복)

## 상속·참조
- 예제 10.12 (E10.12): $R_1 = R_2$(대칭)이면 $R_1$과 $R_2$ 사이 노드가 가상 접지 → 절반 회로 Fig 10.21(b)에서 $R_{out} = r_{O1} \| r_{O3} \| R_1$ (식 10.99), $A_v = -g_{m1}(r_{O1} \| r_{O3} \| R_1)$ (식 10.100)
- 본문 Fig 10.20 (교재 521쪽, 크롭 안 함)의 성질: 직렬 저항 $R_1$, $R_2$ 사이 노드 $X$가 가상 접지가 되려면 (1) $R_1 = R_2$, (2) 양 끝 $A$, $B$가 같은 크기로 반대 방향으로 변해야 함. 연결: `R1: A – X`, `R2: X – B`

## 힌트
### $R_1 + R_2$를 저항 하나로 보기
- $R_1$과 $R_2$ 사이 노드에는 다른 소자가 달려 있지 않으므로, 두 출력 사이에는 합친 저항 하나만 있다고 봐도 된다
- 트랜지스터가 대칭이면 회로는 그대로 대칭이니, 합친 저항의 한가운데를 다시 찾으면 예제의 논리를 쓸 수 있다

## 풀이
### 두 저항을 하나로 합치기
- $R_1$과 $R_2$ 사이 노드에는 다른 소자가 없어 두 저항에 같은 전류가 흐르므로, 두 출력 사이에는 저항 $R_1 + R_2$ 하나만 있다고 볼 수 있다
- 트랜지스터 쌍이 대칭이면 회로 전체가 다시 대칭이 된다
### 가상 접지와 절반 회로
- 차동 입력에서 두 출력은 같은 크기로 반대로 움직이므로, 합친 저항의 한가운데($R_1 + R_2$를 반씩 나눈 점)가 가상 접지다
- 따라서 절반 회로에서 각 출력에 접지로 달린 저항은 $(R_1 + R_2)/2$이다
- 실제 $R_1$–$R_2$ 사이 노드는 $R_1 \neq R_2$이면 가상 접지가 아니다
### 차동 이득
- $Q_1$의 트랜스컨덕턴스 $g_{m1}$, $Q_1$·$Q_3$의 출력 저항 $r_{O1}$, $r_{O3}$로 절반 회로의 출력 저항 $R_{out} = r_{O1} \parallel r_{O3} \parallel \dfrac{R_1 + R_2}{2}$
- $A_v = -g_{m1}\left(r_{O1} \parallel r_{O3} \parallel \dfrac{R_1 + R_2}{2}\right)$
### 답
- 차동 이득 $A_v = -g_{m1}\left(r_{O1} \parallel r_{O3} \parallel \dfrac{R_1 + R_2}{2}\right)$ ($R_1 = R_2$이면 예제의 $-g_{m1}(r_{O1} \parallel r_{O3} \parallel R_1)$)
