# ec2-interactive 및 1014 첫 발행 설계

## 확정된 의도

생명과학 저장소의 bio-interactive(기준 커밋 35d47326830928444004fff3cb197a5991c075ae)를 독립적인 전자회로2 로컬 스킬 ec2-interactive로 이식한다. 공통 화면·검사·저장·최신 정리노트 연결 도구를 재사용하고, 전자회로의 근거 경로·주제 선정·수치 검증·예제를 바꾼다. 첫 실행은 1014 주파수 응답 자료 두 개를 실제 복습노트 폴더에 발행하고 정리노트의 관련 설명에 새 탭 링크를 연결한다.

사용자 결정 #1 = ②(스킬 + 1014 실제 자료 생성·노트 연결) [confirmed]. 접근 #0 = B(공통 도구 이식 + 전자회로 계약). 나머지는 앞선 grill-yourself 설계의 추천값으로 확정한다. 실행 방식은 writing-plans의 계획 검토 단계에서 선택한다.

## 완료 기준

- 자동 선택 가능한 .agents/skills/ec2-interactive/SKILL.md와 supporting resources가 있다. .claude/skills/ec2-interactive는 같은 원본을 가리킨다.
- /ec2-interactive 1014와 /ec2-interactive 차동쌍의 생성 흐름, 날짜 범위, 기존 자료 연결 전용 흐름이 문서화되고 도구가 실행된다.
- 복습노트/1014/에 CS 이득·대역폭·파형 및 두 극점·보데 근사 HTML 두 개와 각각의 .assets 제작자료가 있다.
- 실제 1014 정리노트 HTML의 관련 절에 설명을 담은 새 탭 링크가 있다. 모든 목적지 파일이 존재하며 재실행은 changed: false다.
- 도구 테스트, 별도 회로 계산, 내용 대조, 데스크톱·모바일의 라이트·다크 브라우저 검사를 통과했다. 검토되지 않은 항목은 완료로 보고하지 않는다.

## 동작과 입력

- 날짜: 기존 팩의 .assets/정리노트_*.md와 정리노트_*.html, STT/MMDD 전회2.md, 관련 강의노트 PDF와 Razavi 교재를 읽는다. 적합한 후보 2–4개를 우선하며 1개만 적합하면 1개만 만든다. 0개면 이유를 보고한다.
- 날짜 범위: 정확히 그 이름의 통합 팩 폴더가 있으면 해당 팩을 처리한다. 단일 날짜가 범위 폴더 안에 있으면 그 팩을 처리한다. 정확한 폴더가 없고 포함하는 범위 폴더가 여러 개면 AMBIGUOUS_TARGET으로 후보를 보고하고 임의 선택하지 않는다.
- 주제: MD의 H2/H3 본문 대응이 있는 팩, 이후 최신 끝 날짜 순으로 선택한다. 링크 글자만 일치하는 팩은 우선하지 않는다. 맞는 노트가 없으면 복습노트/주제별/에 생성하며 연결 불가 이유를 보고한다.
- 인자 없음: NO_ARG로 사용법을 보여 준다. 날짜를 추측하지 않는다.
- 기존 자료 연결 요청: 요청한 날짜·주제·전체 범위의 자료와 노트를 읽고 연결 명세만 실행한다. 생성·새 번호 발급을 하지 않는다.

## 전역 제약

- Node.js 20 이상; Windows PowerShell과 macOS의 NFC/NFD 경로를 지원한다.
- 원본은 .agents/skills/ec2-interactive/; .claude/skills/ec2-interactive는 같은 원본을 가리킨다.
- 기본 화면은 회전 없는 2D 회로도·파형·보데 선도이며 의미 있는 과정만 재생한다.
- 공통 상단 바·좌우 패널·od-theme·모바일 서랍·단계 선택·테마 스크롤바를 유지한다.
- HTML은 팩 최상위, 원본·canvas.json·검토 기록은 .assets/자료_인터렉티브_NN_<이름>/에 둔다.
- 기존 인터랙티브 자료를 덮어쓰지 않는다. 새 번호의 저장은 순차 실행한다.
- 정리노트 HTML의 안내·링크만 수정한다. MD·PDF·기존 위젯·본문·스타일·스크립트는 유지한다.
- 수치·회로 그림·패널·설명은 동일 모델을 사용하며 Hz/rad/s, 선형 이득/dB, 반전 부호를 명시한다.
- 수업 밖 위상·정현파 해석은 패널과 근거 문서에 (교과서 보충)으로 표시한다.
- 모든 저장 대상은 기계 검사·독립 회로 검산·내용 검토·브라우저 확인을 통과해야 한다.
- 브라우저 검사는 1440×900과 375×812에서 라이트·다크 모두 수행한다.
- 새 링크는 상대 경로와 target="_blank" rel="noopener noreferrer"를 사용한다.
- 새 안내 표식은 data-ec2-interactive이며 (새 탭) 같은 표시 문구는 붙이지 않는다.
- 외부 게시·자동 커밋·영상·복습문제 생성·SPICE 시뮬레이터는 범위 밖이다.

## 데이터 흐름과 경계

resolve → 근거·주제 브리프 → 템플릿 기반 Main.dc.html → check/steps → 독립 내용·수치 검토 → 임시 build·브라우저 확인 → save → 실제 저장 파일 확인 → note-links dry-run → 연결 → 재실행·실제 링크 확인 → 보고.

resolve({repo,arg})는 kind, folder, exists, date, notes, noteHtml, stt, stts, existing, next를 반환한다. stt는 기존 호환을 위한 대표 경로이고 stts는 선택한 팩 범위의 실제 STT 경로 목록이다.

저장 도구의 반환 {nn,html,dir}를 연결에 사용한다. NN이나 파일명을 연결 단계에서 다시 추측하지 않는다. 연결 명세는 {notes:[{note,links:[{sectionId,html,label,before,after,anchorId?}]}]}이며 모든 파일 경로는 실제 절대 경로다.

기존 bio 연결 도구의 오프셋 기반 삽입을 유지한다. 기본 위치는 절 안 첫 .layer.formal 뒤, 없으면 .layer.eli5 뒤, 둘 다 없으면 제목 뒤다. anchorId를 쓰면 해당 절 안 기존 블록만 허용한다. 같은 절의 같은 목적지 링크는 재사용하고 새 탭 속성만 보정한다. 누락·모호한 절/자료는 해당 연결만 skipped로 보고한다.

## 1014 첫 자료

### 1. CS 이득·대역폭·파형

- 이름: CS_이득과_대역폭. 근거: s0-cs-cl, s0-3db, 강의자료 L05 s5–6, Razavi 11장 해당 식.
- g_m = 2 mS 고정, R_D = 10 kΩ, C_L = 100 fF 기본.
- H(s) = -g_m R_D / (1 + s R_D C_L), ω_p = 1/(R_D C_L), f_p = ω_p/(2π).
- 조작: R_D, C_L, 입력 주파수/극점 비율. 대표 설정: 기본·R_D 10배·C_L 10배.
- 화면: 소신호 회로, 크기 응답과 현재 주파수 표식, 정현파 입출력 비교. 회로 그림은 일반 MOS 실물도 대신 AC 접지로 연결된 R_D·C_L와 g_m v_in 종속 전류원의 등가회로를 정확히 그린다.
- 위상은 연속 표현 -180° - atan(ω/ω_p)로 CS 반전을 포함한다. 파형은 t/T와 각 신호의 V/V_peak를 축에 적고, 실제 진폭을 패널에 표시한다. 입력은 0.1 mV이며 소신호 선형 모델·클리핑 미포함을 명시한다.
- 연결: s0-3db의 formal 설명 뒤, 저항과 커패시턴스를 바꾸며 이득·대역폭·출력 파형을 비교하는 안내.

### 2. 두 극점과 보데 근사

- 이름: 두_극점과_보데_근사. 근거: s1-bode, s2-cs-two-poles, L05 s8–9.
- g_m = 5 mS 고정. 기본 R_S = 1 kΩ, C_in = 100 fF, R_D = 2 kΩ, C_L = 500 fF.
- H(s) = -g_m R_D / [(1+s R_S C_in)(1+s R_D C_L)]. 입력 RC와 출력 RC가 이 모델에서 독립이며 C_gd·몸체 효과·유한 r_o는 제외한다.
- 조작: R_S, C_in, R_D, C_L. 대표 설정: 기본·입력 극점 먼저·극점 겹침·R_D 증가.
- 화면: 입력·출력 노드 회로, 정확한 응답 실선, 보데 근사 점선, 두 극점 표식, 노드별 dB 기여 비교.
- 극점 주파수와 전체 -3 dB 대역폭을 별도 표시한다. 동일 극점에서는 극점 주파수에서 전체 -6.0206 dB, 전체 대역폭은 ω_p sqrt(sqrt(2)-1)/(2π)다.
- 연결: s2-cs-two-poles와 s1-bode의 formal 설명 뒤. 두 절이 같은 자료를 가리키는 것은 의도적이며 절별 중복만 막는다.

1014의 밀러 변환식은 다음 시간 범위이므로 만들지 않는다. 기존 gainbw/cs2p 위젯을 교체하지 않는다. 첫 자료의 추가 학습 목적은 회로·파형·해석 단계 연결과 정확한 응답·근사·전체 대역폭의 구별이다.

## 실패와 보고

NO_ARG, NO_TARGET, AMBIGUOUS_TARGET는 대상 처리 전에 보고한다. 검사·내용 검토·브라우저 실패는 한 차례 모아 수정하고 재검증한 뒤 남으면 주제별 보류한다. 링크 실패는 저장된 자료를 지우지 않고 해당 연결만 보고한다. 쓰기 실패는 소유한 임시/부분 산출물만 복구하며 기존 파일은 유지한다.

보고에는 실제 HTML 절대 경로, 주제 선정 이유, 조작·모드, 단순화·교과서 보충, 검토 결과, 연결 절과 added/updated/unchanged/skipped, 실행·백업 경로를 포함한다. 실제 실행하지 않은 검사는 not_run으로 기록하고 완료라고 표현하지 않는다.
