# 연습문제 13.1 — 바이폴라 차동쌍을 쓰는 발진기의 출력 진폭 제한 (예제 13.1 변형)

## 원문
바이폴라 차동쌍에 대해서 위의 예제를 반복하라.

## 조건
- 예제 13.1의 발진기에서 $H(s)$ 상자 안의 MOS 차동쌍을 바이폴라 차동쌍으로 바꾼 경우
- 참고 회로 (본문 Fig 13.5(a)): 입력 $X$와 귀환된 출력 $Y$가 덧셈기에서 $X - Y$로 합쳐져 $H(s)$로 들어가는 귀환 루프. $H(s)$ 안은 부하 $R_D$ 두 개, $M_1$, $M_2$, 테일 전류원으로 된 MOS 차동쌍, 차동 입력 $V_1$, 차동 출력 $V_2$ (원문에 없음)
- 바이폴라 차동쌍의 부하 저항은 $R_C$, 테일 전류는 $I_{EE}$로 둠 (원문에 없음)
- 소자 값은 주어지지 않음 (답은 기호와 설명으로) (원문에 없음)

## 구할 것
- 바이폴라 차동쌍을 쓸 때 출력 진폭을 제한하는 요인 설명

## 상속·참조
- 예제 13.1 (E13.01): MOS 차동쌍의 입력 스윙이 커지면 이득(입력/출력 특성의 기울기)이 떨어져 루프 이득이 줄고 진폭 성장이 멈춘다. $V_1$이 충분히 크면 테일 전류 $I_{SS}$가 한쪽으로 모두 흘러 $V_2$가 $-I_{SS}R_D$에서 $+I_{SS}R_D$로 스윙하는 것이 최대 진폭
- 본문 Fig 13.5(a) (교재 734쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig13-05-a.png): 연결 `덧셈기: X(+), Y(−) → H(s)`, `R_D(왼쪽): VDD – 왼쪽 드레인`, `R_D(오른쪽): VDD – 오른쪽 드레인`, `M1: D = 왼쪽 드레인, G = 위 V_1 원, S = 공통 소스 노드`, `M2: D = 오른쪽 드레인, G = 아래 V_1 원, S = 공통 소스 노드`, `테일 전류원(라벨 없음): 공통 소스 노드 → 접지`, $V_2$는 두 드레인 사이
- 10장 바이폴라 차동쌍의 대신호 동작: 차동 입력이 약 $4V_T$를 넘으면 테일 전류 $I_{EE}$가 한쪽 트랜지스터로 거의 모두 흐르고, 차동 출력은 $\pm R_C I_{EE}$에서 포화

## 회로 — 없음 (MOS 차동쌍을 바이폴라로 바꾸는 글 문제, 문제 그림 없음)
