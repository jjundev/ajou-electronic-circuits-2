# 예제 12.36 — 극점이 2개인 시스템이 발진할 수 없는 이유

## 원문
왜 2개의 극점을 갖는 시스템은 발진할 수 없는지 설명하라.

## 조건
- 극점이 2개인 증폭기 $H(s)$를 귀환율 $K$(주파수 무관)의 부귀환 루프에 넣은 시스템 (본문 그림 12.65, 원문에 없음)
- 극점 중 적어도 1개는 원점에 있지 않다고 가정 (원문의 각주 17)
- 식 (12.185), (12.186): 발진 조건(바르크하우젠 조건) $|KH(j\omega_1)| = 1$ (인쇄는 닫는 괄호 빠짐), $\angle KH(j\omega_1) = -180^\circ$ (본문 식, 원문에 없음)
- 소자 값은 주어지지 않음 (답은 설명으로) (원문에 없음)

## 구할 것
- 2개의 극점을 갖는 시스템이 발진할 수 없는 이유 설명

## 상속·참조
- 본문 그림 12.65 (교재 704쪽, 크롭 안 함): 부귀환 시스템 블록도. 입력 $X$(개방 원) → 덧셈기(+ 입력) → $H(s)$ 상자 → 출력 $Y$, 출력에서 갈라진 선이 삼각형 $K$ 블록을 거쳐 덧셈기의 − 입력으로 돌아옴
- 식 (12.184): $\dfrac{Y}{X}(s) = \dfrac{H(s)}{1 + KH(s)}$, $KH(s)$를 루프 전송이라 부름. 귀환율 $K$는 주파수 의존성이 없다고 가정 (예: 두 저항의 비)
- 식 (12.185): $|KH(j\omega_1| = 1$ (인쇄 그대로)
  - 닫는 괄호가 빠져 있음(오식으로 보임), 뜻은 $|KH(j\omega_1)| = 1$ (원문에 없음)
- 식 (12.186): $\angle KH(j\omega_1) = -180^\circ$
- 예제 12.35 (E12.35)의 본문 그림 12.64(b) (교재 703쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig12-64.png): 극점 2개 시스템의 보데 그림. 위 크기 $20\log|H|$는 평탄하다가 $\omega_{p1}$에서 꺾여 내려가고 $\omega_{p2}$에서 더 가파르게 꺾여 0을 지나 내려감. 아래 위상 $\angle H$는 0에서 내려가 $-90^\circ$ 근처에서 잠시 평탄해진 뒤 다시 내려가 $-180^\circ$(점선)에 점근

## 회로 — 없음 (그림 없는 글 문제, 풀이는 본문 그림 12.64(b)의 보데 그림을 씀)

## 답 (검증용)
- 그림 12.64(b)에서 보듯이 극점 2개 시스템의 위상 시프트는 $\omega = \infty$에서만 $-180^\circ$에 도달하고, 그때 $|H| \to 0$
- 따라서 식 (12.185)와 (12.186)을 동시에 만족하는 주파수가 없어 발진하지 않음
