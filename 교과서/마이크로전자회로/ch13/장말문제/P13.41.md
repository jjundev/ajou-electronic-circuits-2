# 장말문제 13.41 — 고역 통과 네 단을 쓴 위상 시프트 발진기

## 원문
Suppose a phase shift oscillator incorporates four high-pass sections with equal resistors and capacitors. Derive the oscillation frequency and the startup condition for such a circuit.

## 조건
- 위상 시프트 발진기의 수동 망이 고역 통과 단 네 개로 이루어짐
- 네 단의 저항은 모두 같고 커패시터도 모두 같음
- 그 값을 $R$, $C$로 둠 (원문에 없음)
- 참고 회로 (본문 Fig 13.24(a)): 직렬 $C$, 접지로 가는 $R$로 된 고역 통과 단을 차례로 잇고, 마지막 단 출력을 이득 $-A_0$ 증폭기로 받아 그 출력을 첫 단 입력으로 되돌림. 이 문제에서는 단이 셋이 아니라 넷 (원문에 없음)
- 본문 13.4절의 세 단 해석 결과: 식 (13.32) $\dfrac{V_{out}}{V_{in}} = \dfrac{(RCs)^3}{(RCs)^3 + 6(RCs)^2 + 5RCs + 1}$, 식 (13.35) $\omega_1 = \dfrac{1}{\sqrt{6}RC}$, 식 (13.37) $A = 29$ (본문 식, 원문에 없음)

## 구할 것
- 발진 주파수
- 스타트업 조건
- 스타트업 조건은 필요한 증폭기 이득으로 나타냄 (원문에 없음)

## 상속·참조
- 본문 Fig 13.24(a)(b) (교재 750쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig13-24-a.png): (a) 위상 시프트 발진기 — $C_1$ → $X$ → $C_2$ → $Y$ → $C_3$ → 증폭기 입력, 각 노드에서 $R_1$, $R_2$, $R_3$가 접지로, 증폭기 $-A_0$ 출력 $V_{out}$이 $C_1$로 되돌아감. (b) 같은 수동 망만 따로 그린 것 ($V_{in}$ → … → $V_{out}$)
- 본문 해석 (13.4절, 세 단): $R_3$ 전류를 $V_{out}/R$로 두고 출력에서 입력 쪽으로 노드 전압을 차례로 구함
  - 식 (13.28)–(13.29): $V_Y = \dfrac{V_{out}}{R} \dfrac{1}{Cs} + V_{out}$, $\quad V_X = \left( \dfrac{V_Y}{R_2} + \dfrac{V_{out}}{R_3} \right) \dfrac{1}{Cs} + V_Y$
  - 식 (13.31)–(13.32): $V_{in} = \dfrac{V_{out}}{R^3C^3s^3} + \dfrac{5V_{out}}{R^2C^2s^2} + \dfrac{6V_{out}}{RCs} + V_{out}$, $\dfrac{V_{out}}{V_{in}} = \dfrac{(RCs)^3}{(RCs)^3 + 6(RCs)^2 + 5RCs + 1}$
  - 식 (13.33)–(13.35): $\angle \dfrac{V_{out}}{V_{in}} = 3 \times 90° - \tan^{-1} \dfrac{5RC\omega - (RC\omega)^3}{1 - 6R^2C^2\omega^2}$, 위상 $180°$ 조건 $1 - 6R^2C^2\omega_1^2 = 0$, $\omega_1 = \dfrac{1}{\sqrt{6}RC}$
  - 식 (13.36)–(13.37): $\dfrac{(\sqrt{6})^{-3}A}{5/\sqrt{6} - (\sqrt{6})^{-3}} = 1$, 곧 $A = 29$
