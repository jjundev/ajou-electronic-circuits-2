# 기출 개념 분류 검토 기록

검토일: 2026-10-21. 대상: 13개 시험의 61문항, 카탈로그의 173개 소문항 단위.

각 문항의 전사된 `원문`·조건·구할 것·회로 넷리스트·힌트·기존 풀이 전체를 읽고, 연결된 원본 회로 크롭 63개와 재작성 그림 63개를 시각 대조했다. 원본 PDF의 모든 문장 페이지를 다시 읽어 전사 정확성을 검증한 작업은 아니다. 그림이 없는 문항은 전사 원문과 조건·풀이를 대조했다.

`selection`만 보완하고 61문항을 `reviewed`로 갱신했다. 이는 **개념 분류 검토** 상태이며 정답의 독립 검산이나 특정 날짜 수업 범위 승인을 뜻하지 않는다. 원문 자체의 모호성, 풀이의 추가 가정과 근사는 아래 메모에 남겼다. 문항 전체 채택 원칙은 유지한다.

## 주요 보완

- 일반 캐스코드 부하와 출력에서 소스·이미터를 바라보는 부하를 구분했다.
- 유한 β·rπ·ro, 차동 반회로, 축퇴 저항과 테일 저항, 부하 불일치에 의한 CM-DM 변환을 필요한 소문항에 연결했다.
- 2021 기말 Q3의 부귀환 오분류를 양의 귀환으로 고치고, Q4의 차동쌍 오분류를 제거했다. 귀환망 부하와 전압/전류 이득 단위도 구분했다.
- Miller 극점 해석, MOS 천이 주파수, Sallen-Key 및 적분기 biquad의 전달 함수·고유주파수·Q 설계를 구체화했다.
- 원문이 요구하지 않은 보충 장점이나 풀이가 생략한 유한 β 보정을 모든 소문항의 필수 개념으로 강제하지 않았다.

## 검증

- 61문항의 selection 외 메타데이터와 본문이 작업 전 HEAD와 동일함을 확인했다.
- 61개 분류 해시가 실제 본문·시험/그림 입력 해시와 일치한다.
- 173개 소문항의 표지를 빠짐없이 분류하고, 소문항 개념이 전역 필요 개념에 포함됨을 확인했다.
- 모든 원문·풀이·회로 절을 분류 근거 절에 포함했다.
- 카탈로그 재생성·check, workbook 113개 테스트, review-pack 후보 20개 테스트, 문제설명 source 21개 테스트(61개 실제 기출 소검사 포함)가 통과했다.
