# 장말문제 12.68 — 두 극점 증폭기(예제 12.41)를 K = 0.5 귀환에 쓸 때의 위상 마진

## 원문
Suppose the amplifier in Example 12-41 is described by

$$H(s) = \frac{A_0}{\left(1 + \dfrac{s}{\omega_{p1}}\right)\left(1 + \dfrac{s}{\omega_{p2}}\right)}, \qquad (12.203)$$

where $\omega_{p2} \gg \omega_{p1}$. Compute the phase margin if the circuit is employed in a feedback system with $K = 0.5$.

## 조건
- 예제 12.41의 증폭기 (원문 표기 "Example 12-41")를 다음 전달 함수로 나타냄: $H(s) = \dfrac{A_0}{(1 + s/\omega_{p1})(1 + s/\omega_{p2})}$ (식 12.203)
- $\omega_{p2} \gg \omega_{p1}$
- 예제 12.41에서 이어받는 조건: 두 번째 극점 주파수 $\omega_{p2}$에서 $|H|$가 1(0 dB)로 떨어짐 (원문에 없음)
- 이 회로를 귀환율 $K = 0.5$인 귀환 시스템에 씀
- 식 (12.195): $\text{Phase Margin} = \angle H(\omega_{GX}) + 180^\circ$ ($\omega_{GX}$: 루프 이득 $|KH|$가 1이 되는 이득 교차 주파수) (본문 식, 원문에 없음)

## 구할 것
- $K = 0.5$인 귀환 시스템의 위상 마진

## 상속·참조
- 예제 12.41 (교재 712쪽, PDF 37 왼쪽, 12.8.4 위상 마진): 그림 12.73은 여러 개의 극점을 갖는 시스템의 주파수 응답. 두 번째 극점 주파수에서 크기가 1로 떨어졌다. $K = 1$인 이 증폭기를 쓴 귀환 시스템의 위상 마진을 결정하라
  - 예제 풀이 (참고): 두 번째 극점 주파수(멀리 떨어진 극점)에서 위상이 $-135^\circ$에 도달하므로 위상 마진은 $45^\circ$
  - 예제 뒤 연습문제: $K = 0.5$일 때 위상 마진은 $45^\circ$보다 큰가, 작은가?
- 그림 12.73 (교재 712쪽, 크롭 안 함, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig12-73.png): 보데 그림. 크기 $20\log|H|$는 평탄하다가 $\omega_{p1}$에서 꺾여 내려가고 $\omega_{p2}$에서 0 dB 축과 만난 뒤 더 가파르게 내려감. 위상 $\angle H$는 0에서 내려가 잠시 평탄해졌다가 다시 내려가 $\omega_{p2}$에서 $-135^\circ$를 지남
- 식 (12.195) (교재 711쪽): $\text{Phase Margin} = \angle H(\omega_{GX}) + 180^\circ$. $K$에는 위상 편이가 없으므로 $\angle KH = \angle H$
