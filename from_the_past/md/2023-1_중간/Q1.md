# 기출 2023-1 중간 1 — 차동쌍 CM 제거와 Miller 효과 서술형

## 원문
다음 질문에 간략히 답하시오.

(1) 이상적인 differential pair에서 "common-mode (CM) rejection" 특성의 의미를 설명하시오. 그리고 실제 differential pair에서 CM rejection 특성이 제한되는 2가지 이유를 설명하시오.

(2) 전압 이득 $A_V = -g_m R_D$인 증폭기에서 입력과 출력 사이의 capacitance를 $C_F$라 할 때, 등가 입력 임피던스를 구하시오. 그리고, Miller effect가 주파수 응답 특성에서 대역폭(bandwidth)에 미치는 영향을 설명하시오.

## 조건
- 소문항 두 개에 간략히 답하는 서술형 문제
- (2) 전용: 전압 이득이 $A_V = -g_m R_D$인 증폭기의 입력과 출력 사이에 커패시턴스 $C_F$가 있음

## 구할 것
- (1) 이상적인 differential pair에서 "common-mode (CM) rejection" 특성의 의미를 설명. 그리고 실제 differential pair에서 CM rejection 특성이 제한되는 이유 2가지를 설명
- (2) 등가 입력 임피던스를 구함. 그리고 Miller effect가 주파수 응답 특성에서 대역폭(bandwidth)에 미치는 영향을 설명

## 회로 — 없음 (서술형)

## 풀이
### (1) CM 제거의 의미
- 두 입력에 똑같이 더해진 신호(잡음, 전원 흔들림)에는 출력이 반응하지 않고, 두 입력의 차에만 반응하는 성질
- 이상적 차동쌍은 테일 전류원이 이상적이라 두 드레인 전류의 합이 테일 전류 $I_{SS}$로 고정되고($I_{D1} + I_{D2} = I_{SS}$) 두 쪽이 대칭이다. CM 입력이 변해도 각 전류가 $I_{SS}/2$ 그대로라 출력이 변하지 않는다 ($A_{CM} = 0$)
### (1) 실제 차동쌍의 제한
- 테일 전류원의 출력 저항 $R_{SS}$가 유한: CM 입력이 변하면 테일 전류가 변해 각 출력이 변한다. 부하 $R_D$, 입력 소자 $g_m$이면 단일 출력 $A_{CM} \approx -R_D/(1/g_m + 2R_{SS})$
- 두 쪽의 부조화(부하 저항 차 $\Delta R_D$, 소자 $g_m$ 차): $R_{SS}$로 생긴 CM 전류 변화가 두 출력에 다르게 나타나 차동 출력이 생긴다. 예: $A_{CM-DM} \approx \Delta R_D/(1/g_m + 2R_{SS})$
### (2) 등가 입력 임피던스
- $C_F$가 이득을 바꾸지 않는다고 보면(Miller 근사) $C_F$ 양단 전압은 $v_{in} - A_V v_{in} = (1 + g_m R_D) v_{in}$ ($v_{in}$은 입력 전압)
- 입력 전류 $sC_F(1 + g_m R_D) v_{in}$: $Z_{in} = \dfrac{1}{sC_F(1 + g_m R_D)}$, 곧 입력에서 접지로 $C_{in} = (1 + g_m R_D) C_F$가 달린 것과 같다
### (2) 대역폭에 미치는 영향
- 입력 신호원 저항을 $R_S$라 하면 입력 극점은 $\omega_{p,in} = 1/[R_S (1 + g_m R_D) C_F]$
- $C_F$가 $(1 + g_m R_D)$배로 커 보여 입력 극점이 낮은 주파수로 내려가고 대역폭이 줄어든다. 이득 $g_m R_D$가 클수록 더 심하다
### 답
- (1) CM 입력에는 반응하지 않고 차동 입력에만 반응하는 성질이다. 실제로는 테일 전류원의 출력 저항이 유한해 테일 전류가 CM 입력에 따라 변하고, 두 쪽 소자·부하의 부조화로 CM 신호가 차동 출력으로 바뀐다
- (2) $Z_{in} = 1/[sC_F(1 + g_m R_D)]$ (입력 커패시턴스 $(1 + g_m R_D) C_F$). Miller 효과로 입력 커패시턴스가 커져 입력 극점이 낮아지고 대역폭이 줄어든다
