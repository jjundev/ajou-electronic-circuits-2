# 장말문제 12.61 — 예제 12.38의 세 겹친 극점이 ω = 0.1ω_p에서 만드는 위상

## 원문
The three coincident poles in Example 12-38 do affect the phase even at $0.1\omega_p$. Calculate the phase of the transfer function at $\omega = 0.1\omega_p$.

## 조건
- 예제 12.38의 3단 증폭기가 갖는 세 개의 겹친 극점 (원문 표기 "Example 12-38")
- 예제 12.38: 그림 12.69(a)의 3단 증폭기에 $K = 1$인 부귀환을 걸려고 한다. 다른 커패시턴스를 무시하고 단이 모두 같다고 가정할 때 회로의 주파수 응답을 그리고 안정성 조건을 결정하라. $\lambda = 0$이라고 가정하라 (원문에 없음)
- 참고 회로 (본문 Fig 12.69(a)): 같은 공통 소스단 세 개($M_1$, $M_2$, $M_3$)가 직렬로 이어지고, 각 단은 드레인 저항 $R_D$와 드레인–접지 커패시터 $C_1$을 가짐. $V_{in}$은 $M_1$ 게이트, $M_3$ 드레인이 $V_{out}$ (원문에 없음)
- 식 (12.188): $H(s) = \dfrac{(g_m R_D)^3}{\left(1 + \dfrac{s}{\omega_p}\right)^3}$, $\omega_p = (R_D C_1)^{-1}$ (본문 식, 원문에 없음)
- 세 극점은 $0.1\omega_p$에서도 위상에 영향을 줌
- 각 단 이득의 음의 부호는 생략함 (본문 각주 19, 원문에 없음)

## 구할 것
- $\omega = 0.1\omega_p$에서 전달 함수의 위상

## 상속·참조
- 예제 12.38 (E12.38, 교재 707–709쪽): "그림 12.69(a)의 3단 증폭기에 $K = 1$인 부귀환을 걸려고 한다. 다른 커패시턴스를 무시하고 단이 모두 같다고 가정할 때 회로의 주파수 응답을 그리고 안정성 조건을 결정하라. $\lambda = 0$이라고 가정하라."
  - 그림 12.69(a) (이 파일의 그림 목록에는 넣지 않음, 크롭은 fig12-69-a.png): `RD (세 개): VDD — 각 단 드레인`, `M1: D = n1, G = Vin, S = 0`, `C1: n1 — 0`, `M2: D = n2, G = n1, S = 0`, `C1: n2 — 0`, `M3: D = Vout, G = n2, S = 0`, `C1: Vout — 0`
  - 풀이: 저주파 이득 $(g_m R_D)^3$, 겹친 세 극점 $(R_D C_1)^{-1}$. $|H|$는 $\omega_p = (R_D C_1)^{-1}$에서 60 dB/dec로 떨어지기 시작하고, 위상은 이 주파수의 1/10에서 변하기 시작해 $\omega_p$에서 $-135°$, $10\omega_p$에서 $-270°$에 접근
  - 각주 18: "엄밀히 말하면, 3개의 중복되는 극점은 $0.1\omega_p$ 아래의 주파수에서만 위상에 영향을 미친다."
  - 각주 19: 단순화를 위해 각 단의 이득에서 음의 부호는 생략
  - $H(s) = \dfrac{(g_m R_D)^3}{\left(1 + \dfrac{s}{\omega_p}\right)^3}$ (12.188), $\angle H(j\omega) = -3\tan^{-1}\dfrac{\omega}{\omega_p}$ (12.189), $\omega_{PX} = \sqrt{3}\,\omega_p$ (12.190), 안정 조건 $g_m R_D < 2$ (12.192)

## 회로 — 없음 (전달 함수의 위상 계산, 회로는 예제 12.38의 Fig 12.69(a)로 조건에 적음)
