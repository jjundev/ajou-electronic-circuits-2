# 연습문제 12.36 — 극점 하나가 원점에 있는 2극점 시스템

## 원문
만일 극점 중 1개가 원점에 있다면 어떤 일이 일어나는가?

## 조건
- 예제 12.36의 시스템: 극점이 2개인 증폭기 $H(s)$를 주파수 무관 귀환율 $K$의 부귀환 루프에 넣음 (원문에 없음)
- 바뀐 점: 두 극점 중 1개가 원점($s = 0$)에 있음 (예제는 각주 17에서 적어도 1개는 원점에 있지 않다고 가정)
- 식 (12.185), (12.186): 발진 조건 $|KH(j\omega_1)| = 1$, $\angle KH(j\omega_1) = -180^\circ$ (본문 식, 원문에 없음)

## 구할 것
- 극점 중 1개가 원점에 있을 때 어떤 일이 일어나는가 (발진 여부)

## 상속·참조
- 예제 12.36 (E12.36): 극점 2개 시스템의 위상은 $\omega = \infty$에서만 $-180^\circ$에 도달하고 그때 $|H| \to 0$이라 식 (12.185)와 (12.186)을 동시에 만족하는 주파수가 없음 → 발진하지 않음. 예제는 "극점 중 적어도 1개는 원점에 있지 않다"고 가정 (각주 17)
- 식 (12.185): $|KH(j\omega_1)| = 1$ (인쇄는 닫는 괄호 빠짐), 식 (12.186): $\angle KH(j\omega_1) = -180^\circ$
