# 장말문제 15.38 — 0.9배 코너 각주파수에서 1 dB 감쇠를 갖는 버터워스 차수

## 조건
- 버터워스 필터에서 $\omega=0.9\omega_0$일 때 롤오프는 $1\ \mathrm{dB}$이다.

## 구할 것
- 필요한 필터 차수를 정한다.

## 상속·참조
- 본문의 버터워스 응답은 $|H(j\omega)|=1/\sqrt{1+(\omega/\omega_0)^{2n}}$이며 $\omega_0$는 $-3\ \mathrm{dB}$ 각주파수이다.
