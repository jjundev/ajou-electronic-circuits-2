# 교과서 문제 MD 형식

목표: **md 파일 하나만 보고 원본 문제(조건, 질문, 회로도)를 그대로 복원**할 수 있게 한다.
그림 PNG는 대조용이다. md는 이미지 없이도 완결돼야 한다.

## 폴더와 파일 이름
```
교과서/마이크로전자회로/
  FORMAT.md
  _tools/crop_figures.py      # figures.yaml → 그림 PNG
  _tools/check_md.py          # 형식 검사
  ch<장>/
    예제/E<장>.<NN>.md        # 본문 예제
    연습문제/X<장>.<NN>.md    # 예제 <장>.<NN> 바로 뒤의 연습문제
    장말문제/P<장>.<NN>.md    # 장말 PROBLEMS
    figures/figures.yaml, figures/fig<장>-<NN>.png
```
번호는 두 자리로 채운다 (9.1 → `9.01`).

## frontmatter
```yaml
id: P9.04                 # E/X/P + 장.두자리
kind: 장말문제            # 예제 | 연습문제 | 장말문제 (id 접두어와 일치)
number: "9.4"             # 반드시 따옴표, id 와 일치 (P9.04 → "9.4", P9.10 → "9.10")
section: "9.1.1 전류원으로서의 캐스코드"   # 절 번호가 없는 머리는 원문 머리 그대로 (예: "Design Problems")
book_page: 485            # 교재 쪽
pdf_page: 20              # PDF 페이지(1부터)
difficulty: 1             # 장말문제만: * 개수 (0, 1, 2)
sol: false                # 장말문제만: SOL 마크 여부
source_lang: en           # 원문 언어 (ko | en)
figures:                  # 크롭 이미지가 있는 그림만. id 는 반드시 따옴표 ("9.30" 이 숫자 9.3 으로 바뀌는 것 방지)
  - {id: "9.42", role: problem, panels: [a, b, c, d]}   # role: problem | answer
depends_on: []            # 전제로 하는 문제·예제 id (예: [E9.15])
refs: []                  # 참조하는 식·그림·장 (자유 문자열, 예: "식 9.88")
```

## 본문 절 (순서 고정)
1. `# <종류> <번호> — <짧은 제목>`
2. `## 조건` — 주어진 값, 가정, 회로 설명. 원문을 옮기지 않고 bullet로 재구성. 수치·단위는 빠짐없이
3. `## 구할 것` — 소문항 (a)(b)… 모두
4. `## 상속·참조` — (있을 때만) depends_on 문제의 조건, 참조 식(LaTeX), 공통 가정을 **이 파일 안에 풀어서** 적음
   - 문제를 풀 때 필요한 식·조건만 적는다. 답 줄에서 출처로만 쓰는 식 번호는 frontmatter `refs`에만 둔다
   - 예제 풀이의 결과를 이어받을 때는 그 결과가 쓴 가정($V_T$ 등)도 함께 적는다
   - 크롭하지 않은 참조 그림(본문 그림)도 여기에 적는다. 연결은 `Q_F: C = VCC, B = P, E = X` 형태로 쓴다
5. `## 회로 — Fig <번호>(<패널>)` — 패널마다 하나씩. 넷리스트 + bullet 3개. 마지막 패널 뒤에 이미지 링크
   - 패널이 없는 그림은 `(<패널>)`을 생략하고 frontmatter는 `panels: []`
   - 크롭 이미지에 대한 메모(예: "이미지 오른쪽 (b)는 본문 등가회로")는 bullet이 아니라 이미지 링크 바로 아래 `> 참고: …` 한 줄에 둔다
   - **문제에 회로 그림이 없으면** `## 회로 — 없음 (<이유>)` 한 줄만 둔다 (예: `## 회로 — 없음 (설계 문제, 그림은 풀이에만 있음)`). 이때 넷리스트와 bullet은 적지 않는다
6. `## 답 (검증용)` — 예제만. 최종 답 1–2줄. 풀이에 설계 결과 회로가 있으면 `### 정답 회로 — Fig <번호>`로 넷리스트 + bullet 3개 + 이미지

**원문에 없는 보충:** 작성자가 해석해서 덧붙인 내용(원문에 없는 단위, "두 트랜지스터 동일" 같은 가정, 답의 형태 등)은 그 줄 끝에 `(원문에 없음)`을 붙인다.

## 넷리스트 (```spice 블록)
| 소자 | 형식 | 비고 |
|---|---|---|
| BJT | `Q<이름> C B E npn\|pnp [area=k] [m=k]` | area = 이미터 면적 배수 (10A_E → `area=10`, nA_E → `area={n}`) |
| MOSFET | `M<이름> D G S nmos\|pmos [W/L=a/b] [m=k]` | 바디 단자는 적지 않음. 크기 라벨이 기호면 `W/L={(W/L)_n}`, 배수가 붙으면 `m=3` (3(W/L)_n → `W/L={(W/L)_n} m=3`) |
| R / C / L | `R<이름> n1 n2 [값\|{기호}]` | 값이 기호뿐이면 중괄호 `{R_P}` |
| 전류원 | `I<이름> from to [값]` | **그림의 화살표가 from → to** (SPICE 규약과 같음) |
| 전압원·배터리 | `V<이름> + - [값]` | 첫 노드가 + 단자 |
| 블랙박스 | `X<이름> 노드… box "라벨"` | "Circuit", "Current Mirror", "?" 상자 |
| 연산증폭기 | `X<이름> in+ in- out opamp` | |

- 값은 공백 없는 한 토큰으로 쓴다 (예: `0.2mA`, `1k`, `{R_P}`). `area`, `W/L`, `m`에 숫자가 아닌 기호가 오면 중괄호 `{…}`로 감싼다
- 주석: 줄 앞 `*` 또는 줄 뒤 `; …`
- **노드 이름**
  - 그림에 라벨이 있으면 그대로, 첨자는 붙여 씀: `X`, `P`, `Vout`, `Vin`, `Vb1`, `VREF`, `V1`, `VCC`, `VDD`
  - 라벨 없는 내부 노드: `n1`, `n2`, …
  - 라벨 없는 측정 단자(R_out, I_copy, I_X 화살표가 붙은 개방 단자): `out` (여럿이면 `out1`, `out2`)
  - 접지: `0`
- 그림에 ⇒로 이어진 등가회로가 문제 그림 안에 있으면 별도 패널(`(a-eq)`)로 적는다. 패널 글자가 없는 그림이면 `(eq)`로 쓴다 (`panels: [eq]`).

## 넷리스트 뒤 bullet 3개 (필수)

### `- 단자:` 개방 단자·전원의 의미와 **기호**
각 단자를 `이름 = 의미 (기호)` 형식으로 적는다. 기호는 아래 어휘 중 하나만 쓴다.

| 기호 | 그림 모양 |
|---|---|
| `점 단자` | 채운 점 ● 에서 선이 시작 (바이어스 Vb1, VREF 등) |
| `개방 원` | 빈 원 ○ 단자 (Vin, Vout, R_out 측정 단자 등) |
| `선 끝` | 원·점 없이 선이 끝남 (I_copy, I_X 화살표만 붙은 컬렉터 등) |
| `T 전원 기호` | 짧은 가로 막대(ㅜ) + 라벨 |
| `가로 레일` | 여러 소자가 매달리는 긴 가로선 + 라벨 |

예: `- 단자: Vb1, Vb2 = 이상적 DC 바이어스 (점 단자) / out = 출력 (개방 원) / VCC = 2.5 V 전원 (T 전원 기호)`

### `- 표시:` 그림 위의 글자·화살표 (순서 고정)
`노드 라벨 … / 소자 라벨 … / 부호 … / 화살표 … / 수치·면적 라벨 …` 다섯 칸을 이 순서로 적는다. 칸에 해당하는 것이 없으면 `없음`.
- 노드 라벨: 그림에 인쇄된 노드·단자 이름 전부 (Vb1, X, P, VCC …)
- 소자 라벨: 그림에 인쇄된 소자 이름 전부 (Q1, R_P, Q_F, M1 …). 라벨이 인쇄되지 않은 소자는 `QR1–QR4 (라벨 없음)`처럼 적는다
- 부호: 그림에 인쇄된 +/− 표시와 그 위치 — 연산증폭기 입력(− 위, + 아래), 배터리 양쪽, 전압 극성(+ V_BE −) 등
- 화살표: 각 화살표마다 `이름: 대상, 방향, 모양`
  - 이름이 그림에 **인쇄돼 있으면 따옴표**로 적는다 (`"I_copy1"`). 인쇄돼 있지 않으면 따옴표 없이 적고 `(라벨 없음)`을 붙인다
  - 모양은 `도선 위` (도선 자체에 화살촉) 또는 `도선 옆 별도 화살표 (┌ 꺾임 / L자 / 직선)` 중 하나
  - **소자 기호의 일부인 화살표는 적지 않는다** (전류원 원 안의 화살표, BJT 이미터 화살표, MOSFET 소스 화살표). 전류원 방향은 넷리스트 `I from to`가 이미 정한다
- 수치·면적 라벨: "0.2 mA", "4A_E", "10A_E" 등과 그 위치

### `- 배치:` 그림 모양
- 위→아래 적층 순서, 좌우 위치, 레일·접지 위치, 선이 꺾이는 모양
- 소자가 좌우 반전되어 그려졌으면 (예: 베이스가 오른쪽) 적는다
- **접속점:** 세 갈래 이상 선이 만나는 곳은 원본 표기대로 `(점)` 또는 `(점 없음)`을 적는다. 두 선이 이어지기만 하는 꺾임·끝점, 선이 T 전원 기호·접지에 닿는 곳, 가로 레일에서 아래로 갈라지는 곳은 적지 않는다 (점 없음이 기본)
- **교차:** 마지막에 `교차: 없음` 또는 점 없이 지나가는 교차 목록을 적는다
- **선 경로:** 공통선(베이스 공통선, 컬렉터 공통선 등)은 어느 높이로 지나가는지 적는다 (예: "베이스 공통선은 각 트랜지스터의 베이스 높이로 가로지름")

## 풀이 그림
- 풀이 안의 그림(설계 결과)은 `role: answer`, `## 답 (검증용)`에만 둔다.
- 다른 문제가 그 그림을 문제 그림으로 쓰면, 그 문제에서는 `role: problem`이다 (예: E9.16의 Fig 9.30).

## 수식
- `$…$` / `$$…$$` LaTeX. 단위는 SI (μA, kΩ, V⁻¹ → `\text{V}^{-1}`).
- 조건·구할 것·상속·참조·답 문장의 기호는 LaTeX로 쓴다. 제목과 `단자`·`표시`·`배치` bullet은 넷리스트 이름·그림 라벨을 plain text로 쓴다 (예: R_P, I_copy1).
