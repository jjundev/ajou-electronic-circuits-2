# 장말문제 10.45 — 식 10.147에서 I_D1 − I_D2 = I_SS가 되는 입력 차, 평형 과구동 전압의 √2배임을 확인

## 원문
From Eq. (10.147), determine the value of $V_{in1} - V_{in2}$ such that $I_{D1} - I_{D2} = I_{SS}$. Verify that is result is equal to $\sqrt{2}$ times the equilibrium overdrive voltage.

## 조건
- MOS 차동쌍의 대신호 식 (10.147)
- $I_{D1} - I_{D2} = I_{SS}$
- (원문의 "that is result"는 "that this result"의 오식으로 보임)

## 구할 것
- 식 (10.147)로부터 $I_{D1} - I_{D2} = I_{SS}$가 되는 $V_{in1} - V_{in2}$
- 그 결과가 평형 과구동 전압의 $\sqrt{2}$배임을 확인
  - 원문 표기 "Verify that is result is equal to …" (인쇄 그대로)
  - "this result"(이 결과)의 오식으로 보임 (원문에 없음)

## 상속·참조
- 식 (10.147) (교재 532쪽):
  $$I_{D1} - I_{D2} = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{in1} - V_{in2})\sqrt{\frac{4I_{SS}}{\mu_n C_{ox}\dfrac{W}{L}} - (V_{in1} - V_{in2})^2} \qquad (10.147)$$
- 평형 과구동 전압, 식 (10.111) (교재 526쪽, 각 소자가 $I_{SS}/2$를 흘림):
  $$(V_{GS} - V_{TH})_{equil.} = \sqrt{\frac{I_{SS}}{\mu_n C_{ox}\dfrac{W}{L}}} \qquad (10.111)$$
- 본문 (교재 532–533쪽)은 한 트랜지스터가 꺼지는 경계로 $|V_{in1} - V_{in2}|_{max} = \sqrt{2I_{SS}/(\mu_n C_{ox} W/L)}$ (10.150), $|V_{in1} - V_{in2}|_{max} = \sqrt{2}(V_{GS} - V_{TH})_{equil}$ (10.151)을 적음
- 유도 가정 (교재 530쪽): 채널 길이 변조 무시($\lambda = 0$), 제곱 법칙 $I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$, 두 트랜지스터 동일. KVL $V_{in1} - V_{GS1} = V_{in2} - V_{GS2}$ (10.133), KCL $I_{D1} + I_{D2} = I_{SS}$ (10.134)
- 식 (10.131)–(10.147)의 회로: 본문 Fig 10.31 (교재 530쪽, PDF 18, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-31.png, "대신호 분석을 위한 MOS 차동쌍"). 연결: `R_D: VDD – Vout1`, `R_D: VDD – Vout2`, `M1: D = Vout1, G = Vin1, S = 공통 소스 노드`, `M2: D = Vout2, G = Vin2, S = 공통 소스 노드`, `I_SS: 공통 소스 노드 → 접지` (공통 소스 노드 라벨 없음)
