# 장말문제 10.38 — 전류 밀도에 따른 MOS 차동쌍의 평형 과구동 전압

## 원문
For a MOSFET, the "current density" can be defined as the drain current divided by the device width for a given channel length. Explain how the equilibrium overdrive voltage of a MOS differential pair varies as a function of the current density.

## 조건
- MOSFET의 "전류 밀도" = 주어진 채널 길이에서 드레인 전류를 소자 폭으로 나눈 값

## 구할 것
- MOS 차동쌍의 평형 과구동 전압이 전류 밀도의 함수로 어떻게 변하는지 설명

## 상속·참조
- 본문 식 (10.111) (교재 526쪽, $\lambda = 0$, 제곱 법칙, 각 소자가 $I_{SS}/2$를 흘림):
  $$(V_{GS} - V_{TH})_{equil.} = \sqrt{\frac{I_{SS}}{\mu_n C_{ox}\dfrac{W}{L}}} \qquad (10.111)$$

## 회로 — 없음 (개념 문제, 문제 그림 없음)

## 풀이
### 과구동을 전류 밀도로
- 각 소자가 $I_D = I_{SS}/2$를 흘릴 때 제곱 법칙에서 $(V_{GS} - V_{TH})_{equil.} = \sqrt{\dfrac{2 I_D}{\mu_n C_{ox} W/L}} = \sqrt{\dfrac{2L}{\mu_n C_{ox}} \cdot \dfrac{I_D}{W}}$
- $L$이 정해져 있으면 $I_D$와 $W$는 따로가 아니라 전류 밀도 $I_D/W$로만 들어간다
### 변화
- 평형 과구동은 전류 밀도의 제곱근에 비례한다. 전류 밀도를 두 배로 하면 과구동은 $\sqrt{2} = 1.41$배
- 전류와 폭을 같은 비율로 바꾸면 전류 밀도가 그대로라 과구동도 변하지 않는다
### 답
- $(V_{GS} - V_{TH})_{equil.} = \sqrt{\dfrac{2L}{\mu_n C_{ox}}\dfrac{I_D}{W}}$로 전류 밀도의 제곱근에 비례해 커진다. 전류 밀도가 같으면 $I_D$, $W$ 값과 무관하게 과구동이 같다
