# 장말문제 11.33 — 채널 길이를 2배로 늘린 MOSFET의 폭 조정과 f_T 변화

## 원문
In order to lower channel-length modulation in a MOSFET, we double the device length.

(a) How should the device width be adjusted to maintain the same overdrive voltage and the same drain current?

(b) How do these changes affect the $f_T$ of the transistor?

## 조건
- MOSFET의 채널 길이 변조를 줄이기 위해 소자 길이를 2배로 늘림

## 구할 것
- (a) 같은 과구동 전압과 같은 드레인 전류를 유지하려면 소자 폭을 어떻게 조정해야 하는가?
- (b) 이 변화들이 트랜지스터의 $f_T$에 어떤 영향을 주는가?

## 회로 — 없음 (개념 문제, 그림 없음)

## 풀이
### (a) 제곱 법칙으로 $W$ 정하기
- $I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$에서 $I_D$와 $V_{GS} - V_{TH}$가 같으려면 $W/L$이 같아야 한다
- $L \to 2L$이므로 $W \to 2W$
### (b) $f_T$ 변화
- $g_m = 2I_D/(V_{GS} - V_{TH})$는 그대로이고, $C_{GS} \approx \frac{2}{3}WLC_{ox}$는 $W$와 $L$이 모두 2배라 4배가 된다
- 식 (11.52) $2\pi f_T \approx g_m/C_{GS}$에서 $f_T$는 $1/4$로 준다. 식 (11.183) $2\pi f_T = \dfrac{3}{2}\dfrac{\mu_n}{L^2}(V_{GS} - V_{TH})$로 봐도 $1/L^2$이라 같은 결과다
### 답
- (a) 폭도 2배로 늘린다 ($W/L$ 유지).
- (b) $g_m$은 그대로이고 $C_{GS}$가 4배가 되어 $f_T$가 원래의 $1/4$로 떨어진다.
