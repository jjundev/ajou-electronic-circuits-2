# 장말문제 11.57 — 100 Ω 부하를 이득 0.8로 구동하는 NMOS 소스 폴로어의 최소 입력 커패시턴스

## 원문
An NMOS source follower must drive a load resistance of $100\ \Omega$ with a voltage gain of 0.8. If $I_D = 1\ \text{mA}$, $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $C_{ox} = 12\ \text{fF}/\mu\text{m}^2$, and $L = 0.18\ \mu\text{m}$, what is the minimum input capacitance that can be achieved? Assume $\lambda = 0$, $C_{GD} \approx 0$, $C_{SB} \approx 0$, and $C_{GS} = (2/3) W L C_{ox}$.

## 조건
- NMOS 소스 폴로어가 부하 저항 $100\ \Omega$을 전압 이득 $0.8$로 구동해야 함
- $I_D = 1\ \text{mA}$, $\mu_n C_{ox} = 100\ \mu\text{A/V}^2$, $C_{ox} = 12\ \text{fF}/\mu\text{m}^2$, $L = 0.18\ \mu\text{m}$
- $\lambda = 0$, $C_{GD} \approx 0$, $C_{SB} \approx 0$, $C_{GS} = (2/3) W L C_{ox}$

## 구할 것
- 달성할 수 있는 최소 입력 커패시턴스

## 회로 — 없음 (그림 없는 문제)

## 풀이
### 이득 조건에서 $g_m$
- 소스 폴로어 이득 ($g_m$: NMOS의 트랜스컨덕턴스, $\lambda = 0$, 몸체 효과는 주어지지 않아 무시): $A_v = \dfrac{g_m R_L}{1 + g_m R_L} = 0.8$이므로 $g_m R_L = 4$
- $g_m = 4/100\ \Omega = 40.0\ \text{mS}$
### 필요한 폭
- $g_m = \sqrt{2\mu_n C_{ox}(W/L)I_D}$에서 $W/L = \dfrac{g_m^2}{2\mu_n C_{ox} I_D} = \dfrac{(40\ \text{mS})^2}{2(100\ \mu\text{A/V}^2)(1\ \text{mA})} = 8000$
- $W = 8000 \times 0.18\ \mu\text{m} = 1440\ \mu\text{m}$, $C_{GS} = \tfrac{2}{3}WLC_{ox} = \tfrac{2}{3}(1440)(0.18)(12)\ \text{fF} = 2.07\ \text{pF}$
### 입력 커패시턴스
- $C_{GS}$는 게이트–소스 사이이고 소스가 입력을 따라가므로 밀러로 $(1 - A_v)C_{GS}$. $C_{GD} \approx 0$
- $C_{in} = (1 - 0.8)(2.07\ \text{pF}) = 415\ \text{fF}$
- 이득 0.8을 내는 가장 작은 $g_m$이 $W$를, 곧 $C_{GS}$를 가장 작게 하므로 이 값이 최솟값이다
### 답
- $C_{in,min} = 415\ \text{fF}$
