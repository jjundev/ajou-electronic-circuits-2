# Q1. 서술형: 전압 바이어스 한계, 차동쌍 CM 제거, Miller 효과 (배점: 20점)

## 문제

다음 세 질문에 대해 동작 원리와 수식을 포함하여 상세히 서술하시오. (총 20점)

(a) [7점] 단순 저항 분배를 이용한 전압 바이어스 회로의 근본적인 문제점(공정 파라미터 및 온도 변화에 따른 동작점 변동)을 MOSFET 또는 BJT 전류 방정식을 기반으로 설명하고, 전류 거울(Current Mirror) 회로가 이를 어떻게 극복하여 공정 및 온도 독립성을 달성하는지 그 물리적 원리를 서술하시오.

(b) [7점] 이상적인 차동 증폭기(Differential Pair)에서 공통 모드(Common-Mode, CM) 신호가 출력에서 완전히 상쇄(Rejection)되는 원리를 회로 대칭성과 테일 전류원의 관점에서 설명하고, 실제 회로에서 공통 모드 제거 성능을 저하시키는 2가지 핵심 요인(테일 전류원의 유한 저항 $R_{SS}$, 부하 저항 불일치 $\Delta R_D$)이 출력에 미치는 영향을 수식과 함께 서술하시오.

(c) [6점] 밀러 정리(Miller's Theorem)의 기본 개념(피드백 임피던스의 양단 접지 등가 변환)을 수식으로 제시하고, 반전 전압 이득 $A_v = -|A_v|$를 갖는 증폭기에서 입·출력 노드 사이에 걸린 기생 피드백 커패시터 $C_F$가 왜 입력단 등가 커패시턴스를 급증시키며, 이로 인해 증폭기의 고주파 대역폭(Bandwidth)이 대폭 축소되는 메커니즘을 서술하시오.

## 풀이

### (a) 전압 바이어스 회로의 한계와 전류 거울(Current Mirror)의 극복 원리 [7점]

#### 1. 저항 분배 전압 바이어스의 문제점
- 저항 분배기를 이용한 전압 바이어스는 전원 전압 $V_{DD}$ (또는 $V_{CC}$)를 저항 $R_1, R_2$로 분배하여 트랜지스터의 게이트-소스 전압 $V_{GS}$ 또는 베이스-이미터 전압 $V_{BE}$를 고정한다:
$$V_{GS} = \frac{R_2}{R_1 + R_2} V_{DD}$$
- 그러나 포화 영역의 MOSFET 드레인 전류식과 BJT 컬렉터 전류식은 다음과 같다:
$$I_D = \frac{1}{2} \mu_n C_{ox} \frac{W}{L} (V_{GS} - V_{TH})^2$$
$$I_C = I_S \exp\left(\frac{V_{BE}}{V_T}\right)$$
- **공정 편차(Process Variation)**: 웨이퍼 제조 공정에 따라 문턱 전압 $V_{TH}$, 산화막 두께($C_{ox}$), 이동도 $\mu_n$, 포화 전류 $I_S$가 칩마다 달라지므로, 동일한 $V_{GS}$ 또는 $V_{BE}$를 인가하더라도 바이어스 전류 $I_D$나 $I_C$가 수십~수백 % 변동한다.
- **온도 변화(Temperature Drift)**: 온도가 상승하면 격자 산란으로 이동도 $\mu_n$가 감소하고, 문턱 전압 $V_{TH}$는 약 $-2\,\text{mV/}^\circ\text{C}$로 감소한다. BJT의 경우 $V_T = kT/q$가 상승하고 $I_S$가 지수함수적으로 증가하여 컬렉터 전류가 급격히 상승한다.
- **공급 전압 변동(Supply Sensitivity)**: $V_{DD}$에 노이즈나 리플이 존재할 경우 $V_{GS}$에 직결되어 $I_D$가 심하게 흔들리므로 증폭기의 소신호 파라미터($g_m, r_o$) 및 동작 영역(포화 영역 유지)이 불안정해진다.

#### 2. 전류 거울의 물리적 극복 원리
- 전류 거울 회로는 정확하고 안정적인 기준 전류원 $I_{REF}$를 다이오드 연결 트랜지스터 $M_{REF}$에 흘려 소자 스스로 필요한 게이트 전압을 생성하도록 한다:
$$V_{GS} = V_{TH} + \sqrt{\frac{2 I_{REF}}{\mu_n C_{ox} (W/L)_{REF}}}$$
- 이 전압을 복사 트랜지스터 $M_1$의 게이트에 인가하면, 두 트랜지스터가 하나의 실리콘 칩에 인접 집적되어 있으므로 동일한 공정 파라미터($\mu_n C_{ox}, V_{TH}$)와 동일한 작동 온도를 공유한다.
- 따라서 복사되는 드레인 전류는 다음과 같이 두 트랜지스터의 기하학적 종횡비(Aspect Ratio)의 비율만으로 결정된다:
$$I_{out} = \frac{(W/L)_1}{(W/L)_{REF}} I_{REF}$$
- BJT의 경우에도 이미터 접합 면적비로 결정된다:
$$I_{out} = \frac{A_{E1}}{A_{E,REF}} I_{REF}$$
- 결론적으로 복사비는 기하학적 면적비($W/L$ 또는 $A_E$)로 주어지므로, 온도 변화나 공정 변동이 두 소자에 동일하게 발생하여 상쇄(Tracking)되며, 전원 전압의 변화에도 극히 강인한 일정한 직류 바이어스를 공급할 수 있다.

### (b) 이상적 차동쌍 공통 모드 신호 제거 원리와 성능 저하 2대 요인 [7점]

#### 1. 이상적 차동쌍의 공통 모드 신호 제거(CM Rejection) 원리
- 회로가 완벽한 대칭($M_1 = M_2, R_{D1} = R_{D2} = R_D$)이고 이상적인 정전류원($R_{SS} \to \infty$)이 테일에 연결된 차동쌍을 고려한다.
- 양쪽 게이트에 동일한 공통 모드 전압 $V_{in,CM}$이 인가되면, 테일 노드 전압 $V_P$는 입력을 그대로 추종하여 $V_P = V_{in,CM} - V_{GS}$로 상승한다.
- 그러나 이상적인 전류원 $I_{SS}$의 전류는 전압 변화에 무관하게 일정하므로, 대칭성에 의해 두 브랜치에 흐르는 바이어스 전류는 항상 절반으로 고정된다:
$$I_{D1} = I_{D2} = \frac{I_{SS}}{2}$$
- 게이트-소스 전압 $V_{GS1} = V_{GS2} = V_{TH} + \sqrt{I_{SS} / (\mu_n C_{ox} W/L)}$ 역시 일정하게 유지되며 소신호 전류 변동이 전혀 발생하지 않는다($\Delta I_{D1} = \Delta I_{D2} = 0$).
- 따라서 각 출력 노드의 전압은 다음으로 불변이다:
$$V_{out1} = V_{out2} = V_{DD} - \frac{I_{SS}}{2} R_D$$
- 차동 출력 전압은 $\Delta V_{out} = V_{out1} - V_{out2} = 0$이며, 각 단일단 출력의 공통 모드 전압 이득 역시 $A_{CM} = 0$이 되어 공통 모드 노이즈가 완벽하게 제거된다.

#### 2. 실제 차동쌍에서 공통 모드 제거를 저하시키는 2대 요인

1. **테일 전류원의 유한한 출력 저항 ($R_{SS} < \infty$)**:
   - 실제 테일 전류원은 트랜지스터로 구현되므로 유한한 출력 임피던스 $R_{SS}$를 갖는다.
   - 공통 모드 입력 신호 $v_{in,CM}$이 들어오면 테일 노드 $V_P$의 전압 변동에 의해 테일 저항으로 흐르는 전류가 변동한다:
   $$\Delta I_{SS} = \frac{v_{in,CM}}{R_{SS} + \frac{1}{2 g_m}} \neq 0$$
   - 각 브랜치 전류가 $\Delta I_D = \Delta I_{SS} / 2$만큼 변동하여 단일단 출력에 다음과 같은 유한한 공통 모드 전압 이득이 발생한다:
   $$A_{CM,single} = -\frac{g_m R_D}{1 + 2 g_m R_{SS}} \approx -\frac{R_D}{2 R_{SS}}$$
   - 비록 완전 대칭 회로에서는 차동 출력 $v_{out1} - v_{out2} = 0$이 유지되지만, 단일단 출력 기준으로는 공통 모드 노이즈가 증폭되어 나타나며 후단 회로의 직류 동작점을 교란한다.

2. **부하 저항 및 소자의 비대칭 불일치 ($\Delta R_D \neq 0, \Delta g_m \neq 0$)**:
   - 공정 오차로 인해 두 부하 저항에 불일치($R_{D1} = R_D, R_{D2} = R_D + \Delta R_D$)가 발생하면, 공통 모드 입력 $v_{in,CM}$에 의해 유발된 소신호 전류가 서로 다른 저항을 지나며 차동 전압으로 변환된다.
   - 이로 인해 원치 않는 **공통 모드-차동 모드 변환 이득($A_{CM-DM}$)**이 발생한다:
   $$A_{CM-DM} = \frac{v_{out1} - v_{out2}}{v_{in,CM}} = -\frac{g_m \Delta R_D}{1 + 2 g_m R_{SS}} \approx -\frac{\Delta R_D}{2 R_{SS}}$$
   - 결과적으로 공통 모드 신호(전원선 노이즈, 기생 커플링 잡음 등)가 차동 출력에 직접적인 오차 신호로 나타나게 되며, 공통 모드 제거비가 유한하게 저하된다:
   $$\text{CMRR} = \left|\frac{A_d}{A_{CM-DM}}\right| \approx \frac{g_m R_D}{\Delta R_D / (2 R_{SS})} = \left(\frac{R_D}{\Delta R_D}\right) (2 g_m R_{SS})$$

### (c) 밀러 정리(Miller's Theorem) 및 피드백 $C_F$에 의한 대역폭 감소 메커니즘 [6점]

#### 1. 밀러 정리의 기본 개념
- 전압 이득이 $A_v = \frac{v_2}{v_1}$인 두 노드 1과 2 사이에 피드백 임피던스 $Z$가 연결되어 있을 때, KCL에 의해 노드 1에서 임피던스로 흘러 들어가는 전류는 다음과 같다:
$$i = \frac{v_1 - v_2}{Z} = \frac{v_1 (1 - A_v)}{Z}$$
- 이를 노드 1에서 접지로 연결된 등가 임피던스 $Z_1$으로 치환하면:
$$Z_1 = \frac{v_1}{i} = \frac{Z}{1 - A_v}$$
- 마찬가지로 노드 2에서 접지로의 등가 임피던스는 다음과 같다:
$$Z_2 = \frac{Z}{1 - \frac{1}{A_v}}$$
- 만약 피드백 소자가 커패시터 $C_F$ ($Z = \frac{1}{s C_F}$)인 경우, 노드 1에 보이는 등가 밀러 커패시턴스는 다음과 같다:
$$C_{in,M} = C_F (1 - A_v)$$

#### 2. 반전 증폭기에서의 밀러 효과와 대역폭 축소 원리
- 공통 소스(CS) 또는 공통 이미터(CE)와 같은 반전 증폭기에서는 전압 이득이 음수이다 ($A_v = -|A_v|$).
- 따라서 입력단 등가 커패시턴스는 원래 커패시턴스의 $(1 + |A_v|)$배로 극적으로 증폭된다:
$$C_{in,M} = C_F (1 + |A_v|)$$
- 신호원의 내부 저항 $R_{sig}$와 트랜지스터의 입력 기생 커패시턴스 $C_{gs}$가 함께 존재하는 실제 증폭기 입력단에서, 전체 등가 입력 커패시턴스는 다음과 같다:
$$C_{in,total} = C_{gs} + C_F (1 + |A_v|)$$
- 이 입력 노드에 형성되는 극점(Pole) 주파수는 다음과 같다:
$$\omega_{p,in} = \frac{1}{R_{sig} C_{in,total}} = \frac{1}{R_{sig} [C_{gs} + C_F (1 + |A_v|)]}$$
- $|A_v| \gg 1$인 고이득 증폭기에서는 $(1 + |A_v|) C_F$ 항이 매우 커져 입력 극점 주파수 $\omega_{p,in}$이 출력 극점보다 훨씬 낮은 저주파 영역으로 당겨진다.
- 이 입력 극점이 회로 전체의 **지배적 극점(Dominant Pole)**이 되며, 증폭기의 3dB 대역폭(Bandwidth, $\text{BW} \approx \omega_{p,in}$)을 극단적으로 축소시키는 주요 원인이 된다.
