# 감점 체크리스트

출처: `from_the_past/감점요인.png` (선배 감점 이력) 와 과제 문제 요구사항. 작성 후 본문에서 항목마다 근거 위치를 찾아 ✔ / ✘ 표로 보고한다.

| # | 항목 | 본문에서 찾을 것 |
|---|---|---|
| 1 | $G_m$ 유도 (−5 이력) | 1-(a) 안에 $G_m$ 정확식 유도와 $G_m/g_{m1}$ 값 |
| 2 | 주파수 응답 크기·위상 (−5 이력) | 2-(d) 에 크기와 위상이 함께 있는 Bode 그림 자리 |
| 3 | 모든 MOSFET saturation | 1-(b) 손계산 부등식, 2-(b) SPICE 표 — 모든 MOSFET 이 빠짐없이 |
| 4 | 전력 조건 | 1-(a) 전력 계산식(숫자 대입)과 2-(a) SPICE 전원 전류로 계산한 전력 |
| 5 | 이득 범위 | 설계 목표 이득이 사양 범위 안이고 SPICE 이득도 범위 안 |
| 6 | 오차와 10 % 판정 | 2-(d) 오차 % 와 10 % 비교 문장, 번호 매긴 원인 |
| 7 | 회로도 라벨 | 2-(a) 회로도 자리 alt 에 ".op 라벨, 학번·이름 표기" |
| 8 | 표 순서 일치 | 손계산 W 표, 요약 표, SPICE saturation 표의 MOSFET 순서가 같음 |
| 9 | 바이어스 전압 | 모든 바이어스 전압(입력 CM, Vb 들, 전류원) 값이 표로 있음 |
| 10 | 1 MHz 파형 | 2-(c) 입력·출력 파형 그림 자리와 입력 신호 식 |
