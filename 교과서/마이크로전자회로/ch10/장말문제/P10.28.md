# 장말문제 10.28 — 출력 저항(Early 효과)을 넣어도 식 10.91(v_P = 0)이 성립함을 증명

## 원문
Using a small-signal model and including the output resistance of the transistors, prove that Eq. (10.91) holds in the presence of the Early effect.

## 조건
- 소신호 모델을 쓰고 트랜지스터의 출력 저항 $r_O$를 포함 (Early 효과가 있는 경우)

## 구할 것
- 식 (10.91) $v_P = 0$이 Early 효과가 있을 때도 성립함을 증명

## 상속·참조
- 본문 Fig 10.17(a) (교재 519쪽, PDF 12, 크롭 안 함): 바이폴라 쌍의 소신호 모델. 연결: `vin1 전압원: + = r_π1 위 끝, − = 접지`, `r_π1: 위 끝(+ v_π1) – P(− v_π1)`, `g_m1 v_π1 전류원: R_C 아래 끝(컬렉터) → P`, `R_C: 컬렉터 – 교류 접지`, 오른쪽도 대칭 (`vin2`, `r_π2`, `g_m2 v_π2`, `R_C`). 이상적 테일 전류원은 소신호에서 개방이라 그림에 없음. $V_A = \infty$
- 식 (10.86)–(10.91) (교재 519쪽): 완벽한 대칭, 이상적 테일 전류원, $V_A = \infty$, 차동 입력 $v_{in1} = -v_{in2}$일 때
  - KVL: $v_{in1} - v_{\pi 1} = v_P = v_{in2} - v_{\pi 2}$ (10.86)
  - $P$ 노드 KCL: $\dfrac{v_{\pi 1}}{r_{\pi 1}} + g_{m1} v_{\pi 1} + \dfrac{v_{\pi 2}}{r_{\pi 2}} + g_{m2} v_{\pi 2} = 0$ (10.87)
  - $r_{\pi 1} = r_{\pi 2}$, $g_{m1} = g_{m2}$ → $v_{\pi 1} = -v_{\pi 2}$ (10.88) → $2 v_{in1} = 2 v_{\pi 1}$ (10.89) → $v_P = v_{in1} - v_{\pi 1} = 0$ (10.90), (10.91): $P$는 가상 접지
- 본문 520쪽: "문제 10.28에서, 이 특성이 얼리 효과가 존재할 때에도 역시 유효하다는 것을 증명해 본다"

## 회로 — 없음 (식 증명 문제, 그림 없음)

## 풀이
### 소신호 식
- Fig 10.17(a)에 $r_{O1}$, $r_{O2}$(컬렉터–$P$)를 더하고 대칭($g_m$, $r_\pi$, $r_O$ 같음), 차동 입력 $v_{in1} = -v_{in2}$, 이상적 테일 전류원으로 둔다
- 컬렉터 KCL: $\dfrac{v_{out1}}{R_C} + g_m (v_{in1} - v_P) + \dfrac{v_{out1} - v_P}{r_O} = 0$, 오른쪽도 같은 꼴
- $P$ KCL: $\sum_{k=1,2} \left[\left(\dfrac{1}{r_\pi} + g_m\right)(v_{ink} - v_P) + \dfrac{v_{outk} - v_P}{r_O}\right] = 0$
### 두 식을 더함
- $S = v_{out1} + v_{out2}$라 하면 $v_{in1} + v_{in2} = 0$이므로 컬렉터 식의 합: $S\left(\dfrac{1}{R_C} + \dfrac{1}{r_O}\right) = 2v_P\left(g_m + \dfrac{1}{r_O}\right)$
- $P$ 식: $-2v_P\left(\dfrac{1}{r_\pi} + g_m + \dfrac{1}{r_O}\right) + \dfrac{S}{r_O} = 0$
### $v_P = 0$
- $S$를 없애면 $v_P \left[\dfrac{1}{r_\pi} + \left(g_m + \dfrac{1}{r_O}\right)\dfrac{r_O}{R_C + r_O}\right] = 0$
- 괄호 안이 양수이므로 $v_P = 0$ (그리고 $S = 0$, $v_{out1} = -g_m (R_C \parallel r_O) v_{in1}$)
### 답
- $r_O$를 넣어도 $v_P [1/r_\pi + (g_m + 1/r_O)\, r_O/(R_C + r_O)] = 0$이 되어 $v_P = 0$, 곧 식 (10.91)이 Early 효과가 있어도 성립한다
