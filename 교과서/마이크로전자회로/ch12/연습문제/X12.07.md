# 연습문제 12.7 — 귀환 CG 단의 입력·출력 임피던스가 같아지는 조건 (예제 12.7 변형)

## 원문
어떤 응용에서는 증폭기의 입력과 출력 임피던스가 모두 $50\ \Omega$과 같아야 한다. 어떤 관계가 위 회로의 입력과 출력 임피던스가 같도록 보장하는가?

## 조건
- 예제 12.7과 같은 회로·가정: Fig 12.11 (귀환이 걸린 CG 단), $\lambda = 0$, $R_1 + R_2 \gg R_D$ (원문에 없음)
- 목표: 입력 임피던스와 출력 임피던스가 모두 $50\ \Omega$
- 예제 12.7의 결과: 폐루프 입력 저항 $R_{in} = \dfrac{1}{g_m}\left(1 + \dfrac{R_2}{R_1 + R_2}g_mR_D\right)$, 폐루프 출력 저항 $R_{out} = \dfrac{R_D}{1 + \dfrac{R_2}{R_1 + R_2}g_mR_D}$ (원문에 없음)

## 구할 것
- 위 회로의 입력 임피던스와 출력 임피던스가 같도록 보장하는 관계

## 상속·참조
- 예제 12.7 (E12.07): 개루프 $R_{in,open} = 1/g_m$, $R_{out,open} = R_D$ (식 12.34, 12.35). 폐루프 입력 $\dfrac{v_X}{i_X} = \dfrac{1}{g_m}\left(1 + \dfrac{R_2}{R_1 + R_2}g_mR_D\right)$ (식 12.38), 폐루프 출력 $\dfrac{v_X}{i_X} = \dfrac{R_D}{1 + \dfrac{R_2}{R_1 + R_2}g_mR_D}$ (식 12.43). 두 식 모두 $\lambda = 0$, $R_1 + R_2 \gg R_D$ 가정

## 회로 — Fig 12.11
```spice
RD  VDD   Vout  {R_D}
M1  Vout  n1    Vin  nmos
R1  Vout  n1    {R_1}
R2  n1    0     {R_2}
```
- 단자: VDD = 전원, 값 미지정 (T 전원 기호) / Vin = 입력, M1 소스 (개방 원) / Vout = 출력 (개방 원)
- 표시: 노드 라벨 V_DD (T 기호 오른쪽), V_in (입력 원 왼쪽), V_out (출력 원 오른쪽) / 소자 라벨 R_D (저항 왼쪽), M1 (트랜지스터 왼쪽, 소스 화살표 바로 왼쪽 위), R1, R2 (각 저항 오른쪽) / 부호 없음 / 화살표 없음 / 수치·면적 라벨 없음
- 배치: 왼쪽 세로줄 위→아래 V_DD T 기호, R_D, 드레인 접속점, M1 / M1은 좌우 반전된 NMOS (게이트가 오른쪽, 드레인 위·소스 아래 인출선이 왼쪽, 소스 화살표는 채널에서 왼쪽 바깥을 향함) / 소스에서 세로선이 아래로 내려가 왼쪽으로 꺾여 V_in 원에서 끝남 / 드레인 접속점에서 가로선이 오른쪽으로 가 R1 위 접속점을 지나 V_out 원까지 / 오른쪽 세로줄 위→아래 R1 위 접속점, R1, 게이트 접속점(n1), R2, 접지 / M1 게이트에서 가로선이 오른쪽으로 곧장 n1 접속점 / 접속점 (세 갈래 이상, 3곳): 드레인 = 위 R_D + 아래 M1 드레인 + 오른쪽 가로선 (점), R1 위 = 왼쪽 가로선 + 아래 R1 + 오른쪽 V_out 선 (점), n1 = 위 R1 + 아래 R2 + 왼쪽 게이트 선 (점) / 교차: 없음
