# 예제 10.4 — 입력 CM 레벨을 V_CC에 얼마나 가깝게 둘 수 있나

## 원문
바이폴라 차동쌍이 $1\ \text{k}\Omega$의 부하 저항과 $1\ \text{mA}$의 테일 전류를 가진다. $V_{CM}$을 $V_{CC}$에 얼마나 가까운 값으로 선택할 수 있는가?

## 조건
- 바이폴라 차동쌍, 부하 저항 $R_C = 1\ \text{k}\Omega$, 테일 전류 $I_{EE} = 1\ \text{mA}$
- 두 입력은 같은 CM 레벨 $V_{CM}$ (원문에 없음)
- 참고 회로 (본문 Fig 10.9): 두 부하 $R_C$가 $V_{CC}$에서 각 컬렉터 X, Y로 연결되고, 두 베이스를 묶어 $V_{CM}$ 전압원에 연결, 공통 이미터 노드에서 접지로 테일 전류원 $I_{EE}$ (원문에 없음)
- 기준: 두 트랜지스터가 포화되지 않아야 함, 즉 컬렉터 전압이 베이스 전압 아래로 떨어지지 않음 (원문에 없음)

## 구할 것
- $V_{CM}$을 $V_{CC}$에 얼마나 가까운 값으로 정할 수 있는지

## 상속·참조
- 본문 Fig 10.9 (교재 507쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-09.png): 바이폴라 차동쌍의 CM 입력 응답. $R_{C1} = R_{C2} = R_C$ (그림 안 라벨). 연결: `RC1: VCC – X`, `RC2: VCC – Y`, `Q1: C = X, B = 공통 입력, E = 공통 이미터 노드`, `Q2: C = Y, B = 공통 입력, E = 공통 이미터 노드`, `I_EE: 공통 이미터 노드 → 접지` (공통 이미터 노드는 이 그림에 라벨 없음), `V_CM 전압원: + = 공통 입력(두 베이스를 묶은 선), − = 접지`
- 식 (10.18)–(10.20): 대칭이므로 $V_{BE1} = V_{BE2}$, $I_{C1} = I_{C2} = I_{EE}/2$ (컬렉터 전류 = 이미터 전류로 가정), $V_X = V_Y = V_{CC} - R_C \dfrac{I_{EE}}{2}$
- 식 (10.21): 포화를 피하려면 컬렉터 전압이 베이스 전압 아래로 떨어지면 안 됨 → $V_{CC} - R_C \dfrac{I_{EE}}{2} \ge V_{CM}$

## 회로 — 없음 (문제 그림 없음, 본문 그림 10.9와 식 10.21에서 출발)

## 답 (검증용)
- $V_{CC} - V_{CM} \ge R_C \dfrac{I_{EE}}{2} = 0.5\ \text{V}$ (식 10.22–10.23) → $V_{CM}$은 $V_{CC}$보다 적어도 $0.5\ \text{V}$ 낮아야 함

## 풀이
### 입력이 CM일 때의 컬렉터 전압
- 두 베이스가 같은 $V_{CM}$이면 대칭으로 $I_{C1} = I_{C2} = I_{EE}/2$ (컬렉터 전류 = 이미터 전류로 둠)
- $V_X = V_Y = V_{CC} - R_C \dfrac{I_{EE}}{2}$
### 포화를 피하는 조건
- 컬렉터 전압이 베이스 전압 아래로 내려가면 안 된다: $V_{CC} - R_C \dfrac{I_{EE}}{2} \ge V_{CM}$
- $V_{CC} - V_{CM} \ge R_C \dfrac{I_{EE}}{2} = 1\ \text{k}\Omega \times 0.5\ \text{mA} = 0.500\ \text{V}$
### 답
- $V_{CM}$은 $V_{CC}$보다 적어도 $0.500\ \text{V}$ 낮아야 한다 ($V_{CM} \le V_{CC} - 0.500\ \text{V}$).
