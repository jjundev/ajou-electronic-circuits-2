# 연습문제 10.8 — 테일 전류의 90%를 조종하는 차동 입력 (예제 10.8 변형)

## 원문
테일 전류의 90%를 조종하기 위해 필요한 차동 입력은 얼마인가?

## 조건
- 예제 10.8의 바이폴라 차동쌍(본문 Fig 10.14)에서 트랜지스터 하나가 테일 전류의 90%를 조종함 (예제는 98%)
- 참고 회로 (본문 Fig 10.14): 두 부하 $R_C$가 $V_{CC}$에서 각 컬렉터로, $Q_1$ 베이스 $V_{in1}$, $Q_2$ 베이스 $V_{in2}$, 공통 이미터 노드 P에서 접지로 테일 전류원 $I_{EE}$ (원문에 없음)
- 두 트랜지스터는 동일하고 $\alpha = 1$, $V_A = \infty$, $V_{BE} = V_T \ln(I_C/I_S)$ (원문에 없음)

## 구할 것
- 테일 전류의 90%를 조종하는 데 필요한 차동 입력 $V_{in1} - V_{in2}$

## 상속·참조
- 예제 10.8 (E10.08): $Q_2$가 98%를 흘릴 때 $I_{C1} = 0.02 I_{EE} \approx I_{EE}\exp\dfrac{V_{in1} - V_{in2}}{V_T}$로 놓아 $V_{in1} - V_{in2} \approx -3.91 V_T$를 얻음 (가정: $\alpha = 1$, $V_A = \infty$. $I_{S1} = I_{S2}$는 식 (10.59)→(10.60)에서 말없이 쓰임, 원문에 없음)
- 본문 Fig 10.14 (교재 514쪽, 이 파일의 그림 목록에는 넣지 않음, 크롭은 fig10-14.png): $V_{CC}$ 레일, 두 $R_C$, $Q_1$(베이스 $V_{in1}$), $Q_2$(베이스 $V_{in2}$), 공통 이미터 노드 $P$와 테일 전류원 $I_{EE}$. 연결: `RC(왼쪽): VCC – Vout1`, `RC(오른쪽): VCC – Vout2`, `Q1: C = Vout1, B = Vin1, E = P`, `Q2: C = Vout2, B = Vin2, E = P`, `I_EE: P → 접지`
- 식 (10.63), (10.65): $I_{C2} = \dfrac{I_{EE}}{1 + \exp\dfrac{V_{in1} - V_{in2}}{V_T}}$, $I_{C1} = \dfrac{I_{EE}\exp\dfrac{V_{in1} - V_{in2}}{V_T}}{1 + \exp\dfrac{V_{in1} - V_{in2}}{V_T}}$

## 회로 — 없음 (그림 없는 글 문제)

## 풀이
### 전류 비의 식
- $V_{in1}$, $V_{in2}$를 베이스에 받는 두 트랜지스터 $Q_1$, $Q_2$와 테일 전류 $I_{EE}$로 된 쌍에서 $Q_1$ 컬렉터 전류를 $I_{C1}$이라 한다
- $Q_2$가 90%를 흘린다고 보면 $I_{C1} = 0.1 I_{EE}$
- $I_{C1} = \dfrac{I_{EE}\exp\dfrac{V_{in1} - V_{in2}}{V_T}}{1 + \exp\dfrac{V_{in1} - V_{in2}}{V_T}}$ ($\alpha = 1$, $V_A = \infty$, $Q_1$, $Q_2$가 같다고 봄)
### 차동 입력 풀기
- $\dfrac{e^x}{1 + e^x} = 0.1$ ($x = (V_{in1} - V_{in2})/V_T$) → $e^x = 1/9$
- $V_{in1} - V_{in2} = -V_T \ln 9 = -2.20\ V_T = -57.1\ \text{mV}$ ($V_T = 26\ \text{mV}$)
- 90%에서는 분모의 $e^x$를 무시할 수 없다. 예제처럼 $I_{C1} \approx I_{EE} e^x$로 두면 $-2.30\ V_T$로 약 5% 크게 나온다
### 답
- $|V_{in1} - V_{in2}| = V_T \ln 9 \approx 2.20\ V_T \approx 57.1\ \text{mV}$ ($Q_2$ 쪽이 90%이면 $V_{in1} - V_{in2} = -2.20\ V_T$)
