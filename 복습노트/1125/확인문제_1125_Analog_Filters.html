Q1. 전류 입력·전압 출력 증폭기의 귀환 이름

입력이 전류이고 출력이 전압인 트랜스임피던스 증폭기에 음의 귀환을 걸어요.

귀환망이 감지하는 양과 반송하는 양, 그리고 수업 방식의 귀환 이름이 모두 맞는 것은 무엇인가요?

  1. 출력 전류를 감지하고 입력에 전압을 반송하는 전류-전압(C-V) 귀환이에요.
  2. 출력 전압을 감지하고 입력에 전류를 반송하는 전압-전류(V-C) 귀환이에요.
  3. 출력 전압을 감지하고 입력에 전압을 반송하는 전압-전압(V-V) 귀환이에요.
  4. 감지·반송할 양은 설계자가 자유롭게 고르므로 이 정보만으로는 정할 수 없어요.
힌트 보기

귀환망은 출력에서 무엇을 잴 수 있고, 입력에서 무엇을 빼 줄 수 있는지 원래 증폭기의 출력·입력 종류부터 보세요.

풀이 보기
  1. "이름을 입력 → 출력 순서로 읽어 '전류 입력·전압 출력'을 C-V로 붙였어요." — 출력 전류 감지·입력 전압 반송은 전압 입력·전류 출력 증폭기의 귀환이에요. 이 증폭기는 그 반대예요.
  2. 출력이 전압이라 귀환망은 출력 전압을 감지하고, 입력이 전류라 입력 노드에서 전류를 빼 줘요. 앞 글자가 감지량, 뒤 글자가 반송량이라 V-C예요.
  3. "감지량만 출력 종류로 정하고 반송량은 늘 전압이라고 생각했어요." — 입력이 전류인 증폭기에서는 입력에서 빼 줄 수 있는 것도 전류예요. 반송량은 입력 종류가 정해요.
  4. "감지·반송 양이 증폭기 종류와 무관한 선택이라고 보았어요." — 수업에서는 감지하고 싶어서 고르는 것이 아니라 원래 증폭기의 출력·입력 종류가 감지·반송할 양을 정한다고 했어요.

정답: B

Q2. 전류를 반송하는 귀환망의 연결 자리

예제 IV처럼 입력 신호가 전류 $I_{in}$으로 공통 게이트 $M_1$의 소스 노드에 들어오는 전류 증폭기예요. 귀환망은 출력 전류를 감지해 입력에서 전류 $I_F$를 빼 주려고 해요.

반송 쪽 귀환망을 어디에 어떻게 연결해야 $M_1$ 소스로 들어가는 전류가 $I_{in}-I_F$가 되나요?

  1. $M_1$의 게이트에 연결해 게이트 전압을 바꿔요.
  2. 입력 전류가 지나는 도선을 끊고 그 사이에 직렬로 끼워요.
  3. $M_1$의 드레인 노드 $X$에 연결해요.
  4. 입력 전류가 들어오는 $M_1$ 소스 노드에 같은 노드로(병렬로) 붙여요.
힌트 보기

$M_1$ 소스 노드에 KCL을 쓸 때 $I_F$가 그 식에 들어가려면 어느 노드에 붙어야 하는지 보세요.

풀이 보기
  1. "전압 반송의 연결(서로 다른 노드)을 전류 반송에도 그대로 썼어요." — 게이트에 거는 것은 예제 III처럼 입력과 서로 다른 노드에 전압을 반송하는 방식이에요. 게이트로는 전류가 흐르지 않아 입력 전류에서 빼 줄 수 없어요.
  2. "전류 감지(직렬)와 전류 반송(병렬)의 연결을 바꿔 기억했어요." — 직렬로 끼우면 같은 전류가 귀환망을 지나므로 전류를 재는 연결이 되고, 전류를 빼 주지는 못해요.
  3. "전류만 빼면 어느 노드든 같다고 보고 입력과 다른 노드에 연결했어요." — 드레인 $X$에 붙이면 $I_F$가 $M_1$ 소스 노드의 KCL에 들어가지 않아 입력 전류에서 빠지지 않아요.
  4. 같은 노드에 갈래를 붙여야 그 노드의 KCL이 $I_{S1}=I_{in}-I_F$가 돼요. 전류 반송은 입력과 병렬 연결이고, 이상적인 포트 임피던스는 $\infty$예요.

Q3. 감지 저항을 지운 개루프 이득

예제 III 회로에서 감지 저항 $R_M$을 0으로 보고 지운 개루프예요. $M_1$은 공통 게이트(게이트 접지, 소스 입력), $M_2$는 소스 팔로워이고 그 소스 전류 $I_{out}$이 부하 $R_L$을 지나 접지로 가요. 채널 길이 변조와 몸체 효과는 무시해요.

$g_{m1}=3\ \mathrm{mS}$, $R_D=2\ \mathrm{k\Omega}$, $g_{m2}=2\ \mathrm{mS}$, $R_L=1\ \mathrm{k\Omega}$일 때 $I_{out}/V_{in}$을 mS 단위 숫자만 입력하세요.

힌트 보기

첫 단 이득 $V_X/V_{in}$과 둘째 단 $I_{out}/V_X$를 따로 구해 곱해요. 둘째 단 분모는 저항 두 개의 합이에요.

풀이 보기
  1. $V_X/V_{in}=g_{m1}R_D=3\ \mathrm{mS}\times2\ \mathrm{k\Omega}=6$
  2. $1/g_{m2}=0.5\ \mathrm{k\Omega}$
  3. $I_{out}/V_X=1/(1/g_{m2}+R_L)=1/(1.5\ \mathrm{k\Omega})$
  4. $I_{out}/V_{in}=6/(1.5\ \mathrm{k\Omega})=4\ \mathrm{mS}$

정답: 4

Q4. C-V 출력 쪽 복제를 접지하면

예제 III(C-V 귀환)에서 로딩을 넣으려고 $R_M$ 복제를 입력 쪽($M_1$ 게이트–접지)과 출력 쪽($R_L$ 아래)에 하나씩 달았어요. 그런데 한 학생이 출력 쪽 복제의 끊은 끝(원래 반송 포트)을 V-V 귀환 습관대로 접지했어요.

수업의 종단 규칙과 이 학생의 결과를 바르게 설명한 것은 무엇인가요?

  1. 규칙대로라면 개방해야 해요. 접지하면 $R_M$이 단락돼 로딩이 사라지고 이상적인 결과 $\frac{g_{m1}R_D}{1/g_{m2}+R_L}$가 잘못 다시 나와요.
  2. 접지가 맞아요. 반송 포트는 늘 접지로 종단하므로 결과는 $\frac{g_{m1}R_D}{1/g_{m2}+R_L+R_M}$이에요.
  3. 규칙대로라면 개방해야 하지만, 접지해도 $R_M$이 $R_L$과 병렬로 보일 뿐 이득은 거의 같아요.
  4. 규칙대로라면 단락(접지)이 맞고, 입력 쪽 복제를 개방해야 로딩이 생겨요.
힌트 보기

출력 쪽 복제의 끊은 끝이 원래 어떤 입력에 붙어 있었는지, 그 입력의 이상적인 임피던스가 0인지 $\infty$인지 보세요.

풀이 보기
  1. 끊은 끝은 원래 전압을 빼는 $M_1$ 게이트(전압 입력, 이상 임피던스 $\infty$)에 붙어 있었으므로 개방해요. 개방해야 출력 쪽 복제가 $R_L$과 직렬로 남아 분모에 $R_M$이 더해져요.
  2. "V-V 귀환에서 반송 쪽 복제를 접지하던 습관을 형태와 무관한 규칙으로 일반화했어요." — 종단은 반송 포트라서 정하는 것이 아니라 원래 붙어 있던 쪽의 이상 임피던스로 정해요. 전압 입력은 $\infty$라 개방이에요.
  3. "끊은 끝을 접지했을 때 복제의 두 끝이 같은 노드가 되는 것을 놓쳤어요." — 출력 쪽 복제의 아래 끝은 이미 접지라서 위 끝까지 접지하면 $R_M$ 양 끝이 모두 접지돼 단락돼요. 병렬로 남는 것이 아니라 아예 사라져요.
  4. "로딩이 입력 쪽 복제에서 생긴다고 보았어요." — 입력 쪽 복제는 전류가 흐르지 않는 게이트에 달려 첫 단 이득을 바꾸지 않아요. 로딩을 만드는 것은 출력 쪽 복제이고 둘 다 개방해요.

정답: A

Q6. C-V 폐루프 이득

예제 III(C-V 귀환)의 로딩을 넣은 개루프 이득이 $A_0=(I_{out}/V_{in})|_{open}=3\ \mathrm{mS}$이고, 감지 저항은 $R_M=2\ \mathrm{k\Omega}$이에요.

폐루프 이득 $(I_{out}/V_{in})|_{closed}$를 mS 단위 숫자로, 분수 그대로 계산해 소수 셋째 자리에서 반올림해 둘째 자리까지 입력하세요.

힌트 보기

먼저 귀환 계수 $K$가 무엇인지 $V_F=I_{out}R_M$에서 읽고, 단위가 지워지는 루프 이득을 구해요.

풀이 보기
  1. $K=V_F/I_{out}=R_M=2\ \mathrm{k\Omega}$
  2. $KA_0=2\ \mathrm{k\Omega}\times3\ \mathrm{mS}=6$
  3. $(I_{out}/V_{in})|_{closed}=\frac{3}{1+6}\ \mathrm{mS}=\frac{3}{7}\ \mathrm{mS}\approx0.43\ \mathrm{mS}$
  4. $1/R_M=0.5\ \mathrm{mS}$의 약 86%예요.

정답: 0.43

Q7. C-V 귀환이 바꾸는 입·출력 임피던스

예제 III(C-V 귀환)의 루프 이득이 $KA_0=4$예요.

개루프 값과 비교해 폐루프 입력 임피던스와 출력 임피던스는 각각 어떻게 되나요?

  1. 입력은 5배로 커지고, 출력은 1/5배로 작아져요.
  2. 입력은 1/5배로 작아지고, 출력은 5배로 커져요.
  3. 둘 다 5배로 커져요.
  4. 둘 다 4배로 커져요.
힌트 보기

입력에서는 귀환 전압을 직렬로 빼고, 출력에서는 전류를 감지해 조절한다는 점에서 각각 판단해요.

풀이 보기
  1. "V-V 귀환처럼 출력 임피던스가 늘 작아진다고 외웠어요." — 입력은 맞아요. 출력은 전류를 감지해 조절하므로 전류원이 좋아지는 쪽, 곧 임피던스가 커지는 쪽이에요.
  2. "입력 쪽을 전류 반송(병렬)과 혼동했어요." — 입력에 전압을 직렬로 반송하므로 입력 임피던스는 커져요. 1/5배는 같은 노드에서 전류를 빼는 병렬 반송(C-C)의 경우예요.
  3. 전압을 직렬로 반송하는 입력은 더 좋은 전압 감지기가 되도록 $1+KA_0=5$배 커지고, 전류를 감지하는 출력은 더 좋은 전류원이 되도록 5배 커져요.
  4. "배수를 $1+KA_0$가 아니라 $KA_0$로 썼어요." — 방향은 맞지만 곱하는 배수는 루프 이득 자체가 아니라 $1+KA_0=5$예요.

정답: C

Q8. C-C 루프 끊기에서 보이는 복제

예제 IV(C-C 귀환)에서 귀환망은 $R_F=30\ \mathrm{k\Omega}$, $R_M=3\ \mathrm{k\Omega}$이에요. 로딩을 넣으려고 귀환망 복제를 입력 쪽($M_1$ 소스 노드)과 출력 쪽($R_L$ 아래 노드)에 하나씩 달고 수업 규칙대로 끊은 포트를 종단해요.

입력 쪽과 출력 쪽에서 각 복제가 노드–접지 사이에 보이는 저항으로 맞는 것은 무엇인가요?

  1. 입력 쪽 약 $2.73\ \mathrm{k\Omega}$, 출력 쪽 $33\ \mathrm{k\Omega}$
  2. 입력 쪽 $33\ \mathrm{k\Omega}$, 출력 쪽 약 $2.73\ \mathrm{k\Omega}$
  3. 양쪽 모두 $33\ \mathrm{k\Omega}$
  4. 양쪽 모두 약 $2.73\ \mathrm{k\Omega}$
힌트 보기

입력 쪽 복제의 끊은 포트는 원래 전류 출력에, 출력 쪽 복제의 끊은 포트는 원래 전류 입력에 붙어 있었어요. 각각의 이상 임피던스를 떠올려요.

풀이 보기
  1. "입력·출력 쪽 종단을 바꿔 적용했어요." — 두 값을 서로 바꿨어요. 개방하는 쪽이 직렬 합, 접지하는 쪽이 병렬이에요.
  2. 입력 쪽은 원래 전류 출력(이상 임피던스 $\infty$)이라 개방해 $R_F+R_M=33\ \mathrm{k\Omega}$이에요. 출력 쪽은 원래 전류 입력(이상 임피던스 0)이라 접지해 $R_F\parallel R_M=90/33\approx2.73\ \mathrm{k\Omega}$이에요.
  3. "C-V의 종단 규칙을 C-C에도 그대로 썼어요." — 예제 III(C-V)의 '둘 다 개방'을 그대로 옮겼어요. C-C의 출력 쪽 복제는 원래 전류 입력에 붙어 있어 접지해요.
  4. "전류를 다루는 포트는 모두 접지한다고 보았어요." — 입력 쪽 복제의 끊은 포트는 원래 전류 출력에 붙어 있었어요. 전류 출력의 이상 임피던스는 $\infty$라 개방해야 해요.

정답: B

Q9. 입력 노드의 첫째 전류 분배

$g_{m1}=4\ \mathrm{mS}$, $R_F+R_M=4.75\ \mathrm{k\Omega}$일 때 $I_{in}$의 몇 %가 $M_1$ 소스로 들어가나요? % 기호 없이 숫자만 입력하세요.

Q10. C-C 개루프 출력 임피던스

예제 IV의 로딩을 넣은 개루프에서 출력 임피던스는 부하 $R_L$을 떼고 그 자리의 두 단자 사이에서 봐요. 입력 전류원은 개방하고, $M_2$의 출력저항은 $r_{O2}=40\ \mathrm{k\Omega}$이에요. 귀환망은 $R_F=12\ \mathrm{k\Omega}$, $R_M=4\ \mathrm{k\Omega}$이에요.

$R_{out,open}$은 얼마인가요?

  1. $56\ \mathrm{k\Omega}$
  2. 약 $2.79\ \mathrm{k\Omega}$
  3. $40\ \mathrm{k\Omega}$
  4. $43\ \mathrm{k\Omega}$
힌트 보기

출력 쪽 복제는 어떻게 종단돼 있는지, 그리고 시험전류가 $r_{O2}$와 그 복제를 차례로 지나는지 따라가요.

풀이 보기
  1. "출력 쪽 복제를 개방 종단으로 보았어요." — $R_F+R_M=16\ \mathrm{k\Omega}$은 개방한 입력 쪽 복제에서 보이는 값이에요. 출력 쪽 복제는 접지해서 $R_F\parallel R_M$이에요.
  2. "부하 자리 두 단자 사이에서 본 저항을 병렬로 읽었어요." — $r_{O2}$와 출력 쪽 복제는 시험전류가 차례로 지나는 직렬이에요. 병렬로 묶으면 $R_M\to0$에서 출력 임피던스가 0이 돼 이상적 결과 $r_{O2}$와 맞지 않아요.
  3. "이상적 귀환망($R_M\to0$)의 결과를 그대로 썼어요." — $R_F\parallel R_M=3\ \mathrm{k\Omega}$은 $r_{O2}$의 7.5%라 무시할 만큼 작다고 하기 어려워요. 로딩을 넣으라고 했으므로 더해야 해요.
  4. 출력 쪽 복제는 접지 종단이라 $R_F\parallel R_M=48/16=3\ \mathrm{k\Omega}$이고, 시험전류가 $r_{O2}$와 이것을 차례로 지나 $40+3=43\ \mathrm{k\Omega}$이에요.

Q11. 음수인 K의 해석

예제 IV(C-C 귀환)에서 $I_{out}$은 감지 포트로 들어가는 방향, $I_F$는 입력 노드에서 빠지는 방향을 양으로 정했더니 $K=-R_M/(R_F+R_M)=-0.2$가 나왔어요. 둘째 단이 PMOS 공통 소스라서 로딩을 넣은 개루프 전류 이득은 $A_{I,open}=-15$예요.

이 귀환에 대한 판단으로 맞는 것은 무엇인가요?

  1. $K\lt0$이므로 양의 귀환이에요.
  2. 루프 이득 $KA_{I,open}=3\gt0$이라 음의 귀환이고, $A_{I,closed}=-15/4=-3.75$예요.
  3. 루프 이득은 $-3$이라 분모가 $1-3=-2$가 되고, $A_{I,closed}=7.5$예요.
  4. $K$의 부호가 잘못 나왔으니 $|K|=0.2$로 바꿔 루프 이득을 $-3$으로 계산해요.
힌트 보기

귀환의 종류는 $K$ 하나의 부호가 아니라 무엇의 부호로 판단하는지 떠올려요.

풀이 보기
  1. "$K$의 부호만 보고 귀환 종류를 정했어요." — $K$ 혼자의 부호로는 판단하지 않아요. $A_{I,open}$도 음수라 곱이 양수예요.
  2. $(-0.2)(-15)=3$으로 양수이므로 분모 $1+KA_{I,open}=4$가 1보다 커지는 음의 귀환이에요. 폐루프 이득은 $-15/4=-3.75$예요.
  3. "두 음수 중 하나의 부호를 빠뜨려 루프 이득을 음수로 계산했어요." — $K$와 $A_{I,open}$이 모두 음수라 곱은 $+3$이에요. 한쪽 부호만 반영했어요.
  4. "방향 정의에서 나온 음의 $K$를 오류로 보았어요." — 부호는 $I_{out}$·$I_F$의 방향 정의에서 나온 정상 결과예요. 임의로 절댓값을 쓰면 $A_{I,open}$의 음수와 짝이 맞지 않아요.

정답: B

Q12. 2.4 GHz 신호의 처리 순서

블루투스 2.4 GHz 신호에서 내 채널만 고르려고 해요. 수업에서 아날로그 신호를 디지털로 바꿀 수 있는 대역은 수십 MHz, 높아야 약 100 MHz라고 했어요.

이 신호를 처리하는 방법으로 맞는 것은 무엇인가요?

  1. 2.4 GHz는 약 100 MHz보다 약 24배 높으므로, 아날로그 회로로 먼저 처리해 주파수를 낮춘 뒤 디지털로 바꿔 디지털 필터로 처리해요.
  2. 바로 디지털로 바꿔 디지털 필터로 채널을 골라요.
  3. 증폭기로 신호를 키우면 디지털로 바꿀 수 있는 대역 안으로 들어와요.
  4. 2.4 GHz는 약 100 MHz의 2.4배라서 조금 빠른 디지털 변환기면 충분해요.
힌트 보기

2.4 GHz를 MHz로 바꿔 디지털로 바꿀 수 있는 대역의 위쪽 끝과 비교해 보세요.

풀이 보기
  1. $2400/100=24$라 바로 디지털로 바꿀 수 없어요. 고주파 신호는 아날로그로 먼저 걸러 주파수를 낮춘 다음 디지털 처리로 넘겨요.
  2. "디지털 필터가 모든 주파수에서 쓸 수 있다고 보았어요." — 디지털로 바꿀 수 있는 대역은 높아야 약 100 MHz라 GHz 신호를 그대로 디지털로 바꿀 수 없어요.
  3. "증폭과 주파수 처리를 같은 일로 보았어요." — 증폭기는 신호의 크기를 키울 뿐 주파수를 낮추지 않아요.
  4. "단위 환산에서 1000배를 놓쳤어요." — 2.4 GHz는 2400 MHz라 100 MHz의 24배예요. GHz와 MHz의 1000배 환산을 빠뜨렸어요.

정답: A

Q14. 주파수 특성과 소자로 필터 이름 붙이기

L과 C만으로 만든 회로가 특정한 주파수 대역 하나만 통과시키고 그보다 낮거나 높은 주파수는 차단해요.

주파수 특성과 구현 소자로 이 필터를 바르게 분류한 것은 무엇인가요?

  1. 노치(대역 저지) 필터이고 능동 필터예요.
  2. 대역 통과 필터이고 능동 필터예요.
  3. 저역 통과 필터이고 수동 필터예요.
  4. 대역 통과 필터이고 수동 필터예요.
힌트 보기

통과 대역이 주파수 축의 어디에 있는지, 그리고 이득을 낼 수 있는 소자가 들어 있는지 따로 보세요.

풀이 보기
  1. "대역 통과와 대역 저지를 바꿔 읽고, 소자 구분도 놓쳤어요." — 노치는 특정 대역만 막고 나머지를 통과시켜요. 또 L, C는 이득이 없는 수동 소자예요.
  2. "리액턴스 소자인 L, C를 능동 소자로 보았어요." — 주파수 특성은 맞지만 트랜지스터나 OP-amp가 없으므로 능동 필터가 아니에요.
  3. "특정 대역 하나를 통과시키는 것과 낮은 주파수 쪽을 통과시키는 것을 구별하지 않았어요." — 저역 통과는 낮은 주파수 쪽을 통과시켜요. 이 회로는 낮은 주파수도 차단해요.
  4. 특정 대역 하나만 통과시키므로 대역 통과(BPF)이고, L, C만 써서 이득과 전류 소모가 없는 수동 필터예요.

정답: D
