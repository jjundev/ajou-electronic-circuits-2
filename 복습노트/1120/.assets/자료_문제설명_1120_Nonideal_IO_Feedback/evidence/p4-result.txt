Exact finite-beta hybrid-pi: B=1/R1+1/R2+1/rπ, C=1/RC+1/R1, h=1/R1, Δ=BC+h(gm−h). Av=[B gm−(gm−h)/rπ]/Δ, vb/ve=(C/rπ+h gm)/Δ, Rin=1/[(gm+1/rπ)(1−vb/ve)], Rout=B/Δ. rπ=β/gm. Includes passive emitter-base-collector feedthrough.
Av = RC*(R1*gm*rp + R2*gm*rp + R2)/(R1*R2 + R1*rp + R2*RC*gm*rp + R2*RC + R2*rp + RC*rp)
Rin = (R1*R2 + R1*rp + R2*RC*gm*rp + R2*RC + R2*rp + RC*rp)/((gm*rp + 1)*(R1 + R2 + RC))
Rout = RC*(R1*R2 + R1*rp + R2*rp)/(R1*R2 + R1*rp + R2*RC*gm*rp + R2*RC + R2*rp + RC*rp)
rpi = beta/gm
